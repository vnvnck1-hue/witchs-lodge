마녀산장 프로토타입 (Windows)

실행: WitchsLodge.exe 를 더블클릭하세요.
  - WitchsLodge.exe 와 WitchsLodge.pck 는 반드시 같은 폴더에 두어야 합니다.

조작
  좌클릭(지면)        이동 (가까운 적은 자동 공격)
  좌클릭(산장)        준비 시간에 산장 관리 패널
  용에게 공물 버튼    전투 중 120G로 용 소환
  카드 드래그         손패 카드를 나무·지면·적·산장에 끌어 사용 (우클릭/Esc 취소)
  좌클릭(털 난 양)    마녀가 다가가 양털 수확
  고용 버튼/손님 클릭 문가의 손님을 30G에 도끼 용병으로 고용
  Esc                 일시 정지
  F1                  디버그 메뉴
  F2 / 화면 스타일    부드러운 명암, 따뜻한 산장, 차가운 숲, 툰 셰이딩,
                      강렬한 툰 셰이딩, 두꺼운 툰 외곽선, 기존 화면

카드 코어 적용판 (2026-10-14): 손패·용병 계약·벌목·양털·몬스터 하수인. 시작 골드 40G.
화면 프리셋 기본값은 부드러운 명암.
이미 실행 중인 게임은 종료 후 다시 실행하면 새 7종 프리셋이 나타납니다.

엔진: Godot 4.7.2-stable (Forward+). 라이선스는 GODOT-LICENSE.txt, GODOT-THIRD-PARTY.txt 참고.
