# 카드 포맷 승인·원화 작업 이력

작성·확정일: 2026-10-13

**현재 확정 제작 기준(2026-10-16):** 사용자 승인된 역할별 개별 카드 6종과 [카드 디자인 가이드](card-design-guide.md)를 따른다. 인물·스킬·자원·장비/유물·시설·사건의 고유 포맷, 제목 2줄·설명 4줄 여백과 장식 제한을 새 카드에도 적용한다. 아래의 단일 공통 포맷은 2026-10-13 당시의 승인·제작 이력이며 최신 역할별 기준을 덮어쓰지 않는다.
확정 근거: 사용자가 마지막 라운드 2번을 선택하며 “이걸로 기본 포멧을 결정하자”라고 지시.

## 2026-10-13 당시 확정 포맷

**비대칭 S자 곡선 포맷**을 마녀산장의 기본 카드 디자인으로 사용한다.

## 당시 제작 기준 — 현재는 역할별 디자인 가이드 우선

1. 보라색 카드 바탕, 굵은 검은 먹선, 크림색 이름·설명 패널을 유지한다.
2. 곡선은 굵게 부풀었다가 가늘게 빠지는 흐름을 사용한다. 직선·각진 구획 위주로 바꾸지 않는다.
3. 좌상단에서 내려오는 S자 곡선과 우하단에서 올라오는 곡선을 비대칭으로 배치한다. 양끝이 같은 뿔·리본 장식을 반복하는 구성으로 되돌리지 않는다.
4. 카드 이름과 분류는 위, 큰 원화는 가운데, 효과 설명은 아래에 둔다. 이름과 설명이 곡선에 가려지지 않도록 한다.
5. 캐릭터 카드는 얼굴과 상체를 크게 보여준다. 도끼 용병 시안의 굵은 선, 큰 색면, 인쇄 질감의 원화 스타일을 이어간다.
6. 용병·자원·몬스터가 공유하는 기본 포맷으로 사용한다. 새 카드마다 장식을 추가하기보다 원화·이름·분류·효과 문구를 교체한다.
7. 실사용 에셋의 외곽 모서리는 살짝 라운드 처리하고, 카드 밖은 실제 투명 알파로 내보낸다. 검정 직사각형 바탕을 이미지에 남기지 않는다. (2026-10-13 후속 요청)

이번 확정은 카드의 시각 포맷에 해당한다. 도끼 용병의 시안 문구는 최종 게임 규칙의 확정을 의미하지 않는다. 게임 UI 구현이나 별도 빈 프레임 에셋 제작은 이 작업에 포함하지 않았다.

## 실사용 카드 에셋 — 2026-10-13 후속 제작

사용자 요청에 따라 [도끼 용병·양털·목재·숲의 괴물과 공용 뒷면](../art/cards/README.md)을 게임용 에셋으로 준비했다. 기존 세 카드의 수정본에는 살짝 둥근 모서리와 투명 외곽을 적용하고, 누락된 목재 카드와 뒷면에도 같은 제작 기준을 사용했다. 원래 승인본과 시안은 기록으로 유지하며 **새 실사용 경로는 `godot/assets/cards/`**다.

1024×1536 확대용과 256×384 손패용 RGBA PNG, 한글 문구·획득·대상·텍스처 경로의 JSON, Godot 로딩 도우미를 제공한다. [최종 프롬프트](prompts/cards/production-rounded-v02-prompts.md), [파일 목록](../art/cards/manifest.json), [실제 PNG 갤러리](../godot/screenshots/cards/asset-gallery.png)를 확인한다. 가격·능력치·수량은 이미지에 고정하지 않았다. 카드 획득·드래그·소환 코어는 후속 구현이다.

## 작업 과정

| 단계 | 작업 | 검토 결과 |
| --- | --- | --- |
| 첫 원화 2장 | 최초 카드 레퍼런스를 바탕으로 도끼 용병 제작, 전신에서 얼굴·상체 중심으로 수정 | 상체 구도로 후속 탐색 |
| 장식형 3장 | 타로·고용 계약서·겨울 숲 프레임 | 기본 카드에 비해 특별한 인상이 강함 |
| 단순 기본형 3장 | 테두리형·종이형·그림 중심형 | 너무 평이함 |
| 작은 포인트 3장 | 모서리·붓선·이름 띠 형태 조정 | 최초 레퍼런스의 곡선 감각을 더 반영하도록 요청 |
| 레퍼런스 재접근 3장 | 검은 곡선과 휘어진 이름·설명란 | 문양까지 레퍼런스와 너무 비슷함 |
| 다른 형태 탐색 3장 | 각진 먹선·둥근 창·오프셋 이름 탭 | 곡선 자체를 줄이는 접근으로 의도와 불일치 |
| 곡선 유지·문양 변형 3장 | 유기적인 테두리·비대칭 S자·곡선 연결 | **2번 비대칭 S자 포맷 확정** |

핵심 정정: 사용자는 레퍼런스의 **곡선 뉘앙스**를 유지하면서 **문양과 구성**을 다르게 변형하기를 원했다.

## 후속 카드 시안 — 2026-10-13

사용자 요청으로 확정 기본 포맷을 적용한 나머지 카드 두 장을 제작했다. 아래는 후속 시안이며 별도 사용자 확정 전이다.

- [양털 자원 카드](../art/concepts/cards/wool-resource-v01.png): 바구니에 담긴 양털을 큰 원화로 표현. 수확·산장 판매 문구.
- [숲의 괴물 소환 카드](../art/concepts/cards/forest-monster-summon-v01.png): 기존 숲 조우 원화의 나뭇가지 뿔·이끼 덮인 나무 괴물을 상체 초상으로 표현. 처치 획득·하수인 소환 문구.
- [추가 카드 최종 프롬프트](prompts/cards/additional-cards-v01-prompts.md): 내장 image_gen, 확정 포맷 이미지 및 괴물 정체성 참고 원화 사용.

두 카드 모두 보라색 비대칭 S자 먹선 프레임, 크림색 이름·분류·효과 패널, 굵은 선과 인쇄 질감을 유지했다. 새 가격·능력치·하수인 수명은 추가하지 않았다.

## 실제 게임 스크린샷 배치 시안 — 2026-10-13

- [최종 합성 시안 v02](../art/concepts/cards/game-screen-hand-v02.png): v24 소스 화면을 배경으로 도끼 용병·양털·숲의 괴물 3장을 하단 중앙에 배치했다. 마녀 전체와 산장·목장이 보이도록 카드 크기를 줄였다.
- [큰 카드 합성 v01](../art/concepts/cards/game-screen-hand-v01.png)은 카드가 올라와 화면을 일부 가리는 사용 상태로 사용자가 인정했다. v02는 작게 내려둔 손패 배치 시안으로 함께 보존한다.
- [합성 및 수정 프롬프트](prompts/cards/game-screen-hand-v01-prompt.md).

내장 image_gen으로 만든 화면 합성 시안이다. 배경 이미지의 세부는 생성 과정에서 달라질 수 있으며, 런타임 카드 UI와 드래그 기능을 구현한 캡처는 아니다.

## 카드 화풍에 맞춘 배경 페인트오버 — 2026-10-13

사용자 요청으로 큰 카드 합성 v01의 카드 배치를 유지하고 배경을 덧그렸다.

사용자는 첫 배경 페인트오버 v01이 원래 화면을 지나치게 바꾸었다고 지적했다. 이후 [약한 보정 v02](../art/concepts/environment/08-card-style-game-paintover-v02.png)를 원래 큰 카드 합성본에서 다시 제작했다. 기존 3D 입체감·보라색 눈·부드러운 조명·지면 질감을 유지하고 목재와 일부 경계에 약한 붓선만 더하는 방향이다. [v02 프롬프트](prompts/cards/game-background-card-style-v02-prompt.md)를 함께 보존한다. v01은 미채택 기록이며, v02도 사용자 검토 전이다.

- [배경 페인트오버 v01](../art/concepts/environment/08-card-style-game-paintover-v01.png): 카드 원화의 굵고 변화하는 먹선, 큰 색면, 인쇄 질감을 산장·눈·나무·바위·목장에 적용한 화풍 시안.
- [최종 프롬프트와 입력 자료](prompts/cards/game-background-card-style-v01-prompt.md): 내장 image_gen 사용.

기존 높은 게임 카메라·산장과 목장 위치·큰 카드 3장 구도를 유지하는 것이 목표다. 이미지 생성 과정에서 배경 세부가 바뀔 수 있다. 런타임 모델·재질·셰이더 변경은 없으며, 사용자 검토 전 새 최종 배경 기준으로 확정하지 않는다.
