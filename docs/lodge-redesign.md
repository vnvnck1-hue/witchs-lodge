# 산장 모델 리디자인

2026-10-13. 원화보다 평이한 산장을 Blender에서 다시 모델링하는 작업이다. **v24 초기 모델 생성, GLB 내보내기, 실제 Blender 3면 렌더와 Godot 소스 화면 확인까지 진행한 후 사용자 요청으로 일시정지했다.** 새 모델은 소스에 저장되어 있고, 배포 실행 파일과 PCK는 v23을 유지한다. 지붕 눈의 연결·처짐과 표면 무늬 밀도 보정, 게임 동작 검증과 v24 배포는 남아 있다. [재개 기록](lodge-redesign-resume.md)에서 이어서 작업한다.

## 기준 시트

![산장 정면·오른쪽·후면](../art/model-sheets/lodge-redesign/02-lodge-front-right-back.png)

[원본 PNG](../art/model-sheets/lodge-redesign/02-lodge-front-right-back.png). 내장 image_gen으로 생성한 디자인 시트다. [07 원화](../art/concepts/environment/07-colored-forest-darkness.png)의 작은 본채를 참고했다. 기존 게임 모델의 렌더나 정확한 건축 도면이 아니다. 사용자 승인 여부를 임의로 표시하지 않는다. 보이지 않던 후면은 같은 구조를 바탕으로 추정했다.

정면·오른쪽·후면 순서이며 바닥·처마·용마루의 높이를 비교하도록 가이드를 넣었다. 첫 시안에서 측면 굴뚝이 높고 목재 장식이 붙어 있던 부분을 보정했다. 생성 이미지의 작은 면별 차이는 아래 공통 구조와 실제 Blender 메시에서 통일한다. 픽셀 치수는 실측 치수가 아니다.

## 살릴 형태

- 넓고 큰 단일 박공지붕. 정상에서 가파르게 내려오다가 처마에서 완만해지는 곡선과 두꺼운 박공 목재로 작은 집의 외곽을 만든다.
- 굵고 약간 휜 기둥, 큰 접합부, 둥근 모서리. 낡아 무너지는 집보다 통통하고 안정적인 인상을 우선한다.
- 정면은 오른쪽으로 살짝 치우친 둥근 아치 문, 왼쪽 작은 창, 박공 중앙 다락창이다. 오른쪽 벽에는 큰 사각 창, 후면에는 작은 창 하나를 둔다.
- 지붕 끝의 굵은 교차 목재와 소수의 돌출 목재, 후방 오른쪽의 사각 석재 굴뚝을 둔다. 높은 탑·발코니·여러 박공·추가 장식은 이 본채 설계에 없다.
- 눈은 큰 불규칙 덩어리와 부드럽게 처지는 가장자리로 만든다. 규칙적인 작은 직사각형 타일의 반복을 줄인다.
- 벌꿀색·짙은 갈색 목재, 회갈색 기단, 라벤더 눈, 앰버 창. 넓은 색면과 절제된 붓질을 사용한다.

## Blender 구현 시작값

아래 값은 생성 시트에서 측정한 숫자가 아니라 기존 게임의 배치·문 접근·목장·증축 위치를 고려한 제작 시작값이다. 고정 게임 카메라와 3면도 렌더를 함께 보고 조정한다.

| 항목 | 시작값·방향 |
| --- | --- |
| 좌표 | Godot Y 위, 정면 +Z, 오른쪽 +X, 기단 바닥 중앙 원점 |
| 기존 통행 기준 | 본채 폭 4.9m, 깊이 5.9m. 기존 `LODGE_RECT`와 목장 위치를 확인한다 |
| 벽의 시각적 덩어리 | 폭 약 4.6m, 깊이 약 5.5m, 기단 위 높이 약 2.0m. 이전 2.55m 벽보다 낮고 통통하게 시작한다 |
| 기단 | 높이 약 0.5m. 불규칙한 큰 돌과 출입구 3단 계단 |
| 처마·용마루 | 처마 약 Y=2.6m, 용마루 약 Y=4.6m. 지붕 외폭 약 6.1~6.4m, 길이 약 6.3m |
| 박공 곡선 | 중앙 급경사 → 바깥쪽 완만한 곡선. 직선 지붕에 장식만 붙이는 방식으로 대신하지 않는다 |
| 구조 목재 | 기둥·박공 테두리 두께 약 0.3~0.45m. 중심선과 단면을 함께 변형한다 |
| 문 | 중심 X 약 +0.5m. 아치 포함 내부 높이 약 1.5m, 폭 약 1.0m. 기존 문앞 도착 지점에 연결한다 |
| 눈 | 넓은 곡면 지붕을 따라 큰 불규칙 패치와 연속된 눈 처짐을 만든다. 얇은 카드나 건물 전체 이미지 투영은 사용하지 않는다 |
| 굴뚝·연기 | 후방 오른쪽 지붕. 시트에서 높이를 통일한 후 실제 굴뚝 입구에 `CHIMNEY_TOP`을 맞춘다 |

본채·지붕 목재·눈·기단·문·창·굴뚝을 편집할 수 있게 Blender 컬렉션/오브젝트로 구분한다. 곡선 중심선과 닫힌 단면으로 실제 입체 목재를 만들고, 눈·목재·돌·발광 유리를 별도 재질로 유지한다. `.blend`와 `starter_lodge.glb`를 제공한다. 기존 문 접근·창 빛·벽등·연기·용 앵커는 새 모델과 함께 확인한다.

## 다음 검증

1. Blender의 실제 메시로 정면·오른쪽·후면 렌더를 만들어 시트의 곡선·비례·접합을 비교한다.
2. 기존 게임의 고정 카메라로 산장 실루엣, 목장 가림, 입구와 증축 연결을 확인한다.
3. 재질은 원화의 큰 색면을 유지하고, 과도한 나뭇결·균열·장식 빈도를 추가하지 않는다.
4. 모델 교체 후 시작·증축·방문자·용 화면과 실제 접근/충돌을 검증한다. 그 전까지 게임 모델 교체 완료로 기록하지 않는다.
