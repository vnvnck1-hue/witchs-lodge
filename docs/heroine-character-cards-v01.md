# 아키타입 인물 카드 시안 v01 — 산장에 눌러앉는 아가씨들

작성 2026-10-21 · 사용자 지시: "미소녀물 기본 아키타입을 우리 게임에 적용해서 시안을 짜 봐. 우선 인물 카드이고, 전부 해당 캐릭터 아키타입 컨셉과 어울리는 카드 효과를 가지도록. 플레이어가 카드 인물에 몰입할 수 있도록."

세계 기준은 [전역 지침](../CLAUDE.md)의 중세 기반 판타지. 인물 카드의 선례는 [술 주정뱅이 에린](tavern-cards-v01.md) 하나뿐이라, 에린이 이미 검증한 틀(상주 손님 · 성격을 닮은 게이지 · 성격을 닮은 효과)을 공통 규칙으로 일반화했다. 설계 제약은 [하스스톤 컨셉 §4](hearthstone-inspired-cards-v01.md#4-설계-규칙--하스스톤-너프-사례에서)와 [덱 방향성](deck-archetypes-v01.md)을 따른다.

> **모든 이름·수치·문구는 초안이다.** 확정한 인물만 `catalog.json`·규칙 문서로 옮긴다. 원화는 [카드 디자인 가이드](card-design-guide.md)의 인물 포맷(큰 초상창·작은 종족 배지)으로, 글자는 비워 두고 게임이 그린다.

## 1. 핵심 원칙 — "효과를 읽으면 성격이 보인다"

몰입은 일러스트·대사보다 **카드가 손 안에서 하는 행동**에서 나온다. 그래서 인물마다 아래 세 곳 중 최소 두 곳에 성격을 심었다.

| 성격이 드러나는 곳 | 예 |
| --- | --- |
| **오는 방식**(만남·게이지) | 츤데레는 부탁하지 않을 때 더 오고, 단데레는 말을 세 번 걸어야 대답한다 |
| **쓰는 순간**(효과·대가) | 도짓코는 실수하고, 아가씨는 값을 모르고, 얀데레는 다른 여자를 쓰면 질투한다 |
| **쓰지 않을 때**(손패·주머니에 있을 때의 상시 행동) | 단데레는 손패에 묵힐수록 얼굴을 보이고, 메스가키는 밤사이 카드를 훔쳐 간다 |

추가 원칙:

1. **인쇄 문구 둘째 줄은 그녀의 목소리로 쓴다.** 첫 줄은 규칙, 둘째 줄은 대사이면서 숨은 규칙의 힌트(예: 브리타 "딱히 다른 건 안 고쳐 줄 거예요." → 실제로는 몰래 더 고침).
2. **실패·손해도 사랑스러워야 한다.** 대가가 있으면 그 대가를 성격의 일부로 연출한다(치코의 실수 → 다음엔 반드시 대성공).
3. **판 단위 이야기가 생기게.** 호감 3단계로 효과·표정·대사가 변해, 한 판 안에서 "처음엔 퉁명스러웠는데" 같은 기억이 남게 한다.

## 2. 인물 카드 공통 규칙 (에린 틀의 일반화)

| 항목 | 규칙 초안 |
| --- | --- |
| 만남 | 인물마다 고유 조건 → 손님 차례에 맨 먼저 찾아와 말을 건다(에린과 동일). 대답과 무관하게 인물 카드 1장 획득 |
| 상주 | 한 번 오면 판이 끝날 때까지 산장에 머문다. 정원·숙박비·퇴실 없음. **한 판 상주 인물 최대 3명** → 4번째가 오면 누구를 남길지 고른다(떠난 인물은 그 판에 다시 오지 않음) |
| 게이지 | 산장 관리 '손님' 탭의 인물 칸에 고유 아이콘 3개(에린의 술잔처럼). 다 차면 카드가 손패로(넘치면 주머니). **게이지를 채우는 행동 자체가 그녀의 취향** |
| 호감 3단계 | **낯섦 → 친함 → 특별.** 카드를 쓸 때마다 +1, 4·10회에서 단계 상승(초안). 단계마다 효과 강화 1회, 원화 표정 3종(`art_variants` 재사용), 대사 세트 교체 |
| 대사 말풍선 | 상황 4종: **손패에 들어올 때 / 쓸 때 / 손패에 오래 묵을 때 / 버리거나 주머니로 갈 때.** 단계별로 다른 줄 |
| 순환 방지 | 인물 카드 효과로 자기 게이지를 채울 수 없다(에린 규칙과 같음). 복제·재발동은 하루 상한 |
| 포맷 | 인물 포맷. 분류 띠는 `인물 · <역할>`. 종족 배지는 원화 하단 |
| 호감 시스템 | 아직 공용 시스템이 없다(에린도 손님별 기록만). 이 시안을 채택하면 `resident_affinity` 공용 데이터를 먼저 만든다 |

## 4. 인물별 시안

각 인물: **컨셉 → 만남·게이지 → 카드 효과 → 호감 단계 → 대사 → 원화.**

### 4.1. 브리타 — 츤데레 · 드워프 대장장이 견습

> "딱히 마녀 씨 장비가 걱정돼서 온 거 아니거든요? 고철이 불쌍해서 그런 거예요."

떠돌이 대장장이 케틸의 딸. 아버지보다 솜씨가 좋다는 소리를 듣고 싶어서, 엉터리 장비를 보면 참지 못한다.

| 항목 | 초안 |
| --- | --- |
| 만남 | 장비 카드를 3번 쓴 날 → "누가 이런 엉터리 장비를 쓰래요?"(대답과 무관하게 합류) |
| 게이지 · 모루 불씨 3 | 장비 카드를 쓸 때마다 1. **브리타 카드를 이틀 동안 쓰지 않아도 1**(안 불러 줘서 신경 쓰임) |
| 인쇄 문구 | `용병 한 명의 장비를 손봐 줍니다.` / `딱히 다른 건 안 고쳐 줄 거예요.` |
| 효과(드러난 것) | 용병 1명의 장비 1개 강화 1단계 |
| 효과(숨은 것) | 다음 새벽, **다른 용병의 장비 1개도 몰래 강화**. 아침 토스트 "누군가 밤새 망치질을 했다." |
| 상시 | 손패에 이틀 이상 묵히면, 그날 밤 스스로 나와 가장 망가진 시설을 고치고 주머니로 돌아감 — "…안 불러서 온 거 아니거든요!" |
| 대가 | 없음. 단 숨은 효과는 화면에서 바로 확인할 수 없다(아침에 알게 됨) |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 숨은 강화 1개. 표정: 팔짱, 고개 돌림 |
| 친함 | 숨은 강화 2개. 표정: 곁눈질, 귀 끝이 붉음 |
| 특별 | 숨은 강화 대신 **그 용병 장비에 '브리타의 각인'**(파손 무시 1회). 표정: 망치로 얼굴 가리기. 대사 "…마녀 씨 거니까 특별히 공들인 거예요. 이번만!" |

대사: 들어올 때 "또 불렀어요? 하아, 바쁜데." · 쓸 때 "흥, 이번만이에요." · 묵힐 때 "…저, 여기 있는데요." · 주머니로 "됐어요, 혼자 고칠 거니까!"

원화: 붉은 갈색 두 갈래 땋은 머리, 그을린 볼, 가죽 앞치마와 걷은 소매, 어깨에 멘 작은 망치. 팔짱 낀 상체 초상, 시선은 화면 밖.

**왜 이 효과인가:** 츤데레의 본질은 "말과 행동의 불일치"다. 인쇄 문구가 거짓말을 하고 실제 효과가 더 크게 나와야, 플레이어가 아침마다 "또 몰래 해 줬네"를 직접 겪는다.

### 4.2. 실바 — 쿨데레 · 늑대 수인 은빛 사냥꾼

> "…쓸 만하군. 그 이상도 이하도 아니다."

무리를 떠나 혼자 사냥하는 은빛 털의 늑대 수인. 감정을 낭비라고 여긴다. 파르그(같은 늑대 수인 용병)와 아는 사이일 수 있다(연결 후보).

| 항목 | 초안 |
| --- | --- |
| 만남 | 밤 전투에서 큰 적(엘리트)을 처음 처치한 다음 날 — 숲 가장자리에서 지켜보다 찾아온다 |
| 게이지 · 발자국 3 | 큰 적 처치마다 1 |
| 인쇄 문구 | `밤에 가장 강한 적을 쏘아 맞힙니다.` / `…빗나가는 일은 없다.` |
| 효과 | 밤 · 이번 밤 체력이 가장 높은 적 1을 표시하고 **확정 명중** 큰 피해. 무작위 요소 0 |
| 갭 발동 | **마녀 체력 50% 이하에서 쓰면** 저격 대신 마녀 곁에 선다: 이번 밤 마녀가 받는 피해 절반 + 근처 적에게 2발. 대사 "…물러서. 다치지 마." |
| 대가 | 쓴 다음 날 낮에는 사냥 나가서 산장에 없음(게이지가 오르지 않음) |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 저격 1발. 표정 완전한 무표정 |
| 친함 | 저격 후 남은 화살로 근처 적 1 추가. 귀만 살짝 마녀 쪽으로 |
| 특별 | 갭 발동 조건 50% → 70%. **이 단계에서만 원화가 미소** — 플레이어가 처음 보는 표정 |

대사: 들어올 때 "…불렀나." · 쓸 때 "표적 확인." · 묵힐 때 "…아직인가." · 갭 발동 "물러서라고 했다."

원화: 은회색 늑대 귀와 꼬리, 짧게 자른 은발, 차가운 금색 눈, 어두운 가죽 사냥복과 장궁. 화살을 메기는 옆모습 상체.

**왜 이 효과인가:** 쿨데레는 "정확하고 차가운데, 단 한 순간 감정이 샌다." 무작위 없는 확정 효과가 냉정함을, 마녀가 위험할 때만 바뀌는 효과가 숨긴 마음을 보여 준다. 특별 단계에서만 웃는 원화는 보상 그 자체다.

### 4.3. 페른 — 단데레 · 요정 씨앗 수집가 (기존 손님 승격)

> "……(나뭇잎 뒤로 숨는다)"

기존 요정 고용 손님 페른(`fern`, "수줍은 씨앗 수집가")을 인물 카드로 승격. 새 인물을 늘리지 않으면서 이미 아는 얼굴이 특별해지는 경험을 준다.

| 항목 | 초안 |
| --- | --- |
| 만남 | 페른에게 **말을 세 번** 건다. 1·2번째는 "……"만 하고 숨음, 3번째에 처음 대답 |
| 게이지 · 씨앗 3 | 새벽마다 1(산장에 있어 주기만 하면 됨). 단 그날 침식 카드가 손패에 들어왔으면 오르지 않음(무서워서) |
| 인쇄 문구 | `손패에서 밤을 넘길수록 선물이 커집니다.` / `저, 저기… 아직 준비가…` |
| 상시 · 숨기 | 손패에 들어오면 **나뭇잎에 가려진 그림**으로 놓인다. 새벽을 넘길 때마다 한 꺼풀씩 얼굴이 드러남(최대 3밤) |
| 효과 | 0밤: 씨앗 1(작은 자원) · 1밤: 숲 카드 1장 · 2밤: 숲 카드 2장 중 1장 + 가시 씨앗 · 3밤: 숲 카드 3장 중 2장 + "그동안 모은 거…" 고목의 열쇠 확률 |
| 깜짝 | 기다리는 동안 손패의 다른 카드를 **버리면** 한 꺼풀 다시 숨는다 |
| 대가 | 손패 8칸 중 1칸을 며칠 동안 차지 |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 위 표 그대로 |
| 친함 | 버려도 숨지 않음("이, 이제 괜찮아요") |
| 특별 | 손패에 들어올 때부터 1밤 상태로 시작 |

대사: 들어올 때 "(…부스럭)" · 1밤 "…안녕하세요." · 3밤 "기다려 줘서… 고마워요." · 깜짝 "꺅…!"

원화(3종 필수): ① 나뭇잎 사이로 눈만 ② 얼굴 반 ③ 씨앗 주머니를 두 손으로 내미는 정면. 고사리 잎 머리카락, 반투명 날개, 큰 눈.

**왜 이 효과인가:** 단데레의 핵심은 "기다려 주면 열린다." 손패에 묵힐수록 강해지는 충전형 효과와 단계별 원화로, 플레이어가 그녀를 위해 칸을 비워 두는 선택을 하게 된다.

### 4.4. 로티 — 데레데레 · 인간 양치기 소녀

> "와아, 양이 이렇게 많은 곳은 처음이에요! 저 여기 살래요! 마녀님도 좋아요!"

근처 마을의 양치기. 산장 목장과 마녀를 처음 본 순간부터 좋아한다고 말하고, 숨기는 법을 모른다.

| 항목 | 초안 |
| --- | --- |
| 만남 | 목장에 양(새끼양 포함) 3마리 |
| 게이지 · 양털 뭉치 3 | 양털 수확마다 1 |
| 인쇄 문구 | `마녀를 돌보고 모두를 기운 나게 합니다.` / `또 올게요! 편지도 쓸게요!` |
| 효과 | 마녀 체력 소량 회복 + 그날 용병 전원 작업 속도 상승 |
| 순환 | **쓰고 나도 사라지지 않고 주머니로 돌아간다.** 그리고 손패에 '로티의 편지'(작은 카드: 쓰면 1장 드로우) 1장을 남긴다 |
| 대가 | 효과는 작다(주머니에서 저절로 돌아오는 카드 규칙). 편지가 손패 칸을 차지한다. 편지는 하루 1장까지 |
| 목장 보너스 | 목장에 새끼양이 있으면 회복량 +50%("이 아이 이름은 제가 지었어요!") |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 위 표 그대로 |
| 친함 | 편지 3장을 모아 한 번에 쓰면 '긴 편지': 3장 드로우 + 침식 1 정화 |
| 특별 | 밤에도 쓸 수 있음(밤새 응원) — 용병 공격 속도 소폭 |

대사: 들어올 때 "마녀님! 저 왔어요!" · 쓸 때 "힘내세요! 제가 있잖아요!" · 묵힐 때 "마녀님~? 안 불러 줘요?" · 주머니로 "금방 또 올게요!"

원화: 밀짚모자와 두 갈래 갈색 머리, 주근깨, 크림색 앞치마, 품에 안은 새끼양. 활짝 웃는 정면.

**왜 이 효과인가:** 데레데레는 "애정이 넘쳐흘러서 계속 온다." 사라지지 않는 카드와 손에 쌓이는 편지가 그 넘침을 체감하게 하고, 넘침이 칸을 차지하는 귀여운 부담이 된다.

### 4.5. 엘로이즈 — 얀데레 · 산장 지하실의 유령 신부

> "드디어… 와 주셨군요. 이 산장에서, 아주 오래 기다렸어요. 이제 아무 데도 가지 마세요."

산장 지하에 묻힌 옛 신부의 유령. 언데드 플레이 스타일([덱 방향성 §5](deck-archetypes-v01.md))의 얼굴. 헌신과 집착이 같은 크기다.

| 항목 | 초안 |
| --- | --- |
| 만남 | 언데드 카드(제물의 단검 등)를 처음 쓴 밤이 지난 새벽 — 지하실 문이 저절로 열림 |
| 게이지 · 시든 꽃잎 3 | 침식 카드가 손패에 들어올 때마다 1(어둠을 좋아함) |
| 인쇄 문구 | `손패의 침식을 모두 삼켜 저주로 바꿉니다.` / `다른 사람은… 보지 마세요.` |
| 효과 | 손패의 침식 카드를 **모두 제거**하고, 삼킨 수만큼 이번 밤 적에게 저주(약화) + 시체 1장(최대 3) |
| 상시 · 질투 | 손패에 그녀가 있는 동안 **다른 인물 카드를 쓰면** 손패에 침식 카드 '질투'(사용 불가) 1장이 생긴다 — "누구예요, 그 여자?" |
| 상시 · 헌신 | 마녀가 쓰러질 때 그녀가 손패·주머니에 있으면 **대신 소멸**하고 마녀를 체력 50%로 일으킨다. 판당 1회. 이후 그 판에 다시 오지 않음 |
| 대가 | 질투가 다른 인물들과의 조합을 막는다. 대신 질투로 생긴 침식은 그녀의 연료가 된다(자기 완결) |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 위 표 그대로 |
| 친함 | 저주 범위 확대. 질투가 침식 2장으로 늘어남(더 강하고 더 무겁게) |
| 특별 | 헌신이 소멸 대신 **손패로 돌아옴**("저는 어디에도 안 가요. 당신도요.") |

대사: 들어올 때 "…제 생각, 하셨죠?" · 쓸 때 "당신을 괴롭히는 건 전부 제가 먹을게요." · 질투 "…누구예요, 그 여자?" · 헌신 "괜찮아요. 처음부터 이러려고 기다린 거예요."

원화: 낡은 신부 베일과 빛바랜 웨딩드레스, 창백한 반투명 피부, 시든 꽃다발. 상냥한 미소지만 눈의 하이라이트가 없다. 공포 표현은 절제하고 처연하게.

**왜 이 효과인가:** 얀데레는 "가장 헌신적이고, 가장 위험하다." 마녀의 목숨을 대신하는 최강의 보험과 다른 인물을 견제하는 질투가 한 장에 묶여, 그녀를 들이는 것 자체가 덱의 선택이 된다.

### 4.6. 로자린드 — 아가씨 · 몰락 귀족 영애

> "이 누추한 곳이 숙소인가요? …뭐, 하룻밤쯤은 참아 드리죠. 하룻밤만이에요."

가문이 몰락해 숲으로 도망친 백작가 영애. 아직 하인 몇 명과 가문의 금고 열쇠를 갖고 있지만, 물건값을 모른다.

| 항목 | 초안 |
| --- | --- |
| 만남 | 보유 골드가 처음 200 이상인 날 — "여기, 이 산장에서 가장 좋은 방으로." |
| 게이지 · 금화 자루 3 | 골드를 100 쓸 때마다 1(돈 쓰는 사람을 좋아함) |
| 인쇄 문구 | `골드를 내면 가문의 하인을 부릅니다.` / `값이요? 그런 건 하인이 알아요.` |
| 효과 | 낼 골드를 고른다: **소** = 하녀가 침식 1 정화 · **중** = 그 밤 호위 기사 1 · **대** = 기사 2 + 시설 1개 완전 수리 |
| 엉터리 값 | 매번 가격표가 ±30% 흔들린다. 고를 때 "이 정도면 되겠죠?" — 싸게 걸리면 이득, 비싸게 걸리면 손해 |
| 대가 | 골드 소비. 골드가 모자라면 "외상으로 해 두세요"(다음 날 숙박비 수입 절반) |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 위 표 그대로 |
| 친함 | 가격 흔들림이 −30%~+10%로(마녀 편에서 흥정해 줌) |
| 특별 | 골드 0으로도 쓸 수 있는 선택지 추가: **"제가… 직접 해 볼게요."** 하인 대신 본인이 서툴게 — 결과 무작위(소~대 중 하나), 대사 "손에 물집이… 아니에요, 아무것도!" |

대사: 들어올 때 "부르셨나요? 차는 준비됐겠죠?" · 쓸 때 "세바스티앙, 처리해." · 묵힐 때 "기다리게 하는 건 실례예요." · 주머니로 "흥, 다음엔 더 정중하게 불러 주세요."

원화: 금빛 세로 롤 머리, 낡았지만 고급스러운 진홍 드레스(밑단에 진흙), 레이스 장갑, 부채. 턱을 든 도도한 상체.

**왜 이 효과인가:** 아가씨는 "돈과 권력은 있지만 생활력이 없다." 골드를 바로 힘으로 바꾸는 통로이면서 값을 모르는 무작위가 붙고, 특별 단계에서 처음으로 자기 손을 쓰는 갭이 성장 서사가 된다.

### 4.7. 오벨리아 — 로리바바 · 요정 숲의 장로

> "요 꼬맹이 마녀 좀 보게. 내가 네 할미의 할미가 기저귀 찰 적부터 이 숲에 살았느니라."

외모는 열 살 남짓이지만 수백 년을 산 요정 장로. 고풍스러운 말투, 아이 취급하면 화를 낸다. 단것에는 약하다.

| 항목 | 초안 |
| --- | --- |
| 만남 | 요정 카드(요정의 맞바꿈·숲의 약속 등)를 3장 쓴 날 |
| 게이지 · 나이테 3 | 새벽마다 1. 단 **금빛 꿀술을 그녀에게 대접하면 바로 가득**(단것) |
| 인쇄 문구 | `주머니에서 가장 오래 잊힌 카드를 꺼냅니다.` / `묵은 것은 묵은 것이 아는 법이니라.` |
| 효과 | 주머니에서 **가장 오래 뽑히지 않은 카드 3장**을 보여 준다 → 1장을 손패로, 원하면 나머지 중 1장을 영구 제거("버릴 건 버려야지") |
| 대가 | 쓴 다음 날은 낮잠 — 그녀의 게이지가 하루 오르지 않음 |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 위 표 그대로 |
| 친함 | 3장 → 4장 보기 |
| 특별 | 하루 1번, **오늘 이미 쓴 카드 1장을 손패로 되돌림**("옛이야기 하나 해 주마") |

대사: 들어올 때 "부르는 게 늦었구나, 꼬맹이." · 쓸 때 "어디 보자, 이 할미가 찾아 주마." · 묵힐 때 "흠, 노인을 세워 두다니." · 꿀술 "…맛있구나. 아, 아니, 그럭저럭이로구나."

원화: 등까지 오는 은백색 머리, 작은 몸에 너무 큰 이끼색 장로 예복, 나이테 무늬 지팡이, 나방 날개. 다리를 꼬고 나뭇등걸에 앉은 거만한 표정.

**왜 이 효과인가:** 로리바바는 "겉은 아이, 속은 오래된 지혜." 주머니 바닥에 묻힌 카드를 기억해 내는 효과가 '오래 산 자'를, 꿀술 한 잔에 녹는 게이지가 '아이 같은 면'을 보여 준다. 덱 압축 계열이라 [하스스톤 컨셉](hearthstone-inspired-cards-v01.md)의 정령·엘리스 계열과도 어울린다.

### 4.8. 치코 — 도짓코 메이드 · 고블린 산장 하녀

> "주인님! 산장 청소는 저한테 맡겨 주세요! …아, 방금 그 소리는 신경 쓰지 마세요."

일자리를 찾아 온 고블린 하녀. 의욕은 넘치고 손은 미끄럽다. 니키의 사촌 언니(관계 §5).

| 항목 | 초안 |
| --- | --- |
| 만남 | 산장에 시설이 3개 이상 있는 날 — "이렇게 큰 집엔 하녀가 필요하죠!" |
| 게이지 · 깨진 접시 3 | 시설을 지을 때·고칠 때마다 1 |
| 인쇄 문구 | `산장을 치우고 시설 하나를 고칩니다.` / `이, 이번엔 안 깰게요!` |
| 효과 | 주머니 카드 1장 영구 제거 **또는** 시설 1개 수리(고른다) |
| 실수 30% | 효과 대신 접시를 깨뜨린다 → 쇠붙이 1(판매용) + 그 카드는 손패에 남음. 대사 "으아앙, 죄송해요!" |
| 만회 | 실수한 다음 번 사용은 **반드시 대성공**: 두 효과를 모두 + 시설 체력 최대치 소폭 상승. 대사 "보셨죠? 저 할 수 있어요!" |
| 대가 | 실수 확률 |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 실수 30% |
| 친함 | 실수 20%. 실수해도 쇠붙이 2 |
| 특별 | 실수 10%. 대성공 때 '치코의 차 한 잔'(마녀 소량 회복)을 덤으로 |

대사: 들어올 때 "부르셨어요? 지금 가요— 꺅!" · 쓸 때 "맡겨 주세요!" · 묵힐 때 "청소할 데… 없나요?" · 실수 "으아앙, 죄송해요!"

원화: 연두색 피부, 축 처진 큰 귀, 작은 흰 머릿수건, 크기가 안 맞아 흘러내리는 하녀복, 쌓아 든 접시 탑이 기우뚱. 놀란 표정. 표정 3종: 의욕 · 울상 · 뿌듯.

**왜 이 효과인가:** 도짓코는 "실수가 매력." 실수가 손해로만 끝나면 짜증이 나므로, 실수 다음엔 반드시 대성공을 보장해 "이번엔 깨겠지?"를 기대하게 만든다.

### 4.9. 가르냐 — 연상 누님 · 오크 퇴역 전사 대장

> "애송이들 데리고 고생이 많네, 마녀 아가씨. 누나가 좀 봐 줄게."

전쟁터에서 부대를 이끌다 은퇴한 오크 여전사. 여유 있고 듬직하다. 아무도 모르게 귀여운 것에 약하다.

| 항목 | 초안 |
| --- | --- |
| 만남 | 오크 용병 2명 이상 고용 |
| 게이지 · 엄니 장식 3 | 용병이 쓰러지지 않고 밤을 넘길 때마다 1(아이들을 잘 지켰구나) |
| 인쇄 문구 | `밤새 용병들을 지휘하고 감싸 줍니다.` / `다친 애는 누나 뒤로 와.` |
| 효과 | 밤 · 용병 전원 공격력 상승 + **체력이 가장 낮은 용병이 받을 피해를 대신 받는다**(이번 밤) |
| 갭 · 새끼양 | 목장에 새끼양이 있으면 효과 +50%. 아침에 새끼양을 몰래 쓰다듬다 들키는 대사 이벤트(1회) — "…못 본 걸로 해." |
| 대가 | 대신 맞은 피해만큼 다음 날 가르냐 게이지가 늦게 참 |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 위 표 그대로 |
| 친함 | 감싸기 대상 2명 |
| 특별 | 마녀가 지치면(체력 30% 이하) 마녀도 감싸기 대상에 포함. 대사 "누나한테 기대도 돼." |

대사: 들어올 때 "부를 줄 알았지." · 쓸 때 "전원, 누나 뒤로!" · 묵힐 때 "아껴 두는 거야? 귀엽네." · 새끼양 "…이건, 그, 순찰이야."

원화: 짙은 녹색 피부, 짧은 엄니, 묶어 올린 검은 머리, 흉터 난 팔, 한쪽 어깨만 덮은 낡은 견갑과 털망토, 등의 큰 도끼. 느긋하게 웃는 상체.

**왜 이 효과인가:** 연상 누님은 "포용과 리드, 그리고 의외의 약점." 아군을 감싸는 효과가 포용을, 새끼양 보너스가 갭을 게임 수치로 만든다(목장 시스템과 연결).

### 4.10. 보리 — 강아지 후배 · 개 수인 마녀 제자 지망생

> "마녀님! 저 제자로 받아 주세요! 뭐든 따라 할게요! 진짜 뭐든요!"

마녀를 동경해 졸졸 따라다니는 개 수인 소녀. 마녀가 하는 건 뭐든 흉내 낸다. 칭찬받으면 꼬리가 멈추지 않는다.

| 항목 | 초안 |
| --- | --- |
| 만남 | 마녀가 하루에 카드를 5장 이상 쓴 날 — "방금 그거 어떻게 하신 거예요?!" |
| 게이지 · 꼬리 흔들기 3 | 그녀가 흉내 낸 카드로 적을 처치하거나 자원을 얻을 때마다 1(칭찬받음) |
| 인쇄 문구 | `마녀가 방금 쓴 카드를 흉내 냅니다.` / `저도요! 저도 할 수 있어요!` |
| 효과 | **직전에 쓴 카드의 효과를 절반 위력으로 한 번 더.** 인물·침식 카드는 흉내 못 함. 하루 1회(하스스톤 컨셉 §4 규칙 1) |
| 대가 | 직전 카드가 없거나 흉내 못 하는 카드면 "어… 어떻게 하는 거였죠?" — 카드가 손패에 남는다(손해 없음) |
| 손패 반응 | 손패에서 이 카드를 마우스로 쓰다듬으면 원화의 꼬리가 흔들림(UI 연출만, 효과 없음) |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 절반 위력 |
| 친함 | 75% 위력 |
| 특별 | **100% 위력.** 대사 "마녀님이랑 똑같이 했어요! 칭찬해 주세요!" |

대사: 들어올 때 "마녀님! 오늘은 뭐 해요?" · 쓸 때 "따라 합니다! 얍!" · 묵힐 때 "기다려…는 잘해요!" · 주머니로 "끼잉…"

원화: 크림색 축 늘어진 개 귀, 마구 흔드는 꼬리, 짧은 갈색 머리, 마녀 모자를 흉내 낸 너무 큰 헌 모자, 손에 쥔 나뭇가지 '지팡이'. 반짝이는 눈의 정면.

**왜 이 효과인가:** 후배는 "동경과 흉내." 직전 카드를 따라 하는 효과가 그대로 '흉내'이고, 호감이 오를수록 흉내가 진짜가 되는 것이 그녀의 성장 서사다.

### 4.11. 메리(자칭 녹티스 블러드문) — 중2병 · 마을의 견습 마녀

> "크큭… 당신도 '각성자'였군요. 저는 녹티스 블러드문. 칠흑의 계약자… 본명은 묻지 마세요."

마을 빵집 딸. 마녀를 동경해 스스로 봉인된 힘을 가졌다고 믿는다. 그런데 정말로 아주 조금 마력이 있다.

| 항목 | 초안 |
| --- | --- |
| 만남 | 마녀가 주문 카드(서리 룬 등)를 하룻밤에 3장 쓴 다음 날 |
| 게이지 · 봉인 붕대 3 | 주문 카드를 쓸 때마다 1 |
| 인쇄 문구 | `금단의 주문 셋 중 하나를 외칩니다.` / `크큭, 봉인이 풀리는 소리가 들려…!` |
| 효과 | 거창한 이름의 주문 3개 중 선택. 실제 효과는 작다: 「칠흑의 심연 송곳」 = 적 하나에 작은 피해 · 「혈월 이클립스 레퀴엠」 = 마법탄 잠깐 강화 · 「영겁의 빙결 감옥」 = 적 하나 잠깐 둔화 |
| 갭 · 진짜 각성 | **보름달 카드를 쓴 밤(또는 마녀가 늑대로 변신한 밤)** 에는 같은 주문이 진짜로 강력(5배). 대사가 진지해짐 "…어? 진짜로 나갔어요…?" |
| 상시 · 봉인 | 손패에 침식 카드가 있으면 쓸 때 1장을 '자기 마도서에 봉인'(제거). "어둠은 어둠으로 다스리는 법…" |
| 대가 | 평소엔 약하다 |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 위 표 그대로 |
| 친함 | 진짜 각성 조건에 '상현달 밤' 추가 |
| 특별 | 하루 1번 작은 확률로 평소에도 진짜 각성 — 본인이 제일 놀람 |

대사: 들어올 때 "내 오른팔이… 쑤신다…!" · 쓸 때 "봉인 해제! …살짝만!" · 묵힐 때 "후후, 아직 때가 아니다." · 진짜 각성 "…어? 진짜로?"

원화: 검은 단발에 빨간 리본, 한쪽 눈 안대, 팔에 감은 붕대, 손으로 만든 별자리 망토, 밀가루 묻은 앞치마가 망토 밑으로 보임. 과장된 포즈.

**왜 이 효과인가:** 중2병은 "말은 거창한데 실체는 작다 — 그런데 가끔 진짜다." 이름과 효과의 낙차가 웃음을, 달 시스템과 연결된 진짜 각성이 짜릿한 반전을 만든다.

### 4.12. 니키 — 메스가키 · 고블린 꼬마 소매치기

> "허접~ 마녀 주제에 카드 하나 못 지키냐? 이거 내가 가져갔었는데~?"

치코의 사촌 동생. 손버릇이 나쁘고 마녀를 놀리는 게 낙이다. 그래도 훔친 건 꼭 이자를 붙여 돌려준다.

| 항목 | 초안 |
| --- | --- |
| 만남 | 어느 아침 손패 카드 1장이 사라져 있다 → 그 날 니키가 그 카드를 흔들며 찾아온다(카드는 돌려줌) |
| 게이지 · 훔친 동전 3 | 골드를 얻을 때 30% 확률로 1(몰래 슬쩍) |
| 인쇄 문구 | `다른 이의 카드나 골드를 훔쳐 옵니다.` / `허접~ 이 정도도 못 해?` |
| 효과 | 무작위: 60% 다른 종족 카드 1장 · 40% 골드. 밤에 쓰면 적 하나의 전리품을 미리 훔침 |
| 상시 · 빌려 가기 | 손패에 그녀가 있으면 밤마다 30% 확률로 손패 카드 1장을 '빌려 간다' → **다음 아침 이자를 붙여 돌려줌**(그 카드 + 쇠붙이 1). 침식 카드는 안 훔침("그런 건 필요 없거든?") |
| 역관광 | 빌려 간 밤에 그녀 카드를 쓰면 "앗, 들켰다…!" — 그날 훔친 것을 두 배로 토해 냄 |
| 대가 | 빌려 간 밤엔 그 카드를 못 쓴다 |

| 호감 | 변화 |
| --- | --- |
| 낯섦 | 위 표 그대로 |
| 친함 | 이자에 쇠붙이 대신 골드 |
| 특별 | 가끔 훔친 게 아니라 **직접 사 온** 선물(유물 후보 3 중 1)을 내민다 — "…길에서 주운 거야. 진짜야." |

대사: 들어올 때 "또 나야~ 반가워해도 돼." · 쓸 때 "이런 건 식은 죽 먹기지~" · 묵힐 때 "심심해. 뭐 훔칠까?" · 역관광 "치, 치사하게!"

원화: 연두색 피부, 장난스러운 뾰족니, 짧은 양 갈래 머리, 너무 큰 도둑 망토, 손끝에서 빙글 돌리는 동전과 카드. 한쪽 눈을 감고 혀를 내민 표정.

**왜 이 효과인가:** 메스가키는 "놀리고 도발하지만 결국 미워할 수 없다." 카드를 빌려 가는 짜증과 이자를 붙여 돌려주는 반전, 그리고 그녀를 먼저 써서 되갚는 '역관광'이 관계를 놀이로 만든다.

## 5. 관계도 — 상주 3명 조합의 재미

상주 최대 3명이라 누구를 함께 두느냐가 판의 이야기가 된다. 함께 있으면 아침에 짧은 대화 이벤트가 생긴다(효과는 작게, 이야기는 크게).

| 조합 | 관계 | 함께 있을 때 |
| --- | --- | --- |
| 엘로이즈 ↔ 모두 | 질투 | 다른 인물 카드를 쓸 때마다 질투 침식. **엘로이즈 + 로티**는 최악이자 최고의 궁합 — 로티의 편지가 질투를 부르고, 질투가 엘로이즈의 연료가 된다 |
| 치코 ↔ 니키 | 고블린 사촌 자매 | 니키가 치코의 실수로 깨진 접시를 '훔쳐서' 고쳐 옴 — 실수 시 쇠붙이 +1 |
| 브리타 ↔ 가르냐 | 동경 | 가르냐가 있으면 브리타의 숨은 강화가 무기 우선("누님 도끼를 보고 배웠거든요!" — 츤데레가 누님 앞에선 솔직) |
| 오벨리아 ↔ 메리 | 진짜와 자칭 | 오벨리아가 메리를 '꼬맹이 마녀 2호'라 부르며 가르침 — 메리의 진짜 각성 확률 소폭 상승 |
| 실바 ↔ 보리 | 같은 개과, 정반대 | 보리가 실바를 따라 하려다 혼남. 보리가 실바의 저격을 흉내 내면 위력 손해 없음 |
| 로자린드 ↔ 치코 | 아가씨와 하녀 | 로자린드가 치코를 고용해 버림 — 로자린드 '소' 선택에서 치코 효과가 덤으로(실수 확률 포함) |
| 페른 ↔ 로티 | 수줍음과 넘침 | 로티가 말을 많이 걸어서 페른이 더 빨리 얼굴을 보임(새벽 1밤 추가 진행) |

성격 배치 매트릭스 — 밝음/어두움 × 다가옴/물러섬:

| | 다가온다 | 물러선다 |
| --- | --- | --- |
| **밝다** | 로티 · 보리 · 치코 · 니키 · 에린 | 메리(겉은 다가오지만 자기 세계) |
| **차갑다/거칠다** | 가르냐 · 로자린드 · 오벨리아 | 실바 · 브리타 |
| **어둡다/연약하다** | 엘로이즈 | 페른 |

## 6. 몰입을 위한 연출 체크리스트 (구현 때)

1. **원화 표정 3종**(낯섦·친함·특별) — `art_variants` 구조 재사용(술주정 3종 선례). 페른은 숨기 단계 3종을 따로.
2. **카드 위 말풍선** — 손패에 들어올 때·쓸 때·오래 묵힐 때·버릴 때 한 줄. 같은 줄은 다 듣기 전에 반복하지 않음(에린 잡담 규칙).
3. **숨은 효과의 아침 보고** — 브리타·니키처럼 밤사이 일어난 일은 아침 토스트 한 줄로 '들킨 것처럼' 알려 준다.
4. **게이지 아이콘** — 인물마다 다른 아이콘 3개(모루 불씨·발자국·씨앗·양털·꽃잎·금화·나이테·접시·엄니·꼬리·붕대·동전).
5. **손패 인터랙션** — 보리의 쓰다듬기처럼 효과 없는 작은 반응을 인물마다 하나씩(후속 검토).
6. **목소리** — `voice_<id>` 효과음 슬롯은 이미 있다(없으면 무음). 짧은 감탄사 3종이면 충분.

## 7. 균형 메모 — 하스스톤 규칙 대조

| 규칙 | 해당 인물 | 처리 |
| --- | --- | --- |
| 1. 복제·재발동 횟수 상한 | 보리(흉내), 오벨리아(되돌림) | 하루 1회 |
| 2. 저절로 나오는 카드는 작게 | 로티(순환), 브리타(스스로 출격) | 효과 소량, 편지 하루 1장 |
| 3. 덱 조건 보상은 첫날 작게 | 인물 전원 | 만남 조건 자체가 며칠 걸리게 설계 |
| 4. 무작위는 바닥선 | 치코(실수), 로자린드(엉터리 값), 니키 | 실수 후 대성공 보장, 흔들림 ±30% 상한, 니키는 손해 없음 |
| 5. 회복은 상한 | 엘로이즈(부활), 로티 | 부활은 50%·판당 1회, 로티 회복 소량 |

## 8. 열린 결정 (사용자)

1. **상주 인물 최대 3명**으로 고르게 할지, 제한 없이 전부 받을지.
2. **호감 시스템**을 공용으로 만들지(에린에게도 소급 적용할지).
3. 12명 가운데 **먼저 만들 3명** — 제안: 시스템 검증 폭이 넓은 **브리타(숨은 효과) · 페른(충전형, 기존 손님) · 치코(실수/만회)**. 엘로이즈는 질투·헌신 규칙이 여러 시스템을 건드려 두 번째 묶음 권장.
4. 페른처럼 **기존 손님을 승격**하는 방식을 더 쓸지(예: 신규 대신 시그뉘·에쉬카 승격).
5. 엘로이즈의 원화 수위(처연함 vs 섬뜩함).
