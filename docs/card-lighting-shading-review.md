# 카드 화풍과 실제 게임 라이팅·셰이딩 검토

검토일: 2026-10-13. 현재 소스의 Godot 4.7.2 / Forward+를 실행해 비교했다. 이미지 생성 페인트오버는 이번 근거로 사용하지 않았다.

**사용자 채택:** 검토 후 사용자가 작업 방향을 승인하고 기억하도록 요청했다. 채택 기준은 [아트 방향](art-direction.md)에 기록했다. 시험 수치의 최종 확정이나 기본 게임에 실제 적용하라는 지시와 구분한다. 승인 시점에는 진단 실행만 완료했고 기본 게임에는 미적용이다.

## 결론

**후속 적용 완료 (2026-10-13):** 사용자 요청으로 기본 소스와 배포 PCK에 프리셋 5종을 적용했다. 현재 상태와 실제 화면은 [화면 프리셋 기록](screen-style-presets.md)을 우선한다. 아래 진단 시험의 일괄 밴드 강도는 그대로 확정하지 않고 눈·나뭇잎 강도를 별도로 조절했다.

기존 3D와 보라색 설경을 유지하면서 **부드러운 2~3단 명암, 더 낮은 환경광, 국소적인 따뜻한 조명, 제한된 어두운 경계선**을 함께 사용하는 방향을 권한다. 카드와 같은 굵은 검은 선을 모든 물체에 적용하거나 전체를 인쇄 삽화로 바꾸는 방식은 사용자가 원한 변화량보다 크다.

조명만 바꾸면 대비가 개선되지만 카드의 또렷한 색면과 검은 선을 재현하지는 못한다. 반대로 명암을 모든 재질에 같은 강도로 나누면 눈과 바위의 각진 면이 강조된다. 재질별 강도 조절이 필요하다.

## 실제 코드에서 확인한 차이

- `scripts/world/world.gd`: 환경광 0.65, 방향광 0.60. 그림자 블러 1.6, 광원 각지름 2.5도. SSAO 반경 1.4 / 강도 1.8, 글로우 0.55.
- `shaders/painted_prop.gdshader`, `painted_snow.gdshader`: 이미 SPECULAR=0, ROUGHNESS=1이며 무광이다. 문제를 반사광 탓으로 진단하면 안 된다. `light()`는 넓게 감싼 빛을 거의 전 범위의 smoothstep으로 연결해 둥근 연속 명암을 만든다. `painted_fill`에 의한 자체 밝기도 그림자 대비를 약하게 한다.
- `scripts/visual/painted_models.gd`: 눈 기본색이 이미 보라색이고 환경광도 푸른색이다. 카드의 따뜻한 크림색 밝은 면과 차이가 있다. 배경 전체를 노랗게 바꾸기보다 후속 비교에서 눈 알베도의 보라 채도를 조금 줄이고 주변광으로 분위기를 남기는 편을 제안한다. 이 알베도 변경은 이번 캡처에서 시험하지 않았다.
- `shaders/painted_ground.gdshader`: 카메라 투영 클린 플레이트와 지역 색 마스크를 사용하고 EMISSION=c×0.44가 더해진다. 방향광만 바꿔서는 지면 표현 전체가 바뀌지 않는다. 바닥은 별도 예술 방향 검토가 필요하며 이번에 셀 명암을 적용하지 않았다.
- 눈 재질은 `shadows_disabled`이며 눈 메시의 그림자 투사도 꺼져 있다. 이전 자기 그림자 얼룩을 피하기 위한 구성이다. 이를 일괄 켜면 기존 문제가 돌아올 수 있다.

## 실제 엔진 비교

카드 3장을 검토용 CanvasLayer에 표시하고 동일 카메라·모델·배치로 캡처했다. 정적인 배경과 설정 비교용이며 양·눈 입자·연기는 각 실행에서 다를 수 있다. 카드 표시는 비상호작용 진단용이고 카드 게임플레이 구현은 아니다.

| 캡처 | 적용 | 관찰 |
| --- | --- | --- |
| [현재 설정](../godot/screenshots/card-style-review/baseline.png) | 소스 기본값 | 둥근 볼륨과 밝은 면의 부드러운 연결이 강하다. 카드 원화는 훨씬 강한 명암과 선을 가진다. |
| [조명 조정](../godot/screenshots/card-style-review/lighting.png) | 환경광↓, 방향광↑, 글로우↓, SSAO↓, 그림자 경계 조정 | 산장 그림자와 면의 구분이 개선된다. 표면의 연속 명암은 그대로라 화풍 차이는 남는다. |
| [조명 + 부드러운 3단 명암](../godot/screenshots/card-style-review/soft-bands.png) | 위 조명에 방향광의 명암 밴드·자체 밝기 감소 | 나무·바위의 색면 구분이 생긴다. 눈 면도 각져 보여 눈에 같은 강도로 적용하는 것은 권하지 않는다. |

| 항목 | 현재 | 시험값 |
| --- | ---: | ---: |
| 환경광 에너지 | 0.65 | 0.42 |
| 달 방향광 에너지 | 0.60 | 0.88 |
| 글로우 강도 | 0.55 | 0.22 |
| SSAO 반경 | 1.4 | 0.85 |
| SSAO 강도 | 1.8 | 1.0 |
| 그림자 블러 | 1.6 | 1.1 |
| 방향광 각지름 | 2.5° | 1.4° |

이 값은 이 프로젝트를 위한 비교 출발값이지 모든 게임에 적용하는 권장 기본값은 아니다.

3단 시험은 방향광만 기존 연속 명암과 밴드 명암을 65% 혼합했다. 다른 국소 광원은 연속 감쇠를 유지해 창문·화염 주변에 동심원 모양의 밝기 단계가 생기지 않게 했다. painted_fill은 기존의 60%로 줄였다. 프랍·눈·기존 stylized 재질의 1,181개 표면에 런타임 복제 재질을 사용했고, 원본 셰이더 파일은 변경하지 않았다.

## 실제 적용 방향과 아직 비교하지 않은 항목

1. **광원:** 현재 보라·청록 숲과 앰버 창문 구도를 유지한다. 환경광을 낮추고 한 방향광으로 큰 명암을 만든다. 창문·용·마법의 실제 국소 광원과 감쇠는 유지한다.
2. **명암:** 목재·바위·인물에 부드러운 2~3단 명암을 적용한다. 눈·양털·나뭇잎은 밴드 혼합을 더 약하게 하며, 그림자 아래의 보라색은 남긴다. 이번의 일괄 65%보다 재질별 조절판이 다음 비교 대상이다.
3. **경계:** 전체 검은 테두리보다 산장·인물·큰 프랍의 외곽과 접합부에 짙은 자주색을 제한적으로 사용한다. 예컨대 출력 화면 기준 약 1px의 낮은 불투명도 외곽선부터 비교한다. 모든 법선 경계를 강조하면 지붕 눈·나무 잎 내부가 지저분해질 수 있다. 외곽선 구현은 이번 캡처에 넣지 않았고 성능·선 떨림도 아직 검증하지 않았다.
4. **재질:** 카드의 먹선은 목재 접합·바위 균열 등 소수 위치의 알베도에 넣는 편을 제안한다. 표면 전체에 종이 노이즈를 뿌리는 방식은 피하고 기존 큰 색면을 유지한다. 새 텍스처 제작은 이번 범위에 포함하지 않았다.
5. **후처리:** SSAO는 짧은 접촉 그림자 용도로 줄여 사용하고 글로우는 창문·마법 중심으로 제한한다. 지면은 명암 단계나 법선 외곽선의 적용 대상에서 분리한다. UI 카드에는 월드 조명이나 컬러 그레이딩을 적용하지 않는다.

## 재현과 검증 범위

[진단 실행 스크립트](../godot/tools/review_card_lighting.gd)를 프로젝트 루트의 `.tools/Godot-4.7.2.exe`로 실행한다.

```text
--path godot --script res://tools/review_card_lighting.gd -- --review=baseline --output=res://screenshots/card-style-review/baseline.png
--path godot --script res://tools/review_card_lighting.gd -- --review=lighting --output=res://screenshots/card-style-review/lighting.png
--path godot --script res://tools/review_card_lighting.gd -- --review=soft_bands --output=res://screenshots/card-style-review/soft-bands.png
```

세 캡처 모두 저장 결과 OK와 대응 JSON 설정 기록을 확인했고 화면을 직접 검토했다. 파서·셰이더 컴파일 오류는 없었다. 제한된 환경의 사용자 로그/셰이더 캐시 쓰기 및 인증서 저장소 경고는 로그에 남았다. 이 캡처로 플레이 기능·전투 중 시인성·목표 하드웨어의 프레임 성능을 검증했다고 해석하지 않는다. 원래 게임 진입 장면과 기본 라이팅·셰이더는 그대로이며 진단 실행에서만 변경했다.

## 공식 근거

- [Godot spatial shader 참고](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html): `light()`의 광원별 실행, `LIGHT_IS_DIRECTIONAL`, `ATTENUATION`, `DIFFUSE_LIGHT` 누적과 무광/그림자 관련 동작.
- [Godot StandardMaterial3D](https://docs.godotengine.org/en/stable/tutorials/3d/standard_material_3d.html): Toon 명암과 환경광의 관계, 조명과 독립적인 emission의 동작.
- [Godot 깊이 기반 후처리](https://docs.godotengine.org/en/stable/tutorials/shaders/advanced_postprocessing.html): 외곽선 후속 구현에 사용할 깊이 읽기·역투영 구조. 이번에는 해당 효과를 구현하지 않았다.

화풍의 적합성 및 시험 수치는 카드 원화·현재 게임 캡처를 비교한 디자인 판단이다. 공식 문서가 이 게임의 예술 방향을 보증하는 것은 아니다.
