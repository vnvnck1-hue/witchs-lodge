# 아트 방향과 제작 참고

## 현재 목표

사용자가 2026-10-13에 승인한 [프랍·텍스처 밀도 축소 이미지](../art/concepts/environment/04-prototype-reference-simplified.png)를 프로토타입의 최우선 시각 기준으로 사용한다. 더 높은 고정 쿼터뷰, 워크래프트·하스스톤식으로 살짝 과장한 프랍 실루엣, 낮은 장식 밀도, 큰 색면의 절제된 페인터리 텍스처와 2~3등신 SD 캐릭터를 결합한다. 실제 게임 에셋이나 카메라 값을 추출한 자료는 아니다.

![프로토타입 승인 기준](../art/concepts/environment/04-prototype-reference-simplified.png)

후속 요청의 숲 어둠과 배경색은 [최신 보라·남색·청록 분위기 수정본](../art/concepts/environment/07-colored-forest-darkness.png)을 참고한다. 06 수정본도 보존한다. [실제 3D 수정 상태](art-refinement-progress.md)는 별도로 기록하며 원화와 동일한 최종 결과가 완성된 것으로 표시하지 않는다.

## 형태와 재질

### 캐주얼 재질 표현 적용 기획 (2026-10-14)

사용자 제공 Casual / REALISM 비교 이미지를 바탕으로 [실제 게임 적용 기획서](casual-material-application-plan.md)를 작성했다. 작은 무늬·흠집의 개수를 줄이고, 적은 수의 큰 특징과 형태를 따르는 패턴을 남긴다. 산장 목재·지붕 눈·바위부터 개별 비교하며 기존 구도와 분위기를 유지한다. 레퍼런스 원본도 문서에 포함했다. 현재는 기획만 작성했으며 이 계획에 따른 신규 에셋·재질 수정은 미착수다.

### 카드와 월드의 화풍 통일 — 사용자 채택 방향 (2026-10-13)

사용자가 [실제 게임 라이팅·셰이딩 검토](card-lighting-shading-review.md)의 작업 방향을 승인하고 기억하도록 요청했다. 이후 월드 시각 작업은 아래 기준을 따른다.

- 기존 3D 형태·카메라·배치와 보라·인디고 설경을 유지하면서 카드의 또렷한 명암과 조화시킨다.
- 사용자가 강조한 수정 폭은 ‘살짝’이다. 원래 화면을 바로 알아볼 수 있게 유지하고, 이후 수정도 명암·색·질감을 조금씩 조정해 비교한다.
- 환경광을 낮추고 달 방향광으로 큰 명암을 만든다. 창문·등불의 따뜻한 앰버 국소광을 유지한다.
- 목재·바위·캐릭터에 부드러운 2~3단 명암을 적용하는 방향으로 진행한다. 눈·양털·나뭇잎은 강도를 낮춰 각진 면이 과하게 드러나지 않도록 재질별로 조절한다.
- 제한된 얇은 짙은 자주색 경계와 접합부의 먹선을 검토한다. 배경 전체를 굵은 검은 선과 인쇄 삽화로 바꾸거나 눈밭에 촘촘한 질감을 추가하지 않는다.
- SSAO는 짧은 접촉 음영 중심으로 줄이고 글로우는 창문·마법에 제한한다. UI 카드에는 월드 조명·색보정을 적용하지 않는다.

승인은 작업 방향에 대한 것이다. 진단 시험값(환경광 0.42, 방향광 0.88, 글로우 0.22)과 일괄 65% 명암 밴드는 최종 확정 수치가 아니다. 얇은 경계선과 재질별 밴드 조정은 후속 구현·비교 대상이다.

**이 승인 시점의 적용 상태:** 별도 진단 실행에서만 시험했으며 기본 게임 소스 라이팅·셰이더와 배포 실행 데이터에는 아직 적용하지 않았다. 기본 소스는 환경광 0.65, 방향광 0.60, 글로우 0.55와 기존 연속 명암을 사용한다.

**후속 적용 완료 (2026-10-13):** 사용자 지시로 실제 게임에 적용했다. 기본값은 부드러운 명암이며 따뜻한 산장·차가운 숲·툰 셰이딩·기존 화면 프리셋을 제공한다. F2 또는 오른쪽 위 메뉴로 전환한다. [현재 프리셋과 실제 화면·검증](screen-style-presets.md)을 따른다. 기본 소스와 배포 PCK 모두 갱신했다. 눈·나뭇잎의 밴드 강도를 줄이고 제한된 자주색 윤곽 음영을 적용했으며, 픽셀 폭을 고정한 외곽선은 별도 후속 대상이다.

**추가 비교 프리셋 (2026-10-13):** 사용자 요청으로 강렬한 툰 셰이딩과 두꺼운 툰 외곽선을 추가해 총 7종을 제공한다. 강한 2단 명암·낮은 환경광·간결한 색면과, 깊이·법선 경계의 픽셀 반경 3 외곽선을 각각 비교한다. 이 두 버전의 강한 표현은 선택용 프리셋이며 기본값과 기존 화면을 살짝 다듬는 기본 작업 방향은 유지한다. 실제 배포 실행파일에도 적용했다.

- 환경은 큰 다각형 면과 간결한 색 덩어리로 구성한다. 나무, 눈 덮개, 산장 목재와 돌의 형태를 쉽게 구분한다.
- 프랍의 두꺼운 모서리·완만한 곡선·약간 과장한 비율로 스타일을 만든다. 표면을 세밀하게 채워 형태를 설명하지 않는다.
- 텍스처는 큰 색면, 넓은 명암과 드문 붓질로 정리한다. 촘촘한 균열·나뭇결·낱잎·반점과 눈밭의 작은 색조각을 줄인다. 해상도·선명도를 유지하면서 무늬 빈도를 낮추며, 흐림 효과로 대체하지 않는다.
- 산장은 작은 본채와 단순한 박공지붕을 기본으로, 증축 시 작은 공간이 이어 붙는 구조로 표현한다.
- 사람 캐릭터는 약 2~3등신: 큰 머리, 짧은 몸과 팔다리, 간결한 얼굴과 두툼한 손·신발.
- 캐릭터의 등신을 줄이되 건물에 비해 거인처럼 커지지 않도록 문·울타리·양과의 상대 크기를 유지한다.
- 용은 비상 소환의 힘이 드러나도록 지붕과 사람보다 훨씬 크게 표현한다.

## 시점과 공간

카드 코어의 다음 UI는 [기획서 v0.3](kingdom-integration-design.md)을 따른다. 기존 원화는 월드 표현 기준이며 손패가 없는 이미지를 최종 HUD 배치로 해석하지 않는다. 하단 손패를 두고 산장·목장·두 숲길·유효 드래그 대상의 가독성을 실제 사용 가능 화면 영역에서 검증한다. 사용자는 카드 사용 시 카드가 크게 올라와 화면을 일부 가리는 첫 합성 배치를 인정했다. 작은 기본 손패와 확대된 사용 상태를 구분해 검토한다. 카드 초상과 소환 인물의 이름·도구·실루엣을 연결하고 재료는 수량으로 묶는다. [카드 기본 포맷과 3종 원화·배치 시안](card-format-design-summary.md)은 제작됐고, 런타임 카드 UI는 아직 미구현이다.

승인 이미지의 더 높은 쿼터뷰로 지붕 윗면·목장 바닥·마녀 모자 윗면과 바닥의 길이 충분히 읽히게 한다. 시네마틱한 낮은 시점이나 전경 흐림보다 플레이 공간의 가독성이 중요하다. 직교 카메라의 하향 각도 65~70°는 블록아웃 제안이며 이미지와 비교해 조정한다.

지형은 거의 평평하다. 산장 주변의 관리 영역과 나무 사이에 넓은 눈밭을 남기고, 주변 나무는 간격을 두어 배치한다. 두 갈래 정도의 진입로와 작은 양 목장을 배치하고, 손님·공사·전투에 필요한 이동 공간을 남긴다. 바위·수풀·통나무와 최소한의 생활 소품만 드문드문 사용하며 버섯·꽃·잔가지·자갈·룬석 군집으로 채우지 않는다.

원화에 들어간 바위·잔가지·추가 길 등은 생성 결과의 세부 표현이며 구현 시 유지해야 하는 확정 요소는 아니다.

## 색과 정서

퍼플·인디고 분위기를 중심으로 눈은 라벤더와 페리윙클, 그림자는 짙은 보라로 표현한다. 나무 자체의 짙은 초록색이 은은하게 드러나되 장면 전체가 녹색으로 바뀌지 않게 한다.

창문과 등불은 따뜻한 앰버색이다. 숲 가장자리의 옅은 보랏빛 안개로 조금 음산한 기분을 만든다. 용의 공격에서는 불덩이와 주변 반사광만 강한 주황빛으로 강조하고 퍼플톤 환경을 유지한다.

## 모델링 참고 시트의 한계

루트 폴더의 이전 산장 3면도는 단순화 이전의 높은 탑과 여러 지붕을 가진 산장을 기준으로 만든 자료다. 최신 작은 본채의 리모델링은 [새 산장 3면도와 설계](lodge-redesign.md)를 우선한다. 다른 프랍은 [starter 시트](../art/model-sheets/starter/README.md)와 [모델링 인수인계](modeling-handoff.md)를 사용한다.

원본에 보이지 않는 후면은 추정했다. 생성 시트에는 일부 사선 표현과 방향 간 구조 차이가 남아 있어 엄밀한 투영도나 치수 도면으로 사용할 수 없다. 모델링 시 블록아웃에서 지붕 연결, 깊이와 높이를 검토해야 한다. 프랍 간 절대 축척과 수치 치수는 정하지 않았다.

## 제작 기록

총 37장의 PNG를 원본 해상도로 보존한다: 내장 image_gen으로 만든 이미지 35장과 사용자 제공 참고 이미지 2장. 프랍·텍스처 밀도를 줄인 승인 원화, 후속 숲 분위기 수정본, 새 산장 3면도 초안과 굴뚝 보정본을 보존했다. 파일명, 픽셀 크기, 바이트 크기, SHA-256과 용도는 [manifest.json](../art/manifest.json)에 기록했다. [수정 프롬프트](prompts/prototype-reference-simplified.md)도 함께 보존한다.

사용자 제공 참고 이미지의 제작자·출처·이용 조건은 대화에서 제공되지 않았다. 다른 제작자의 원본 참고와 이 대화에서 생성한 결과는 구분하여 보관한다. 별도의 이용 라이선스는 이 자료집에 추가하지 않았다.
