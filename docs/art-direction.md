# 아트 방향과 제작 참고

## 현재 목표

높은 고정 게임 시점에서 읽히는 알비온 온라인풍 로우폴리 환경과, 더 낮은 등신의 SD 캐릭터를 결합한다. 실제 게임 에셋이나 카메라 값을 추출한 자료는 아니며, 컨셉 이미지로 비율과 분위기를 검토하는 단계다.

## 형태와 재질

- 환경은 큰 다각형 면과 간결한 색 덩어리로 구성한다. 나무, 눈 덮개, 산장 목재와 돌의 형태를 쉽게 구분한다.
- 산장은 작은 본채와 단순한 박공지붕을 기본으로, 증축 시 작은 공간이 이어 붙는 구조로 표현한다.
- 사람 캐릭터는 약 2~3등신: 큰 머리, 짧은 몸과 팔다리, 간결한 얼굴과 두툼한 손·신발.
- 캐릭터의 등신을 줄이되 건물에 비해 거인처럼 커지지 않도록 문·울타리·양과의 상대 크기를 유지한다.
- 용은 비상 소환의 힘이 드러나도록 지붕과 사람보다 훨씬 크게 표현한다.

## 시점과 공간

높은 쿼터뷰로 지붕과 두 건물 면, 바닥의 길이 동시에 읽히게 한다. 시네마틱한 낮은 시점이나 전경 흐림보다 플레이 공간의 가독성이 중요하다.

지형은 거의 평평하다. 산장 주변의 관리 영역은 대체로 둥글고, 그 밖에는 빽빽한 숲이 이어진다. 두 갈래 정도의 진입로와 작은 양 목장을 배치하고, 손님·공사·전투에 필요한 이동 공간을 남긴다. 군중이나 소품으로 일상 장면을 과하게 채우지 않는다.

원화에 들어간 바위·잔가지·추가 길 등은 생성 결과의 세부 표현이며 구현 시 유지해야 하는 확정 요소는 아니다.

## 색과 정서

퍼플·인디고 분위기를 중심으로 눈은 라벤더와 페리윙클, 그림자는 짙은 보라로 표현한다. 나무 자체의 짙은 초록색이 은은하게 드러나되 장면 전체가 녹색으로 바뀌지 않게 한다.

창문과 등불은 따뜻한 앰버색이다. 숲 가장자리의 옅은 보랏빛 안개로 조금 음산한 기분을 만든다. 용의 공격에서는 불덩이와 주변 반사광만 강한 주황빛으로 강조하고 퍼플톤 환경을 유지한다.

## 이미지의 역할

| 자료 | 용도 |
| --- | --- |
| gameplay 01~04 | 최신 SD 게임 컨셉: 방문, 증축, 일반 위협, 용 방어 |
| exploration 06 | 로우폴리 게임 시점의 기준. 캐릭터는 SD 전 단계 |
| exploration 04 | 초기 퍼플톤 및 복합 산장 형태의 참고 |
| environment 01~03 | 전경 구도와 공터·숲 배치 대안 |
| model-sheets | 이전 복합 산장과 대표 침엽수의 제작 참고 |
| archive | 보정 전 생성 결과 보존 |
| references | 사용자가 처음 제공한 분위기 참고 이미지 |

## 모델링 참고 시트의 한계

산장 3면도는 단순화 이전의 높은 탑과 여러 지붕을 가진 산장을 기준으로 만든 자료다. 최신 로우폴리 산장의 확정 설계도가 아니다.

원본에 보이지 않는 후면은 추정했다. 생성 시트에는 일부 사선 표현과 방향 간 구조 차이가 남아 있어 엄밀한 투영도나 치수 도면으로 사용할 수 없다. 모델링 시 블록아웃에서 지붕 연결, 깊이와 높이를 검토해야 한다. 프랍 간 절대 축척과 수치 치수는 정하지 않았다.

## 제작 기록

총 19장의 PNG를 원본 해상도로 보존한다: 내장 image_gen으로 만든 이미지 17장과 사용자 제공 참고 이미지 2장. 파일명, 픽셀 크기, 바이트 크기, SHA-256과 용도는 [manifest.json](../art/manifest.json)에 기록했다.

사용자 제공 참고 이미지의 제작자·출처·이용 조건은 대화에서 제공되지 않았다. 다른 제작자의 원본 참고와 이 대화에서 생성한 결과는 구분하여 보관한다. 별도의 이용 라이선스는 이 자료집에 추가하지 않았다.
