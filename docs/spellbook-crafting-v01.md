## 2. 모닥불 vs 마법책

| | 모닥불 | 마법책 |
| --- | --- | --- |
| 성격 | 불로 익힌다 | 마력으로 바꾼다 |
| 만드는 것 | 음식(고기 스튜, 약초 스튜) | 물약 · 장비 · 마법 카드 |
| 조건 | 불이 켜져 있어야 함(목재 연료) | 낮에만, 시간 정지 |
| 조작 | 재료 카드를 모닥불에 끌어 놓기(기존) | 책 클릭 → 창에서 슬롯에 넣고 [제작] |

## 4. 제작 창 구성 (화면은 시안 확정 후 조정)

- **펼친 마법책.** 왼쪽 페이지 = 제작법 목록, 오른쪽 페이지 = 재료 슬롯 3칸 + 결과 미리보기 + [제작] 버튼. 아래 = 손패의 재화(수량 배지).
- **목록:** 분류 탭(물약 · 장비 · 마법). 아는 제작법은 이름·그림·재료가 보이고, 모르는 것은 `???`와 빈 실루엣. 탭마다 "알아낸 수 / 전체 수"(예: 2 / 5).
- **아는 제작법 클릭:** 오른쪽 슬롯에 필요한 재료가 자동으로 채워진다(부족한 재료는 빨간 수량).
- **실험:** 손패 재화를 클릭·끌어서 슬롯에 넣는다. 슬롯 하나 = 재료 한 종류, 수량은 슬롯에서 +/−.
  - 조합이 어떤 제작법과 정확히 맞으면 → 제작 성공 + **"새로운 비법을 책에 적었다"** 연출, 목록의 `???`가 그 제작법으로 바뀐다.
  - 맞지 않으면 → **재료는 사라지지 않고** "아무 일도 일어나지 않았다". (실험 비용을 둘지는 플레이테스트 후 결정)
- **제작법 획득:** 보상으로 받으면 해당 `???` 칸이 열리며 같은 연출.
- **결과:** 완성 카드는 손패로, 손패가 가득이면 주머니로(기존 규칙).
- **책 소품 상태:** 낮 + 지금 재료로 만들 수 있는 아는 제작법이 있으면 촛불이 밝아지고 은은한 빛. 마우스 올림 = 강조. 밤 = 어둡게, 클릭 시 "밤에는 마법책을 펼칠 수 없습니다".
