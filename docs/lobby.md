# 로비(타이틀) — 컨셉 원화 재현 + 인물 아이들링

사용자 요청 2026-10-24: "지금 이 컨셉원화 완벽하게 그대로 로비에 재현해줘. (…) 인물 일러스트들이 자연스럽게 아이들링할 수 있도록 쉐이더로 애니메이션 해줘. 천천히 자연스럽게."

- 원화: [races-closeup-distant-v02](../art/concepts/lobby/races-closeup-distant-v02/03-races-closeup-distant.png) (1920×1080)
- 레이어 분리 요청·납품: [codex-lobby-layers-v01](handoff/codex-lobby-layers-v01.md), 결과 기록 `art/lobby/layers-v01/`
- 코드: `godot/scripts/ui/title_screen.gd`(화면), `godot/scripts/ui/lobby_rig.gd`(인물별 움직임 값), `godot/shaders/lobby_idle.gdshader`

## 화면 구성

원화에서 오려 낸 레이어를 무대(`LobbyStage`)에 겹친다. 무대는 원화(1920×1080) 왼쪽에 720px 이어 그린 확장까지 합친 **2640×1080**이고
(배경·인물만 `_wide` 판, 타이틀·메뉴는 원화 좌표 그대로 x+720 — [왼쪽 확장 요청](handoff/codex-lobby-wide-v01.md)),
**화면 높이에 꼭 맞춰 메뉴가 있는 오른쪽 끝에 붙인다**(사용자 요청 2026-10-24: 울트라와이드에서 위가 잘림 → 위아래를 자르지 않음).
16:9 에서는 원화 그대로, 21:9·3440×1440 처럼 넓으면 왼쪽 확장 그림이 드러나고, 4:3 처럼 좁으면 왼쪽 인물이 조금 잘린다.
약 2.44:1보다 더 넓을 때만 가로에 맞추고 위아래를 조금 자른다.

| 순서 | 레이어 (`godot/assets/ui/lobby/`) | 내용 |
| --- | --- | --- |
| 1 | `lobby_bg_wide.png`(없으면 `lobby_bg.png`) | 인물·글자를 지운 배경판(설경·산장·라벤더 안개·크림 여백). 정지 |
| 2 | `lobby_characters_wide.png`(없으면 `lobby_characters.png`) | 일곱 인물 덩어리. `lobby_idle.gdshader` 로 아이들링 |
| 3 | `lobby_title.png` | 타이틀 「마녀산장」 + 초승달·지붕 장식·덩굴 |
| 4 | `lobby_menu_*.png` | 메뉴 글자 다섯 줄 + 금색 초승달·밑줄 |

정지 상태(셰이더 `idle_amount = 0`)에서 겹친 화면은 원화와 같다. 원화의 한 가지 결함인 타이틀·메뉴 뒤 **직사각형 크림 상자 경계**만
배경판에서 부드러운 안개로 풀었다.

## 메뉴

원화 문구 그대로: **이어하기 · 새로운 이야기 · 기록 보관소 · 설정 · 나가기**. 글자는 원화 픽셀 그림이고 그 위에 투명 버튼이 놓인다.

- 마우스를 올리거나 키보드로 고른 줄로 금색 초승달과 밑줄이 0.32초에 걸쳐 옮겨 가고, 고른 줄은 원화의 「이어하기」 크기(약 1.24배)로 커진다.
  처음에는 원화처럼 「이어하기」가 골라져 있다. 「나가기」는 올리면 살짝 커지고 따뜻해진다.
- 이어하기(저장)·기록 보관소는 아직 기능이 없어 누르면 메뉴 아래에 안내가 잠깐 뜬다. 이어하기 버튼 자체는 비활성.
- 로비 음악(저녁 배경음)은 끊기지 않고 계속 되풀이한다(사용자 요청 2026-10-24).
- 새로운 이야기 → 네 마녀 선택, 설정 → 소리·화면·튜토리얼 설정(이전과 같음).
- 영어(F8)에서는 원화 글자 그림을 숨기고 같은 자리에 게임이 번역된 글자를 그린다(타이틀 로고는 그대로).

## 인물 아이들링 (`lobby_idle.gdshader`)

뼈 없는 한 장 그림을 **구역별 UV 비틀기**로 움직인다. 구역 지도(`lobby_character_ids_wide.png`, 없으면 `lobby_character_ids.png`, Codex 납품)를
`tools/build_lobby_weights.gd` 가 부드러운 가중치 3장(`lobby_weights_0~2.png`, 480×270, 구역 4개씩)으로 굽고,
셰이더는 픽셀마다 구역 변위를 가중 합한다. 경계는 약 20px에 걸쳐 섞여 찢어지지 않는다.

구역마다: 목·허리 피벗을 중심으로 **1도 미만** 천천히 기울고(두 주기를 섞어 기계적이지 않게), 숨에 맞춰 피벗 위쪽이 살짝 부풀며 떠오른다.
부위는 부모 인물을 이어받고 제 움직임을 더한다.

| 구역 | 성격 | 기울기 / 주기 | 숨 주기 |
| --- | --- | --- | --- |
| 인간 남자 | 차분 | 0.32° / 10.5초 | 4.8초 |
| 늑대 수인 | 조금 경계 | 0.40° / 8.6초 | 4.3초 |
| 오크 | 크고 느리게 숨쉰다 | 0.26° / 12초 | 5.8초 |
| 요정 | 가볍게 떠 있다 | 0.55° / 7.2초, 떠오름 2.6px | 3.4초 |
| 마녀 | 차분 | 0.30° / 11초 | 5.0초 |
| 마녀 모자 | 마녀를 따라 조금 늦게 | +0.22° | — |
| 드워프 | 묵직하게 거의 안 흔들림 | 0.20° / 13초 | 5.6초 |
| 고블린 | 부산하게 | 0.50° / 7.4초 | 4.0초 |
| 고블린 귀 | 9초에 한 번 짧게 씰룩 | 1.4° | — |
| 요정 날개 | 천천히 파닥임 | 1.1° / 2.9초 | — |
| 요정 더듬이 | 흔들흔들 | 2.0° / 4.6초 | — |
| 늑대 귀 | 11초에 한 번 씰룩(보이는 경우) | 1.6° | — |

값은 `lobby_rig.gd` 의 `REGIONS` 한 곳에서 고친다. 인물 몸·머리 최대 변위 약 3~5px, 최대 속도 6px/s 이하(1080 기준).

## 검증

```text
.tools/Godot-4.7.2.exe --headless --path godot --script res://tools/build_lobby_weights.gd
.tools/Godot-4.7.2.exe --headless --path godot --script res://tools/verify_lobby.gd
.tools/Godot-4.7.2.exe --path godot --resolution 1280x720 --script res://tools/capture_lobby.gd
```

- `verify_lobby.gd`(헤드리스): 리그 값(느린 주기·인물마다 다른 박자), 셰이더 식을 CPU로 재현한 최대 변위·속도, 레이어 파일, 메뉴·강조 이동·안내·언어 전환·화면비 5종(16:9·2:1·21:9·3440×1440·4:3) 맞춤·음악 반복.
- `capture_lobby.gd`(실제 렌더 — 셰이더 컴파일과 원화와의 픽셀 일치·찢어짐은 헤드리스로 볼 수 없어서): 1920×1080 SubViewport에 그려
  정지 화면을 원화와 비교(`LOBBY_DIFF`), 아이들링 장면과 차이 8배 그림, 강조 이동, 1774×887 창, 2560×1080 울트라와이드(확장 부분 움직임 포함)를 `godot/screenshots/lobby/`에 남긴다.
