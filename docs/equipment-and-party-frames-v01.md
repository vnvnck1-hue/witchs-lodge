# 장착 장비 v0 · 용병 초상 메달 v01 (2026-10-19)

카드 컨셉을 잡기 전에 **마녀·용병에게 장비를 끼우는 기능**을 먼저 넣고, 늘어난 용병을 한눈에 관리할 **초상 메달**을 메인 화면 오른쪽에 붙였다.
장비 5종의 이름·수치는 기능 시험용 임시값이며, 카드 컨셉이 확정되면 바꾼다.

## 1. 장착 규칙

| 항목 | 규칙 |
| --- | --- |
| 칸 | 착용자마다 **무기 · 방어구 · 장신구** 3칸 (`Cfg.EQUIP_SLOTS`) |
| 착용자 | 마녀, 살아 있는 용병(하수인 제외). 장비마다 `who`: 마녀 전용 / 용병 전용 / 공용 |
| 장착 | 장비 카드를 **마녀·용병(월드) 또는 화면의 초상 프레임**에 끌어 놓는다. 낮·밤 모두 가능 |
| 카드 | 착용 중에는 손패에서 빠져 활동 중(`in_play`)이 된다. 버림패로 가지 않는다 |
| 교체 | 같은 칸에 다른 장비를 놓으면 이전 장비는 **같은 카드 그대로 손패**로(가득 차면 주머니) |
| 벗기기 | 초상 프레임의 채워진 칸을 클릭 → 손패로 |
| 반환 | 용병이 쓰러지거나 계약을 해지하면 끼운 장비가 모두 손패로 돌아온다 |
| 제한 | 늑대(보름달) 상태의 마녀는 장비를 바꿀 수 없다 |

수치 키: `max_hp`(더함, 현재 체력도 같이 오름), `damage`(피해 배율 더함), `armor`(받는 피해 감소율, 합 상한 60%), `speed`(이동 배율 더함), `regen`(초당 회복).
마녀의 `damage`는 마법탄에만 적용한다(늑대 물기·스킬 제외). 유물 배율과는 곱한다.

## 2. 용병 초상 메달 (사용자 확정 2026-10-19)

시안 A(왼쪽 용병 명부)·B(초상 메달) 중 **B 초상 메달**로 확정했고, 자리는 **화면 오른쪽 가장자리 세로 줄**로 옮겼다(A는 제거).

- 손님 컷아웃 초상(`assets/portraits/`)의 머리·어깨를 둥글게 오려 금빛 테로 감싼다. 테두리 바깥이 **체력 고리**(12시부터 시계 방향, 낮으면 빨갛게), 고리 아래 **장비 점 3개**(무기·방어구·장신구), 그 아래 이름표.
- **직업 배지는 메달 왼쪽**(바깥 테에 걸침)에 직업 색 원 + **직업 픽토그램**(`assets/ui/jobs/<job>.png`, Codex 납품 v02 — [요청서](handoff/codex-job-pictograms-v02.md)). v01(검+방패·활+화살·도끼·바구니)은 20px에서 뭉개져 사용자 피드백으로 **물건 하나·캔버스를 꽉 채운 굵은 실루엣**(검·D자 활·큰 도끼·버섯)으로 다시 그렸다. 배지 안 아이콘은 원 지름의 90%. 그림이 없으면 글자(전·사·벌·채)로 대신한다.
- 체력 30% 미만이면 빨간 맥동, 산장 안 대피 중이면 흐리게 "산장 안".
- 자리: 일시 정지 버튼 아래(디자인 y 110)부터 산장 관리 버튼 위(아래 앵커 y 676)까지, 메달 중심 x 1538(오른쪽 앵커). 반지름 29, 한 칸 114 = 바깥 테 지름 76 + 장비 점 7 + 틈 4 + 이름표 18 + 틈 9. 최대 5명, 넘치면 마지막 자리에 "+N".
  (2026-10-19 수정: 처음 배치는 간격 104에 배지가 메달 왼쪽 위로 튀어나와 이름표가 다음 메달 배지와 겹쳤다 → 배지를 왼쪽 옆으로, 간격을 다시 계산.)
- **지도 창은 오른쪽 위에서 왼쪽(목표판·유물칸 아래, 디자인 22·262)으로 옮겼다.** 오른쪽 가장자리는 메달 줄 전용.
- 메달·장비 점 위에 올리면 설명이 메달 왼쪽에 뜬다(이름·직업·체력·상태·장비 목록 / 장비 효과). 채워진 장비 점을 클릭하면 벗겨 손패로.
- 장비·고기 스튜 카드를 메달에 끌어 놓으면 그 용병이 대상이 된다. 마녀 장비 3칸은 상태판 오른쪽에 붙는다.
- 캡처: `godot/screenshots/party-frames/` — `medallion-right`, `-hover`, `-drag-equip`, `-map-open`(지도 창 왼쪽).
  (헤드리스 더미 렌더러로는 초상 오림·체력 고리 모양을 볼 수 없어 `tools/capture_party_frames.gd`로 창을 짧게 띄워 찍었다.)

## 4.9 용병 관리 창·툴팁 종족 줄 (2026-10-24)

- 메달 줄이 꽉 차 마지막 자리에 뜨는 "+N" 원을 누르면 **용병 관리 창**(scripts/ui/merc_panel.gd)이 열린다. 활동 중인 용병 전원을 한 줄씩 — 둥근 초상(체력 고리·직업 배지) · 이름·직업·종족 · 한 줄 소개 · 체력 · 하는 일 · 장비 3칸. 낮·밤 언제든 열리고 여는 동안 시간이 멈춘다. Esc·닫기·바깥 클릭으로 닫힌다.
- "+N"에 올리면 남은 인원과 클릭 안내 툴팁, 메달 툴팁에는 이름 아래 **종족 — <종족명>** 줄(종족 보조색).
- 검증: tools/verify_merc_panel.gd(헤드리스), 캡처: tools/capture_merc_panel.gd → godot/screenshots/merc-panel/ (창 안 초상 오림·배치는 더미 렌더러로 볼 수 없어 캡처).
