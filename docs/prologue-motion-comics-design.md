# 프롤로그 모션 코믹스 기획 v01

작성: 2026-10-18 · 요청: 사용자(“컷신 원화를 카드 그래픽 스타일에 맞추고, 정적 슬라이드 대신 레이어가 나뉜 시네마틱 일러스트로 모션 코믹스를 구성하라”) · 상태: **기획·에셋 요청 단계, 사용자 컷별 검수 대기**

현재 구현([prologue.gd](../godot/scripts/ui/prologue.gd))은 1920×1080 정지 그림 4장을 5.5초씩 아주 느리게 확대하며 자막을 띄운다. 이 문서는 그 4장을 **같은 서사·같은 자막**으로 유지하면서, 각 컷을 여러 장의 투명 레이어로 나눠 서사에 맞춰 순차 등장·이동·전환하는 모션 코믹스로 다시 구성하는 기획이다. 에셋 요청은 [코덱스 요청서](handoff/codex-prologue-motion-comics-v01.md), 런타임은 Claude가 구현한다.

## 2. 레이어 좌표계와 카메라

- **설계 화면**: 1920×1080(16:9). 게임은 이 좌표로 연출을 계산하고 실제 창 크기에 맞춰 전체를 균등 배율한다.
- **레이어 캔버스**: 2304×1296(설계 화면의 120%). 캔버스 원점은 화면 좌상단에서 (−192, −108). 패닝·줌 때 가장자리가 비지 않도록 여유를 둔다.
- 각 레이어 PNG는 **캔버스 좌표의 잘라낸 영역(트림)**으로 납품하고, 컷별 `cutN.json` 매니페스트가 `pos`(캔버스 안 좌상단)와 `size`를 기록한다. 배경은 캔버스 전체 RGB, 나머지는 RGBA.
- **카메라**: 줌 1.00~1.12, 팬 ±8%(≈ ±150px). 줌 중심은 컷마다 지정한다. 레이어는 깊이값(`depth` 0=가장 멀리, 1=가장 앞)에 따라 팬에 `(depth−0.5)×2×팬량`의 시차(parallax)를 받는다.
- **등장 방식 공통 어휘**
  - `ink-in`: 알파 0→1(0.5s) + 아주 약한 스케일 0.97→1.0. 먹선 그림이 종이에 찍히는 느낌.
  - `slide`: 지정 오프셋에서 정지 위치로 ease-out 이동.
  - `walk`: 좌우 이동 + 사인 상하 흔들림(±2px, 주기 0.5s).
  - `breathe`: 알파 또는 스케일을 사인으로 천천히 반복(2~3s).
  - `drift`: 느린 평행 이동 + 미세 스케일(연기·안개).
  - `flicker`: 등불·창문 글로우의 알파 노이즈(0.85~1.0).
  - `blink`: 눈빛 레이어의 알파를 가끔 0.1s 끈다.

## 3. 컷별 구성

자막은 기존 문장이다. 각 컷 안에서 1행→2행으로 나뉘어 뜨고, 자막 패널은 화면 아래 22%에 둔다. 아래 1/4은 레이어 디자인에서도 어둡고 단순하게 유지한다.

### 컷 1 — 마녀사냥의 끝 (8.5초)

> 마녀사냥이 끝났을 때, 살아남은 마녀는 넷뿐이었다. / 넷은 동서남북으로 흩어져 몸을 숨겼다.

| 깊이 | 레이어 | 내용 | 연출 |
| --- | --- | --- | --- |
| 0.0 | `cut1_sky` (RGB 전체) | 보라·남색 밤하늘, 먼 산 능선, 하늘에 번진 자주빛 연기 | 0.0s 페이드 인 0.8s, 이후 아주 느린 줌 |
| 0.2 | `cut1_village` | 먼 중세 마을 실루엣, 첨탑, 앰버 불꽃 | 0.6s ink-in, 불꽃 영역 `breathe`(앰버 글로우는 게임이 모듈레이트) |
| 0.3 | `cut1_smoke` | 마을 위로 솟는 큰 연기 덩어리 | 1.0s부터 `drift`(위로 12px/s, 스케일 1.0→1.06 반복) |
| 0.5 | `cut1_hills` | 네 마녀가 선 중간 언덕과 침엽수 띠 | 1.4s 아래에서 `slide`(+40px, 0.8s) |
| 0.6 | `cut1_witch_1~4` | 등을 보인 작은 망토 인물 4명(각각 별도 파일, 낮고 둥근 후드, 특정 방위 상징 없음) | 2.0s 언덕 가운데에 모여 `ink-in` → 4.0s부터 좌상·우상·좌하·우하로 2.2s `slide`하며 알파 1→0.35 |
| 0.9 | `cut1_fore` | 앞쪽 어두운 능선·나무 실루엣 | 처음부터, 팬 시차만 |
| — | 게임 입자 | 떠오르는 불티(앰버 점) | 0.0s부터, 마을 쪽에서 발생 |

- 자막: 1행 2.0s, 2행 4.2s.
- 카메라: 6.5s부터 마을 쪽(화면 중앙 위)으로 줌 1.00→1.08(2.0s).
- **전환 T1(연기 덮기)**: 8.5s에 `cut1_smoke`를 스케일 2.4배·알파 1로 0.7s 동안 키워 화면을 덮고, 컷 2의 `cut2_fog`가 그 위에서 1.0s에 걷힌다.

### 컷 2 — 깊은 숲의 산장 (8.5초)

> 마을에도 도시에도 마녀가 머물 자리는 없었다. / 당신은 깊은 숲에 작은 산장을 열었다.

| 깊이 | 레이어 | 내용 | 연출 |
| --- | --- | --- | --- |
| 0.0 | `cut2_sky` (RGB 전체) | 밤하늘·먼 숲·눈 덮인 공터 바닥 | 처음부터 |
| 0.3 | `cut2_trees_left` / `cut2_trees_right` | 좌·우 침엽수 무리 | 0.0s 안쪽(각 +120/−120px)에서 바깥으로 1.4s `slide`: 숲이 갈라지며 산장이 드러남 |
| 0.5 | `cut2_lodge` | 목재·돌 산장, 창문 **불 꺼진 상태**, 굴뚝 연기 없음 | 0.8s `ink-in` |
| 0.55 | `cut2_window_glow` | 창문 앰버 빛만 | 4.2s 알파 0→1(0.8s) + `flicker`: “산장을 열었다” 순간 불이 켜진다 |
| 0.55 | `cut2_smoke` | 굴뚝 연기 | 4.6s부터 알파 0→1, `drift` |
| 0.7 | `cut2_witch` | 승인 초상과 같은 마녀, 뒷모습/비스듬한 뒷모습, 등불 든 손 | 1.0s 화면 x 38%에서 47%(문 앞)까지 3.0s `walk` |
| 0.72 | `cut2_lantern_glow` | 등불 빛만 | 마녀에 붙어 이동, `flicker` |
| 1.0 | `cut2_fore` | 앞쪽 눈 덮인 가지·바위 실루엣 | 팬 시차, 6.0s부터 살짝 `drift` |
| 0.95 | `cut2_fog` (RGBA 전체) | 보랏빛 눈안개 | 0.0s 알파 1 → 1.0s에 0 |

- 자막: 1행 1.6s, 2행 4.2s(창문이 켜지는 순간과 맞춘다).
- 카메라: 6.0s부터 문 쪽으로 줌 1.00→1.10(2.5s).
- **전환 T2(지하로 내려가기)**: 8.5s에 컷 2 전체가 위로 200px 이동하며 0.5s 페이드 아웃, 검은 막 0.2s, 컷 3이 −200px에서 내려와 자리 잡는다.

> 산장 아래에는 봉인석이 잠들어 있다. / 숲의 오래된 것들이 노리는 돌이다.

| 깊이 | 레이어 | 내용 | 연출 |

| 0.25 | `cut3_shafts` | 바닥 틈새로 내려오는 앰버 빛줄기 | 0.6s 알파 0→0.8(1.0s), 느린 흔들림(회전 ±1°) |

## 4. 자막·틀·입력

- 자막 패널: 화면 아래, 폭 64%, 크림 종이(`MoonSkin` paper 스타일) + 2px 먹선. 글자는 카드 제목 글꼴, 30px, 먹색. 한 글자씩 25ms 간격으로 타이핑하고 2행은 같은 패널에 줄을 추가한다.
- 틀: `panel_frame.png`(1920×1080 RGBA, 가장자리 먹선 물결 비네트, 중앙 투명)를 가장 위에 얹는다. 보라 바탕이 아니라 **검은 먹선과 아주 어두운 보라 그림자**만으로 카드 원화창 느낌을 낸다.
- 입력: 클릭·Space·Enter는 현재 컷을 즉시 종료 상태로 보내고 전환을 시작한다. Esc·건너뛰기 버튼은 전체를 0.35s 페이드로 끝낸다.
- 페이지 표시 `n / 4`와 건너뛰기 버튼은 기존 위치 유지.

## 5. 에셋 규격 요약

| 항목 | 값 |
| --- | --- |
| 캔버스 | 2304×1296, 원점(−192, −108) |

| 화풍 참조 | 승인 사건 카드·인물 카드 원화, 카드 화풍 마녀 초상 |

세부 파일 목록·프롬프트 지시·완료 기준은 [코덱스 요청서](handoff/codex-prologue-motion-comics-v01.md)에 있다.

## 6. 구현 범위(Claude)

1. `godot/scripts/ui/prologue.gd`에 레이어 모드 추가: 매니페스트가 있는 컷은 레이어 타임라인으로, 없으면 기존 정지 그림으로 재생. 한 컷이라도 레이어가 없으면 그 컷만 정지 그림을 쓴다.
2. 타임라인은 위 표를 데이터(배열)로 두고, `_process`에서 시간 기반으로 평가한다(트윈 누적 대신 결정적 계산 → 헤드리스 검증 가능).
3. 검증 `godot/tools/verify_prologue_motion.gd`: 매니페스트·파일 존재, 레이어 수, 자막 순서, 컷 진행·건너뛰기, 폴백 동작, 특정 시각의 레이어 상태(예: 컷 2 4.2s 이전 창문 글로우 알파 0).
4. 납품 후 `--import`, 검증, 루트 `WitchsLodge.exe` 재내보내기.

## 7. 검수 요청 사항(사용자)

컷별로 다음을 봐 주면 된다.

- 컷 1~4의 **합성 미리보기**가 카드 화풍(먹선·색면·질감)에 맞는가.
- 레이어 분리 단위가 연출 표에 맞는가(예: 창문 글로우·룬·눈빛이 별도인가).
- 마녀가 승인 초상과 같은 인물로 보이는가.
- 각 컷의 연출 타이밍·전환 아이디어(연기 덮기 → 지하로 내려가기 → 룬 섬광)가 의도에 맞는가.

## 8. 미정·후속

- 효과음·BGM 큐(불티, 창문 켜짐, 룬 점등, 거미 등장)는 이번 범위 밖. 타임라인 표의 시각을 큐 지점으로 재사용할 수 있다.
- 마녀 4명의 개성(동서남북)은 미정이므로 컷 1 인물은 익명 실루엣으로 둔다.
- 다른 언어 자막은 패널 높이가 자동으로 늘어나도록 구현하되 실제 긴 문장 검증은 다국어 단계에서 한다.
