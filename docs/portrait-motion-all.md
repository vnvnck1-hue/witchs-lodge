# 전 손님 초상 모션 — 종족·성격별 셰이더 아이들링 (2026-10-23)

사용자 요청: 에린 초상에 넣은 셰이더 아이들링([에린 초상 모션](erin-portrait-motion.md))을 **모든 인물 초상**에 알맞게 적용하고,
초상이 통째로 **위아래로 떠다니는(위빙) 움직임은 삭제**.

## 동작

모든 손님(42명)이 대화 창·도착 소개 초상에서 숨·몸 흔들림·고개 아이들링을 한다. 같은 묶음 손님이 같은 박자로 숨쉬지 않게 인물마다 시계 위상(`motion_phase`, 0~20초)을 흩는다.
가슴 모핑은 에린만이다. 초상이 없는 인물(익명 실루엣)은 움직이지 않는다.

| 종족 | 성격 | 값 |
|---|---|---|
| 인간 | 에린과 같은 기본 | 기본값 |
| 드워프 | 묵직하게, 덜 흔들림 | 숨 1.5 rad/s·크기 1.15, 흔들림 0.6·빠르기 0.85, 고개 0.8 |
| 요정 | 가볍게 떠 있듯, **날개가 천천히 계속 파닥임** | 숨 2.1·크기 0.8, 흔들림 1.3·1.2, 날개 0.10·4.2 rad/s(가운데 ±0.14 데드존) |
| 고블린 | 부산하게 고개를 까딱, **옆으로 뻗은 귀가 10초에 한 번 씰룩** | 숨 2.4, 흔들림 0.9·1.6, 고개 1.5, 귀 0.16·22 rad/s(얼굴 데드존 0.08) |
| 수인 | 차분, **머리 위 귀가 10초에 한 번 쫑긋** | 숨 1.7·1.1, 흔들림 0.8, 고개 1.2, 귀 0.30·20 rad/s(얼굴 위쪽만) |
| 오크 | 크고 느린 숨 | 숨 1.35·크기 1.35, 흔들림 0.7·0.8, 고개 0.9 |

개인 보정: 노인(오스윈·두르가·울마)은 느리고 작게, 토르빈은 말수 적게(흔들림·고개 0.7), 들뜬 네리·핍·브륀힐드는 고개를 더, 윌로우는 날개를 느리게.

**상하 부유 삭제:** `guest_arrival.gd` 의 `sin(clock*0.7)*2` 부유를 모든 손님에서 없앴다. 초상 위치는 등장 트윈(가로 미끄럼·스케일)이 끝나면 고정이다.
(손님 말풍선 알림 메달 전체가 1.5px 떠 있는 `guest_interactions.gd` 의 흔들림은 초상이 아니라 알림 틀의 움직임이라 그대로 두었다.)

## 파일

- `godot/shaders/guest_portrait_motion.gdshader`: 새 uniform `motion_phase`·`breath_amount`·`sway_amount`·`sway_rate`·`head_amount`, 보조 움직임 `accent_*`
  (타원 안을 `accent_center` 기준으로 `accent_axis` 방향으로 늘였다 줄임. `accent_burst` 1 이면 `pow(max(sin(0.61t+1.7),0),24)` 문으로 약 10초에 한 번만, `accent_inner` 데드존으로 얼굴은 제외).
  기본값이면 이전 에린 셰이더와 같은 결과다.
- `godot/scripts/ui/portrait_motion.gd`: 셰이더 기본값(`DEFAULTS`), 인물별 머리 중심(`HEADS`, 원화 UV), 종족 성격(`RACE_STYLE`), 개인 보정(`PERSON_STYLE`), `for_profile()`.
  프로필에 `portrait_motion` 이 직접 있으면(에린) 그것이 우선.
- `godot/scripts/ui/guest_arrival.gd`: `_apply_portrait_motion` 이 기본값으로 되돌린 뒤 그 손님 값을 얹는다(재질 공유 시 앞 손님 값 잔류 없음). 상하 부유 제거.
- `godot/tools/portrait_grid_sheet.gd`: 머리 좌표를 읽은 0.1 UV 격자 시트(헤드리스) → `godot/screenshots/portrait-motion-all/grid-*.png`. 에린 실측(0.53, 0.17)이 기존 값(0.55, 0.16)과 맞아 읽기 방식을 확인했다.
