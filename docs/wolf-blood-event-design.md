# 늑대의 피 — 늑대수인 대화 이벤트와 달 카드 3종 (v01)

작성 2026-10-18 · 사용자 기획: "늑대수인이 손님으로 와서 배가 고프다며 검은 양 한 마리를 얻어먹을 수 있냐고 묻는다. 수락하면 [늑대의 피] 카드를 주고, 이 카드를 마녀에게 쓰면 잠시 괴로워한 뒤 초승달·상현달·보름달 카드가 나타나 주머니로 들어간다. 달 카드는 밤에만, 한 밤에 한 장만 쓴다."
세계관 기준은 [전역 지침](../CLAUDE.md)(중세 기반 판타지), 손님·대화 체계는 [종족 시스템 1차](races-guests-v01.md)·[손님 이벤트 UI](guest-events-ui.md), 카드 흐름은 [손패 흐름 v1](hand-draw-flow-design-v01.md)을 따른다.

## 1. 흐름 한눈에

```text
파르그(늑대 수인) 입실 ─ 말 걸기 "…배가 고프다" ─┬─ 수락: 목장의 검은 양 1마리 소멸 → [늑대의 피] 카드 1장
                                                    └─ 거절: 아무 일 없음(다음 방문 때 다시 물을 수 있음)
[늑대의 피]를 마녀에게 드래그 → 마녀가 1.6초 괴로워함(이동·공격 불가) → 초승달·상현달·보름달 3장이 주머니로 날아 들어감
밤 손패에 달 카드가 올라오면 마녀에게 드래그 → 그 밤 동안 효과 · 한 밤에 한 장만
  초승달: 공격 속도 ↑ / 상현달: 공격 속도·이동 속도 ↑ / 보름달: 늑대로 변신(근접·빠름·Q 할퀴기·E 덮치기)
새벽: 효과 종료(늑대 → 마녀)
```

## 2. 손님과 대화 이벤트

- **인물**: 수인 7명 중 늑대 수인 **파르그(fargh)**. 새 인물을 늘리지 않고(종족당 7명 규칙·`verify_races` 유지) 파르그의 "특별 이야기"로 넣는다. → §7 Q1
- **발동 조건**: 파르그가 입실했고 **목장에 어른 검은 양이 1마리 이상** 있으며 이번 판에서 아직 늑대의 피를 받지 않았을 때. 조건이 안 맞으면 기존 이야기("쇠와 썩은 잎")가 그대로 나온다. → §7 Q3
- **우선 발동**: `GUEST_STORY_EVERY`(손님 2명 중 1명만 이벤트) 표본 추출을 건너뛰고 **항상** 말을 건다. 한 판에 한 번뿐인 이벤트가 표본에서 빠지지 않게.
- **대화**(선택이 처음으로 게임 상태에 개입하는 이야기. `guest_dialogues.gd`의 "선택은 이야기만 바꾼다" 원칙의 예외로 문서에 남긴다):
  - 말 걸기: `…주인. 부탁이 있다.`
  - 제목: `검은 양 한 마리`
  - 도입: `…배가 고프다.\n사흘을 굶었다. 산장 음식으론 안 된다.\n목장의 검은 양… 한 마리만 다오.`
  - 선택 1(수락, 효과 `wolf_blood`): `좋아, 한 마리 데려가.` → 답: `…은혜는 잊지 않는다.\n이걸 받아라. 늑대의 피다.\n달이 뜨는 밤에 쓰면… 알게 된다.`
  - 선택 2(거절): `양은 줄 수 없어.` → 답: `…그런가.\n산장 주인의 양이다. 알았다.\n…다음에 다시 묻겠다.`
  - 맺음: `…잘 자라.\n오늘 밤은 내가 깨어 있다.`
- **수락 처리**: 목장에서 어른 검은 양 1마리를 고른다(털이 자란 양보다 안 자란 양을 우선) → 보랏빛 poof와 `sheep_flee` 소리로 사라짐 → 검은 양 카드(in_play)는 버림패 → `wolf_blood` 카드 1장을 손패(가득 차면 주머니)에 → 토스트. 거절은 `complete`를 부르지 않아 다음 방문 때 다시 물을 수 있다(`completed_stories`에 넣지 않음).
- 파르그를 고용 중이면 손님으로 오지 않으므로 이벤트도 없다(기존 규칙).

## 3. 카드 4종

| id | 이름 | 포맷(카드 가이드) | 분류 띠 | 시간대 | 대상 | 인쇄 문구(2줄) |
| --- | --- | --- | --- | --- | --- | --- |
| `wolf_blood` | 늑대의 피 | 사건 | 늑대 수인의 선물 · 변화 | 낮·밤(`both`) | 마녀 | `마녀에게 쓰면 잠시 고통스럽습니다.` / `달의 힘 세 가지가 주머니에 들어옵니다.` |
| `crescent_moon` | 초승달 | 스킬 | 늑대의 피 · 밤의 힘 | 밤 | 마녀 | `밤에 마녀에게 씁니다.` / `오늘 밤 공격 속도가 오릅니다.` |
| `half_moon` | 상현달 | 스킬 | 늑대의 피 · 밤의 힘 | 밤 | 마녀 | `밤에 마녀에게 씁니다.` / `오늘 밤 공격과 이동이 빨라집니다.` |
| `full_moon` | 보름달 | 스킬 | 늑대의 피 · 밤의 힘 | 밤 | 마녀 | `밤에 마녀에게 씁니다.` / `오늘 밤 늑대로 변신합니다.` |

- **늑대의 피 사용**: 마녀에게 드래그(기존 `player_hit` 판정). 사용 즉시 소비 → 마녀 `suffer(1.6s)`(§5) → 1.0초 뒤 세 장을 **주머니에 직접 추가**하고 손패 UI가 "주머니로 날아드는" 연출을 보여 준다. 드로우 스택에는 세지 않는다(카드 사용 1회만 센다).
- **달 카드 공통 규칙**: `CARD_PHASE = "night"`(낮 손패에는 안 올라옴). 밤 전투(`COMBAT`) 중 마녀에게 드래그. **한 밤에 한 장**: 이미 그 밤에 달 카드를 썼으면 "오늘 밤은 이미 달의 힘을 썼습니다"로 거부(소비 안 함).
- **소모 여부**(사용자 확정 2026-10-18, §7 Q2): **1회용.** 쓴 달 카드는 버림패로 가고 돌아오지 않는다. 늑대 변신은 한 판에 한 번뿐이다.

## 4. 효과 수치(시험값, `config.gd`)

| 상태 | 효과 |
| --- | --- |
| 초승달 `crescent` | 마법탄 간격 1.0 → **0.65초**(`MOON_CRESCENT_ATTACK = 0.65` 배율) |
| 상현달 `half` | 마법탄 간격 **0.65초** + 이동 속도 3.5 → **4.55**(`MOON_HALF_MOVE = 1.3`) |
| 보름달 `full` | 늑대 변신(아래) |

**늑대(보름달)**: 체력은 마녀와 같은 풀을 그대로 쓴다. 지팡이·마법탄 대신 근접 물기 평타.

| 항목 | 값 |
| --- | --- |
| 이동 속도 | 3.5 × **1.6** = 5.6 |
| 평타 | 근접(사거리 **1.5m**), 피해 **14**, 간격 **0.55초**, 선딜 0.12 |
| Q 할퀴기 | 커서 방향 전방 **부채꼴 110°·반경 2.4m**를 **0.45초 동안 4번** 할큄, 1회 **9** 피해(합 36), 할퀴는 동안 이동 불가, 쿨다운 **7초** |
| E 덮치기 | 커서 아래 적(없으면 가장 가까운 적) **2~7m** 거리의 적 하나에게 **0.25초** 도약 후 물어뜯기 **32** 피해 + 그 적 0.6배 감속 1.5초, 쿨다운 **10초** |
| 조작 | 우클릭 이동·대상 공격, A·S는 그대로. **손패 잠김**(사용자 확정, §7 Q4): 늑대인 동안 카드 드래그 불가, 손패가 어두워지고 "늑대는 카드를 쓸 수 없습니다". 양 수확은 밤이라 원래 불가 |
| 종료 | 밤 전투가 끝나는 순간(`CLEARING`) 마녀로 돌아옴. 늑대 상태로 쓰러지면 기존 패배 처리 |

## 5. 연출

- **괴로움**(`player.suffer`): 1.6초 동안 입력·공격 무시, 몸을 웅크리고 좌우로 떨며(`body.rotation`, `position.y`), 0.3초마다 붉은·보라 `Fx.flash` + `witch_hurt`. 끝나면 달 세 장이 솟아 주머니로 날아간다(손패 UI `_start_reveal` 역방향: 마녀 머리 위 화면 좌표 → 주머니 버튼).
- **변신**: 보랏빛 `Fx.poof` + 연기, 마녀 모델 숨김 → 늑대 모델 표시, `mon_big`을 울음 대체음으로. 새벽에 역순.
- **늑대 모델**: 2026-10-21 정식 늑대인간(Tripo, `visual/werewolf_visual.gd`, [기록](character-3d-pipeline.md))으로 교체. 예전 임시: `visual/wolf_visual.gd` — 원시 도형(회색 몸통 캡슐·머리·주둥이·귀 2·다리 4·꼬리)으로 만든 블록아웃. 달리기(다리 4박자·몸 상하 바운드), 정지 숨쉬기, 할퀴기(앞발 휘두름), 덮치기(몸 앞으로 늘어남), 피격 움찔. 노드 구조는 `{"root","body","head"}`로 마녀와 같은 피벗 규약.
- **스킬 표시**: 늑대일 때만 화면 왼쪽 아래(상태 패널 위)에 Q·E 아이콘 두 개와 쿨다운 부채꼴. 아이콘 원화는 코덱스에게, 납품 전엔 글자 Q/E 원형.
- **달 효과 표시**: 상태 툴팁 줄에 "오늘 밤: 초승달" 식으로 추가하고, 마녀 발밑에 은은한 달빛 고리(초승달 흰빛·상현달 노란빛·보름달 보라빛).
