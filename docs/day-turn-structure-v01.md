# 낮 턴제 · 저녁 정비 · 밤 실시간 — 하루 구조 재편 (v01)

작성 2026-10-25 · 상태: **기획 문서(미구현)** · 상위 방향: [코어 방향 재정립 §0](core-direction-kingdom-sts-v01.md) · 관련: [용병 고유 키트 v02](mercenary-unique-kit-v02.md) · Claude

**사용자 방향**과 **제안**을 구분한다. 수치는 모두 시험값이다. 세계 기준은 [전역 지침](../CLAUDE.md)의 중세 기반 판타지다.

---

## 1. 사용자 방향 (2026-10-25)

1. 지금까지의 맥락(킹덤식 운영 · 슬더슬식 덱 순환 · 롤토체스식 오토배틀러 · 마녀 조작 캐릭터 제외)을 유지한다.
2. **낮을 실시간으로 흐르게 두지 않고, 행동 단위의 턴제로 바꾼다.**
3. 판을 시작하면 매번 **무작위 주변 환경**에 따라 **격파할 적 거점, 보물상자, 던전**(던전 공간으로 이동해 일정한 전투를 수행) 등이 생긴다.
4. 각 요소는 수행에 **[시간]**이 든다. 예를 들어 **낮은 총 5[시간]**이고, 거점 도전에 n시간, 보물상자 열기에 n시간, 던전 도전에 n시간이 든다. 주어진 시간 안에서만 행동할 수 있다.
5. **시간에 따라 생기던 재화는 턴 단위로 얻는다.** 예: 나무꾼은 낮에 목재 1개만, 채집가는 낮에 한 번만 채집. 양털은 양 마릿수로 정해지므로 그대로 둔다.
6. 낮 시간을 다 쓰면 낮이 끝나고, 밤 전투 전에 **저녁 시간**이 주어진다. 저녁에는 용병이나 낮에 얻은 재화로 건물을 짓는 등 **전투 준비**를 하고, 준비가 되면 **밤으로 턴을 넘긴다.**

이 결정은 [코어 방향 §0.4](core-direction-kingdom-sts-v01.md)에서 열어 둔 질문 **"마녀가 빠지면 낮의 제약을 무엇으로 둘까?"**에 대한 답이다. 동시에 [§2 진단](core-direction-kingdom-sts-v01.md)의 **"한 세션의 목표가 불분명하다"**도 다룬다 — 무작위 지점들이 그날 할 일을 눈앞에 보여 준다.

## 2. 한 판의 흐름 (제안)

```text
새벽 ─ 보상 고르기 · 숙박비 정산 · 손님 도착 · 그날 지도 공개
  ↓
낮(턴제, [시간] 5) ─ 지점을 골라 시간을 쓴다. 용병을 골라 보낸다
  ↓ 시간을 모두 쓰면(또는 '낮 마치기')
저녁(정비, 시간 제한 없음) ─ 건설 · 장비 · 거점 배치 · 덱 정리 → '밤 맞이'
  ↓
밤(실시간) ─ 용병 오토배틀 + 카드(마력)
  ↓
새벽 …(12일 = 한 챕터 = 슬더슬의 한 판)
```

| 시간대 | 성격 | 롤토체스·슬더슬 대응 | 플레이어가 고르는 것 |
| --- | --- | --- | --- |
| 낮 | 턴제 · 자원(시간)이 제한된 탐험 | 슬더슬의 지도 고르기 | 어디에 시간을 쓰고, 누구를 보낼지 |
| 저녁 | 무제한 정비 | 롤토체스의 준비 라운드 | 무엇을 짓고, 누구를 어디에 세우고, 덱을 어떻게 다듬을지 |
| 밤 | 실시간 전투 | 롤토체스의 전투 라운드 + 손패 | 언제 어떤 카드로 개입할지 |

### 선례

- **Thronefall** — 낮에 짓고 밤에 실시간 방어. 낮의 선택을 밤이 시험한다.
- **The Last Spell** — 낮은 턴제 건설·정비, 밤은 몰려오는 적과 전투.
- **슬레이 더 스파이어** — 갈림길 지도에서 전투·엘리트·상점·보물·휴식을 고른다.

(선례는 구조 비교용 일반 지식이다. 이번에 따로 조사하지 않았다.)

## 3. 낮 — [시간] 5칸 (제안)

### 3.1 낮 지도

- 새벽에 **그날의 지점들**이 숲 위에 드러난다. 별도 지도 화면보다 **3D 숲을 그대로 내려다보며 지점을 고르는 방식**을 추천한다(산장의 살아 있는 느낌 유지).
- 판 시작 때 **월드 설정**(주요 종족 둘)과 함께 **지점 배치**(거점·상자·던전의 위치와 종류)가 무작위로 정해진다. 날마다 일부 지점이 새로 생기거나 사라진다.
- 지점을 누르면 필요한 시간, 보낼 용병 칸, 예상 보상과 위험이 뜬다.

### 3.2 지점 종류

| 지점 | 시간 | 하는 일 | 얻는 것 · 대가 |
| --- | --- | --- | --- |
| **적 거점** | 2~3 | 용병 몇 명을 보내 짧은 자동 전투 | 부수면 **그 방향의 밤 습격이 줄어듦**(킹덤의 포탈 공격). **놔두면 날마다 커져 그 방향 습격이 늘어남** |
| **보물상자** | 1 | 열기(가끔 함정·약한 적) | 카드 · 장비 · 골드 |
| **던전** | 3~4 | 던전 공간으로 이동해 여러 번 전투(첫 예시: 니벨라 보스 방) | 강한 보상(전설 카드·유물). 다치면 그날 밤 전력이 줄어듦 |
| **수확 강화** | 1 | 벌목·채집·사냥 중 하나를 더 함 | 그날 해당 재화 +1 |
| **손님 깊은 대화** | 1 | 펜티먼트식 3단계 이야기 진행 | 관계 · 그 용병 카드 강화([키트 v01 M5](mercenary-unique-kit-v01.md)의 "이벤트 → 카드 강화" 안) |
| **제단 · 봉인 의식** | 1~2 | 봉인 의식 단계 진행 | 챕터 목표([코어 방향 §5.2](core-direction-kingdom-sts-v01.md)) |
| **쉬기** | 1 | 다친 용병 회복 | 밤 전력 회복 |

- 지점 종류는 시험안이다. 1차 구현은 **적 거점 · 보물상자 · 수확 강화 · 쉬기**부터, 던전은 1종으로 시작한다(§8).

### 3.3 "누구를 보내느냐" — 핵심 장치

- 거점·던전·상자에는 **용병을 골라 보낸다.** 보낸 용병은 그 지점의 자동 전투를 치른다(밤과 같은 오토배틀 규칙, 마력 카드는 쓰지 않거나 지점 전용 소수 카드만).
- **다친 상태는 그날 밤까지 이어진다.** 낮에 강한 용병을 던전에 보내면 그날 밤 그 용병이 약하다.
- 그래서 낮의 선택은 **시간 + 밤에 쓸 전력**을 걸고 하는 것이 된다. 킹덤의 "동전 하나의 경쟁"이 **시간과 사람의 경쟁**으로 바뀐다.
- 비전투직(나무꾼·채집가)은 지점 전투에 보낼 수 없다(또는 보물상자만).

### 3.4 시간 5칸의 조정

- 5칸이면 하루에 두세 가지만 할 수 있어 긴장감이 좋다.
- 후반에 할 일이 늘면 빠듯할 수 있다 → **시간을 늘리는 투자** 후보: 산장 증축(+1), 특정 용병 특성, 낮 카드.
- 반대로 **시간을 깎는 위협** 후보: 안개의 밤 다음 날 시간 -1, 침식 카드.

## 4. 재화 — 턴 단위 획득 (사용자 방향 + 제안)

| 재화 | 이전(실시간) | 바뀐 방식 |
| --- | --- | --- |
| 목재 | 나무꾼이 낮 동안 벌목한 만큼 | **나무꾼 1명당 낮마다 1.** [수확 강화]에 시간 1을 쓰면 +1 |
| 채집물(약초·보물상자·유물) | 채집가가 숲을 돌며 확률 획득 | **채집가 1명당 낮마다 한 번 채집**(기존 확률표 그대로 1회 굴림) |
| 사냥감(생고기·가죽) | 사냥꾼이 토끼·사슴을 쏜 만큼 | **사냥꾼 1명당 낮마다 1** |
| 양털 | 양 마릿수 | **그대로**(양 마릿수로 정해짐) |
| 숙박비 | 손님 묵을 때 자동 | **새벽에** 그날 묵은 손님 수만큼 |
| 골드(기타) | 판매·전리품 | 그대로. 크라냐 전리품 등 밤 처치 보상은 새벽 결산 |

- 하루 수입이 정해진 숫자가 되므로 **헤드리스 시뮬로 12일치 경제를 바로 계산**할 수 있다(코어 방향 §5.4).
- 재화 숫자화([코어 방향 §4.1](core-direction-kingdom-sts-v01.md))와 같은 방향이다 — 턴 단위 획득은 재화를 카드가 아니라 숫자로 다룰 때 자연스럽다.

## 5. 저녁 — 정비 (제안)

시간 제한 없이 준비하고, **'밤 맞이'**를 누르면 밤이 시작된다.

| 할 일 | 내용 |
| --- | --- |
| 건설 | 방책 · 감시탑 · 목장 · 산장 증축 등. 낮에 얻은 재화와 골드로 |
| 장비 | 용병 3칸 장비 끼우기·바꾸기(구현됨) |
| 거점 배치 | 초상 메달을 거점(동·서 숲길 안쪽/바깥쪽 · 산장 앞 · 감시탑 · 목장)에 끌어 놓기([키트 v02 R7](mercenary-unique-kit-v02.md)) |
| 덱 정리 | 모닥불 영구 제거, 제단 강화(하루 횟수 제한) |
| 오늘 밤 확인 | 밤 규칙·방향별 예상 습격(거점을 부쉈는지에 따라 달라짐)을 미리 보여 줌 |

- 저녁에 할 일과 낮 행동의 경계는 §7의 결정 질문.

## 6. 기존 결정과의 연결

| 기존 결정 | 이 구조에서 |
| --- | --- |
| 마녀 조작 캐릭터 제외(§0) | 걷는 시간 제약 대신 **[시간] 5칸**이 낮의 제약 |
| 봉인세 · 봉인 의식 · 봉인석 균열 | 시간 5칸 중 몇 칸을 목표에, 몇 칸을 생존에 쓸지가 매일의 고민 |
| 낮 전용 소수 카드(Q1) | **낮 카드는 시간을 다룬다.** 예: [지름길 지도] 거점 도전 시간 -1 · [밤샘] 오늘 시간 +1, 대신 그날 밤 모든 용병 기세 -20 |
| 용병 = 골드로 고용하는 유닛(Q2) | 낮 지점에 보낼 사람이자 밤의 전력. 두 곳에 동시에 쓸 수 없는 사람이 핵심 자원 |
| 판마다 덱 초기화(Q3) · 월드 설정 | 종족 둘 + **지점 배치**가 판마다 달라져 로그라이크 변주가 커짐 |
| 행상 브로크(3일마다) | 그날 지도에 **상인 지점**(시간 0~1)으로 등장 |
| 니벨라 보스 방 | 첫 **던전**의 토대 |
| 오토배틀러 · 기세 | 낮 지점 전투도 같은 규칙으로 자동 진행 |

### 6.1 용병 키트 v02에 생기는 영향

[용병 고유 키트 v02](mercenary-unique-kit-v02.md)의 실시간 낮을 전제로 한 특성은 턴 단위로 바꿔야 한다.

| 인물 | v02 특성 | 턴제 낮에 맞춘 수정안 |
| --- | --- | --- |
| 토르빈 | 낮 벌목 속도 +25%, 새벽 목재 +1 | **낮마다 목재 +1 추가**(나무꾼 기본 1 → 2) |
| 모가 | 낮에 벤 나무 자리에 그루터기 부적 | 낮마다 그루터기 1개 생김(벤 목재 수만큼) |
| 미라 · 페른 | 새벽 보상 관련 | 그대로 |
| 크라냐 | 큰 적 처치 골드 | 그대로(새벽 결산) |
| 브륀힐드 | 밤 시작 30초 내기 | 그대로(밤 규칙) |
| 전투직 전원 | — | **낮 지점 전투에도 같은 자동 스킬로 참여** |

- 새 특성 후보: "이 용병을 낮 지점에 보내면 필요 시간 -1"(요정·수인 정찰형), "낮에 보내도 밤 전에 체력 50% 회복"(드워프·오크 강건형).

## 7. 결정할 질문

### 7.0 사용자 결정 (2026-10-26) — 아래 표와 §3.3보다 우선

| # | 결정 |
| --- | --- |
| D1 | **용병을 "보내지" 않고 플레이어가 직접 움직인다.** 마녀 조작 캐릭터가 빠졌으므로 아무 용병이나 골라 선두로 삼아 움직이면 **나머지 용병이 따라온다**(무리 이동). 산장 밖 필드로 나갈 때도 아무 용병을 골라 나가면 전원이 따라 나온다. 선두는 언제든 바꿀 수 있다. **낮 전투 피해는 모두 계속 이어진다**(밤까지, 회복 수단 전까지) |

| D2 | 손님 응대(고용·짧은 대화·깊은 대화)는 **모두 0시간** |

| D7 | **낮 지점 전투에도 밤 덱을 그대로 쓴다.** 전투마다 덱 전체를 새로 섞어 시작 손패를 뽑고, 끝나면 초기화(슬더슬 전투와 같음) |
| D8 | (D1에 따라) 지도 화면 없이 **3D 숲 필드를 무리가 직접 걸어 다닌다** |

| D4 | 시간 5칸을 늘리는 수단 | 산장 증축 +1, 일부 낮 카드. 위협으로 -1도 둠 |
| D5 | 거점을 놔두면 | 날마다 단계가 올라 그 방향 밤 습격 +1그룹. 3단계면 공성 괴물 추가 |
| D6 | 던전 범위 | 1차는 1종(니벨라 보스 방 확장), 3~4시간, 전투 2~3번 연속 |
| D7 | 낮 지점 전투에 카드를 쓰나 | 쓰지 않음(밤의 손패와 분리) 또는 지점 전용 소수 카드 |
| D8 | 낮 지도 표시 방식 | 3D 숲 위에서 지점 고르기(추천) / 별도 지도 화면 |

## 8. 조심할 점

1. **낮의 살아 있는 느낌.** 메뉴 고르기처럼 느껴지면 산장의 따뜻함이 줄어든다. 시간을 쓸 때 용병이 실제로 숲으로 걸어가고, 해가 움직이는 연출을 3D 월드 위에서 보여 준다.
2. **던전 제작량.** 새 공간이 필요하다. 1종으로 시작한다.
3. **거점을 놔뒀을 때의 대가가 분명해야 한다.** 놔둬도 괜찮다면 아무도 시간을 쓰지 않는다. 성장 단계와 밤 습격 증가를 숫자와 화면으로 보여 준다.
4. **시간 5칸의 빠듯함.** 시뮬로 "하루에 할 수 있는 것 / 하고 싶은 것"의 비율을 잰다.
5. **기존 실시간 낮 코드.** 손님 도착 시각(`GUEST_ARRIVALS`)·낮 90초(`PREP_TIME`)·야생동물 사냥·나무꾼 벌목 AI·채집가 탐색 등은 턴제 낮에서 연출로만 남기거나 정리한다.
