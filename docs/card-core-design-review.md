# 마녀산장 — 카드 코어 전환과 기존 기획 충돌 검토

검토일: 2026-10-13 · 변경 전: [킹덤 접목 v0.2](kingdom-integration-design-v0.2.md) · 변경 후: [카드 코어 v0.3](kingdom-integration-design.md)

**카드 방향은 기존 산장·양·용의 설정과 양립한다. 다만 영구 주민 중심의 인력 수명, 양모 자동 판매, 야간 행동 제한, 반복 생산의 경제 계산은 그대로 병용할 수 없다.** 해당 규칙은 v0.3에서 교체하거나 후속 재검증 대상으로 돌렸다.

로컬 기획서·내러티브·인수인계·현재 Godot 설명과 관련 경제/설정 코드를 대조했다. 아래는 문서와 규칙의 검토이며 구현 버그 재현이나 플레이테스트 보고가 아니다. 이번 작업은 기획 자료만 수정했다.

v0.2의 절 번호는 보존한 원문 기준이다. 초기 [Godot 인수인계](godot-prototype-handoff.md)와 [현재 실행판 설명](../godot/README.md)은 v22의 버튼 중심 규칙을 설명하므로 새 카드 규칙과 병합해 구현 완료처럼 표시하지 않는다.

## 2. 양립하는 기존 요소

- 산장·마녀·양 목장·설산 숲·따뜻한 일상과 위협의 대비는 그대로 사용할 수 있다.
- 숙박비의 자동 정산과 용병 카드 획득은 별도 사건이다. 정산 뒤 고용하는 시험안이면 숙박 수입을 해치지 않으며 중복 정산도 막을 수 있다.
- 클릭 이동·자동 공격은 월드 조작으로 유지하고 카드 드래그 입력을 분리한다. 마녀가 이동해 양털을 수확하는 행동과 원격 유효 위치에 계약을 소환하는 행동은 역할이 다르다.
- 두 숲길·낮 준비/밤 검증·시설 성장·용 공물은 사용할 수 있다. 밤에 보유 카드를 새로 쓰는 판단이 추가된다.
- 산장/마녀 사망 시 패배, 양 사망 후 재구입, 출현 예약과 적 정리 후 밤 종료는 유지한다. 하수인은 적 수에 포함하지 않는다.
- 기존 승인 원화는 환경·카메라·프랍의 기준으로 유지한다. 카드 UI가 없던 원화를 최종 HUD 배치 기준으로 사용하지 않는다.

## 3. 카드 방향에서 새로 생기는 충돌 위험

| 위험 | 정리한 규칙 / 남은 확인 |
| --- | --- |
| 드래그가 지면 클릭으로 전달되어 마녀 이동 | UI가 누르기·드래그·놓기를 모두 소비. 입력 검증 필요 |
| 적 위에 용병을 겹쳐 소환하거나 벽 뒤에 배치 | 발견한 유효 지면·경로 검사, 실제 소환 위치 미리보기 |
| 드래그 도중 대상 사망·선점으로 카드만 사라짐 | 놓는 순간 재검사, 소비와 등록 함께 확정. 실패는 미소비 |
| 하수인 죽음으로 같은 카드를 재획득 | 보상은 지정한 적 개체 사망에만. 아군 재드롭 없음 |
| 하수인이 살아 있어 밤이 끝나지 않음 | 적·아군 집계 분리. 아군과 귀가자는 밤 종료를 막지 않음 |
| 손패가 차서 보상 손실·정리 강요 | 수량 묶음, 초과 획득 창고 보관, 가시 장수와 소유 상한 분리 |
| 벌목 용병을 밤에 무료 전투 인력으로 전환 | 계약 임무 고정. 중단 시 다음 안전한 낮에 재개. 실패/사망과 대기 구분 |
| 소모 용병 때문에 복구 불가능 | 기본 숙박 유지, 골드 수리·재고용 경로. 생존 가능성은 실제 검증 필요 |
| 전투가 카드 읽는 속도보다 빠름 | 실시간을 기준판으로 두고 감속/전략 정지를 별도 비교 |

## 4. 추가 결정과 밸런스 확인

사용자 방향에서 아직 정하지 않은 내용은 v0.3에 시험안으로 표시했다. 이 항목 때문에 기획 업데이트를 중단할 필요는 없으나 제품 규칙으로 확정하기 전 비교가 필요하다.

1. **하수인 수명:** 현재/다음 전투 종료까지를 첫 시험값으로 둔다. 영구 하수인을 원하면 누적 병력·회복·사망 손실·동시 상한을 다시 설계해야 한다.
2. **용병 공급과 비용:** 하루2명·계약30G·한 전투 수명은 기존30G 영구 주민보다 비싸다. 이전 전투 수치로 생존 가능한지, 매일 같은 계약 구매가 의무가 되는지 확인한다.
3. **양털의 선택:** 초기 판매4G는 획득 경로를 닫는 시험값이다. 제작·선물 사용처가 들어와야 자원 사용처의 고민이 커진다. 첫날 생산 여부·미수확 축적 한도도 시험안이다.
4. **벌목의 가치:** 계약료와 목재가 절약하는 수리비·향후 제작 가치를 비교한다. 산장 피해가 적은 날에도 벌목이 정답이면 안 되고, 어느 상황에서도 계약료를 회수하지 못해도 안 된다. 자원 나무 공급·재생과 손상별 실제 회복량을 함께 측정한다.
5. **소유·시간:** 가시8장·활동4명·초과 창고 보관·미사용 계약 무기한 유지는 초기 사용성 기준이다. 장기 비축 규모·창고 접근·시간 정지·세이브는 최종 미정이다.
6. **후속 범위:** 탐험·봉인·외곽 생산은 삭제하지 않았다. 다만 계약 경제와 호위 조건을 다시 닫은 후 구현한다. 현재 게임이 이 기능을 제공한다고 표현하지 않는다.

## 5. 검토 결과

현재 기획서 v0.3, 내러티브, 저장소 진입 안내에 카드 방향을 반영하고 이전 v0.2와 초기 인수인계의 역할을 표시했다. 직접 충돌하는 인력·양모·야간 제한·경제·제작 순서는 새 기준으로 교체했다. 원작 리서치와 이전 검토는 근거/기록으로 보존한다.

다음 제작 전에 할 일은 카드 코어의 실제 동작과 계약 사용처를 비교하는 것이다. 이번 문서 검토는 플레이 밸런스·하수인 최종 수명·야간 드래그 사용성의 검증을 대신하지 않는다.
