# 코어 방향 재정립 — 운영은 킹덤, 덱빌딩은 슬더슬 (v01)

작성 2026-10-25 · 상태: **기획 문서(미구현) · 최우선 과제(2026-10-25 사용자 지시)** · Claude

2026-10-24~25 사용자와의 방향 대화를 정리한 문서다. **사용자 확정**과 **제안**을 구분한다. 수치는 모두 시험값 제안이다. 이 문서의 결정이 끝나기 전에는 이에 걸리는 카드·재화·손패 규칙을 새로 늘리지 않는다.

세계 기준은 [전역 지침](../CLAUDE.md)의 중세 기반 판타지다. 관련 문서는 [킹덤 코어 리서치](kingdom-core-research.md), [킹덤 접목 v0.2(보존)](kingdom-integration-design-v0.2.md), [카드 코어 v0.3](kingdom-integration-design.md), [카드 전환 충돌 검토](card-core-design-review.md), [손패 흐름 기획](hand-draw-flow-design-v01.md), [볼륨 확장 v0.2](game-volume-expansion-plan.md), [덱 아키타입](deck-archetypes-v01.md), [유사 게임 리서치](similar-games-research.md)다.

## 1. 사용자 방향 (확정)

1. **운영을 기반으로 하고, 카드 코어는 라이트하게 가져간다.** (2026-10-24)
2. 지금 재미가 없는 원인은 **한 세션의 목표가 불분명하고, 허들이 거의 없어 너무 쉽고, 밸런스가 엉성한 것**이다. (2026-10-24)
3. **운영은 킹덤에서, 덱빌딩은 슬레이 더 스파이어(슬더슬)에서 가져온다.** 시작 덱이 있고, 웨이브를 막으며 강한 카드를 모아 덱을 강화하고, 덱을 압축하며 진행한다. **사용한 카드는 슬더슬처럼 다시 순환시킨다.** (2026-10-25)

정리하면 이 게임은 정통 "덱빌딩 로그라이크"가 아니라 **카드로 꾸리는 산장 생존 운영 로그라이트**다. 카드는 밤의 전투 행동에 집중하고, 판의 뼈대는 운영과 목표가 잡는다.

## 2. 진단 — 왜 쉽고 목적이 흐린가

코드와 수치로 확인한 사실(2026-10-24 기준, 실측 플레이가 아니라 계산).

| 문제 | 근거 | 결과 |
| --- | --- | --- |
| **패배 조건이 둘뿐** | 산장 붕괴(`world/lodge.gd`), 마녀 사망(`actors/player.gd`) | 그 사이의 실수(양·손님·골드 낭비)에 대가가 거의 없음 |
| **유지비 없음** | 급료·식량·세금 같은 지출 규칙이 없음 | 골드·재화는 쌓이기만 함 |
| **목표가 수동적** | 승리 = 12밤을 넘김(`chapter_data.gd`) | 낮 90초에 "무엇을 해야 하는지"가 없음. 제단·감시탑·목장은 "하면 좋은 것"일 뿐 |
| **마녀가 너무 강함** | 마녀 `BOLT_DAMAGE 12`/1초 ≈ 초당 12, 용병 `8`/1.5초 ≈ 초당 5.3 | 마녀 한 명이 용병 2명 이상의 화력 + 스킬 + 급료 없음. 운영 없이 직접 해결 가능 |
| **산장이 단단함** | `LODGE_HP 300`, 서리 거미 5 피해/2초 | 거미 1마리 기준 120초를 버팀 |
| **화폐가 갈라짐** | 골드 + 재화 7종(목재·양털·검은 털·생고기·스튜·가죽·장작) | 재화마다 쓰는 곳이 따로 있어 **선택끼리 경쟁하지 않음** |
| **손패가 인벤토리처럼 동작** | 버림패 비순환(확정 규칙 5·6), 재화가 손패 칸 점유 | 뽑는 설렘이 없고, 막힘을 메우는 장치(낮·밤 손패 교체, 달빛 스택, 모닥불 태우기)가 계속 늘어남 |

## 3. 킹덤 비교 — 무엇을 가져오나

킹덤 쪽 내용은 [킹덤 코어 리서치](kingdom-core-research.md)와 일반적인 시리즈 지식(주로 Two Crowns)에 기반한다. 이번에 직접 플레이하거나 다시 조사하지 않았다.

### 3.1 축별 비교

| 축 | 킹덤 | 마녀산장(현재) | 차이가 만드는 결과 |
| --- | --- | --- | --- |
| 화폐 | 동전 하나로 모든 것을 삼 | 골드 + 재화 7종 + 카드 | 선택끼리 경쟁하지 않음 |
| 주인공 | 군주는 거의 못 싸움. 동전을 떨어뜨리는 것이 전부 | 마녀가 최강 전투원 | 투자 없이 직접 해결 가능 |
| 실패 | 왕관을 뺏기면 끝. 그 전에 동전·주민·성벽이 서서히 깎임 | 산장·마녀 체력 0이면 끝. 그 전엔 손실이 거의 없음 | 실수의 대가가 없음 |
| 시간 압박 | 날이 갈수록 적이 강해지고, 블러드문·겨울이 옴 | 정해진 12일 대본 | 서두를 이유가 없음 |
| 목표 | 포탈 파괴 → 배 건조 → 다음 섬 | 12밤 버티기 | 목표가 수동적 |
| 유지비 | 겨울엔 농장 수입 없음, 지갑 한도, 탐욕이 동전을 털어감 | 없음 | 자원이 쌓이기만 함 |
| 공간 | 1차원 선 위의 좌우 방어선 | 쿼터뷰, 두 숲길, 용병 동행 | 표현력은 크지만 어느 쪽이 약한지 읽기 어려움 |
| 정보 | UI 거의 없음, 세계로 보여 줌 | HUD·카드·초상 메달·지도 | 친절하지만 화면 부담이 큼 |
| 서사 | 거의 없음 | 손님·종족·네 마녀·사건 | 우리의 확실한 강점 |
| 메타 진행 | 배에 실을 수 있는 것만 다음 섬으로 | 챕터 사이 덱 전체 유지(v0.2 결정) | 챕터 2부터 눈덩이 위험 |

### 3.2 가져올 것 (제안, 우선순위 순)

| 순서 | 킹덤 요소 | 마녀산장 구현 | 고치는 문제 |
| --- | --- | --- | --- |
| 1 | 동전 하나의 경쟁 | 결제 화폐는 **골드 하나**. 재화는 "팔면 골드, 직접 쓰면 더 좋은 효과" | 선택이 서로 부딪히지 않음 |
| 2 | 무력한 군주 | 마녀의 강한 공격에 **마나 비용**(§4). 기본 화력을 낮추고 카드·장비로 끌어올림 | 너무 쉬움 |
| 3 | 배라는 목표 | **봉인 의식**(챕터 목표) + **3일 주기 봉인세**(단기 목표) — §5 | 목표가 불분명함 |
| 4 | 서서히 깎이는 실패 | **봉인석 균열** 누적, 용병 부상·이탈, 침식 카드 | 실수의 대가가 없음 |
| 5 | 겨울 | **모닥불 장작 유지비** — 밤마다 장작이 없으면 산장이 얼어붙음 | 자원이 쌓이기만 함 |
| 6 | 포탈 공격 | **둥지 정화 원정** — 용병을 이끌고 숲속 둥지(니벨라 보스 방 등)를 부수면 그 길의 습격이 줄어듦. 마녀가 산장을 비우는 위험이 함께 생김 | 방어만 반복함 |
| 7 | 배의 적재 한도 | 챕터 사이 **짐 꾸리기**(카드 N장·용병 M명만 가져감) | 챕터 2 이후 눈덩이 |

### 3.3 지켜야 할 우리 강점

1. **사람에게 얼굴과 이야기가 있다.** 용병은 종족·이름·사건·장비를 가진다. 잃으면 더 아프므로 허들의 감정적 무게가 된다.
2. **밤에도 개입할 수단(카드)이 있다.** 킹덤은 밤에 지켜보는 시간이 길다.
3. **마녀 직접 조작의 손맛.** 없애지 않고 비용을 붙인다.
4. **산장의 따뜻함.** 손님을 맞이하는 축과 숙박 수입이 경제의 원천이라는 점이 장르 안에서 고유하다.

### 3.4 따라가지 말 것

- 걸어 다니며 동전을 떨어뜨리는 느린 반복(우리는 카드 드래그·클릭으로 이미 피함).
- 긴 판에서 한 번의 실수로 전부 잃는 구조(하루 단위 저장이나 새벽 재도전 같은 완충을 둠).
- 판단에 필요한 정보까지 숨기는 것. **목표·마감·위협 예고는 보여 주고, 효율·조합·종족 같은 재미 정보만 발견하게** 한다.

## 4. 슬더슬 덱 순환 — "낮은 킹덤, 밤은 슬더슬" (제안)

두 게임을 한 시간대에 섞지 않고 **낮과 밤으로 나눈다.**

### 4.1 낮 = 킹덤 (카드 없음, 또는 거의 없음)

- **골드 하나로 운영한다.** 숙박비를 받고, 용병을 고용하고, 감시탑·방책·목장을 짓고, 상인에게서 카드를 사거나 뺀다.
- **목재·양털·고기 같은 재화는 카드에서 빼서 숫자로** 만든다. 재화가 덱에 섞이면 순환할 때 쓸모없는 카드를 뽑게 된다(슬더슬에 "목재 카드"가 없는 이유).
- 낮의 판단 = "밤을 위해 무엇에 투자할까". 골드를 성벽·용병에 쓸지, 덱(카드 구매·제거·강화)에 쓸지가 같은 동전을 두고 경쟁한다.

### 4.2 밤 = 슬더슬 (덱 순환)

- 해가 지면 덱을 섞고 **5장**을 뽑는다. 손패 한도는 지금처럼 8장(`HAND_VISIBLE`).
- **마녀의 마나가 에너지**다. 초당 일정량이 차고, 카드에는 마나 비용이 있다.
- 카드를 쓰면 버림패로 간다. **카드를 쓸 때마다, 또는 몇 초마다 1장을 뽑는다.** 덱이 비면 버림패를 섞어 다시 덱으로 만든다.
- **새벽이 되면 손패를 모두 버린다**(슬더슬의 턴 종료). 손패 막힘이 구조적으로 사라진다.
- 마녀의 강한 공격은 마나를 쓰는 카드가 된다. 기본 자동 공격은 약하게 남긴다. → §3.2의 2번(무력한 군주)이 여기서 풀린다.
- 실시간 무작위 드로우의 짜증은 [손패 고민 시간](hand-focus-time.md)(손패에 손을 올리면 시간이 멈춤)과 "쓴 만큼 바로 채워지고, 쓰는 속도는 에너지가 제한"하는 구조로 줄인다. 실시간 덱 순환의 선례: 클래시 로얄(8장 덱·손패 4장·엘릭서), Ratropolis(실시간 덱빌딩 디펜스).

### 4.3 덱 성장 — 12일 챕터 = 슬더슬의 한 판

| 슬더슬 | 마녀산장에 이미 있는 것 | 바꿀 점 |
| --- | --- | --- |
| 시작 덱 | 시작 카드(`STARTER_CARDS`) | 약 10장: 기본 마법탄 5, 서리 룬 2, 수호 등불 2, 마녀 고유 1(시험안) |
| 전투 후 3장 중 1장 보상 | 새벽 보상(`REWARD_CHOICES := 3`) | 그대로 사용. **건너뛰기**도 허용(압축의 첫걸음) |
| 상점·카드 제거 | 행상 브로크(3일마다, `merchant.gd`) | 카드 제거 서비스(골드) 추가 |
| 모닥불 강화 | 마녀의 제단 | 의식 대신 "카드 1장 강화" 선택지 |
| 카드 제거(압축) | 모닥불에 카드 태우기 | 버림패로 보내던 것을 **영구 제거**로 |
| 저주 카드 | 침식 카드(침식된 기도문·독 포자) | 그대로. 제거에 골드가 들어 낮 운영과 이어짐 |
| 파워 카드 | 용병 계약·감시탑 등 활동 카드 | 쓰면 덱에서 빠지고 월드에 남음(또는 낮 골드 구매로 이동, §7 Q2) |
| 유물 | 장비 3칸, 전리품 카드 | 장비를 유물 역할로 |

### 4.4 종족 아키타입과의 연결

**사용자 방향(2026-10-25): 고용한 각 용병은 고유 카드와 패시브를 가지며, 고용하면 그 카드가 덱에 들어와 전투 방향을 바꾼다.** 24명 초안과 공통 규칙(카드 2장, 이동 후 시전, 빈자리 카드, 종족 시너지)은 [용병 고유 패시브·카드 기획](mercenary-unique-kit-v01.md)에 있다.

[덱 아키타입](deck-archetypes-v01.md)의 "고용한 용병 구성이 덱 방향이 된다"는 유지한다. 의미만 옮긴다: **그 종족 용병이 산장에 있으면, 그 종족 카드가 새벽 보상·상점·용병 사건으로 덱에 들어온다.** 고블린을 많이 들이면 덱이 고블린 카드로 기운다.

## 5. 세션 목표와 허들 (제안)

### 5.1 단기 목표 — 3일 주기 봉인세

- 행상 브로크와 같은 3일 주기에 **봉인 수호회(혹은 영주의 징수인)**가 와서 봉인세로 골드(와 재화)를 걷는다.
- 금액은 점점 오른다. 시험안: 3일째 30G, 6일째 60G + 목재 3, 9일째 100G + 양털 3.
- 못 내면 바로 지지 않고 벌을 받는다: 봉인석 균열 +1, 다음 밤 강화, 손님 발길 감소 중 택.
- 낮 HUD에 "이번 주기에 모아야 할 것"이 늘 보인다.

### 5.2 장기 목표 — 봉인 의식 (킹덤의 "배")

- 12일째 밤 전에 제단에서 **봉인 의식**을 단계별로 완성한다. 단계마다 골드·재화가 크게 든다.
- 완성도가 보스의 밤 난이도와 네 마녀 이야기의 **수호/파괴 결말**을 가른다([내러티브 §9.1](narrative.md)).

### 5.3 허들 — "잃을 수 있는 것"

| 허들 | 방식 | 만들어지는 판단 |
| --- | --- | --- |
| 용병 급료 | 새벽마다 용병 1명당 골드 | 많이 고용할지, 소수 정예로 갈지 |
| 봉인석 균열 | 산장이 맞을 때·세금 미납 시 누적, 회복은 비쌈. 일정 수치면 패배 | 산장 체력과 별개로 쌓이는 되돌리기 어려운 압박(킹덤의 왕관) |
| 겨울 장작 | 밤마다 모닥불 장작 소모, 없으면 산장이 얼어 손님 감소·용병 체력 감소 | 목재를 짓기에 쓸지, 버티기에 쓸지 |
| 용병 부상 | 쓰러진 용병은 즉시 회복 대신 며칠 이탈하거나 장비를 떨어뜨림 | 용병을 아끼는 운영 |
| 산장 수용 한계 | 방이 모자라면 손님이 돌아감 | 증축이 선택이 아니라 투자가 됨 |

전부 넣을 필요는 없다. **봉인세 + 급료 두 개만으로도** 골드가 "쌓이는 숫자"에서 "모자란 숫자"로 바뀐다.

### 5.4 밸런스 측정 — 헤드리스 자동 플레이

- `godot/tools/sim_balance.gd`(가칭): 정책 몇 가지(아무것도 안 함 / 고용만 함 / 무난하게 운영함)로 12일을 헤드리스로 돌려, 밤마다 산장 체력·골드·균열·덱 구성을 기록한다.
- 목표 곡선(시험값):
  - 아무것도 안 하면 2일째 밤에 진다.
  - 고용만 하면 6~9일 사이에 무너진다.
  - 무난하게 운영하면 12일을 깨되 여유가 30% 안팎이다.
- 이후 카드·시스템을 넣을 때마다 이 기준선으로 난이도 변화를 확인한다.

## 7. 결정할 질문

**사용자 결정(2026-10-25):**
- **Q1 → 낮 전용 소수 카드.** 낮에도 초대장·씨앗 같은 몇 장만 쓰고, 밤 덱과는 분리한다(제안안 "낮엔 카드 없음"이 아님).
- **Q2 → 골드로 고용하는 유닛.** 낮에 골드로 고용하면 월드에 남는다(킹덤식). 그 종족 카드가 덱에 들어오는 통로가 된다.
- **Q3 → 판마다 초기화.** 슬더슬처럼 매 챕터 시작 덱부터. 영구 해금만 남긴다(v0.2 "덱 전체 유지" 결정을 대체).
- **Q6 → 봉인석 균열부터.** 봉인세·급료는 이번 1순위에서 빠졌다.
- Q4·Q5·Q7은 미정.

| # | 질문 | 제안 |
| --- | --- | --- |
| Q1 | 낮에도 카드를 쓸까? | **쓰지 않는다.** 낮까지 덱을 돌리면 "밤 카드가 낮 손패를 막는" 문제가 돌아온다. 낮 행동(고용·건설·구매)은 골드로 직접 |
| Q2 | 용병은 카드인가 유닛인가? | **유닛.** 낮에 골드로 고용하면 월드에 남는다. 종족 카드가 덱에 들어오는 통로가 된다 |
| Q3 | 챕터 사이에 덱을 유지할까? | **짐 꾸리기**(카드 N장·용병 M명). 판마다 초기화도 비교안 |
| Q4 | 밤 드로우 리듬은? | 시작 5장 + 카드 사용 시 1장, 또는 N초마다 1장. 시뮬로 비교 |
| Q5 | 마나 수치는? | 시작 3, 초당 0.5 충전, 최대 5(시험값) |
| Q6 | 봉인세·급료·균열·겨울 장작 중 무엇부터? | **봉인세 + 급료** 먼저, 균열은 그다음 |
| Q7 | 봉인석 균열이 일정 수치면 패배인가? | 패배 조건 추가(킹덤의 왕관)를 제안. 산장 붕괴 패배는 유지 |

## 8. 진행 순서 (제안)

1. **결정** — §7 질문에 사용자 답을 받는다. 이 문서를 v02로 갱신하고 확정/제안을 다시 나눈다.
2. **측정 기준선** — 현재 판을 헤드리스 자동 플레이로 돌려 "지금 얼마나 쉬운가"를 숫자로 남긴다(§5.4).
3. **목표와 허들** — 봉인석 균열(Q6 결정) + 봉인 의식. 기존 카드 구조를 건드리지 않고도 넣을 수 있어 먼저 한다. 봉인세·급료는 그다음 후보.
4. **재화 숫자화** — 재화를 카드에서 빼고 골드 하나로 결제를 모은다(§4.1).
5. **밤 덱 순환** — 마나, 순환 드로우, 새벽 손패 버리기, 시작 덱(§4.2~4.3).
6. **압축·강화** — 모닥불 영구 제거, 브로크 제거 서비스, 제단 강화.
7. **재측정** — 2의 기준선과 비교해 목표 곡선에 맞춘다.

각 단계는 헤드리스 검증 스크립트를 함께 둔다(전역 지침).
