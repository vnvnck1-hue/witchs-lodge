# 손님 도착 · 플로팅 알림 UI v2

> 이전 구현 기록. 현재 크기·시간·초상 이동·선택형 대화와 관리창은 [손님 UI v4](guest-events-ui.md)를 따른다.

2026-10-15 · 사용자 레이아웃 시안에 맞춰 기존 소개 화면을 교체했다.

## 적용한 표현

- **투명 초상:** 기존 두 일러스트의 배경을 image_gen으로 제거했다. 아치 프레임 없이 인물 실루엣이 어두운 패널의 왼쪽과 위로 돌출된다.
- **시안 비율:** 2540×1385 참고 화면에서 알림 전체가 화면 너비 약 47%를 차지하는 중앙 배치와 세로 중심 약 48%를 기준으로 했다. 초상과 패널·텍스트는 하나의 비율로 축소된다.
- **어두운 패널:** 밝은 종이 말풍선, 전체 화면 암막, 외곽 금테, 진행 버튼을 제거했다. 거의 검은 보랏빛 배경 위에 크림색 이름과 밝은 대사를 배치한다.
- **비차단 알림:** 게임 시간·손님 이동·고용·카드·이동/줌 입력·상시 HUD와 BGM을 계속 유지한다. 이 모듈은 시간 정지나 오디오 믹스에 개입하지 않는다.
- **VisualShader:** 편집 가능한 8노드 CanvasItem 그래프 `guest_ink_panel.tres`로 두 개의 느린 파형을 합성해 패널의 실제 가장자리를 움직인다. 배경색도 아주 약하게 흐르며 글자 자체는 변형하지 않는다.
- **모션 그래픽:** 노크 알림 뒤 패널이 펼쳐지고, 초상 → 이름 → 직업·설명 → 대사 각 줄이 시간차를 두고 부드럽게 올라오며 나타난다. 타자기 효과 대신 줄 단위 클리핑·이동·페이드를 사용한다.

## 재생과 게임 연결

기존 준비 시간 5·30·60초의 실제 숙박 묶음 신호를 그대로 사용한다.
노크 알림 1.15초 뒤 손님 한 명당 약 7초씩 자동 재생하고 사라진다. 긴 대사는 조금 더 유지한다.
기본 정원 두 명과 증축 후 세 명을 실제 프로필 순서대로 보여 준다. [손님 확장](guest-roster.md)으로 기존 두 명에 다섯 명을 추가해 총 일곱 초상을 순환하며, 첫인사와 재방문 대사는 인물별 방문 횟수로 바뀐다.

모든 Control은 마우스 입력을 통과시키고 이 모듈에는 입력 처리 함수가 없다.
HUD 아래 CanvasLayer에서 재생하므로 손패·관리창·다른 알림을 계속 사용할 수 있다.
Esc는 게임의 원래 일시 정지 메뉴를 연다. 사용자가 직접 정지하면 소개 타임라인도 멈췄다가 이어진다.
전투·종료로 넘어갈 때는 남은 숙박 소개를 정리한다.

브람을 소개한 뒤 숙박 정산과 고용 제안, 용병 계약 카드까지 같은 이름을 유지한다.
첫 대사와 이후 묶음·일차에 따른 인사/소문은 `guest_profiles.gd`에서 편집한다.
새 미스터리의 진실이나 결말을 확정한 것은 아니다.

## 주요 파일

- `scripts/ui/guest_arrival.gd`: 플로팅 배치, 자동 순서와 모션, 노크 종소리. 시간 정지·BGM 변경 없음.
- `scripts/audio/sound_bank.gd`: 외부 선택 오디오 로딩은 유지하고, 독립 PCK에서 원본 파일 대신 import remap만 있는 경우에도 배경음을 읽도록 리소스 로딩 경로를 보완했다.
- `scripts/ui/guest_profiles.gd`: 손님 정보, 대사, 투명 초상 경로.
- `shaders/guest_ink_panel.tres`: UV·시간·파형·실루엣·색·출력으로 연결된 실제 VisualShader.
- `shaders/guest_portrait.gdshader`: 인물의 투명 실루엣 보존, 옷의 맨 아래 2.5%만 부드럽게 처리.
- `tools/build_guest_panel.gd`: VisualShader 그래프 재생성 도구.
- [투명 초상과 생성·편집 프롬프트](../godot/assets/portraits/README.md).
- `tools/verify_guest_arrival.gd`: 실제 렌더링·게임 입력·BGM 연속성·알파·모션 순서·셰이더 경계 변화 검증.

기존 자동 검증이나 녹화에서 소개를 생략할 때만 개발 인자 `-- --guest-intros=off`를 사용한다.
일반 실행은 자동 소개가 켜져 있다. 결과는 `output/guest-floating-v2/`에 저장한다.
이전 v1의 시간 정지·수동 진행·밝은 말풍선과 그 검증 기록은 현 버전의 동작 기준이 아니다.

## 실행판과 검증 결과

소스와 독립 PCK에서 각각 **48항목 통과**: 실제 도착, 배경 제거 알파, 시안 비율, 등장 순서, 실제 이동·줌·카드 집기·취소, HUD 유지, 게임 시간 진행, 동일 BGM 플레이어의 재생 위치 진행과 볼륨 유지, 자연스러운 자동 종료, 숙박·고용, 증축 정원, 원래 정지 메뉴·전투·종료 동작을 확인했다.
VisualShader를 별도 투명 뷰포트에 렌더링해 0초와 3초에서 가장자리 3879개 샘플의 알파가 실제로 변하는 것을 확인했다.
기존 카드 코어 **51항목**도 소개를 켠 기본 상태에서 통과했다.

새 패키지는 `build/WitchsLodge.pck`, 교체 전 패키지는 `build/WitchsLodge-before-floating-guests.pck`에 있다.
`게임실행.bat` 또는 `build/WitchsLodge.exe`로 실행한다.
`tools/record_guest_floating.gd`는 실제 배포 실행판에서 자동 소개와 계속 움직이는 월드를 녹화한다.
검토 GIF는 `art_sources/assemble_guest_preview.py`로 실제 렌더 프레임에서 만든다(비교 녹화는 낮 프리셋 사용).
