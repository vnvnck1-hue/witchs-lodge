# 용병 고유 키트 v02 — 특성 · 자동 스킬 · 카드 1장

작성 2026-10-25 · 상태: **발상 초안(미구현)** · 상위 방향: [코어 방향 재정립 §0](core-direction-kingdom-sts-v01.md) · 이전 판: [v01(카드 2장 구성, 대체됨)](mercenary-unique-kit-v01.md) · Claude

**검토·승인은 [카드 검토 페이지](../output/card-concept-review/card-concepts.html)의 `용병 고유 카드` 탭(`#mc`)에서 한다.** 항목마다 상세 동작·수치·이유가 있다. 이 문서는 같은 데이터(`output/card-concept-review/mercs.json`)의 요약이다. 이름·수치·문구는 모두 시험값이다. 세계 기준은 [전역 지침](../CLAUDE.md)의 중세 기반 판타지, 인물 설정은 [종족 손님 42명](races-guests-v01.md).

## 1. 사용자 결정 (2026-10-25)

1. 용병은 **롤토체스처럼** 게이지가 차면 고유 스킬을 자동으로 쓴다. 스킬은 강한 공격, 위치를 옮기며 치기, 특정 카드 생성 등. 기본은 오토배틀러이고 카드와 엮는다.
2. **플레이어 조작 마녀 캐릭터를 빼 보는 방향.**
3. 용병 = **특성(패시브) + 자동 스킬 + 카드 1장**(B안).

## 2. 공통 규칙

### R1 · 마녀 조작 캐릭터 없음

- 플레이어는 화면을 내려다보는 산장 주인 · 마녀는 산장 안에서 지켜보며 주문(카드)을 보내는 이야기 속 인물
- 마녀 클릭 이동·Q/E·마법탄·마녀 사망 패배를 뺀다(시험 방향).
- 패배: 산장 붕괴 또는 봉인석 균열 한도.
- 낮 행동은 클릭으로: 손님·브로크·모닥불·제단을 눌러 창을 연다.
- 늑대의 피 보름달은 용병 대상(예: 파르그 변신)으로 옮기는 안.
- 비교안: 군주형 마녀(깃발·시전 기점·운영의 손·왕관).
- 이유: 용병이 싸우는 오토배틀러에서 강한 마녀는 운영을 지운다. 먼저 빼 보고 판단한다.

### R2 · 용병 = 특성 + 자동 스킬 + 카드 1장

- 고용하면 특성·자동 스킬이 켜지고 · 고유 카드 1장이 밤 덱에 들어감
- 특성: 늘 켜진 패시브.
- 자동 스킬: 기세가 차면 스스로 쓴다(대상 규칙이 정해져 있음).
- 고유 카드: 플레이어가 쓰는 명령 1장. 해고하면 빠진다(덱 압축).
- 용병 상한 5명 → 용병 카드 최대 5장 + 임시 카드.
- 이유: 자동(스킬)과 수동(카드)을 깔끔하게 나눈다.

### R3 · 기세

- 전투직: 평타 +10, 피격 시 받은 피해만큼(1회 최대 +15) · 비전투직: 밤에 산장 안에서 초당 +4~5
- 인물마다 시전 기세 80~120. 시전 후 0.
- 이름과 색(금빛)을 플레이어 마력(푸른빛)과 구분.
- 용병 머리 위 기세 막대 + 초상 메달 체력 고리 안쪽 기세 고리. 시전 때 스킬 이름이 짧게 뜬다.
- 카드로 기세를 올리는 효과(+20~60)가 오토배틀과 카드를 잇는다.
- 이유: 롤토체스의 마나를 우리 말로. 가독성이 핵심.

### R4 · 자동 스킬 대상 규칙

- 스킬마다 '누구를·어디를' 고르는 규칙이 있다 · 예: 적이 가장 몰린 곳 · 체력이 가장 높은 적 · 가장 먼 적
- 대상 규칙은 카드에 적혀 플레이어가 예측할 수 있다.
- 사냥 표식 카드는 모든 대상 규칙보다 우선.
- 반짝이 미끼처럼 적을 모아 '가장 몰린 곳'을 유도하는 카드가 판을 짠다.
- 조건부 스킬(예: 체력 70% 이하일 때)은 조건이 맞을 때까지 기세 100에서 기다리되, 5초가 지나면 그냥 쓴다.
- 이유: 오토배틀러지만 플레이어가 읽고 조종할 수 있게.

### R5 · 카드 사용 방식(마녀 없이)

- 지점(그 용병 이동 후 시전) · 용병 본인 · 아군 용병 지정 · 시야 안 지점 · 즉시
- 지점: 놓은 곳으로 그 용병이 이동해 사거리에 들면 시전. 점선·도착 예상 시간 표시. 6초 안에 못 닿으면 취소·마력 반환.
- 용병 본인 / 아군 용병 지정: 월드 또는 초상 메달에 놓는다.
- 시야 안 지점: 산장·용병·감시탑이 밝힌 곳 어디든. 안개 속엔 못 쓴다.
- 즉시: 드로우·덱 조작·마력.
- 이유: 신의 손이 되어도 시야가 제약이 되어 배치가 중요하다.

### R6 · 임시 카드

- 비전투직 자동 스킬이 만드는 카드 · 마력 0, 이번 밤만, 새벽에 사라짐
- 손패가 가득하면 그 용병은 기세 100에서 기다린다(넘쳐서 사라지지 않음).
- 임시 카드는 덱에 들어가지 않는다 — 덱 순환과 별개.
- 고블린 3명 시너지(0마력 카드 드로우)와 맞물린다.
- 이유: 말씀하신 '카드를 만드는 고유 스킬'. 산장 안의 사람들이 밤에도 일한다.

### R7 · 거점 배치

- 낮에 초상 메달을 거점에 끌어 놓아 담당 지정 · 밤에는 카드(진격 나팔·도망쳐! 등)로만 옮김
- 거점 후보: 동·서 숲길 안쪽/바깥쪽, 산장 앞, 감시탑, 목장.
- 비전투직은 밤에 산장 안(배치 없음).
- 체력 30% 이하 용병은 산장으로 물러나 회복(두르가 특성 2배).
- 롤토체스의 칸 배치에 해당.
- 이유: 마녀 동행 대신 배치를 정하는 수단.

### R8 · 용병이 쓰러지면

- 고유 카드가 그 밤 동안 [빈자리]로 바뀜 · 자동 스킬·특성 꺼짐, 새벽에 정리
- 빈자리 카드는 쓸 수 없고 마력 1을 내고 버릴 수 있다.
- 다시 일어나는지(부상 이탈)는 허들 결정을 따른다.
- 샤가의 재의 축복이 보험.
- 이유: 용병을 잃는 아픔이 덱에도 남는다.

### R9 · 종족 시너지 2단계 · 원화 범위

- 같은 종족 2명/3명 이상 · 카드 24장 원화 + 스킬은 아이콘·이펙트
- 시너지는 종족 구역 맨 위에 있다.
- 고유 카드 24장: 1차는 인물 포맷에 기존 초상 재사용, 승인된 것부터 전용 원화(Codex). 카드 글자는 게임이 그린다.
- 자동 스킬은 카드가 아니므로 원화 대신 스킬 아이콘 24개와 이펙트.
- 이유: 제작량을 카드 48장 → 24장 + 아이콘으로 줄인다.

## 5. 설계 점검

- **직업별 역할:** 전투용병 = 탱커·도발·돌진(자동), 재배치·지역 장악(카드) / 사냥꾼 = 광역·저격·누적(자동), 표식·기세 조작(카드) / 나무꾼 = 임시 방책·속박 카드 생성, 창가 지원(자동), 길 통제(카드) / 채집가 = 회복·덱 다듬기(자동), 덱 엔진(카드).
- **카드가 오토배틀에 개입하는 네 갈래:** 대상 바꾸기(사냥 표식·반짝이 미끼), 기세 조작(나방 가루·매복·쓴 약·판돈 올리기), 재배치(진격 나팔·도망쳐!), 생존(맹세의 방패·재의 축복).
- **위험:** 임시 카드·드로우 엔진(타크·러스크·피클·모미·고블린 시너지)이 겹치면 손패가 넘친다 → 밤당 추가 드로우 상한을 시뮬로 정한다. 자동 스킬 5개가 동시에 터지면 읽기 어렵다 → 기세 고리·스킬 이름 표시·이펙트 정리가 먼저.
- **밸런스:** 오토배틀은 헤드리스 시뮬로 조합별 승률·밤별 산장 체력을 잴 수 있다(코어 방향 §5.4).

## 6. 진행

1. 사용자 검토(검토 페이지 `#mc`) → 승인분 확정.
2. 오토배틀 토대(마녀 제외 플래그, 거점 배치, 기세·자동 스킬 틀) → 인간 4명 키트로 시험. 헤드리스 검증.
3. 밤 덱 순환과 고유 카드 1장 편입.
4. 나머지 20명 + 종족 시너지.
