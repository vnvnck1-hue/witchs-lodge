# 신규 손님 다섯 명 · 총 일곱 초상

2026-10-15 · 기존 브람·미라에 올라프·토르빈·네리·오스윈·세라를 추가.

현재는 [손님 UI v4](guest-events-ui.md)에서 작은 도착 소개·산장으로 이동하는 초상·좌상단 말풍선과 인물별 선택형 대화까지 연결했다. 아래 v3 검증 수치는 추가 당시 기록이다.

| 인물 | 직업 | 소개의 인상 |
| --- | --- | --- |
| 브람 | 도끼 용병 | 마녀를 경계하지만 잠자리가 필요한 손님 |
| 미라 | 떠돌이 약초상 | 산장 불빛을 반가워하는 정중한 손님 |
| 올라프 | 경비 용병 | 수프와 지붕을 먼저 찾는 무뚝뚝한 실리파 |
| 토르빈 | 고참 용병 | 문과 창가를 살피는 말수 적은 호위꾼 |
| 네리 | 숲길 전령 | 호기심이 많고 겁을 농담으로 감추는 배달부 |
| 오스윈 | 유적 기록가 | 숲의 이상을 기록하는 조용한 학자 |
| 세라 | 떠돌이 교역상 | 소문보다 눈앞의 환대와 거래를 믿는 상인 |

각 인물은 고유 ID·초상·직업·설명과 세 가지 인사/숲의 소문을 갖는다. 숲의 소문은 손님의 경험과 주장으로, 미스터리의 진실을 확정하지 않는다.

## 실제 방문 순서

기본 두 명 정원에서는 첫날 **브람·미라 → 올라프·네리 → 토르빈·오스윈**, 이튿날 첫 묶음에서 **세라**가 등장한다. 용병 이름은 미사용 계약·활동 용병·기존 손님과 겹치지 않게 선택하며, 선호 용병이 이미 고용되어 있으면 기존 이름 풀에서 빈 이름을 고른다.

증축 뒤 세 번째 자리는 다음 일반 여행자가 채운다. 같은 묶음의 두 여행자는 서로 다른 인물이다.
인물별 방문 횟수로 첫인사와 재방문 대사를 바꾸며 낮이 바뀌어도 횟수를 유지한다.

새 용병은 기존 도끼 용병 계약·정산 규칙을 사용한다. 정원·숙박비·고용비·카드 능력과 월드 여행자 모델은 기존 시스템을 따른다.
초상과 텍스트는 기존 비차단 플로팅 UI에서 재생되며 게임·BGM·조작은 계속 유지된다.

## 에셋·검증

모든 새 초상은 built-in image_gen으로 각각 생성한 실제 투명 PNG이며 `godot/assets/portraits/guest_<id>_cutout.png`에 저장한다.
[에셋 목록과 전체 프롬프트](../../godot/assets/portraits/README.md).
`tools/verify_guest_roster.gd`는 일곱 정의와 PNG의 알파, 모든 대사의 표시 범위, 실제 이틀치 방문·정산·고용·재방문을 검사하고 실제 알림 화면을 캡처한다.
검증 출력은 `output/guest-roster-v3/`에 저장한다.

소스와 독립 PCK에서 각각 **95개 검사 통과**, 기존 카드 코어 **51개 검사 통과**.
기본 정원으로 이틀 동안 일곱 명이 모두 실제 숙박 묶음에 포함되는 것, 신규 다섯 PNG의 투명도와 모든 대사가 패널 안에 표시되는 것, 고용 이름과 비용이 유지되는 것을 확인했다.
`output/guest-roster-v3/new-guests.png`는 실제 패키지의 다섯 초상을 사용해 렌더링한 확인용 갤러리다.
