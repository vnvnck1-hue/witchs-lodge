# 용병 동행(사냥꾼·전투용병이 마녀를 따라 숲을 다닌다) — v1

2026-10-22 · 구현 Claude. 수치는 모두 `godot/scripts/config.gd`의 `ESCORT_*` 시험값이다.

마녀가 산장 주변을 벗어나 숲(전투 구역)으로 나가면 **사냥꾼·전투용병이 후다닥 따라나와** 마녀 곁에 붙어 다니며 함께 싸운다.
나무꾼·채집가·숲의 괴물 하수인은 지금처럼 자기 일을 한다.

## 사용자 확정(2026-10-22)

| 질문 | 결정 |
|---|---|
| 따라나오는 기준 | 마녀가 **산장 중심 14m 밖**으로 나가면 출발. **11m 안**으로 돌아오면 정찰로 복귀(히스테리시스). (처음 18/14 → 2026-10-22 사용자 요청으로 더 빨리 따라나오도록 당김) |
| 달리기 | **마녀와의 거리에 비례**해 빨라진다(멀수록 더 빨리 합류). 출발할 때든 필드에서 벌어졌을 때든 같다 |
| 밤(웨이브) | **낮에만 동행.** 밤에는 지금처럼 산장 수비(정찰·감시탑). 일몰이 되면 동행 중이던 용병은 산장으로 돌아가 정찰 |
| 길가 사냥 | 사냥꾼은 **마녀가 가만히 서 있을 때만** 주변(마녀 10m) 사냥감을 쏜다. **마녀가 움직이면 바로 사냥을 끊고 따라간다** |
| 부상자 | **무조건 따라온다.** 체력과 무관(모닥불 휴식 중이어도 나선다) |

## 행동

1. **출발**: 낮(준비 시간)이고 마녀가 산장 중심 `ESCORT_LEAVE_RADIUS`(14m) 밖이면 전투직(사냥꾼·전투용병)이 정찰·대기·사냥을 끊고 `ESCORT` 상태가 된다. 처음 나설 때 "용병 n명이 마녀를 따라 숲으로 나섭니다" 토스트 한 번.
2. **따라가기**: 마녀와 `ESCORT_FOLLOW_DIST`(전투용병 2.2m · 사냥꾼 3.0m · 짐을 든 사냥꾼 1.8m) 안이면 멈춰 서고, 멀어지면 다시 걷는다.
   속도는 **마녀와의 거리에 비례**한다: `ESCORT_SPEED_NEAR`(3m)에서 걷기(2.6m/s), `ESCORT_SPEED_FAR`(18m) 이상에서 `ESCORT_SPEED_MAX_MULT`(2.4배 → 6.2m/s), 그 사이는 선형. 6m에서 이미 3.8m/s로 마녀(3.5)보다 빠르고, 12m에서 5.0m/s. 필드에서 벌어졌을 때도 같은 식으로 빨라져 합류한다.
   `ESCORT_WARP_DIST`(30m)보다 멀어진 채 `ESCORT_WARP_TIME`(4초)이 지나면(막힘·끼임 안전장치) 마녀 근처 이동 가능 지면으로 순간이동(포프 연출).
3. **전투**: 동행 중에는 산장 기준이 아니라 **마녀 기준**으로 적을 찾는다. 마녀 `ESCORT_ENGAGE_RADIUS`(10m) 안의 `enemies`(맹독 곤충 포함, 밤 웨이브 적 포함)를 발견하면 교전. 대상이 마녀에게서 `ESCORT_DISENGAGE_RADIUS`(14m) 밖으로 벗어나면 놓아주고 다시 따라간다. 공격 방식(활 7m·검 1.3m·피해·간격)은 기존과 같다.
4. **길가 사냥(사냥꾼)**: 마녀가 `ESCORT_STILL_TIME`(0.6초) 이상 제자리에 서 있으면 마녀 `ESCORT_HUNT_RADIUS`(10m) 안 토끼·사슴을 쏜다. 마녀가 움직이기 시작하거나 사냥감이 그 반경 밖으로 달아나면 사냥을 끊고 바로 따라간다. 전리품은 기존처럼 들고 다니다 마녀 2.2m 안에서 건넨다.
5. **복귀**: 마녀가 산장 중심 `ESCORT_RETURN_RADIUS`(11m) 안으로 돌아오거나, 일몰(웨이브 시작)이 되거나, 마녀가 쓰러지면 동행을 끝내고 정찰로 돌아간다. 교전 중이면 교전을 마친 뒤 산장 규칙(DISENGAGE 18m)으로 놓아준다.
6. **동행 중에는 모닥불 휴식을 가지 않는다**(부상자도 따라옴). 밤에 하던 감시탑 배치는 낮이라 해당 없음.

## 상태·표시

- `ally.gd`에 `State.ESCORT` 추가, `escort` 플래그가 교전·사냥 중에도 "지금 마녀 기준으로 판단 중"임을 기억한다.
- 명부·초상 메달 상태: "마녀와 동행 중" / 머리 위 "동행". 영문 "Escorting the witch" / "Escort".

## 구현

- `godot/scripts/config.gd`: `ESCORT_*` 상수.
- `godot/scripts/actors/ally.gd`: `_update_escort()`(출발·복귀 판정), `_escort()`(따라가기·달리기·워프·길가 사냥 시작), `_find_enemy()`/`_engage()`/`_hunt()`의 마녀 기준 분기, 상태 문구, `interrupt()`에서 동행 해제.
- `godot/scripts/game/contract_director.gd`: `note_escort_start()` — 출발 토스트를 3초 안에 한 번으로 묶는다.
- `godot/assets/i18n/en.json`, `tools/i18n/overrides.json`: 영문 문구.

실제 장면에서 전투용병·사냥꾼을 고용하고 마녀를 산장 14m 밖에 세워 출발 → 거리 비례 달리기(멀수록 빠르고 가까워지면 느려짐) → 접근 거리 → 필드에서 벌어지면 다시 달려 합류 → 마녀 곁 적(맹독 곤충) 교전 → 처치 뒤 다시 동행 →
마녀가 서 있을 때 사냥꾼 사냥 시작 → 마녀가 움직이면 사냥 중단 → 마녀 복귀 시 정찰 → 밤에는 출발하지 않음 → 나무꾼은 따라오지 않음을 확인한다.
