# 손님 도착 · 대화 이벤트 UI v4

2026-10-15 · 카드 위의 작은 도착 소개, 산장으로 이동하는 초상, 선택형 대화와 손님 관리.

**대사 전환 수정(2026-10-15):** 대화창을 처음 열 때만 인물·정보 등장 연출을 재생한다. 같은 대화를 이어가거나 선택에 따른 반응·마무리로 넘어갈 때는 초상·이름·직업·패널을 유지하고 대사 텍스트만 즉시 갱신한다.

이 수정은 소스 121항목·실행판 130항목 검증을 통과했다. 반응과 마무리 전환에서 정보·패널의 등장 연출이 재시작되지 않는 것과 대사가 즉시 교체되는 것을 포함한다. 검증 기록은 `output/guest-dialogue-text-update/`, 수정 전 백업은 `build/WitchsLodge-before-dialogue-text-update.pck`에 있다.

## 실제 플레이 흐름

준비 시간 5·30·60초의 실제 방문 묶음으로 작동한다. 0.6초의 도착 알림 뒤 각 손님을 손패 바로 위에서 소개한다. 초상·이름·직업·대사를 순차 표시하고, 대사 길이에 따라 한 사람당 약 3.4~5초 유지한다. 화면 너비 약 32%이며 어두운 패널을 가로로 넓혀 대사를 최대 세 줄로 정리한다.

소개가 끝나면 패널과 글자만 먼저 사라지고, 인물 초상이 0.65초 동안 작아지며 오른쪽 아래 **산장 관리** 버튼으로 이동한다. 창 크기가 바뀌어도 실제 버튼 위치를 계속 추적한다. 도착을 마친 초상마다 손님 수 배지와 짧은 원형 반응을 표시한다. 도착 소개는 게임 시간·카드·이동·HUD·BGM을 계속 유지한다.

소개를 마친 손님은 2초 뒤 왼쪽 위에 초상과 짧은 말풍선으로 말을 건다. 대화는 자동으로 열리지 않는다. 말풍선을 클릭하면 이전 큰 중앙 초상 UI로 전환해 **손님의 이야기 → 마녀의 답변 두 가지 → 선택에 따른 반응 → 마무리**를 진행한다. 대사는 손님의 경험을 표현하며 숲의 진실을 확정하지 않는다.

직접 연 대화 중에는 준비 시간이 멈춘다. 재생 중인 BGM 플레이어를 그대로 유지해 음악은 이어진다. 다음 버튼 또는 Enter/Space로 진행하고 선택지는 클릭하거나 방향키/Tab으로 고른 뒤 Enter/Space로 결정한다. Esc/돌아가기는 완료 처리 없이 닫는다. F11 전체화면 전환도 가능하다.

## 산장 관리

- **시설:** 기존 객실·목장·묘지 증축, 양 구입, 수리, 회복.
- **손님:** 현재 방문 인물·초상·상태, 대화 시작/완료, 실제 고용 기회가 있을 때 기존 비용의 용병 계약.
- **대화 기록:** 이 실행에서 완료한 대화의 날짜·인물·제목과 실제 선택을 포함한 대화 전문.

손님이 있으면 오른쪽 아래 관리 버튼은 손님 탭을 먼저 연다. 건물을 클릭하면 시설 탭이 열린다. 관리창에서 연 대화를 마치면 손님 탭으로 돌아간다. 퇴실·고용·전투 전환 때 현재 손님과 미완료 알림을 정리하고, 완료 기록은 유지한다. 같은 인물의 완료한 이야기는 재방문 시 자동으로 다시 알리지 않는다. 손님 탭에서 다시 이야기를 들을 수 있으며 각 방문에서는 한 번만 완료 기록을 남긴다. 영구 저장은 기존 프로토타입과 같이 이번 범위에 없다.

## 일곱 인물의 대화

| 인물 | 이야기 |
| --- | --- |
| 브람 | 숲길에서 자기 목소리가 자신을 부른다 |
| 미라 | 겨울에도 자라며 숲을 향하는 약초 |
| 올라프 | 숲으로 들어간 흔적만 남은 발자국 |
| 토르빈 | 성당이 없는 산길에서 들린 종소리 |
| 네리 | 받는 이 없이 산장만 그려진 편지 |
| 오스윈 | 세 번 베꼈는데 서로 달라진 문양 |
| 세라 | 여섯 개에서 일곱 개로 늘어난 유리병 |

[다섯 신규 인물의 초상과 방문 순환](guest-roster.md). 대화 선택은 이야기만 바꾸며 보상·가격·전투 능력을 추가하지 않는다.

## 편집 위치와 검증

- `godot/scripts/ui/guest_arrival.gd`: 작은 자동 소개·초상 이동, 중앙 대화 표현 모드.
- `godot/shaders/guest_portrait_motion.gdshader`: 초상 아이들링·등장 가슴 모핑(에린). [erin-portrait-motion.md](erin-portrait-motion.md)
- `godot/scripts/ui/guest_interactions.gd`: 말풍선 클릭·대화 진행·시간 정지/BGM 유지·관리 탭.
- `godot/scripts/game/guest_events.gd`: 실제 방문 ID, 도착 완료, 대화 대기·완료·퇴실과 기록.
- `godot/scripts/game/guest_dialogues.gd`: 일곱 대화와 각 두 답변.
- `godot/scripts/ui/guest_profiles.gd`: 일곱 초상·직업·세 가지 도착 인사.
- `godot/tools/verify_guest_events.gd`: 실제 렌더·클릭·대화 양쪽 분기·기록·관리·수리·고용·시간/BGM·해상도·패배 전환 검사.

독립 PCK의 실제 렌더 검증 **126항목 통과**, 소스의 headless 검증 **117항목 통과**(화면 캡처 9항목 제외), 현재 인물 순환 **88항목 통과**, 기존 카드 코어 **52항목 통과**. 출력은 `output/guest-events-v4/`, 실행판 검증과 화면은 그 안의 `pack/`에 저장한다. 초상·인사와 두 답변을 포함한 모든 대사는 실제 글꼴로 표시 범위를 검사한다. 기존 v2의 48항목 검증과 v3의 95항목 기록은 당시 레이아웃의 기록이다.

배포 데이터는 `build/WitchsLodge.pck`, 교체 전 백업은 `build/WitchsLodge-before-guest-events-v4.pck`. `게임실행.bat` 또는 `build/WitchsLodge.exe`로 실행한다. 기존 개발용 `-- --guest-intros=off`는 도착 소개만 생략하며 실제 손님 이벤트 등록은 유지한다.

`godot/tools/record_guest_events.gd`로 도착부터 대화 종료까지 실제 렌더 프레임을 녹화한다. 검토용 낮 프리셋을 사용하며 게임 기본 화면 설정은 바꾸지 않는다.
