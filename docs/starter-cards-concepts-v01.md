# 시작 카드 재기획 — 컨셉 아이디어 모음 (v01)

작성 2026-10-25 · 사용자 요청 "현재 시작 카드가 너무 빈약하다, 새로운 컨셉의 시작 카드를 기획하자"에 대한 **발상 초안**이다. 이름·수치·문구는 모두 제안이며, 채택한 것만 규칙 문서와 `catalog.json`으로 옮긴다. 세계 기준은 [전역 지침](../CLAUDE.md)의 중세 기반 판타지, 연관 문서는 [네 마녀](four-witches-v01.md)·[덱 아키타입](deck-archetypes-v01.md)·[낮·밤 손패](hand-draw-flow-design-v01.md)·[하스스톤 차용 카드](hearthstone-inspired-cards-v01.md).

## 1. 지금 시작 카드 진단

현재 `Cfg.STARTER_CARDS`(config.gd:133) 6장, 시작 손패 3장 무작위.

| 카드 | 낮/밤 | 하는 일 |
| --- | --- | --- |
| 서리 룬 | 밤 | 범위 폭발 + 둔화 |
| 수호 등불 | 낮(설치) | 빛 안의 적 둔화 |
| 숙박 초대장 | 낮 | 손님 1명 부르기 |
| 새끼양 | 낮 | 목장에 양 1마리 |
| 잠자는 가시 씨앗 | 낮 | 자라서 밤에 방책 |
| 목장의 검은 양 | 낮 | 목장에 검은 양 1마리 |

빈약하게 느껴지는 이유:

1. **전부 "한 번 놓으면 끝"인 소모품이다.** 다 쓰고 나면 시작 카드는 기억에 남지 않는다. 키우고, 다시 쓰고, 바뀌는 카드가 없다.
2. **밤 카드가 서리 룬 1장뿐이다.** 첫 밤 손패는 사실상 룬 하나와 공격 버튼이다.
3. **가축이 2장 겹친다**(새끼양·검은 양). 6장 중 2장이 같은 동사.
4. **선택이 없다.** 매 판 같은 6장, 같은 출발. 주요 종족 둘이 바뀌는 판인데 시작은 늘 같다.
5. **마녀의 정체성이 약하다.** 북쪽 마녀(서리·보호·봉인)라는 색이 룬 1장에만 있다. "내 마녀의 물건"이라는 느낌이 없다.
6. **이야기가 없다.** 산장을 처음 여는 마녀가 무엇을 들고 왔는지, 누가 남긴 것인지가 카드에 없다.

아래 컨셉은 이 여섯 가지 중 무엇을 푸는지 함께 적는다.

## 2. 컨셉 아이디어 12가지

### A. 서명 카드 — 매일 손으로 돌아오는 마녀의 물건 (풀이: 1·5)

소모되지 않는 **고유 카드 1장**. 쓰면 버림패가 아니라 다음 새벽(또는 해질녘)에 손패로 돌아온다. 하스스톤 영웅 능력, 슬레이 더 스파이어의 기본 카드 자리.

- **마녀의 빗자루** — 낮: 산장 한 칸 청소(손님 만족 +), 밤: 마녀 짧은 돌진 회피.
- **서리 지팡이 끝** — 낮: 모닥불·화덕에 냉기를 걸어 음식 보존(스튜 하루 더), 밤: 작은 서리 화살 3발.
- **봉인 열쇠** — 하루 한 번, 손패 1장을 "봉인"해 주머니로 돌리지 않고 다음 낮/밤까지 보관.

손패 칸을 1칸 차지하는 대신 항상 쓸 거리가 있다. 손패 크기와 맞물려 균형을 본다.

### B. 낮·밤 양면 카드 — 해질녘에 뒤집히는 생활 도구 (풀이: 2·1)

지금 손패 규칙은 "낮 카드는 밤에 주머니로". 양면 카드는 **주머니로 가지 않고 뒤집혀 남는다.** 중세 산장의 평범한 생활 도구가 밤에는 방어 도구가 되는 맛.

| 카드 | 낮 면 | 밤 면 |
| --- | --- | --- |
| **건초 더미** | 목장 가축 먹이(성장 하루 단축) | 불을 붙여 길목 화염 방벽 |
| **빨랫줄** | 양털·가죽 말리기(가공 자원 +1) | 걸린 적 속박 2초 |
| **양치기 종** | 흩어진 가축 모으기·손님 호객 | 울리면 주변 적 어그로를 산장 문으로 |
| **소금 항아리** | 고기 절이기(생고기 → 보존육) | 문턱에 뿌려 망령·언데드 진입 차단 |
| **물레** | 양털 → 실(장비 수선 재료) | 서리 실을 짜 적 둔화 그물 |

시작 덱에 2~3장만 넣어도 첫 밤 손패가 두꺼워진다.

### C. 선택형 시작 꾸러미 — 판 시작 때 셋 중 하나 (풀이: 4·3)

첫 새벽(멀리건 화면 자리)에 **꾸러미 3개 중 1개**를 고른다. 공통 3장 + 꾸러미 3장.

| 꾸러미 | 들어 있는 것 | 덱 방향 |
| --- | --- | --- |
| **양치기의 짐** | 새끼양·검은 양·양치기 종 | 목장·양털 경제, 파르그 늑대의 피 루트 |
| **여관 주인의 장부** | 숙박 초대장 2장·환영의 빵 | 손님 많이 받기 → 용병·종족 덱 빨리 굴리기 |
| **파수꾼의 상자** | 서리 룬·수호 등불·가시 씨앗 | 첫 며칠 방어 안정 |
| **약초꾼의 바구니** | 약초 씨앗·이끼 붕대·독버섯 | 회복·독, 동쪽 마녀 맛보기 |

꾸러미 해금을 업적·챕터 보상으로 묶으면 메타 진행 축도 생긴다.

### D. 선대 주인의 유품 — 산장에 남아 있던 물건 (풀이: 6·1)

마녀가 산장을 "물려받았다"는 서사. 시작 카드 일부가 **전 주인이 남긴 유품**이고, 특정 조건에서 비밀이 풀린다.

- **낡은 숙박 장부** — 쓰면 손님 1명. 장부에 이름이 3명 쌓이면 "단골" 페이지가 열려, 고른 종족 손님을 한 명 지명해 부른다.
- **녹슨 열쇠 꾸러미** — 산장의 잠긴 방(헛간·지하 저장고·다락)을 하나 연다. 방마다 다른 보상(장비 1·자원 꾸러미·유물 단서).
- **금 간 수정구** — 오늘 밤 올 적 무리를 미리 보여 준다. 세 번 쓰면 깨지며 "선대 마녀의 마지막 예언" 사건.
- **할머니의 앞치마** — 장신구. 요리 결과물 +1. 입고 있으면 가끔 선대 마녀의 혼잣말(대사).

### E. 첫 동료 카드 — 처음부터 곁에 있는 작은 존재 (풀이: 2·6)

혼자 시작하는 마녀에게 **반려 사역마 1장**. 인물 포맷.

- **늙은 양치기 개 '보리'** — 낮엔 가축 지킴, 밤엔 산장 문 앞 짖어 적 위치 표시. 죽지 않고 지치면 쉰다.
- **서리 까마귀** — 하늘에서 안개를 걷어 시야. 다른 카드로 "물어 오기"(버림패 1장 회수).
- **고양이 사역마 '잿빛'** — 손패 1장을 훔쳐 와 다음 날 돌려준다(카드 보관·지연). 쥐 떼 사건 방지.

캐릭터 3D가 필요하므로 [캐릭터 3D 프로세스](character-3d-pipeline.md) 비용이 붙는다. 우선은 초상 메달 + 기존 모델 재사용으로 시험 가능.

### F. 부화·성장 카드 — 품고 기다리는 시작 카드 (풀이: 1)

잠자는 가시 씨앗의 방향을 넓힌다. 시작부터 **시간이 지나야 진가가 나오는 카드** 1~2장.

- **서리 까마귀 알** — 산장 화덕 곁에 두면 3일 뒤 부화 → E의 서리 까마귀 사역마.
- **겨울 사과 묘목** — 7일째 첫 열매. 열매 = 회복·손님 대접·상인 판매용.
- **봉인석 조각** — 밤을 넘길 때마다 금이 메워진다(0/5). 다 메우면 유물 "온전한 봉인석"(챕터 서사와 연결).

### G. 진화하는 기본 주문 — 쓸수록 바뀌는 룬 (풀이: 1·5)

서리 룬을 **성장 카드**로 바꾼다. 하스스톤 퀘스트·카드 진화 문법.

- 서리 룬 → 적 10마리 얼림 → **서리 문양**(범위 ×1.5) → 적 25마리 → **겨울 봉인**(밤 1회, 화면 전체 3초 정지).
- 진행도는 카드 배지에 숫자로 표시(`badge`). 시작 카드가 판 끝까지 주인공이 된다.

### H. 빚과 약속 — 처음부터 쥐고 시작하는 목표 (풀이: 3·6)

**부정적인 시작 카드**로 판의 첫 목표를 준다. 서쪽 마녀(계약) 맛보기.

- **영주의 세금 고지서** — 손패 1칸 차지. 7일째 새벽까지 금화 100을 산장 관리창에서 내면 사라지고 "영주의 인장"(상인 할인) 보상. 못 내면 침식 카드 2장.
- **마을 사람과의 약속** — "양털 5개를 겨울 전에". 지키면 인간 손님 확률↑.

긴장감을 주지만 초심자에게 부담이므로 C의 선택형 꾸러미 중 하나("빚진 마녀" 하드 꾸러미)로 넣는 것이 안전하다.

### I. 정보·탐색 카드 — 덱 방향을 고르게 돕는 카드 (풀이: 4)

이번 판의 주요 종족 둘을 일부러 숨기는데, 시작 카드로 **엿볼 수단**을 준다.

- **찢어진 숲 지도** — 근처 종족 마을 하나의 위치·종족 공개(엘리스 지도 컨셉과 연결).
- **나그네의 소문** — 내일 올 손님 둘의 종족을 미리 보고, 그중 1명을 오늘 밤으로 당긴다.
- **산장 간판** — 걸어 둔 종족 그림(고를 수 있음)에 따라 그 종족 손님 확률↑. 종족 덱을 일찍 정하는 장치.

### J. 네 마녀별 시작 덱 — 마녀마다 다른 출발 (풀이: 5·4·6)

[네 마녀](four-witches-v01.md)의 권능을 시작 덱에 그대로 옮긴다. 마녀 선택이 곧 시작 덱 선택.

| 마녀 | 시작 덱 성격 | 대표 시작 카드 예 |
| --- | --- | --- |
| **북쪽(현 주인공)** — 서리·보호·봉인 | 방어·안정, 양 목장 | 서리 룬(진화형), 수호 등불, 봉인 열쇠(서명), 새끼양, 건초 더미(양면), 녹슨 열쇠 꾸러미 |
| **동쪽** — 생명·약초·성장 | 씨앗·회복·사역마 | 가시 씨앗 ×2, 약초 씨앗, 이끼 붕대, 다람쥐 사역마, 물뿌리개(서명: 식물 성장 하루) |
| **남쪽** — 불·솥·변환 | 화력·요리·주점 | 화염병, 대솥(서명: 재료 2장 → 비약), 생고기, 맥주통, 숙박 초대장, 장작 |
| **서쪽** — 저주·계약·망령 | 약화·대가·언데드 입문 | 저주 인형, 피의 계약서, 낡은 숙박 장부, 촛대 망령, 세금 고지서(빚), 망자의 동전 |

지금은 북쪽만 손보고, 다른 마녀는 챕터 확장 때 같은 틀로 채운다.

### K. 따뜻한 첫 손님 선물 — 프롤로그 동반 카드 (풀이: 6)

시작 카드 일부를 **도입부 사건에서 받는** 형태로 바꾼다. 같은 카드라도 "누가 줬는지" 기억이 남는다.

- 첫 손님(인간 나그네)이 숙박비 대신 **"나그네의 장화"**(장비)와 **"편지 한 통"**(다음 손님 지명)을 놓고 간다.
- 마을 양치기 소녀가 **새끼양**을 맡기고 간다 → 다 키워 돌려주면 보상, 안 돌려주면 내 양.

### L. 부적·의식 재료 — 작고 싸지만 조합되는 카드 (풀이: 1·3)

1장으로는 약하지만 **다른 카드에 붙이면 강해지는** 작은 재료. 덱빌딩의 "조합" 손맛.

- **마가목 가지** — 등불에 붙이면 빛 반경 +50%, 룬에 붙이면 범위 +1m.
- **검은 털 한 줌** — 의식·주문에 붙이면 효과 1회 반복.
- **눈 녹은 물 한 병** — 씨앗에 붓으면 즉시 하루 성장, 적에게 뿌리면 둔화.

## 3. 추천 조합 — 북쪽 마녀 새 시작 덱(안)

위 컨셉에서 지금 시스템과 가장 잘 붙고 제작 비용이 낮은 조합.

**공통 시작 4장 + 꾸러미 3장(선택) = 7장, 시작 손패 3장 유지**

| 자리 | 카드 | 컨셉 | 낮/밤 |
| --- | --- | --- | --- |
| 서명 | **봉인 열쇠**(또는 서리 지팡이 끝) | A | 양쪽, 매일 돌아옴 |
| 공통 | **서리 룬**(진화형) | G | 밤 |
| 공통 | **건초 더미** | B | 양면 |
| 공통 | **녹슨 열쇠 꾸러미** | D | 낮 |
| 꾸러미 | 양치기의 짐 / 여관 주인의 장부 / 파수꾼의 상자 중 택1 | C | — |

- 첫 밤 손패: 서명 + 룬 + 건초 더미(밤 면) → 밤 카드 최소 3장.
- 매 판 꾸러미 선택으로 출발이 달라진다.
- 서리 룬 진화와 열쇠 꾸러미 방으로 "판 내내 남는 시작 카드"가 생긴다.

## 4. 정해야 할 것 (사용자 질문)

1. **방향**: 위 컨셉 중 끌리는 것 2~4개는? (추천: A 서명 + B 양면 + C 꾸러미 + G 진화 룬)
2. **장수**: 시작 덱을 지금 6장 근처로 둘지, 8~10장으로 두껍게 할지.
3. **선택 여부**: 매 판 같은 시작(고정)인가, 꾸러미 선택(C)인가.
4. **부정적 시작 카드(H 빚)**를 기본에 넣을지, 하드 옵션으로만 둘지.
5. **동료(E)**처럼 새 캐릭터 3D가 필요한 컨셉을 이번에 넣을지, 뒤로 미룰지.
