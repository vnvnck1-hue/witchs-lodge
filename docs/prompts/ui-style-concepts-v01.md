# UI 아트 시안 생성 프롬프트 · v01

도구: 내장 image_gen, transparent_background=true. 각 스타일을 별도 호출했다.

입력 1: `output/ui-style-concepts-v01/source-toon-default-clean.png` — 실제 소스 실행 캡처, 배치 참고.
입력 2: `godot/screenshots/cards/asset-gallery.png` — 기존 승인 카드 스타일 참고.

최종 합성 배경: 새로 실행한 배포판의 `pack-toon-default-clean.png`. 투명 UI 아트를 Godot Control/AtlasTexture로 배치하고 캡처했다. 배경을 생성하거나 재그리지 않았다.
