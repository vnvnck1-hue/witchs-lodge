# 원화에 맞춘 3D 프랍 수정 기록

2026-10-13. **진행 중**이다. 아래 게임 렌더는 실제 Godot 4.7.2 Forward+ 뷰포트이며, 원화와 최대한 동일한 상태에 도달했다고 평가하지 않는다.

## 비교 기준과 실제 결과

구도·프랍 수·표면 밀도는 사용자가 승인한 [04 원화](../art/concepts/environment/04-prototype-reference-simplified.png)를 따른다. 배경색을 접목한 숲의 어둠은 [최신 07 분위기 수정본](../art/concepts/environment/07-colored-forest-darkness.png)을 비교한다. 이전 06도 보존한다. 현재 실행 데이터는 **v23**다.

![원화와 실제 렌더 비교](../godot/screenshots/art-refinement/comparison-v23.png)

[최신 시작 화면](../godot/screenshots/art-refinement/v23-pack-start.png), [방문자](../godot/screenshots/art-refinement/v23-pack-guests.png), [증축 화면](../godot/screenshots/art-refinement/v23-pack-extension.png), [전투](../godot/screenshots/art-refinement/v23-pack-combat.png), [용](../godot/screenshots/art-refinement/v23-pack-dragon.png). 모두 갱신한 Windows 실행 파일에서 캡처했다. `before.png`, `v01`~`v23`는 단계별 비교 기록이다. 테스트용 `flat`, `no_ssao`, `no_shadow` 캡처는 원인 분리용이며 최종 라이팅이 아니다.

v23에서는 나무의 분리된 방사형 가지를 5단의 연결된 가지 덩어리로 교체했다. 각 단의 눈은 가지와 같은 높이 곡선을 따라 정상에서 넓게 펼쳐지고, 상단의 눈 양을 늘렸다. 나무 에셋은 11개 메시·3,880폴리곤이며 나무 수는 유지한다. 바위는 넓은 밑면과 기울어진 큰 옆면, 끊어진 균열, 부드러운 눈 가장자리로 수정하고 UV를 덩어리 전체에 연속으로 배치했다. 지붕에는 굵은 교차 장식과 돌출 목재를 추가하고 굴뚝과 연기 앵커를 함께 +X로 0.8m 옮겼다. 숲 가장자리의 눈·프랍·지면에는 더 짙은 보라·청록 색 마스크를 적용하고 중앙 지면의 주황색을 완화했다. 카메라, 배치된 프랍 수, 게임 진행과 기존 충돌 형상은 변경하지 않았다.

## 수정한 실제 에셋

Blender의 `bpy` 생성 스크립트로 메시·UV·재질을 작성하고 GLB로 내보냈다. 수작업 스컬프팅 결과라고 표시하지 않는다.

- 산장: 기단의 개별 돌, 두꺼운 목재 프레임, 아치 문, 창틀, 눈 지붕, 굴뚝. 따뜻한 개별 벽돌과 석재 계단을 추가하고 지붕 눈의 색과 곡률을 조정했다.
- 침엽수: 원뿔 블록아웃을 5단의 닫힌 가지 덩어리와 별도 눈 덮개로 교체했다. 눈이 잎에 묻히거나 각진 끝으로 잘리던 문제를 조정하고 눈 양을 줄였다. 나무 수는 18그루다.
- 바위: 높이가 다른 주암·부암과 작은 돌, 비대칭 절단면, 개별 눈 덮개. 하나의 넓고 평평한 눈 덩어리로 보이던 실루엣을 수정했다.
- 판석: 불규칙한 외곽선, 큰 크기, 마녀를 향해 굽는 배치.
- 통·통나무·장작·건초·수풀·양·마녀·지팡이: 실제 GLB와 페인터리 재질로 교체했다.
- 증축: 본채와 같은 눈 지붕·목재·기단·창문으로 된 GLB로 교체했다.
- 여행자: 겨울 코트·털 후드·배낭·침낭·지팡이의 GLB로 교체했다.
- 숲 괴물: 보라색 잎 외피·굽은 뿔·황록색 눈을 가진 GLB로 교체했다.
- 용: 몸·목·머리·날개를 독립 GLB로 만들고 기존 날갯짓·고개 움직임·발사 앵커에 연결했다. 넓은 비늘과 날개막 붓질을 추가하고 붉은색을 조정했다.
- 목장 문: 울타리와 맞는 두꺼운 목재·둥근 모서리로 교체했다. 폭발의 불투명한 원과 강한 섬광을 줄여 모델과 전장이 읽히도록 했다. 피해 반경·피해량은 그대로다.

모델 원본: [환경 생성 스크립트](../godot/art_sources/build_painted_assets.py), [캐릭터 생성 스크립트](../godot/art_sources/build_character_assets.py), [편집용 Blender 파일](../godot/art_sources/painted_assets.blend), [19개 에셋의 메시 기록](../godot/art_sources/asset_evidence.json). GLB는 `godot/assets/painted/`에 있다. 좌표는 Y 위, 정면 +Z, 바닥 피벗이다. Blender 파일은 에셋별 컬렉션으로 나누고 기본으로 본채만 표시한다. 캐릭터 스크립트는 환경 13개를 먼저 재생성한 뒤 캐릭터 파트 6개를 추가한다.

## 텍스처와 조명 방식

`material_atlas.png`는 내장 image_gen으로 새로 생성한 목재·돌·눈·잎·양털·건초의 6칸 디퓨즈 아틀라스다. 원화의 프랍 이미지를 평면으로 잘라 표시한 것이 아니다. `ground_cleanplate.png`는 원화에서 모든 프랍과 조명 웅덩이를 제거하도록 image_gen으로 편집한 지면 이미지다.

원본 생성 파일은 각각 `exec-ff935bf2-cc07-44f0-a159-e027a7362b38.png`, `exec-a43ca2f3-491c-4845-a206-c594e1119dbf.png`이며 프로젝트 안에 결과를 보존한다.

`character_atlas.png`는 내장 image_gen으로 생성한 비늘·날개막·보라색 잎·가죽의 4칸 아틀라스다. [최종 프롬프트와 생성 기록](../godot/art_sources/character-atlas-prompt.md)을 보존한다. 런타임 재질에서 각 파트의 색과 텍스처 빈도를 조정한다. 숲 가장자리에는 지면 셰이더의 공간 마스크로 보라·청록의 유색 어둠을 더했다.

지면에는 기준 카메라의 화면 좌표로 UV를 계산해 길과 색 덩어리를 배치했다. 지면의 안개·붓질은 텍스처에 포함되어 있고, 별도의 체적 안개 시뮬레이션이나 실시간 전장의 안개 시스템은 아니다. 지면의 앰버색 웅덩이는 셰이더의 공간 색 마스크와 실제 국소 광원을 혼합한다. 카메라를 자유롭게 바꾸는 제품에서는 지면 UV를 다시 설계해야 한다.

무광 프랍은 실제 달빛·국소광·그림자와 약한 페인터리 보조광을 사용한다. GLB의 양면 표시를 재질 교체 후에도 유지한다. 얇은 눈 덮개의 그림자 얼룩을 줄이기 위해 눈 재질은 그림자를 받지 않고, 다른 프랍과 건물·지면은 실제 그림자를 유지한다. 따라서 모든 면이 물리 기반 셰이딩만으로 원화 색을 재현하는 구조는 아니다.

현재 카메라: 정사영, 수평 35°, 하향 50°, size 21, 화면 비율 2:1. 숫자는 생성 이미지에서 추출한 카메라 값이 아니라 실제 렌더를 비교해 조정한 값이다.

## 검증과 남은 차이

실제 Windows 실행 파일의 시작·방문자·증축·전투·용 장면과 UI 없는 화면을 캡처했다. `WitchsLodge.pck`를 v23으로 갱신했고 이전 데이터는 `WitchsLodge-before-art.pck`로 보존했다. v23의 임포트·내보내기·6개 실행 캡처는 종료 코드 0이며 오류 로그는 비어 있다. [실제 GLB·캡처·PCK 해시 기록](../godot/art_sources/refinement_evidence-v23.json)을 함께 보존한다.

게임 진행과 충돌은 기존 구현을 유지한다. v22 소스 자동 플레이에서 확인한 3웨이브 VICTORY, 용의 연속 구매 중복 차감 방지, 양 3마리 생존 결과도 보존한다. t=348.6, 숙박 수입 360G, 산장 체력 295, 플레이어 체력 95이며 로그는 `godot/art_sources/autoplay-v22.log`다. 이 결과를 v23 자동 플레이를 새로 실행한 결과로 표시하지 않는다.

완료 판단 전에 더 맞춰야 할 부분:

1. 침엽수는 연결된 구조로 수정됐지만 단과 눈 무늬의 반복이 강하다. 원화의 불규칙한 눈 처짐과 풍성한 잎 끝을 더 맞춰야 한다.
2. 바위는 큰 면과 균열을 수정했지만 외곽과 눈 덮개가 원화보다 규칙적이고 매끈하다. 새 시각적 외곽과 기존 단일 원통 충돌 형상의 일치도 추가로 확인해야 한다.
3. 산장의 장식, 목재·지붕 색면과 표면 빈도, 전면 실루엣에 차이가 남아 있다.
4. 지면 붓질·연기·숲 가장자리 안개는 원화의 층과 다른 부분이 있다. 지면의 안개는 고정된 이미지와 색 마스크다.
5. 새 여행자·괴물·용의 모델은 연결됐지만 원화의 부드러운 외피와 비례를 더 맞출 필요가 있다. 특히 용의 날개막은 실루엣이 각지고 주름이 부족하다.

목표는 여전히 원화에 최대한 가까운 모델링·라이팅·텍스처링이며, 플레이 검증 통과를 시각적 완료의 근거로 사용하지 않는다.
