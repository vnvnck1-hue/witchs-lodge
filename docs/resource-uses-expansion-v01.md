# 재화 사용처 확장 기획 v0.3 — 모닥불 연료·스튜

작성 2026-10-18. 상태: **사용자 확정(2026-10-18) · 구현 완료(2026-10-18)**. 검증: `tools/verify_campfire.gd` 39/39.

> 구현 메모: 기존에는 낮이면 모든 용병이 어디서든 초당 1씩 회복했다(`MERC_REGEN`). 규칙 3에 맞춰 **낮 회복은 켜진 모닥불 곁(반경 3.4m)에서만 초당 0.3**으로 바꿨다. 밤에 산장 안으로 대피한 비전투직의 회복과 화로의 온기석 유물 회복은 그대로다. 다친 전투직(전투용병·사냥꾼)은 낮에 불이 켜져 있으면 모닥불 둘레 자리로 가서 쉬고, 다 낫거나 불이 꺼지면 정찰로 돌아간다. 고기 스튜 카드 원화는 Codex가 자원 포맷으로 납품했다([요청서](handoff/codex-meat-stew-card-v01.md), `verify_card_art_coverage` 통과).

사용자 지시: "양털이랑 목재, 생고기, 가죽 같은 재화로 할 수 있는 게 또 뭐가 있을까? 지금은 사용처가 너무 제한적이야."
v0.1(아이디어 20여 개) → v0.2(모닥불 조리 4종) → **v0.3: 사용자가 직접 정리한 규칙 4개로 확정.** 양털·가죽의 새 쓰임(누비 가죽옷·가죽 주머니)과 장작불은 이번 범위에서 뺐다.

세계 기준은 [전역 지침](../CLAUDE.md)대로 **중세 기반 판타지**다. 재화 1장 = 1개, 손패 8장 원칙([재화 1장=1개 밸런스](resource-single-card-balance-v01.md))을 지킨다.

## 1. 배경

- 앞마당 모닥불은 대기 용병이 모이는 자리일 뿐 기능이 없었다(`lodge_yard.gd`).
- 용병은 체력 40으로 쉽게 다치는데, 회복 수단은 마녀가 생고기를 먹는 것뿐이었다.
- 생고기는 판매·마녀 회복, 목재는 수리·건축에만 쓰였다.

## 2. 사용자 확정 규칙

1. **모닥불은 목재를 태운다.** 목재 1개당 일정 시간이 지나면 꺼진다. 그래서 하루에 몇 번씩 목재를 넣어야 한다. 마녀가 모닥불 주변으로 가면 꺼지기까지 남은 시간을 **간단한 링 게이지**로 보여 준다. 목재를 넣으면 게이지가 차오른다.
2. **모닥불이 켜져 있어야** 모닥불에서 무언가를 만들 수 있다.
3. 전투로 다친 용병은 **낮에 모닥불에서 아주 천천히** 회복한다.
4. **생고기로 스튜**를 만들 수 있고, 스튜는 용병의 체력을 회복시킨다.

## 3. 사용자 결정(객관식 답변)

| 항목 | 결정 |
| --- | --- |
| 스튜 대상 | **끌어 놓은 용병 한 명.** 대신 회복량이 크다(최대 체력의 80%) |
| 불이 꺼지면 | 조리·낮 회복이 멈추고 **앞마당 빛도 꺼진다**(불빛·불꽃이 사라져 마당이 어두워짐) |
| 연소 시간 | **목재 1개 = 60초, 최대 3개(180초)** |
| 낮 회복 속도 | **초당 0.3** (체력 40을 다 채우는 데 약 2분 10초) |

## 4. 동작 명세

| 항목 | 내용 | 상수(`config.gd`) |
| --- | --- | --- |
| 시작 상태 | 새 판은 목재 1개분(60초)이 들어 있어 켜진 상태 | `CAMPFIRE_START_FUEL` |
| 연소 | 낮·밤 상관없이 남은 시간이 줄어든다. 0이 되면 꺼진다 | `CAMPFIRE_FUEL_PER_TIMBER 60`, `CAMPFIRE_MAX_TIMBER 3` |
| 목재 넣기 | 목재 카드를 모닥불에 끌어 놓는다. 남은 시간 +60초(최대 180초). 가득 차 있으면 넣을 수 없다. 꺼진 불에 넣으면 다시 켜진다 | — |
| 링 게이지 | 마녀가 모닥불 반경 안에 있거나, 손에 목재·생고기 카드를 들고 있을 때 모닥불 위에 뜬다. 채움 = 남은 시간 / 최대(180초). 목재를 넣으면 부드럽게 차오른다. 꺼지면 빈 링 | `CAMPFIRE_GAUGE_RANGE` |
| 스튜 만들기 | 불이 켜져 있을 때 생고기 카드를 모닥불에 끌어 놓으면 **고기 스튜** 카드가 손패로 온다. 꺼져 있으면 "불이 꺼져 있습니다 — 목재를 넣으세요" | — |
| 스튜 쓰기 | 스튜 카드를 다친 용병에게 끌어 놓으면 그 용병이 최대 체력의 80%만큼 회복한다. 체력이 가득한 용병에게는 쓸 수 없다. 밤에도 쓸 수 있다 | `STEW_HEAL_RATIO 0.8` |
| 낮 회복 | 준비 시간(낮)에 불이 켜져 있으면 모닥불 반경 안의 용병이 초당 0.3 회복 | `CAMPFIRE_HEAL_PER_SEC 0.3`, `CAMPFIRE_HEAL_RADIUS` |
| 꺼진 모습 | 불꽃·불빛이 사라지고 숯만 남는다. 타닥 소리도 멈춘다 | — |

생고기의 기존 쓰임(판매·마녀가 먹기)은 그대로 둔다. 목재의 기존 쓰임(수리·건축·제단·감시탑)도 그대로다.

## 5. 구현 위치

- `config.gd`: 위 상수.
- `lodge_yard.gd`: 연료 상태·연소·켜짐/꺼짐 외형·낮 회복·링 게이지.
- `card_use_resolver.gd`: 모닥불 대상 판정(목재 넣기·스튜 만들기), 스튜 사용 판정.
- `card_catalog.gd`: 고기 스튜 카드.
- 검증: `tools/verify_campfire.gd`(헤드리스).
