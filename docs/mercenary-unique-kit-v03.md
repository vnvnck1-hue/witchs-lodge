# 용병 고유 키트 v03 — 고유 카드 · 고유 패시브 · 고유 스킬

**검토·승인은 [카드 검토 페이지](../output/card-concept-review/card-concepts.html)의 `용병 고유 카드` 탭(`#mc`)에서 한다.** 항목마다 상세 동작·수치·이유가 있다. 이 문서는 같은 데이터(`output/card-concept-review/mercs.json`)의 요약이다. 이름·수치·문구는 모두 시험값이다. 세계 기준은 [전역 지침](../CLAUDE.md)의 중세 기반 판타지, 인물 설정은 [종족 손님 42명](races-guests-v01.md).

## 1. 사용자 결정 (2026-10-26)

1. 용병마다 **고유 카드**(고용하면 즉시 덱에 추가, 인물마다 최대 2장) · **고유 패시브**(카드 생성일 수도, 전투 보조일 수도) · **고유 스킬**(기세가 꽉 차면 사용) — 이 세 가지가 기본 포맷.
2. 세 능력은 **인물마다 확연히 달라 캐릭터성이 드러나야** 한다. 캐릭터가 곧 덱 아키타입 전략이 된다.
3. 전투 중 드로우는 없다(시작 손패 5장). 이후 카드는 **용병이 싸우면서 만들어 준다**. 예전 "카드 3장 쓰면 1장 드로우"는 특정 캐릭터의 고유 능력으로 흡수한다(코어 방향 Q4).
4. 마력 시작 3 · 초당 0.5 · 최대 10(Q5). 무리는 선두를 골라 직접 움직인다, 낮 피해는 이어진다, 낮 전투도 밤 덱을 전투마다 새로 섞어 쓴다(D1·D7).

## 5. 설계 점검

- **카드 공급원의 분포.** 생성형 19명(호령·통나무·돌 방패·내기·고약·결투 신청·다듬은 가지·변명·급조 방책·잡동사니·피냄새·그림자 화살·꿀단지·도망쳐!·전리품 자랑·나무의 용서·재의 부적 등), 드로우형 3명(피클 [셈 매듭] · 페른 [반딧불 씨앗] · 샤가 [뼈 점], 샤가는 생성도 겸함), 회수형 1명(미라), 할인형 1명(틸리아). 가로크는 공급 대신 "지킬 사람 하나"에 모든 것을 건다 — 의도적으로 카드 공급이 없는 인물.
- **공급이 생기는 조건이 서로 다르다.** 전투 시작(브람·토르빈·브륀힐드·라르크), 피해를 받음(하랄·두르가·파르그), 적 처치(올라프·티슬·타크·사야·크라냐), 설치물(토르그림·모가), 카드 사용 수(피클·미라), 카드를 안 씀(우르소·페른), 적 접근(모미), 침식(샤가). 같은 조건을 공유하는 인물끼리는 대상·결과가 다르게 했다(예: 올라프는 표식한 적, 사야는 가장 먼 적, 크라냐는 큰 적).
- **서로 반대인 짝.** 빠르게 쏟는 덱(틸리아·피클·고블린)과 기다리는 덱(페른·우르소), 튼튼한 설치(토르그림)와 싸고 많은 설치(러스크), 큰 회복(미라)과 잦은 작은 회복(모미)과 대가 있는 회복(두르가).
- **조합 엔진 예.** 설치물 덱: 토르빈 통나무 + 토르그림 복제 + 러스크 톱날 + 모가 부서짐 보상. 카드 폭주 덱: 피클 셈 + 틸리아 할인 + 고블린 3명 복제. 표적 덱: 타크 미끼 + 올라프 표식 + 불화살·화살세례.
- **위험.** ① 생성 카드가 넘쳐 손패 10을 채우면 판단이 흐려짐 → 대기열 3, 인물별 손패 최대치(고약 2, 꿀단지 3 등)와 전투당 횟수 상한. ② 0마력 생성 카드 + 피클 셈 = 무한 드로우 위험 → 셈은 생성 카드를 세되 고블린 복제로 생긴 카드는 세지 않는 안을 시뮬에서 확인. ③ 브륀힐드 [내기] 성공 보상(고유 카드 2장 + 마력 2)이 과할 수 있음. ④ 비전투직이 무리 뒤에서 맞는 규칙(R4)의 체감.
- **밸런스.** 헤드리스 오토배틀 시뮬로 인물 조합별 전투당 생성 카드 수·마력 낭비·승률을 잰다(코어 방향 §5.4).
