## 1. 왜 이 컨셉들인가

하스스톤에서 오래 기억되는 카드는 숫자가 센 카드가 아니라 **덱을 짜는 방식을 바꾸거나(레노·제피리스·바쿠), 판 전체를 하나의 목표로 묶거나(퀘스트·비취 골렘), 한 판의 이야기를 만드는(엘리스·요그사론)** 카드였다. 마녀산장은 이미 종족 덱·주머니·침식·발견형 카드를 갖고 있어 이 패턴들이 바로 맞물린다.

## 2. 상위 5개 — 규칙 초안

### 2.1. 대솥 처방 (← 카자쿠스) · 마법책 제작에 접목

| 항목 | 초안 |
| --- | --- |
| 위치 | [마법책 제작](spellbook-crafting-v01.md) 창 안의 "처방" 탭. 낮·시간 정지 규칙 그대로 |
| 1단 기반 | 이슬(회복 계열) · 피(공격 계열) · 재(방어·시설 계열) 중 하나 |
| 2단 효과 | 기반에 따라 효과 후보 **3개 중 2개** 선택 (예: 이슬 → 체력 회복 / 침식 정화 / 둔화 해제) |
| 결과 | 고른 조합으로 이름이 붙은 **물약 카드 1장**이 손패로(넘치면 주머니). 예: "서리 이슬 회복약" |
| 재료 | 약초 + 정화된 정수(기존 새 재화). 강한 조합일수록 정수 소비 ↑ |
| 노리는 재미 | 받는 카드가 아니라 **만드는 카드**. 매 판 다른 조합 |
| 열린 결정 | 처방을 "제작법 발견(???)"과 별개로 둘지, 처방 자체도 발견 대상으로 둘지 |

### 2.2. 다섯 종족의 건배 · 산장 지붕의 정령 (← 레노 · 제피리스) · 화합 덱의 핵심

| 카드 | 조건 | 효과 초안 |
| --- | --- | --- |
| **다섯 종족의 건배** | 고용 중인 용병의 종족이 **모두 다르고 3종족 이상** | 산장·용병 크게 회복(완전 회복 아님) + 침식 1장 정화 |
| **산장 지붕의 정령** | 주머니(덱)에 **같은 이름의 카드가 없음** | 지금 상황에 맞는 카드 3장 중 1장 선택 |

정령의 후보 표(규칙 기반, 위에서부터 먼저 맞는 줄):

| 상황 | 후보 3장 |
| --- | --- |
| 밤 | 방어 주문 계열(서리 룬·덩굴 덫·송진 횃불 등) |
| 산장 체력 50% 이하 | 겨울 장작·갱도 버팀목·겨울잠 털가죽 |
| 손패에 침식 2장 이상 | 이끼 붕대·순례자의 축복·산장 대청소 |
| 그 외 낮 | 자원·용병·드로우 계열 |

화합 덱([덱 방향성 §6.1](deck-archetypes-v01.md))에 명확한 덱 조건을 준다. 교훈(레노): **완전 회복 금지, 상한 있는 보상.**

### 2.3. 종족의 숙원 (← 퀘스트)

| 항목 | 초안 |
| --- | --- |
| 획득 | 그 종족 용병 이벤트 보상 또는 판 시작 시 선택(열린 결정) |
| 성격 | 손패에 들어오면 **사용할 수 없고 진행도만 쌓인다.** 손패 1칸을 계속 차지하는 것이 대가 |
| 고블린의 숙원 | 졸개 30마리 부르기 → **대장 그라즈** 합류(전설 용병) |
| 언데드의 숙원 | 시체 10구 바치기 → **망자의 왕관**(마녀가 망자의 군주로 영구 변신, 새벽마다 언데드 카드 1장) |
| 드워프의 숙원 | 시설로 밤 5번 버티기 → **돌의 군주 망치** |
| 표시 | 카드 위에 진행도(12/30) 런타임 표시. 원화에 숫자를 굽지 않는다 |

### 2.4. 사촌 패거리 누적 (← 비취 골렘)

기존 **사촌 패거리**에 판 단위 카운터를 더한다: 쓸 때마다 이번 판 졸개 수 +1(2 → 3 → 4…, 상한 8). 카드 위에 "패거리 +3" 표시. 구현 비용 낮음(카운터 하나 + 소환 수).

### 2.5. 찢어진 숲 지도 (← 엘리스 스타시커)

`찢어진 숲 지도`(주머니에 섞임) → 뽑아 쓰면 `고목의 열쇠`가 주머니에 섞임 → 열쇠를 쓰면 **손패의 일반 카드가 모두 숲의 보물(유물·권능급)로 변신**. 침식 카드는 변하지 않는다. 며칠에 걸친 연쇄, 보물상자와 같은 계열.

## 3. 나머지 컨셉 (후보)

| 컨셉 | 원본 | 초안 | 연결 |
| --- | --- | --- | --- |
| 순혈의 맹세 | 바쿠·겐 | 고용 용병이 모두 한 종족이면 마법탄이 그 종족 성질(고블린 폭발·드워프 관통·요정 둔화) | 종족 덱. 첫날 약하게, 용병 수에 비례 |
| 잠든 숲의 거인 | 크툰·갈라크론드 | 주머니에 있는 동안 숲 카드를 쓰면 성장, 밤에 깨우면 그만큼 강함 | 숲 카드 |
| 대물림 검 | 왕살해자 | 쥔 용병이 쓰러지면 강화를 유지한 채 주머니로 | 장비 |
| 서리 여왕의 왕관 | 자락서스 | 마녀 영구 변신: 얼음창 마법탄, 밤마다 서리 룬 | 보름달 변신 확장 |
| 지팡이 고르기 | 핀리 경 | 판 시작 지팡이 3개 중 1개 → 마법탄 성질 | 참나무 지팡이 |
| 드워프 음유 장로 | 브란 | 드워프 카드 효과 2회 (하루 2회 상한) | 드워프 |
| 몰래 탄 사촌 피클 | 패치스 | 고블린 카드 사용 시 주머니에서 튀어나와 졸개 1 | 고블린 |
| 숙성 | 다크문 타락 | 손패에서 밤을 넘기면 숙성 버전으로 | 주점 술, 손패 8칸 긴장 |
| 폭주하는 마법서 | 요그사론 | 이번 판 쓴 주문 수만큼 무작위 주문 (산장 붕괴 없음) | 에린 계열 |
| 불의 정령 화로 | 라그나로스 | 시설: 밤마다 무작위 적에게 큰 불덩이 | 시설 포맷 |
| 떠돌이 발명가 손님 | 박사 붐 | 발명가 + 부서지면 터지는 폭탄 수레 2 | 범용 강카드 |
| 앞뒤 안 가리는 돌격대장 | 리로이 | 밤 시작 즉시 돌진, 대신 늑대 2마리 등장 | 오크 이벤트 |
| 겨울의 끝 종 | 데스윙 | 모든 적·우리 시설 파괴, 손패 전부 버림 | 비상 버튼 |
| 망자 여왕의 반지 | 실바나스 | 낀 용병이 쓰러지면 곁의 적 하나가 해골 아군 | 언데드 |

## 4. 설계 규칙 — 하스스톤 너프 사례에서

1. **다시 발동·복제 카드는 횟수 상한을 둔다**(쉬더웍). 연출 길이도 같이 본다.
2. **주머니에서 저절로 나오는 카드는 효과를 작게**(패치스).
3. **판 시작부터 켜지는 덱 조건 보상은 첫날 작게, 날이 갈수록 크게**(바쿠·겐).
4. **무작위 카드는 결과의 바닥선을 둔다** — 산장이 한 번에 무너지지 않는다(요그사론).
5. **회복 보상은 상한을 둔다** — 완전 회복 금지(레노).
