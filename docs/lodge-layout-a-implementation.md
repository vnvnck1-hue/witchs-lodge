## 4. 검증

헤드리스(`.tools/Godot-4.7.2.exe --headless --path godot --script res://tools/verify_lodge_layout.gd`): **RESULT 83/83**. main 병합 뒤 재실행: **RESULT 92/92**(묘지 16기라 포켓 검사가 8개 늘었다). 적 보행 검사는 main의 마녀 자동 공격에 적이 죽지 않도록 마녀를 제단 공터 쪽에 두고 체력을 크게 준다. 배포판 `build/WitchsLodge.pck`도 병합 뒤 헤드리스로 다시 내보냈다.

- 배치 관계(증축 예약이 본채 왼쪽 벽에 연속, 목장 오른쪽, 모닥불 현관 앞 8.1m, 바위 29개)
- 공터: 감시탑 2·제단 1, 길·모닥불·목장 문과 분리, 제단 공터에 가지 길이 닿음
- 후면 차단: 현관에서 산장 뒤 6개 지점·묘지 자리 8곳으로 가는 경로 없음, 왼쪽 눈밭↔목장 동쪽 경로가 산장 뒤를 지나지 않음, **모든 벌목 나무의 충돌을 끄고 다시 구워도** 후면 우회가 열리지 않음, 예약 영역·띠 안의 벌목 나무 0그루, 자원 나무 3그루 접근 가능, 예약 영역 안 숲 부품 0개
- 웨이브: 두 스폰이 내비메시 위, 현관·목장 문까지 경로 존재, 좌우 거리 차 5m 이내, 공격 지점 전부 앞·옆면이며 도달 가능, 실제 적 한 마리가 오른쪽 스폰에서 산장 공격 거리까지 걸어오고 산장 뒤로 돌지 않음
- 생활 동선: 대기 자리 16곳이 불에서 떨어진 내비메시 위, 현관→모닥불·목장 문·제단 공터·감시탑 공터·4개 랜드마크·손님 길 연결, 마녀 실제 보행 4구간

## 5. 남은 일·주의

- **합병 메모(2026-10-18)**: main의 다른 세션 작업을 먼저 커밋(c73a6f8)한 뒤 병합했다. 코드는 자동 병합됐고 README 둘과 인수인계 문서만 손으로 합쳤다. `contract_director.gd`의 옛 `YARD` 상수(16자리)는 미사용이라 제거했다. `graveyard.gd`의 `PLOT_OFFSET`은 16기 `PLOTS`에도 적용된다(뒷줄 z −9.5, 띠 뒤 변과 1.5m).
- 숲 군집은 자동으로 밀어낸 결과라 군집별 "초승달·능선·쐐기" 실루엣이 일부 느슨해졌다. 캡처 기준으로 산장 주변은 승인 원화와 맞지만, 외곽 군집은 아트 담당이 한 번 다듬는 것이 좋다.
- 감시탑·제단 공터는 자리만 예약했다. 탑 외형·공격·비용, 제단 이전·해금 변경, 모닥불의 휴식 상태·집결 시점·인원 배분, 최대 증축 크기는 인수인계 문서대로 미정.
- 밤 색감은 기존 `day_cycle` 밤 프리셋 그대로다(이번 작업은 배치·충돌·내비만 바꿨고 컬러톤·표현은 건드리지 않았다). 낮 승인 원화 대비 밤의 보라·분홍 비중은 별도 검수 항목.
- 증축 사각형(z −1.7까지)과 후면 띠(z −3.3) 사이에 1.6m 깊이의 막다른 눈밭이 남는다. 통과로가 아니고 공격 지점도 두지 않지만, 증축 최종 크기가 정해지면 띠 앞 변을 그에 맞춰 당길 수 있다.
