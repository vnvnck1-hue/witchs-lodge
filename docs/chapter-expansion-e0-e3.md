# 볼륨 확장 E0~E3 — 12일 챕터 구현

2026-10-17 · Godot 4.7.2 · 기획: [game-volume-expansion-plan.md](game-volume-expansion-plan.md) v0.2 · 구현 Claude

3웨이브(3일) 시연판을 **12일 챕터 1(산장 방어)**로 늘렸다. 1차 마일스톤 E0~E3 범위다. 수치는 모두 시험값이다.

## 무엇이 바뀌었나

### E0 · 챕터 데이터화

- 하루(낮+밤) 구성은 `godot/scripts/game/chapter_data.gd`의 `CHAPTER_1.days`가 정한다. 12일이다.
- 밤마다 다음 값을 정한다.
  - 밤 규칙(`night`)
  - 기본 체력(`hp`)
  - 양을 노리는 수(`sheep`)
  - 표식 개체 순번(`marked`)
  - 출현 그룹: `[시각, 인원, 적 종류]`
  - 하루 사건: `unlock`(제단), `reward`(새벽 보상), `market`(장날)
- 1~3일은 기존 `Cfg.WAVES`와 같다. 지금의 3웨이브가 그대로 챕터의 정착기가 된다.
- 다음 코드가 이 데이터를 쓴다.
  - 웨이브 감독(`wave_director.gd`): 날짜별 데이터와 그룹별 적 종류를 읽는다.
  - 세션(`game_session.gd`): `total_days()`(12)를 지나야 승리한다. 승리 문구는 "챕터 1 완료"다.
  - HUD: "n일차 밤 / 12"와 오늘 밤 규칙 이름을 표시한다.

### E1 · 밤 규칙 · 적 종류 · 봉인석 · 보스

**밤 규칙 9종**

| 규칙 | 날짜 |
| --- | --- |
| 습격 | 1·2일 |
| 큰 습격 | 3일 |
| 고요 | 4·11일 |
| 침식된 자들의 밤 | 5·7일 |
| 안개 | 6일 |
| 양 도둑 | 8일 |
| 포위 | 9일 |
| 봉인석 탈취 | 10일 |
| 보스 | 12일 |

- 안개의 밤에는 마녀의 시야가 0.6배로 줄어든다(`fog_of_war.sight_mult`).
- 낮이 시작될 때와 밤이 시작될 때 각각 규칙을 알린다.

**적 종류**

정의는 `Cfg.ENEMY_KINDS`, 동작은 `monster.gd`의 `configure(kind)`에 있다.

| 종류 | 특징 |
| --- | --- |
| 숲의 괴물 | 기존과 같음 |
| 침식된 자 | 4.5m 원거리 공격. 산장을 치면 주머니에 침식된 기도문을 넣음 |
| 맹독 곤충 | 빠르고 약함. 마녀를 물면 독 포자를 넣음 |
| 공성 괴물 | 마녀·용병·방책을 무시하고 산장만 노림. 산장 피해 3배 |
| 보스 빈 굴의 주인 | 아래 참고 |

**보스 빈 굴의 주인**

- 체력 1400. 한 번에 받는 피해는 최대 150이다(용 불덩이 대비).
- 14초마다 울부짖어 숲의 괴물 2마리를 불러내고, 저주의 속삭임을 남긴다.
- 처치하면 전리품 카드 **겨울잠 털가죽**을 준다.

**봉인석**

- 산장이 무너질 때의 패배 문구를 "산장이 무너지고 봉인석을 빼앗겼습니다"로 바꿨다.
- 규칙은 그대로다.

### E2 · 마녀의 제단

**흐름**

- 달빛 돌 제단 랜드마크에 제단(`world/altar.gd`)을 둔다.
- 4일차 낮에 해금된다. 바닥에 보랏빛 문양이 나타난다.
- 손패의 목재 10개로 복구하면 나무 제단과 촛불이 생긴다.
- 제단을 클릭하면 마녀가 다가가고, 3.2m 안에 들어오면 제단 창(`ui/altar_panel.gd`)이 열린다.

**의식**

- 하루에 한 번 치를 수 있다.
- 처음 완성하면 **권능 카드**를 얻는다. 다시 치르면 **오늘 밤 축복**을 받는다.

| 의식 | 공물 | 권능 카드 | 축복 |
| --- | --- | --- | --- |
| 수의의 의식 | 양털 3 | 수의 | 오늘 밤 마녀·아군이 치명타를 한 번 버팀(체력 1) |
| 가시의 봉헌 | 숲의 괴물 카드 1 | 가시 속박 | 가시 방책 공격력 ×1.5 |
| 붉은 만찬 | 어른 양 1마리 | 붉은 잔 | 마법탄 피해의 30% 흡혈 |

- 붉은 만찬에 바친 양은 "잃은 양"으로 세지 않는다.
- 축복 상태는 `ChapterDirector`(`game/chapter_director.gd`)가 관리한다. 밤 정리 때 모두 사라진다.

### E3 · 덱빌딩 볼륨

**새벽 보상**

- 4·6·8·10일 낮이 시작되면 카드 3장 중 1장을 고른다. 받지 않을 수도 있다.
- 후보는 숲 카드와 기존 카드에서 뽑는다.

**장날**

- 6·11일에 연다. 행상이 카드 4장을 골드로 판다.
- 침식 카드를 15G에 정화할 수 있다.
- 화면은 `ui/offer_screen.gd`다. 열려 있는 동안 게임이 멈춘다.

**숲 카드 5종**

| 카드 | 효과 |
| --- | --- |
| 이끼 붕대 | 마녀 회복 + 침식 카드 1장 정화 |
| 송진 횃불 | 5초 동안 타는 불길 |
| 반딧불이 떼 | 반경 8m 안개 걷기 |
| 덩굴 덫 | 피해 + 강한 속박 |
| 겨울 장작 | 밤에도 산장 +60 |

**침식 카드 3종**

- 적이 주머니에 넣는다. 한 밤에 최대 2장이다.
- 셋 다 쓸 수 없고 손패 한 칸을 차지한다.

| 카드 | 손패에 있을 때 |
| --- | --- |
| 침식된 기도문 | 추가 효과 없음 |
| 독 포자 | 새벽마다 마녀 체력 -8. 치명적이지 않음 |
| 저주의 속삭임 | 그날 아침 드로우를 막음 |

- 이끼 붕대나 장날 정화로 없앤다. 버림패를 거치지 않고 사라진다.

**새 카드의 원화**

- 권능·전리품·숲·침식 카드 12종은 아직 원화가 없다.
- 임시로 `tools/build_expansion_placeholder_cards.py`가 만든 판을 쓴다(역할 색, 제목, 규칙 2줄).
- 카탈로그에 `"placeholder": true`로 표시했다. 정식 원화는 [card-design-guide.md](card-design-guide.md) 기준으로 같은 경로에 덮어쓰고, 표시를 지운다.

## 검증

```text
.tools/Godot-4.7.2.exe --headless --path godot --script res://tools/verify_chapter.gd
```

- `tools/verify_chapter.gd`(`chapter_check.gd`)는 **63/63 통과**다. 다루는 항목:
  - 카탈로그
  - 챕터 데이터: 1~3일과 기존 웨이브의 일치, 표식 순번이 숲의 괴물에 걸리는지
  - 세션 흐름: 3일 뒤 4일차로 이어짐, 12일 뒤 승리
  - 적 종류별 수치·행동, 보스의 피해 상한·부름·전리품
  - 침식 상한
  - 5일차 밤의 출현 구성
  - 안개 시야
  - 축복 4종과 소멸
  - 제단: 해금, 복구, 의식 3종, 하루 한 번 제한, 창을 열면 정지
  - 신규 카드 9종의 판정과 효과
  - 침식 카드: 사용 거부, 새벽 효과, 정화
  - 새벽 보상·장날: 구매, 중복 구매 거부, 골드 부족 거부, 정화
- 결과 파일은 `godot/art_sources/chapter-verify.json`이다.
- **실제 렌더 캡처**(`tools/capture_chapter.gd` → `godot/screenshots/chapter/`)도 했다. 헤드리스 더미 렌더러로는 다음을 확인할 수 없기 때문이다.
  - 새벽 보상·장날·제단 창의 배치
  - 임시 카드 원화
  - 제단 모형
  - 적 종류 표식과 보스 크기
  - 이 캡처로 제단 창의 자동 줄바꿈 높이 버그를 찾아 고쳤다.
