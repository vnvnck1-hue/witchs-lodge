# 킹덤 시리즈 코어 리서치 — 마녀산장 적용 근거

작성일: 2026-10-13 · 범위: 공식 소개와 퍼블리셔 자료 기반 시스템 분석. 실제 플레이 실험이나 이용자 인터뷰를 수행한 보고서는 아니다.

**후속 방향 안내:** 아래는 킹덤 접목을 검토한 당시 리서치다. 이후 사용자가 카드 코어를 채택해 다음 제작 기준은 [v0.3](kingdom-integration-design.md)이다. 경제의 기회비용·낮밤·두 길·영역 확장은 참고하되 영구 주민 모집과 반복 생산은 [이전 v0.2](kingdom-integration-design-v0.2.md)의 제안 기록으로 구분한다. 변경 근거는 [카드 전환 충돌 검토](card-core-design-review.md)를 본다.

## 1. 결론

마녀산장에는 **골드의 기회비용, 주민에게 맡기는 실행, 낮의 준비와 밤의 검증, 두 방향의 방어, 위험을 감수하는 영역 확장**을 가져오는 것이 적합하다. 현재 숙박·증축·양·용의 구조가 이 경제에 자연스럽게 연결된다. 쿼터뷰와 마녀의 클릭 이동·자동 공격을 유지하는 접목안을 권한다.

이는 원작의 성공 원인을 입증한 결론이 아니라, 아래 자료와 당시 마녀산장 규칙을 비교한 **설계 해석**이다. 당시 접목 규칙은 [보존한 v0.2](kingdom-integration-design-v0.2.md)에 정리했다.

## 2. 조사 범위와 근거 수준

- 사용자가 제공한 [나무위키 킹덤 시리즈](https://namu.wiki/w/Kingdom%20%EC%8B%9C%EB%A6%AC%EC%A6%88)는 접근 실패로 본문을 확인하지 못했다. 해당 문서를 읽은 것처럼 인용하지 않았다.
- 원작 확인은 공식 시리즈 사이트, 각 작품의 공식 소개, Steam의 제작사 제공 설명, Raw Fury의 발표 자료를 사용했다. 가격·리뷰 비율은 접목 근거에서 제외했다.
- 공통 구조는 Classic과 New Lands, 확장 가능한 기본형은 Two Crowns를 중심으로 봤다. Eighties는 다른 배경에서도 주민·경제·방어 구조가 유지되는 사례로 참조했다.
- 테마별 특수 능력·직업·아이템과 버전별 세부 수치를 혼합하지 않았다. 정확한 직업 구매 비용, 적 증가 공식, 왕관 손실 후 복구 절차, 농장 효율은 이번 근거에서 확정하지 않는다.
- 연결된 Notion에서 ‘마녀산장’을 검색했으나 정확히 일치하는 프로젝트 자료를 확인하지 못했다. 유사한 마녀 관련 문서는 이 게임의 설정으로 사용하지 않았다. 우리 게임의 기준은 로컬 기획과 구현이다.

## 4. 원작 코어를 기능과 판단으로 분해

### 4.1 같은 동전의 경쟁

**확인 사실:** Classic은 동전을 주민 모집과 왕국 성장에 쓰며, 공식 소개는 동전 하나의 사용이 번영과 쇠퇴의 균형을 바꿀 수 있다고 설명한다. [Classic 공식 소개](https://kingdomthegame.com/kingdom-classic-2/)

**해석:** 핵심은 돈을 많이 모으는 행위보다 지금 방어에 쓸 돈을 미래 수입에 투자할지 결정하는 것이다. 여러 성장 항목이 서로 다른 자원을 요구하면 이 직접적인 경쟁이 약해질 수 있다.

**적용:** 숙박으로 번 골드를 객실·주민·방책·수리·양·용이 함께 사용한다. 첫 검증에는 목재·마나·식량 같은 별도 결제 자원을 넣지 않는다. 양을 잃으면 재구입 비용이 용 공물 비축을 잠식한다.

### 4.2 군주 한 명과 주민의 실행

**확인 사실:** New Lands는 주민이 건설·공격·방어를 돕는다고 명시한다. Eighties는 모집한 아이에게 병사·건설자 역할을 부여하고 시설을 확장하는 구조를 설명한다. [New Lands 제작사 제공 설명](https://store.steampowered.com/app/496300/Kingdom_New_Lands/), [Eighties 공식 출시 발표](https://rawfury.com/kingdom-eighties-launches-on-steam-june-26/)

**해석:** 플레이어가 모든 생산과 전투를 직접 수행하는 대신 사람과 시설에 투자하고 결과를 관찰할 때, 준비 단계의 판단이 전투 결과로 이어진다. 주민의 행동이 읽혀야 이 연결이 성립한다.

**적용:** 숙박객과 정착 주민을 구분한다. 목수는 건설, 사냥꾼은 지정 숲길 방어를 자동 수행한다. 마녀의 기존 자동 공격은 약한 길 지원에 사용한다. 모든 작품·테마의 주인공이 공격 능력이 없다고 일반화하지 않는다. Two Crowns는 테마별 군주·탈것 능력도 소개한다. [Two Crowns 공식 소개](https://kingdomthegame.com/kingdom-two-crowns/)

### 4.3 낮의 투자, 밤의 결과

**확인 사실:** Classic과 Two Crowns 모두 밤의 적 침입을 설명한다. Two Crowns는 밤의 방어에 궁수·기사·공성 병기와 능력을 사용하는 구조를 제시한다. [Classic 공식 소개](https://kingdomthegame.com/kingdom-classic-2/), [Two Crowns 제작사 제공 설명](https://store.steampowered.com/app/701160/Kingdom_Two_Crowns/)

**해석:** 제한된 준비 시간이 투자의 순서와 완료 시점에 의미를 준다. 밤은 전혀 별개의 전투 미니게임이 아니라 낮의 준비를 시험하는 단계다.

**적용:** 현재 준비 90초를 낮으로 표현한다. 건설에는 주민과 시간이 필요하고 밤에는 미완성 작업을 중단한다. 어떤 시설이 늦게 완성되었는지 결과 화면에서 보여준다. 조명과 시간 표현은 보라 설경과 어두운 숲의 기존 분위기를 유지한다.

### 4.4 안전지대 밖의 기회

**확인 사실:** Two Crowns는 경계 밖 숲·유적의 보물과 지식을 탐험하고, 성장으로 유닛·기술을 열며, 적의 근원을 공격해 섬을 확보한다고 설명한다. [Two Crowns 제작사 제공 설명](https://store.steampowered.com/app/701160/Kingdom_Two_Crowns/)

**해석:** 탐험은 수집품을 늘리는 기능뿐 아니라 경제와 방어의 다음 단계를 여는 동기가 될 수 있다. 밖으로 나갈수록 이동 시간과 방어 범위가 늘어나는 부담을 설계할 수 있다. 이는 접목을 위한 해석이며 공식 자료에서 특정 이동 공식까지 확인한 것은 아니다.

**적용:** 중앙 산장을 중심으로 두 숲길을 각각 안쪽·바깥쪽 노드로 나눈다. 바깥 등불을 복구하면 채집터와 다음 단서를 발견하지만 주민과 시설을 멀리 보내야 한다. 장기 목표는 숲의 위협 근원 봉인으로 제안한다.

### 4.5 적은 입력과 발견의 즐거움

**확인 사실:** 시리즈는 미니멀한 전략·자원 관리 게임으로 소개된다. New Lands는 NPC·아이템·석상의 도움과 규칙을 스스로 알아가는 경험을 강조한다. [시리즈 공식 소개](https://kingdomthegame.com/), [New Lands 공식 소개](https://kingdomthegame.com/kingdom-new-lands-2/)

**해석:** 조작 수를 줄이면서도 공간·비용·시간의 조합으로 판단을 늘릴 수 있다. 다만 설명 부족이 신규 플레이어에게 언제나 즐겁다는 근거는 없다.

**적용:** 클릭 이동과 가까운 대상의 행동 버튼을 기본으로 사용한다. 비용·완료 시간·방어 방향은 명확히 보여주고, 숲의 비밀과 조합의 효율은 발견하도록 남긴다. 자유 건축과 주민 개별 이동 명령은 첫 범위에서 제외한다.

## 5. 마녀산장 현재 상태와의 차이

아래는 코드와 기존 문서를 읽은 결과다. 이번 조사에서 게임을 실행하거나 전투 밸런스를 재검증하지 않았다.

| 항목 | 현재 구현 | 접목에서 필요한 변화 |
| --- | --- | --- |
| 경제 | 준비 중 3회 손님 도착, 정원 2명, 1인 15G 자동 지급 | 기존 수입을 유지하고 신규 투자 항목 추가 |
| 객실 | 60G로 즉시 증축, 정원 2→3명 | 목수 작업과 완성 시간을 추가 |
| 실행 주체 | 마녀의 클릭 이동·자동 공격, 손님은 입퇴실 | 정착 주민의 역할·행동·방향 배치 |
| 방어 | 두 길 출현, 적은 산장·양을 목표로 접근 | 길별 방책과 사냥꾼, 돌파 후 목표 처리 |
| 공간 성장 | 중앙 본채의 객실 1회 증축 | 숲길 전진과 새 경제·목표의 해금 |
| 비상 수단 | 120G, 웨이브당 1회, 종료까지 용 방어 | 효과는 유지하고 상시 용 전략의 기회비용 검증 |
| 종료 | 3웨이브 정리 시 시연 완료, 산장·마녀 사망 시 실패 | 첫 실험 종료는 유지. 장기판의 근원 봉인은 별도 제안 |

| 경계 전진, 숲 발견, 근원 공세 | 코어 완성 단계에 포함 | 고정 공터에서 반복 방어하는 구조를 넘어갈 동기 |

| 복잡한 접객·인테리어·다중 재료 제작 | 후속 | 첫 실험에서 운영 부담과 결제 자원 분산을 줄임 |

## 7. 아직 검증해야 할 가설

| 가설 | 확인 방법 | 실패하면 조정할 것 |
| --- | --- | --- |
| 주민에 투자한 결과를 체감할 수 있다 | 같은 마녀 조작에서 방책·사냥꾼 유무 비교 | 마녀·주민 피해량, 방책 지연 효과 |
| 두 길을 나누면 지원 방향 판단이 생긴다 | 길별 피해·마녀 체류·방어 투자 기록 | 길 이동 시간, 적 분배, 상태 표시 |
| 용과 성장의 비용 경쟁이 생긴다 | 증축·주민·공물의 실제 구매 순서 비교 | 소환 가격보다 먼저 수입과 영구 방어 효율 |
| 영역 확장이 경제를 키우며 부담도 만든다 | 전진한 판과 중앙 유지 판의 순수입·손실 비교 | 채집 수익, 이동, 외곽 시설 비용 |
| 산장 운영의 따뜻함을 유지한다 | 플레이 후 산장·손님·양이 어떤 역할로 기억되는지 질문 | 방문 장면, 복구 비용, 전투 비중 |

이 가설의 성공률이나 시장 반응은 현재 자료로 확정할 수 없다. 경제 산술과 실제 전투 가능성도 별도로 검증해야 한다.
