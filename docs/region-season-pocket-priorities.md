# 세계관·지역과 계절·마녀의 주머니 — 구현 우선순위와 진행 기록

작성일: 2026-10-16 · 기준 기획: [region-season-pocket-design.md](region-season-pocket-design.md)

## 2. 구현한 규칙 (2026-10-16 소스·실행판 적용)

| 항목 | 동작 | 근거 |
| --- | --- | --- |
| 마녀의 주머니 | 기존 창고가 주머니(덱)가 된다. 좌하단 주머니 버튼으로 열면 **주머니·손패·활동 중·버림패** 목록을 보기만 할 수 있고, 손패↔주머니 이동 버튼은 없다. 낮에는 열어 두는 동안 시간이 멈추고 밤에는 멈추지 않는다(기존 창고와 같음) | 확정 규칙·목록 확인 |
| 시작 손패 | 시작 카드 6장을 모두 주머니에 넣고 **시작 손패 고르기 화면**을 연다. 주머니의 서로 다른 3장(`STARTER_DRAW`)이 좌하단 주머니에서 날아와 가운데에 펼쳐지고, 한 장을 클릭해 "교체" 표시를 붙일 수 있다(`MULLIGAN_SWAPS` 1). 확정하면 표시한 카드는 주머니로 날아가 돌아가고(다시 뽑히지 않음) 다른 카드가 날아와 공개된 뒤, 세 장이 차례로 손패로 내려간다. 고르는 동안 시간 정지, Esc 불가, Enter/Space로 확정. 남은 3장은 아침마다 한 장씩 온다 | 2번 + 사용자 결정 |
| 신규 획득 | 손패에 먼저, 손패 8장이 가득 차면 주머니로. 묶음 자원은 손패에 같은 묶음이 있으면 손패가 가득 차도 거기에 합산하고, 없으면 주머니 묶음에 합산 | 1·3번 |
| 아침 드로우 | 2일차부터 낮이 시작될 때 주머니에서 무작위 1장(`MORNING_DRAW`). 뽑힌 카드는 주머니 버튼에서 날아와 **화면 가운데에 손패의 1.25배(`DRAW_REVEAL_SCALE`)로 잠깐 공개**(금빛 고리·입자·효과음)된 뒤 손패 **오른쪽 끝**에 쌓인다. 채집가·독버섯·마법서적 드로우도 같은 연출. 손패가 가득 차면 건너뛰고 주머니에 보존(토스트 안내). 단, 손패에 같은 자원 묶음이 있으면 가득 차도 그 묶음에 1개 합산한다 | 4번 |
| 묶음 자원 드로우 | 목재 ×20에서 드로우하면 손패에 목재 1, 주머니에 19가 남는다. 손패에 같은 자원 묶음이 있으면 거기에 합산한다(손패 안 묶음 유지는 현재 동작을 따른 시험 규칙) | 8번 |
| 버림패 | 서리 룬·초대장·보물상자·독버섯·마법서적처럼 즉시 효과가 끝나는 카드는 사용 즉시 버림패로. 자원(목재·양털·검은 털·생고기·가죽)은 수량만 차감. 버림패는 되돌아오지 않는다 | 5·6번 |
| 활동 카드 | 나무꾼·사냥꾼·전투용병·채집가·숲의 괴물(용병·하수인), 새끼양·검은 양(입식), 가시 씨앗·수호 등불(설치물)은 사용 시 **활동 중** 목록으로 가고, 개체가 쓰러지거나(사망·시듦·파괴) 등불이 꺼지면 버림패로 간다 | 5번 + 활동 종료 시점의 시험 규칙 |
| 채집가 | 사용하면 본래 효과(탐색 출발) + 주머니에서 1장 드로우. 주머니가 비면 드로우만 생략하고 사용 가능. 손패가 가득 차면 드로우를 건너뛴다 | 7번·드로우 카드 예시 |
| 독버섯 | 마녀에게 끌어 놓으면 체력 `MUSHROOM_HP_COST`(시험값 10)를 치르고 주머니에서 무작위 1장. 체력이 비용 이하이면 거부(치명적 비용 불허 — 시험 규칙). 주머니가 비면 사용 불가·비용 없음 | 7번 |
| 오래된 마법서적 | 어디에 놓아도 된다. 주머니에 실제로 있는 카드 중 서로 다른 최대 3장(`SPELLBOOK_CHOICES`)을 앞면으로 펼치고 1장을 골라 손패로. 1~2장뿐이면 있는 만큼. 고르지 않은 카드는 주머니에 유지, 고르는 동안 시간 정지, Esc로 닫을 수 없다 | 10번 |
| 자원은 손패에서만 | **모든 자원 사용은 손패에 뽑힌 자원만 가능.** 건축·증축(`economy.timber()`), 산장 수리·판매·봉헌·생고기 섭취는 손패의 카드·수량만 쓴다. 주머니 속 자원은 `consume_id`로도 쓰지 않는다. HUD의 목재·양털 숫자는 손패 수량이고, 툴팁에 "주머니 n개는 뽑아야 사용"을 함께 보인다 | 9번(확정) |
| 손패 순서 | 손패 순서 = 받은 순서. 드로우·획득 카드는 항상 오른쪽 끝에 붙는다(`_move_to_hand_end`) | 사용자 결정 |

- 독버섯·마법서적의 획득 경로(사용자 결정 2026-10-16): **채집가 줍기 표**. 지점 1곳당 1회 굴림, 하루 3지점. 시험 확률은 목재 36% · 생고기 18% · 토끼 가죽 13% · 보물상자 10%(하루 1개) · **독버섯 8%** · **오래된 마법서적 3%(하루 1권, 넘치면 독버섯으로 대체)** · 빈손 12%. 기존 표(40/20/15/10/15)에서 목재·생고기·가죽·빈손을 조금씩 줄여 11%를 만들었다. 하루 기대값은 독버섯 약 0.24장, 서적 약 0.09장(약 11일에 1권)이며 플레이테스트로 조정한다. 주운 카드는 다른 자원처럼 용병이 들고 있다가 마녀에게 건네고, 손패 우선·넘치면 주머니로 들어간다. F1 디버그 지급(독버섯 2·서적 1)도 유지한다.
- 손패 UI 안내 문구와 주머니 버튼 툴팁("마녀의 주머니(덱) n장 · 버림패 n장")을 바꿨다. 자원 툴팁은 "손패+주머니"로 표기한다.

## 4b. 주머니 갤러리 — 카드를 넓게 펼쳐 보기(2026-10-16)

주머니 창을 텍스트 목록에서 **카드 갤러리**로 바꿨다(보기 전용, 카드 상태는 건드리지 않음). 구현은 `godot/scripts/ui/pocket_gallery.gd`(새 모듈)이고 `card_hand.gd`는 창을 만들고 툴팁만 붙인다.

- 창 크기 1500×790(디자인 px). 주머니·손패·활동 중·버림패 네 구역을 `HFlowContainer`로 150×225 카드(2:3)를 가로로 늘어놓고, 넘치면 세로 스크롤. 카드 아래 이름 줄(계약 인물·×수량 포함). 버림패는 어둡게 물들인다.
- **마우스 오버**: 올린 카드 한 장을 `CardView`(손패와 같은 스프링·그림자)로 제자리에서 1.6배로 띄우고, 나머지 위에 어둠(α 0.66)을 깐다. 올린 카드는 창 밖으로 나가지 않게 안쪽으로 민다. 오버 판정은 매 프레임 좌표로 하고(`_poll`), 올린 카드가 덮는 영역 안에서는 옆 카드로 넘어가지 않으며 타일이 마우스를 먹지 않아 휠 스크롤이 막히지 않는다.
- **툴팁**: 손패 툴팁(`card_hand.tooltip`)을 그대로 쓰되 올린 카드의 오른쪽(자리가 없으면 왼쪽)에, 위 끝을 맞춰 화면 안에 가둔다. 사용법 줄 대신 구역 설명(아침 드로우 대기·손패·활동 중·버림패)을 적는다. 툴팁이 창 위에 그려지도록 `card_hand`의 자식 순서를 창 → 툴팁으로 바꿨다.
- 검증: `godot/tools/verify_pocket_gallery.gd` 26/26(펼침 폭·한 줄 8장·버튼 없음·오버 시 확대·어둠·툴팁 위치와 화면 안·해제·다시 펼침·닫기). 회귀 `verify_pocket.gd` 59/59, `verify_ui_extension.gd` 96/96, `verify_moon_runtime.gd` 82/83(기존 실패 1건 그대로).
- 실제 화면은 헤드리스로 볼 수 없어 `godot/tools/capture_pocket_gallery.gd`로 5프레임을 `godot/screenshots/pocket-gallery/`에 저장해 확인했다(어둠 블렌딩·올린 카드 그림자·툴팁 배치).
- 배포판 `build/WitchsLodge.pck` 갱신. 이전 데이터는 `build/WitchsLodge-before-pocket-gallery.pck`.

## 4c. 손패 흐름 v1 — 낮·밤 손패 분리, 달빛 스택, 모닥불 태우기(2026-10-18)

손패가 막히는 문제의 후속 기획·구현은 [손패 흐름 기획 v0.1 §7](hand-draw-flow-design-v01.md#7-사용자-결정과-v1-구현-기록-2026-10-18)에 기록했다. 요약: 낮 손패에는 낮 카드만, 밤 손패에는 밤 카드만(`Cfg.CARD_PHASE`), 전환 때 반대 시간대 카드는 주머니로 가고 넣은 만큼 뽑는다. 모든 드로우는 지금 시간대에 쓸 수 있는 주머니 카드에서만 뽑는다. 카드 3장을 쓰면 1장(주머니 옆 달빛 스택), 켜진 모닥불에 카드를 태우면 1장(하루 2회, 침식은 드로우 없이 체력 -5). 검증 `verify_hand_flow.gd` 54/54, `verify_pocket.gd` 59/59.
