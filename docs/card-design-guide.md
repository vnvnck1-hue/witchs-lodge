# 마녀산장 카드 디자인 가이드

확정일: 2026-10-16 · 기준: 사용자 승인 역할별 개별 카드 6종

**시대 배경 공통 기준 추가(2026-10-17, 사용자 확정):** 카드의 설정과 원화도 중세를 기반으로 일반적인 판타지 문법에 따라 어느 정도 각색할 수 있는 세계를 따른다. 인물의 복식·장비, 건축·생활 도구·재료·사건 장면은 중세의 생활감과 분위기를 바탕으로 구성하고 마법·종족·조형을 게임에 맞게 각색한다. 신규 제작·재제작의 프롬프트와 결과 검수에 반드시 반영한다. 공통 기준은 [아트 가이드](art-direction.md)와 [세계관 기획](world-races-card-formats-v01.md)을 따른다.

## 1. 앞으로의 카드 제작 기준

**신규 카드와 기존 카드의 재제작은 이 가이드와 아래의 역할별 승인 PNG를 따른다.** 사용자가 개별 제작한 6종에 대해 “좋아. 지금 카드들의 포멧을 카드 디자인 가이드에 잘 기록해줘. 앞으로 생성하는 카드들에도 이 포멧을 잘 지키도록”이라고 지시한 것을 확정 근거로 삼는다.

이 문서는 카드의 시각 포맷에 관한 제작 기준이다. 그림에 적힌 예시 효과·수치의 게임 규칙 확정, 기존 게임 에셋의 자동 교체를 뜻하지 않는다. 이후 사용자가 명시적으로 변경한 부분은 그 지시를 반영해 이 문서와 참조 경로를 갱신한다.

참조 우선순위는 **최신 사용자 지시 → 이 가이드와 역할별 승인 개별 PNG → 레이아웃 수치 → 제작 이력**이다. 6종이 한 장에 담긴 초기 비교판은 전체 방향을 보여주는 이력이다. 개별 PNG와 다를 때는 여백과 장식을 정리한 개별 PNG를 기준으로 한다. `drafts/`, 빈 원화창 탐색 A/B/C, 절제 수정 v03, 기존 S자 접목 v04~v06은 최종 제작 템플릿으로 사용하지 않는다.

## 3. 공통 화풍과 먹선

- 보라색 카드 바탕, 크림색 이름·설명 패널, 굵고 가늘어지는 검은 먹선, 페인터리 인쇄 질감을 공유한다.
- 먹선은 카드의 핵심 디자인 요소다. 역할별 원화창·패널과 자연스럽게 연결하되 이름과 설명의 중앙 사용 면적을 보존한다. 원화·표식에 맞춰 선의 연결과 두께를 정리할 수 있지만 승인된 역할의 골격을 새 포맷으로 재해석하지 않는다.
- 큰 색면과 명확한 명암, 두꺼운 윤곽을 유지한다. 카드가 작아졌을 때 읽히지 않는 촘촘한 장식·미세 무늬를 늘리지 않는다.
- 외곽은 약하게 라운드 처리하고 손패에 나란히 놓을 수 있는 직사각형 2:3 실루엣을 유지한다. 원화창이 마름모여도 카드 자체를 마름모·열쇠·방패 모양으로 잘라내지 않는다.
- 원화는 해당 카드가 사용되는 세계·지역·계절을 반영한다. 승인 사례의 겨울·숲 배경은 다른 지역·계절 카드에 강제로 반복하는 규칙이 아니다.
- 종족 표시는 인물 역할 안에서 작은 배지·보조 문양으로 구별한다. 역할과 종족은 별도 축이다. 고블린에게 보너스를 주는 스킬은 스킬 포맷을 유지한다.

종족별 세부 외형·문장과 새로운 하위 역할은 [통합 기획](world-races-card-formats-v01.md)의 후보·미정 구분을 따른다. 이번 6종 승인만으로 모든 종족 프레임이나 추가 카드 종류를 확정하지 않는다.

## 4. 비율과 이름·설명의 최소 영역

**기본 원본은 1024×1536, 세로 2:3이다.** 고해상도는 같은 비율로 확대하고 좌표도 비례 적용한다. 여러 카드를 비교판에 배치할 때도 각 카드의 가로·세로 배율을 동일하게 유지한다. 비교판 셀에 맞춰 카드 높이를 줄이거나 폭을 늘리지 않는다.

아래는 신규 제작에서 확보할 안전 영역이다. 장식보다 우선한다.

| 영역 | 1024×1536 기준 좌표 | 보장할 사용량 |
| --- | --- | --- |
| 제목 | x=110..914, y=72..236, 804×164 | 약 70px 글꼴·76px 행간에서 제목 2줄 |
| 분류 | y=267..307 부근, 제목과 별도 줄 | 약 38~40px 크기의 역할·분류 한 줄 |
| 설명 패널 | x=55..970, y=1120..1495 부근 | 한 덩어리로 이어진 크림색 바탕 |
| 설명 안전 영역 | x=110..914, y=1185..1445, 804×260 | 약 48px 글꼴·60px 행간에서 설명 최소 4줄 |
| 작은 배지 | 원화 하단 y=1020..1120 부근 | 종족·자원 표식. 설명 안전 영역 위에서 종료 |

제목·설명 안전 영역에는 장식 먹선, 문양, 프레임 꼭짓점, 종족·자원 아이콘, 돌·기둥, 종이 접힘과 구분선을 넣지 않는다. 짧은 한국어 이름·효과 때문에 패널을 줄이지 않는다. 긴 번역에 필요한 빈 공간을 남기고 제목 2줄과 설명 최소 4줄을 수용하도록 구성한다. 더 긴 문구는 줄바꿈·번역 길이·배치를 함께 검토하고 필요하면 원화·장식 면적을 줄여 글 영역을 확보한다. 글씨를 과도하게 줄이거나 원화를 비균등 확대해서 해결하지 않는다.

수치의 기계 판독 원본은 [card-role-layout-v02.json](card-role-layout-v02.json)이다. 좌표는 **새 제작·레이아웃 검수 기준**이며 승인 PNG의 모든 곡선을 픽셀 단위로 추출한 마스크는 아니다. 신규 카드에서는 제목·설명 공간을 먼저 잡고 원화 높이·배지·장식을 그 바깥에 맞춘다. 승인 PNG를 재배치할 때도 이 차이를 인지하고 필요한 여백을 확보한다.

## 5. 다국어와 인쇄 문구

- 카드 이름·분류·설명·종족명은 번역 대상이다. 각 위치에 긴 번역을 넣을 공간을 유지한다.
- 시안 PNG에는 검수용 한국어를 인쇄할 수 있다. 시안의 한글을 구운 PNG만으로 다국어 대응이 완료된 것으로 취급하지 않는다.
- 실제 다국어 배포에서는 프레임·원화와 동적 텍스트를 분리하고 로케일별 글꼴·줄바꿈·오버플로를 확인한다. 그림의 문장·인물 정체성을 해치지 않고 글을 교체할 수 있어야 한다.
- 원화에 가격·공격력·체력·수량·지속시간 같은 변경 가능한 수치를 장식으로 구워 넣지 않는다. 별도로 요청한 런타임 정보는 UI 규칙으로 다룬다.
- 이름과 설명의 철자·띄어쓰기는 확정된 원문과 대조한다. 그림에 임의의 새 효과·게임 규칙·조건을 추가하지 않는다.

## 6. 매번 적용할 제작 절차

1. 카드의 역할을 정하고 **위 표의 해당 역할 PNG를 먼저 열어 실제 모양을 확인**한다. 여러 역할의 장식을 임의로 섞지 않는다.
2. 새 제목·분류·본문, 종족 표식 여부, 원화의 주제·지역·계절을 정리한다. 기존 카드 재제작이면 현재 데이터의 이름·효과를 먼저 확인한다.
3. 해당 역할의 승인 PNG를 이미지 생성의 실제 참고 입력으로 사용한다. 이번 6종의 실제 생성 프롬프트와 추가 수정도 아래 링크에서 확인한다.
4. 프롬프트에는 중세 기반 판타지의 시대 배경과 각색 방향, 단일 카드 2:3, 역할 고유 창 형태, 제목 2줄·설명 4줄 안전 영역, 글칸 안 장식 금지, 정확한 인쇄 문구와 바꿀 원화를 명시한다.
5. 생성 결과를 원본 크기로 검수하고 아래 실패 사례가 있으면 수정한다. 특히 좁은 제단 제목·작은 설명란·긴 마름모 끝·사건 중앙 문양이 다시 생기지 않는지 본다.
6. 승인 기준 PNG와 기존 배포 파일은 보존하고 새 버전 경로에 저장한다. 파일·해시·실제 프롬프트·수정 이유를 남긴다. 사용자가 게임 적용을 요청한 범위에서만 런타임 자산을 교체한다.

프롬프트에 포함할 공통 지시 예시:

```text
Set the artwork in a medieval-based fantasy world. Allow familiar fantasy
adaptations while keeping a medieval sense of daily life and atmosphere.
Create one upright 1024x1536 card, true 2:3, using the supplied APPROVED
<role> card as the frame/layout reference. Preserve its purple stock,
black variable-width ink waves, cream title/rules panels, role-specific
art window and painterly style. Change only <subject and approved text>.
Reserve a two-line title field and a clean continuous four-line rules field.
No badge, ornament, divider, stone block or artwork-frame point may overlap
these text safe areas. Keep enough blank space for longer translations.
Preserve proportions; do not squeeze the card to fit a comparison board.
```

공통 지시와 함께 각 역할의 고유 구조와 정확한 인쇄 문구를 명시한다.

## 7. 생성 후 검수 기준

신규 카드는 다음 기준으로 확인한다.

- 설정·복식·장비·건축·소품·장면이 중세 기반 판타지에 어울리고, 각색한 요소도 그 생활감과 분위기에 맞는가.
- 원본의 치수·비율이 맞고 카드 전체가 잘리지 않은 단일 이미지인가.
- 같은 역할의 승인 PNG와 원화창·패널·외곽 구조가 일치하는가.
- 이름·분류·설명·종족 표기가 원문과 일치하고 글자 누락이나 장식의 가림이 없는가.
- 제목 2줄·설명 4줄 여백을 유지하고 짧은 문구 때문에 패널을 줄이지 않았는가.
- 자원의 중복 가로선, 시설의 좁은 이름판·설명칸, 사건의 중앙 갈래 문양, 설명란을 찌르는 마름모·방패 끝이 없는가.
- 실사용 PNG의 RGBA와 외곽 투명 알파를 확인했는가. 참조 이미지에 배경이 있더라도 생성 결과의 실제 알파를 검사한 뒤 투명 완성으로 기록한다.
- 손패용 축소본은 256×384 등 같은 2:3을 유지하며 이름·역할·종족과 주요 원화 형태가 구별되는가.
- 다국어 구현 단계에서 여러 언어의 긴 제목·긴 설명을 실제 배치해 줄바꿈·글꼴·넘침을 확인했는가. PNG 시각 검수만으로 다국어 구현이 완료됐다고 표시하지 않는다.

## 9. 기존 게임 카드 적용

사용자의 전체 에셋 갱신 요청에 따라 앞면 26종과 공용 뒷면 1종에 적용했다. [적용 카드 목록·개별 PNG·검수·배포 기록](card-role-format-rollout-v02.md)을 참조한다. 역할 포맷의 시각 기준은 계속 2절의 승인 개별 PNG 6종이다.
