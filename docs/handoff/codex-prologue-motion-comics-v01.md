# Codex에게 요청하는 에셋 작업 — 프롤로그 모션 코믹스 레이어 (v01)

요청자: Claude (게임 구현 담당) · 2026-10-18 · 기획: [프롤로그 모션 코믹스 기획 v01](../prologue-motion-comics-design.md)

사용자 지시 요약: “게임 시작 컷신 원화가 현재 카드 일러스트 스타일과 다르다. 카드 그래픽 스타일에 맞춰 다시 그리고, 정적 슬라이드가 아니라 레이어가 나뉜 시네마틱 일러스트(모션 코믹스)로 구성하라. 사용자가 각 컷을 검수한다.”

## 역할 분담

- **Codex 책임:** 아래 4컷의 레이어 PNG 전체 + 매니페스트 JSON 4개 + 틀 1장 + 검수용 미리보기·컨택트 시트의 생성·트림·검증·문서화.
- **Claude 책임:** 레이어 타임라인 재생 코드, 자막 패널, 전환, 검증 스크립트, 실행파일 내보내기. 레이어가 없는 동안은 기존 정지 그림(`godot/assets/ui/ftue/prologue_0N.png`)으로 동작하므로 **경로·파일명·매니페스트 형식만 맞으면 납품 즉시 적용된다.**
- **수정 금지:** `godot/scripts/**`, `godot/scenes/**`, `godot/shaders/**`, `godot/assets/cards/catalog.json`, `godot/project.godot`, 기존 `godot/assets/ui/ftue/prologue_0N.png`·`title_bg.png`·`witch_*.png`(폴백·타이틀·초상으로 계속 쓴다). Claude가 동시에 코드를 고치고 있다. 다른 작업의 변경을 되돌리지 말 것. **커밋하지 말 것.**
- Godot 실행파일 `.tools/Godot-4.7.2.exe`. 임포트는 이전처럼 격리 프로젝트에서 해도 되고, 실제 게임 폴더에서 `--headless --path godot --import`를 해도 된다(수정 금지 경로에 생기는 `.uid` 등 부산물은 지우지 말고 그대로 둔다).

공통 규칙:

- 중세 기반 판타지. 돌·목재·초가·양모·가죽·철·양초·횃불. 총기·현대 의복·전기 조명 금지.
- 색: 밤은 보라·인디고·청록, 따뜻한 빛은 창문·촛불·불꽃의 앰버만. 고어·잔혹 묘사 금지(마녀사냥도 연기·불·실루엣만).
- **모든 레이어에 글자·로고·서명·워터마크 금지.** 자막·페이지 표시는 게임이 그린다.
- 주인공 마녀는 방위 상징(서리·불꽃·약초·망령) 없음. 컷 1의 네 마녀는 익명 실루엣(낮고 둥근 후드, 뾰족모자·지팡이 금지).
- 각 레이어는 **같은 조명·같은 먹선 두께·같은 질감**으로, 겹쳤을 때 한 장의 그림으로 보여야 한다. 레이어마다 화풍이 달라지면 실패다.
- 화면 아래 1/4은 자막 패널이 올라가므로 모든 컷의 레이어 합성 결과에서 어둡고 단순해야 한다.

## 좌표계와 파일 형식

- 설계 화면 1920×1080. **레이어 캔버스 2304×1296**(120%), 캔버스 원점은 화면 좌상단 기준 (−192, −108). 즉 화면 중앙은 캔버스 (1152, 648).
- 배경 레이어(`*_sky`, `*_wall`, `*_sky_dusk`, `*_sky_night`)는 **캔버스 전체 2304×1296 RGB** PNG.
- 그 외 레이어는 **RGBA, 불투명 영역만 남기고 트림**한 PNG. 트림 전 캔버스 안 위치를 매니페스트에 적는다. 전체 폭이 필요한 띠(언덕·앞쪽 능선·안개 등)는 캔버스 폭 2304 그대로 둬도 된다.
- 글로우 레이어(`*_window_glow`, `*_lantern_glow`, `*_runes`, `*_shafts`)는 **빛만** 담은 RGBA(검은 바탕이 아니라 투명 바탕 위의 반투명 앰버/청록). 게임이 가산 혼합으로 얹는다.
- 알파 가장자리는 깨끗한 안티에일리어싱. 트림 뒤 남는 반투명 띠·후광·회색 테두리 금지. 트림 기준은 알파 8/255 초과.
- 매니페스트 `godot/assets/ui/ftue/motion/cutN.json`:

```json
{
  "cut": 1,
  "canvas": [2304, 1296],
  "layers": [
    { "id": "sky",     "file": "cut1_sky.png",     "pos": [0, 0],      "size": [2304, 1296], "depth": 0.0, "blend": "normal" },
    { "id": "village", "file": "cut1_village.png", "pos": [860, 420],  "size": [640, 220],   "depth": 0.2, "blend": "normal" },
    { "id": "window_glow", "file": "...", "pos": [0, 0], "size": [0, 0], "depth": 0.55, "blend": "add" }
  ]
}
```

`id`는 아래 표의 레이어 이름(접두사 `cutN_` 제외)과 **정확히 일치**해야 한다. 게임 코드가 id로 연출을 찾는다. `blend`는 글로우만 `add`, 나머지 `normal`.

## 제작 절차(컷마다)

1. **마스터 합성본**을 먼저 한 장 만든다(2304×1296, 카드 화풍, 모든 요소가 정지 위치에 있는 완성 그림). `art/concepts/ftue-motion-v01/cutN_master.png`에 저장. 이것이 사용자 검수의 1차 대상이다.
2. 마스터를 참고 입력으로 **클린 플레이트**(인물·연기·글로우·괴물을 뺀 배경)를 만든다. 인물이 있던 자리는 배경으로 자연스럽게 메운다.
3. 마스터를 참고 입력으로 각 요소를 **투명 배경 단독 레이어**로 뽑는다(`transparent_background=true`). 마스터와 같은 각도·크기·조명·먹선을 유지한다. 전체 캔버스로 생성한 뒤 트림해 위치를 계산해도 되고, 요소만 생성한 뒤 마스터 위치에 맞춰 배치해도 된다.
4. 레이어를 매니페스트 위치대로 겹쳐 **`godot/screenshots/ftue/motion/cutN_preview.png`(1920×1080, 화면 영역만)**을 만들고, 마스터와 비교해 어긋난 레이어를 고친다.
5. 4컷을 모두 마치면 **컨택트 시트** `godot/screenshots/ftue/motion/contact-sheet.png`(컷별 미리보기 + 레이어 썸네일, 파일명 라벨)를 만든다.

## A. 컷 1 — 마녀사냥의 끝

자막(그림에 넣지 말 것): “마녀사냥이 끝났을 때, 살아남은 마녀는 넷뿐이었다. / 넷은 동서남북으로 흩어져 몸을 숨겼다.”

| 레이어 id | 형식 | 내용 | 배치 지침(캔버스 2304×1296) |
| --- | --- | --- | --- |
| `sky` | RGB 전체 | 남색·보라 밤하늘, 먼 산 능선, 자주빛으로 번진 연기 색 | 마을 자리(중앙 위, 약 x 1000~1300, y 480~620)는 비워 두거나 어두운 지평선만 |
| `village` | RGBA | 먼 중세 마을 실루엣: 삐뚤한 지붕, 좁은 돌 첨탑, 창과 지붕 사이의 앰버 불꽃 | 중앙 위 지평선. 작게(폭 500~700) |
| `smoke` | RGBA | 마을에서 솟는 큰 연기 덩어리 2~3개(자주·보라, 먹선 윤곽) | 마을 위. 게임이 이것을 2.4배로 키워 화면을 덮으므로 **덩어리 형태가 크게 확대돼도 읽히게** 단순하게 |
| `hills` | RGBA 전체 폭 | 중간 언덕 띠와 침엽수 실루엣, 위에 네 갈래 눈길 | y 700~1000 부근. 언덕 위 평평한 자리(x 900~1400)에 인물이 선다 |
| `witch_1`~`witch_4` | RGBA 4개 | 등을 보인 작은 망토 인물. 낮고 둥근 후드, 손·지팡이·가방 없음. 각각 조금씩 다른 망토 색조(보라·남색·자주·청록) | 캔버스에서 높이 160~220px. 네 명이 **언덕 가운데에 모여 선 위치**로 배치(게임이 네 방향으로 흩어 놓는다) |
| `fore` | RGBA 전체 폭 | 앞쪽 어두운 능선·나무 실루엣, 거의 단색 | y 980~1296. 아래 1/4은 단순한 어둠 |
