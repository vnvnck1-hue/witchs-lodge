## B. 타이틀 배경 (필수)

- `godot/assets/ui/ftue/title_bg.png`, **RGB 1920×1080**. 밤의 산장을 약간 높은 쿼터뷰로 본 정경(게임 카메라와 비슷한 각도). 창문 앰버 빛, 달빛 눈밭, 보라·청록 숲. 게임은 이 그림을 아주 천천히 좌우로 패닝하므로 **좌우 8%는 잘려도 되는** 구도로.

- **생성·기록:** 내장 `image_gen` 8회(7종 + 첫 장 수정 1회). 승인 환경 이미지와 게임 화면을 실제 참고 입력으로 사용했다. 첫 장의 불필요한 산장·모자·지팡이를 제거했다. [실제 프롬프트·참고 입력·재생성 이력](../prompts/ftue/ftue-prologue-v01-prompts.md), [생성 기록 JSON](../../output/ftue-prologue-v01/generation-manifest.json), [채택 원본 및 미채택 초안](../../art/concepts/ftue/).
- **직접 시각 확인:** [7장 미리보기 시트](../../godot/screenshots/ftue/asset-sheet.png)에서 하단 1/4 자막 여백, 타이틀 왼쪽 40% 메뉴 영역과 상단 제목 공간, 줌·패닝 여백을 확인했다. 중세 판타지·보라 설경·앰버 빛을 유지했고, 글자·워터마크·주인공 방위 상징·잔혹 묘사가 없다. 인물 뒤 회색은 시트의 검수용 바탕이며 실제 PNG 바깥은 투명하다.
- **파일 검증:** 7장 모두 크기·PNG RGB/RGBA·8비트 채널·알파·SHA-256 검증 통과. 잠금 실루엣은 보이는 모든 픽셀이 정확한 단색인지도 검사했다. [검증 JSON](../../output/ftue-prologue-v01/asset-verification.json)의 `passed=true`.
- **Godot 임포트:** 지정 Godot 4.7.2와 동일 SHA-256 실행 파일로 `--headless --path godot --import`를 수행해 **종료 코드 0**을 확인했다. 수정 금지 경로에 `.gd.uid` 등이 자동 생성되지 않도록 **이미지 전용 격리 프로젝트**에서 실행했고, 7개의 `.png.import` 및 해당 컴파일 텍스처만 실제 게임에 반영했다. 게임 폴더 전체 임포트·게임 코드 실행 검증과는 구분한다. [실행 위치·결과](../../output/ftue-prologue-v01/godot-import-result.json), [stdout](../../output/ftue-prologue-v01/godot-import.stdout.log), [stderr](../../output/ftue-prologue-v01/godot-import.stderr.log).
- **로드 검증:** Godot에서 임포트된 텍스처 7개를 모두 로드하고 크기와 이미지 디코딩을 확인했다. [텍스처 로드 결과](../../output/ftue-prologue-v01/texture-load-verification.json)도 `passed=true`. 샌드박스의 인증서 저장소·사용자 저장소 접근 진단은 로그에 남아 있지만 이미지 임포트와 로드는 통과했다.
- **수정 범위·커밋:** 이미지·미리보기·문서·검증 산출물을 작성했고 **수정 금지 경로는 직접 수정하지 않았다. 커밋하지 않았다.** 작업 중 관찰된 동시 구현 변경은 검증 JSON에 따로 기록하고 그대로 보존했다. `.tools/Godot-4.7.2.exe`는 처음에 134바이트 LFS 포인터여서 동일 객체(SHA-256 일치)의 실제 실행 파일로 복원했다. 현재 다른 프로세스가 이를 사용 중이므로 종료하거나 교체하지 않고 실행 파일 상태를 유지했다. `output/`의 임시 실행 파일 사본은 정리했다.
