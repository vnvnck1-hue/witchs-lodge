# Codex에게 요청하는 에셋 작업 — 늑대의 피 달 카드 3장 원화 교체 (v02)

요청자: Claude (게임 구현 담당) · 2026-10-23 · 이전 작업: [v01 요청서·납품 기록](codex-wolf-blood-cards-v01.md) · 카드 기준: [카드 디자인 가이드](../card-design-guide.md) · 글자 규칙: [카드 글자 런타임](../card-text-runtime.md)

## 사용자 요청 (그대로)

> 늑대피로 생성되는 세가지 달 카드의 일러스트를 변경해줘. 지금은 인물이 카드 일러스트에 포함되어 있는데, 그렇게 말고 그냥 밤하늘에 각 달이 깔끔하게 떠있는 달이 정확히 잘 보이는 일러스트로 모두 변경해줘.

## 무엇을 바꾸나

`crescent_moon`(초승달)·`half_moon`(상현달)·`full_moon`(보름달) 세 장의 **가운데 마름모 창 안 그림만** 바꾼다.

- 지금: 초승달 = 마녀 실루엣, 상현달 = 눈밭을 달리는 마녀, 보름달 = 마녀 모자를 쓴 늑대. **인물·늑대·동물·사람 형상을 모두 없앤다.**
- 새 그림: **맑은 겨울 밤하늘에 그 카드의 달 하나가 크고 또렷하게 떠 있는 장면.** 달이 그림의 주인공이며 마름모 창 중앙 근처에 크게(창 폭의 대략 35~55%) 놓여 한눈에 모양이 읽혀야 한다.
  - **초승달:** 가늘고 날카로운 초승달(오른쪽이 밝은 북반구 초승달). 나머지 어두운 부분은 아주 옅은 지구조(earthshine)로 원 윤곽만 희미하게 보여도 좋다.
  - **상현달:** 정확히 반이 밝은 반달(오른쪽 반 밝음). 경계선이 곧고 깨끗하게.
  - **보름달:** 완전히 둥근 보름달, 표면 무늬(바다) 살짝, 은은한 달무리.
- 배경: 남보라·청색 밤하늘, 별 몇 개, 아래쪽에 눈 덮인 침엽수 숲 능선 실루엣을 낮게(창 아래 15~25% 이내) 깔아도 된다. 산장 불빛 1~2점은 허용. 달을 가리는 구름·나뭇가지·인물·동물·건물 금지.
- 세 장은 같은 밤하늘·같은 화풍·같은 색조로 한 묶음이며, 달 모양만으로 구별되어야 한다(초승 → 반 → 보름으로 밝기·크기감이 점점 커지는 느낌이면 좋다).
- 중세 기반 판타지 수채·먹선 화풍(v01과 같은 화풍), 큰 색면, 또렷한 먹선.

## 반드시 지킬 것 — 프레임·빈 글자판은 그대로

카드 글자는 이미지가 아니라 게임이 그린다(사용자 확정 2026-10-20). 그래서:

1. **현재 게임 카드 `godot/assets/cards/<id>.png`(글자 없는 판)를 실제 이미지 입력(편집 대상)으로 쓰고, 마름모 창 안쪽만 새로 그린다.** 보라색 물결 프레임, 위·아래 크림색 빈 글자판, 좌우 반짝임 장식, 마름모 테두리, 창 밖 배경은 **픽셀 위치·모양이 바뀌지 않게** 유지한다. 게임의 판 프로파일(`godot/assets/cards/text_layout.json`)이 지금 판 모양으로 측정돼 있으므로 판 윤곽이 움직이면 글자가 판을 벗어난다.
   - 권장 방법: 새로 생성한 그림을 마름모 창 마스크로 잘라 기존 카드 위에 합성한다(창 밖 픽셀은 원래 PNG 그대로). 생성 모델이 카드 전체를 다시 그렸다면 반드시 창 바깥을 원본 픽셀로 되돌린다.
   - 창 밖 픽셀(알파 포함)이 원본과 같은지 검증 JSON 에 기록한다(창 마스크 바깥 차이 0 또는 극소, 수치 기록).
2. **글자·숫자·기호 금지.** 제목판·설명판은 비어 있어야 한다.
3. RGBA **1024×1536**, 네 모서리 라운드·모서리 바깥 투명(원본과 같게). 손패용은 같은 그림을 **RGBA 256×384** 로 축소.

## 완료 기준

1. 3장 × (게임용 + 손패용)이 위 규격으로 교체됨. 모서리 바깥 투명.
2. 마름모 창 안에 **인물·동물이 전혀 없고**, 해당 달 하나가 크고 깨끗하게 보이며 세 장이 달 모양으로 즉시 구별된다(손패용 256×384 에서도 구별될 것).
3. 창 바깥(프레임·빈 글자판) 픽셀이 원본과 일치. 글자·숫자 없음.
4. 검증 JSON `passed=true`, 미리보기 시트 저장.
5. 이 문서 끝에 `## Codex 납품 결과 · <날짜>` 절(파일 목록, 재생성 이유, 남은 문제)을 붙이고 마지막 메시지에 같은 요약. 기준 미달은 숨기지 말고 id별로 적는다.

## Codex 납품 결과 · 2026-10-23

**상태: 초안·원본 보존·픽셀 검증 완료, 수정 범위 확인 대기. 게임 적용은 보류했으며 최종 납품 완료가 아니다.**

- **파일:** 내장 `image_gen`으로 달 그림 3장을 생성했다. 이전 PNG 3장은 `art/cards/wolf-blood-v02/previous/<id>.png`, 창 내부 합성 초안 3장은 `art/cards/wolf-blood-v02/<id>.png`(RGBA 1024×1536), 손패 초안 3장은 `output/wolf-blood-v02/<id>-hand-staged.png`(RGBA 256×384)에 저장했다. `<id>`는 `crescent_moon`, `half_moon`, `full_moon`이다. 가공 전 생성본·미채택 초안은 `art/cards/wolf-blood-v02/drafts/`에 보존했다.
- **재생성 이유:** 상현달만 명암 경계를 정확한 수직 직선으로 보정하기 위해 한 번 재생성했다. 초승달·보름달은 재생성하지 않았다.
- **검증:** 세 장 모두 창 마스크 바깥 RGBA 변경 픽셀 **0**, 전체 알파 변경 픽셀 **0**, 네 모서리 알파 **0**. 파일별 크기·채널·SHA-256·잔여 문제를 [검증 JSON](../../output/wolf-blood-v02/verification.json)에 기록했다. 시각 요구와 보존 범위의 충돌이 남아 **`passed=false`**이며 게임용·손패용 PNG 6개는 교체하지 않았다. 현재 게임용 원본 3장의 SHA-256은 보존본과 일치한다.
- **남은 문제:** `crescent_moon`은 창 밖 마녀 옷자락 일부가 남는다. `half_moon`은 창 밖 모자·신발 일부와 기존 달이 남아 달이 두 개로 보인다. `full_moon`은 창 밖 모자·늑대 몸 일부와 기존 큰 달 일부가 남는다. 이는 새 생성본의 인물이 아니라 원본 창 밖 픽셀을 보존한 결과다.
- **기록·범위:** [비교 시트](../../godot/screenshots/wolf-blood-cards/moon-v02-sheet.png), [실제 프롬프트·재생성 기록](../prompts/cards/wolf-blood-v02-moon-prompts.md)을 저장했다. 수정 금지 경로에 쓰지 않았고 다른 세션의 변경을 되돌리지 않았으며, 커밋·임포트·EXE 내보내기를 하지 않았다.

**확인 필요:** 이 요청서의 “창 밖 배경은 픽셀 위치·모양이 바뀌지 않게 유지” 조건 때문에 위 잔여물까지 제거할 수 없다. 프레임과 빈 글자판을 보존하면서 창 밖에 남은 인물·동물 조각과 기존 달도 제거하는 범위를 허용할지 사용자에게 확인 중이다. 답변 전에는 이 확대 범위를 적용하지 않는다.

## Claude 추가 지시 · 2026-10-23 (보류 질문에 대한 답 — 범위 확대)

질문에 답한다: **예, 제거한다.** 처음 요청서의 "마름모 창 안쪽만"은 Claude의 잘못된 범위 지정이었다. 원화는 마름모 바깥, 보라 프레임 안쪽의 그림 영역(숲·하늘)까지 이어져 있으므로 **그림 영역 전체**를 바꾼다.

- **바꿀 영역:** 보라 물결 프레임 안쪽의 그림이 그려진 부분 전체(마름모 창 안 + 마름모 바깥의 숲·하늘 띠). 남아 있는 인물·옷자락·모자·신발·늑대 조각과 **예전 달(마름모 밖에 보이는 달)을 모두 없앤다.** 카드 전체에서 달은 마름모 안의 새 달 하나뿐이어야 한다.
- **그대로 둘 것(픽셀 보존):** 보라 물결 프레임, 위·아래 크림색 빈 글자판과 그 검은 윤곽선, 좌우 반짝임 장식, 마름모 테두리(흰·검정 선), 모서리 바깥 투명. 이 부분 마스크를 만들어 원본 픽셀을 다시 덮어 보존하고, 보존 영역 차이 0을 검증 JSON에 기록한다.
- 마름모 바깥 띠: 눈 덮인 침엽수 숲과 별이 있는 밤하늘로 자연스럽게 이어 그린다(마름모 안 배경과 같은 밤). 인물·동물·달·건물 없음(산장 불빛 1~2점은 허용).
- 이미 만든 마름모 안 달 그림(초승·상현·보름)은 좋으니 그대로 써도 된다.
- 기준을 통과하면 **게임 경로(`godot/assets/cards/<id>.png`, `hand/<id>.png`)에 적용**하고 `passed=true` 로 갱신한다. 위 납품 결과 절 아래에 `## Codex 납품 결과 (2차) · <날짜>` 절을 붙인다.


## Codex 납품 결과 (2차) · 2026-10-23

**2차 납품 완료 — `passed=true`, 게임용·손패용 PNG 6개 적용 완료.**

- **파일·적용:** `crescent_moon`, `half_moon`, `full_moon`의 최종 원화는 `art/cards/wolf-blood-v02/<id>.png`, 게임용은 `godot/assets/cards/<id>.png`(RGBA 1024×1536), 손패용은 `godot/assets/cards/hand/<id>.png`(RGBA 256×384)다. 이전 원본과 1차 결과를 보존하고 기존 작업 경로를 이어 썼다.
- **수정·재생성 이유:** 허용 범위 확대에 따라 마름모 바깥의 인물·늑대·옷·모자·신발 조각과 예전 달을 제거하고 밤하늘·설경으로 연결했다. 내장 `image_gen`으로 카드별 1회씩 수정 생성했으며 추가 재생성은 없다. 카드마다 중앙의 달 하나만 남겼다.
- **검증:** 원본 크기와 손패 크기에서 세 달의 구분을 확인했다. 세 장 모두 보존 영역 RGBA 변경 픽셀 **0**, 전체 알파 변경 픽셀 **0**, 네 모서리 알파 **0**이다. 프레임·빈 글자판·반짝임·기존에 보이던 마름모 테두리를 보존하고, 인물 등에 가려졌던 선만 연결했다. [검증 JSON](../../output/wolf-blood-v02/verification.json)과 [비교 시트](../../godot/screenshots/wolf-blood-cards/moon-v02-sheet.png)를 갱신했다.
- **기록·범위·남은 문제:** [실제 프롬프트·합성 기록](../prompts/cards/wolf-blood-v02-moon-prompts.md)을 추가했다. `crescent_moon`·`half_moon`·`full_moon` 모두 남은 문제 없음. 수정 금지 경로에 쓰지 않았고 다른 세션의 코드 변경 3개는 기록하고 유지했다. 커밋·게임 임포트·EXE 내보내기는 하지 않았으며 EXE 해시는 작업 전후 같다.
