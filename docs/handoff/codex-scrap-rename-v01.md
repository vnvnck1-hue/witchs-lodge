# Codex에게 요청하는 에셋 작업 — "고물" → "쇠붙이" 카드 2장 재제작 (v01)

요청자: Claude (게임 구현 담당) · 2026-10-19 · 이전 요청서: [고블린 카드 13장](codex-goblin-cards-v01.md) · 카드 기준: [카드 디자인 가이드](../card-design-guide.md)

## 배경

사용자 지시로 고블린 판매용 재화 카드 `scrap`의 표시 이름이 **"고물" → "쇠붙이"** 로 바뀌었다. 앞으로 약초·정수와 함께 마법책 제작 창에서 쓰는 **제작 재료**가 될 예정이다. `catalog.json`·코드·검증 스크립트는 이미 바뀌었고(id는 `scrap` 그대로), 남은 것은 **카드 원화에 그려진 옛 문구**뿐이다. 이번 작업으로 아래 2장(게임용 + 손패용)을 같은 경로에 **덮어쓴다**.

"고물 방책"(`junk_barricade`)·"고물 갑옷"은 이름을 그대로 두기로 했으니 **건드리지 않는다.**

## 역할 분담

- **Codex 책임:** 카드 2장(원본·게임용·손패용)의 생성·후처리·검증·문서화.
- **Claude 책임:** 게임 코드·카탈로그·검증 스크립트·실행파일 내보내기.
- **수정 금지:** `godot/scripts/**`, `godot/scenes/**`, `godot/shaders/**`, `godot/tools/**`, `godot/assets/cards/catalog.json`, `godot/project.godot`, 이번 2장 외 기존 `godot/assets/cards/**/*.png`, `art/cards/goblin-v01/**`(이전 원본은 보존), `docs/` 의 기획 문서(이 요청서 끝의 납품 결과 절만 추가), 루트 `WitchsLodge.exe`(Claude가 내보낸다). 다른 작업의 변경을 되돌리지 말 것. **커밋하지 말 것.** Claude와 다른 세션들이 같은 저장소에서 동시에 작업 중이다.

## 반드시 따를 기존 기준

먼저 읽기: [카드 디자인 가이드](../card-design-guide.md)(§2 역할별 포맷, §4 안전 영역, §6 절차, §7 검수), [고블린 카드 요청서](codex-goblin-cards-v01.md)(같은 카드의 이전 납품 방식과 끝의 납품 결과 절), 아트 가이드 `docs/art-direction.md`, 전역 지침 `CLAUDE.md`(중세 기반 판타지).

**실제 이미지 참고 입력(필수, 매 장):**

1. **자원 역할 승인 PNG** `art/concepts/cards/roles-individual-v02/03-resource-timber.png` — 직사각형 계열 원화창, 원화·설명 전환부의 작은 자원 표식 하나, 하나로 이어진 설명 패널.
2. **지금 게임 카드(교체 대상)** `godot/assets/cards/scrap.png`, `godot/assets/cards/junk_sack.png` — 화풍·프레임·글자체·고블린 색조의 직접 기준. 같은 묶음으로 보여야 한다.
3. 같은 역할의 게임 카드 `godot/assets/cards/timber.png`·`rabbit_pelt.png`(화풍 일관성).

공통 요건(이전 요청서와 동일):

- **RGBA 1024×1536(2:3), 네 모서리 라운드, 모서리 바깥 투명.** 손패용은 같은 그림을 **RGBA 256×384**로 균등 축소.
- 인쇄 문구(제목·분류 띠·설명 2줄)는 아래 표 **그대로**(철자·띄어쓰기·가운뎃점 ` · ` 포함). 제목 2줄·설명 4줄 안전 영역을 비워 둔다. 글칸 안 장식 금지, 원화에 수치·숫자 금지(단, `scrap` 인쇄 문구 "1개 4G."는 표 그대로 둔다).
- **"임시 카드" 같은 문구를 넣지 않는다.** 그림 안 어디에도 옛 이름 "고물"이 남지 않게 한다.
- 중세 기반 판타지, 겨울 숲·산장. 고블린 보조색(이끼·구리)과 리벳 모티프를 원화 안에 은근히.

## 카드 2장 (인쇄 문구는 이 글자 그대로)

| id | 포맷 | 카드 이름 | 분류 띠 | 인쇄 문구 (2줄) |
|---|---|---|---|---|
| `scrap` | 자원 | 쇠붙이 | 고블린 · 판매용 | 산장에 놓으면 팝니다. / 1개 4G. |
| `junk_sack` | 자원 | 잡동사니 자루 | 고블린 · 자원 꾸러미 | 낮에 열면 자원이 나옵니다. / 가끔 쇠붙이도 섞입니다. |

### 원화 내용

- **쇠붙이(`scrap`) — 원화 새로 그림:** 녹슨 쇠붙이 한 줌 — 찌그러진 숟가락, 경첩, 납작한 쇠 조각·리벳 몇 개. 지금 카드의 부서진 냄비·구멍 난 통 같은 **"쓸모없는 쓰레기" 느낌은 줄이고**, 앞으로 제작 재료로 쓰일 **쓸 만한 재료 더미**처럼 보이게: 크기별로 대충 모아 둔 쇠 조각, 녹 사이로 드러난 쇠 광택, 작업대(나무 판) 위나 가죽 천 위에 소복이. 겨울 산장 배경·눈은 지금처럼 유지. 원화·설명 전환부의 작은 자원 표식은 숟가락+경첩 대신 **쇠 조각 몇 개(또는 경첩 하나)** 로 단순하게.
- **잡동사니 자루(`junk_sack`) — 문구만 교체:** 그림·프레임·제목·분류·첫 줄은 **지금 카드 그대로** 두고, 설명 둘째 줄 "가끔 쓸모없는 고물도 섞입니다." → **"가끔 쇠붙이도 섞입니다."** 만 바꾼다. 설명 패널 영역만 다시 그리는(인페인팅/패널 재합성) 방식을 권장한다. 글자체·크기·색·가운데 정렬·행간이 첫 줄과 맞아야 하고, 지운 자리에 얼룩·잔상이 남지 않아야 한다. 가능하면 자루 입구에 녹슨 쇠 조각 하나가 보이면 좋지만 필수는 아니다(그림을 바꾸면 전체 일관성을 다시 확인).

두 장을 나란히 놓았을 때 같은 묶음으로 보이고, 손패 크기(256×384)에서도 쇠붙이가 "쇠 조각 더미"로 읽혀야 한다.

## 완료 기준

1. 카드 2장 × (게임용 + 손패용)이 위 경로·규격으로 교체됨. 모서리 바깥 투명.
2. 자원 승인 PNG·지금 카드와 원화창·프레임·글자 배치가 일치하고, 인쇄 문구가 표와 정확히 같다(원본 크기로 직접 확인, 오탈자 0, "고물" 글자 0).
3. 쇠붙이 원화가 "쓸 만한 쇠 재료"로 읽히고, 잡동사니 자루는 문구 외 변화가 없거나 의도한 작은 변화만 있다.
4. 글자 안전 영역 침범 없음, 금지 수치·임시 문구 없음, 미리보기 시트로 일관성 확인.
5. `--import` 종료 코드 0, 검증 JSON `passed=true`.
6. 이 문서 끝에 `## Codex 납품 결과 · <날짜>` 절(파일 목록, 재생성 이유, 남은 문제)을 붙이고 마지막 메시지에 같은 요약. 기준 미달은 숨기지 말고 id별로 적는다.

## Codex 납품 결과 · 2026-10-19

두 카드의 원본·게임용·손패용 총 6개 PNG를 지정 경로에 납품했다. 내장 `image_gen`으로 카드마다 승인 자원 PNG와 기존 게임 카드 4장을 실제 참고 입력했으며, 각각 첫 생성본을 채택했다. 가공 전 생성본은 `art/cards/scrap-rename-v01/drafts/`에 보존했다.

| id | 보존 원본 · RGBA 1024×1536 | 게임용 · RGBA 1024×1536 | 손패용 · RGBA 256×384 |
| --- | --- | --- | --- |
| `scrap` | [PNG](../../art/cards/scrap-rename-v01/scrap.png) | [PNG](../../godot/assets/cards/scrap.png) | [PNG](../../godot/assets/cards/hand/scrap.png) |
| `junk_sack` | [PNG](../../art/cards/scrap-rename-v01/junk_sack.png) | [PNG](../../godot/assets/cards/junk_sack.png) | [PNG](../../godot/assets/cards/hand/junk_sack.png) |

- **scrap 제작 이유·결과:** 제목을 `쇠붙이`로 교체하고, 제작에 쓸 만한 납작한 쇠 조각·경첩·숟가락·리벳을 나무 작업대와 가죽 천 위에 모은 새 원화를 만들었다. 눈·겨울 숲·따뜻한 산장과 기존 먹선·색조를 유지하고 자원 표식을 쇠 조각으로 단순화했다. 인쇄 문구는 `고블린 · 판매용`, `산장에 놓으면 팝니다.`, `1개 4G.`로 확인했다.
- **junk_sack 제작 이유·결과:** 설명 둘째 줄만 `가끔 쇠붙이도 섞입니다.`로 바꿨다. 생성본의 해당 설명 패널만 기존 카드에 합성했으며, 허용한 사각형 `[180,1306,845,1385)` 밖 변경 픽셀은 **0**이다. 기존 그림·프레임·제목·분류·첫 줄은 픽셀 단위로 동일하다. 새 둘째 줄의 글자체·크기·색·가운데 정렬과 깨끗한 종이 배경을 원본 크기로 확인했다.
- **검증:** 6개 PNG의 규격·RGBA 채널·모서리 투명 알파·SHA-256, 원본과 게임용의 해시 일치, 손패의 정확한 1/4 균등 축소를 검증했다. 새 카드의 인쇄 문구·오탈자·옛 이름 부재, 자원 프레임·글자 여백·중세 판타지 표현과 손패 실루엣도 직접 확인했다. **[검증 JSON](../../output/scrap-rename-v01/verification.json) `passed=true`.**
- **import:** 요청된 `.tools/Godot-4.7.2.exe --headless --path godot --import`를 실행해 종료 코드 **0**을 확인했다. 게임용·손패용 텍스처 로드·규격·알파는 **4/4 통과**했고, 각 `.import`가 가리키는 캐시의 원본 MD5도 현재 PNG와 일치한다. [import 로그](../../output/scrap-rename-v01/import.log), [텍스처 검증](../../output/scrap-rename-v01/texture-verification.json).
- **기록:** [새 2장·이전 2장·승인 자원 PNG 미리보기](../../godot/screenshots/scrap-rename/sheet.png), [실제 프롬프트·참고 입력·후처리](../prompts/cards/scrap-rename-v01-prompts.md), [문구 시각 검수](../../output/scrap-rename-v01/visual-review.json), [자루 픽셀 보존 검증](../../output/scrap-rename-v01/junk-sack-pixel-diff.json).
- **작업 경계:** 코드·씬·셰이더·도구·카탈로그·프로젝트 설정·다른 기존 카드·`art/cards/goblin-v01/**`·실행파일은 수정하지 않았다. 시작 시점 보호 파일 1132개와 비교했고, 다른 세션에서 완료된 고블린 카드 요청서 납품 절 및 프롬프트 문서 변경 2건은 해시와 함께 관찰 기록으로 남기고 그대로 보존했다. 이 요청서는 기존 본문을 유지하고 이 절만 추가했다. **커밋·실행파일 내보내기는 하지 않았다.**
- **남은 문제:** `scrap`, `junk_sack` 모두 납품 기준 미달 사항 없음. Godot 로그에는 시스템 루트 인증서 저장소 읽기 오류가 있으나 로컬 import와 텍스처 검증은 정상 통과했다. 실행파일 갱신은 요청서에 명시한 Claude 담당으로 남긴다.
