## 바꿀 것 / 유지할 것

- **바꿀 것 (오직 등짐):** B의 흰 보따리와 그 끈을 없애고, A의 **갈색 둥근 배낭 + 배낭 위에 가로로 얹은 크림색 말린 담요 + 배낭 옆에 매단 작은 등불(노란 유리 면)** 로 바꾼다. 배낭 멜빵이 어깨 위로 보이게 하되, B의 짧은 망토 목도리 위/아래 겹침이 자연스러워야 한다. 크기는 A와 비슷하게, 머리보다 높이 솟지 않게.
- **유지할 것 (나머지 전부 B 그대로):** 각도·카메라·자세(A자 팔), 머리 덩어리 모양, 단추 눈·코·홍조·작은 미소, 큰 귀와 왼쪽(화면 기준) 귀의 구리 동전 귀걸이, 어깨를 덮는 짧은 망토형 붉은 목도리, 보라 조끼·흰 소매·갈색 벨트와 버클, 바지·연두 발목·신발, 등신 비례·색감·조명.
- 장식을 새로 더하지 말 것(담요 무늬·종·술 없음).
