# Codex에게 요청하는 에셋 작업 — 보름달 늑대인간(마녀 변신체) 3D 모델링용 3/4뷰 원화 시안 2개 (v01)

요청자: Claude · 2026-10-21 · 절차: [캐릭터 3D 적용 프로세스](../character-3d-pipeline.md) 1단계 · 설정: [늑대의 피](../wolf-blood-event-design.md) §5

## 목적

플레이어 마녀가 보름달 카드로 변신하는 **늑대인간**의 정식 3D 모델 기준 원화. 지금 게임에는 원시 도형으로 만든 임시 늑대(`godot/scripts/visual/wolf_visual.gd`)가 들어 있다.
사용자가 두 시안 중 하나를 승인하면 Tripo 로 모델링한다.

사용자 지시: "현재 게임 캐릭터들에 어울리는 선에서, **기존 캐릭터보다 살짝 변형이 있어도 좋다**."
→ 화풍(점토 장난감·큰 색면·외곽선 없음)은 그대로 지키되, 비례와 인상은 일반 손님보다 조금 크고 거칠게 바꿔도 된다.

## 역할·제한

- 새 파일은 `art/concepts/characters/werewolf-witch-model-v01/` 안에만 만든다.
- **수정 금지:** `godot/**`, `docs/**`(이 문서 포함), 기존 원화·초상·레퍼런스·다른 캐릭터 시안. **커밋하지 말 것.**

## 입력 이미지 (실제 이미지 입력으로 열어서 사용)

1. **변신 전 마녀(정체성·색 1순위):** `art/concepts/characters/witch-north-model-v01/witch-3q-a-v01.png` — 보라 두건 망토·갈색 웨이브 머리·크림 원피스·갈색 벨트·허리 등불.
2. **화풍·카메라 기준:** `art/concepts/characters/goblin-nib-model-v03/nib-3q-v03.png` — 같은 무광 점토 장난감 마감, 같은 카메라 높이.
3. **구분해야 할 캐릭터:** `art/concepts/characters/beastfolk-common-model-v02/beastfolk-common-3q-v02.png` — 이미 있는 순한 회색 늑대 수인 손님. 늑대인간은 **이것과 한눈에 달라 보여야 한다**(옷 입은 귀여운 수인 ✕).
4. 조형 언어 참고: `art/references/characters/stylized-toy-chibi-ref-01.png` (인물·의상 복제 금지).

## 공통 요건 (두 시안 모두)

- **화풍:** 니브·마녀와 같은 매끈한 무광 점토·비닐 장난감, 큰 색면 3~5개, 장식 최소, 외곽선·먹선 없음, 부드러운 명암. 털은 가는 털결이 아니라 **큰 덩어리 몇 개(뭉친 털 술)**로 조형.
- **마녀의 흔적:** 변신한 마녀임을 알 수 있게 마녀 A 시안의 요소를 남긴다 — **보라 두건 망토(찢기거나 작아져 어깨·목에 걸림)**, 갈색 머리 색이 섞인 정수리·갈기 털, 갈색 벨트(버클) 정도. 크림 원피스는 찢겨 사라지거나 허리 아래 짧은 자락만.
- **털색:** 마녀 머리색과 연결되는 **짙은 갈색~회갈색** 계열 + 밝은 크림 배·주둥이. 수인 손님의 회색과 겹치지 않게.
- **눈:** 하이라이트 없는 단순한 눈이되 **연보라로 빛나는 듯한 색**(마녀 마법의 색). 단추 눈 크기는 니브보다 작고 가늘게(살짝 날카로운 인상). 무섭기보다 "든든하고 사나운" 정도 — 피·상처·이빨 디테일 금지, 송곳니는 짧게 두 개만 보여도 된다.
- **덩치:** 마녀보다 확실히 크고 묵직하게(같은 화면에서 마녀의 약 1.3~1.5배 부피감). 1536 캔버스에서 전체 높이 약 1,150~1,250px.
- **모델링 자세:** 3D 리깅용. 앞-왼쪽 3/4뷰(약 30~45°), 니브 v03 과 같은 카메라 높이. 전신·한 명, 두 발로 서고 **팔은 몸통에서 떨어진 A자**, 두 손은 비우고 **손가락(발톱) 덩어리는 뭉툭하게 3~4개**. 다리 두 개 분명히 분리, 꼬리는 다리·팔과 겹치지 않게 뒤-옆으로. 망토 조각은 몸에 붙게 짧게.
- 중세 기반 판타지. 진짜 투명 알파(본체 255·바깥 0, 외곽 1~2px 안티에일리어싱), 원본 `raw/` 보존, 정사각형 1536×1536.

## 시안 차이

| 파일 | 시안 | 방향 |
| --- | --- | --- |
| `werewolf-3q-a-v01.png` | A · 점토 장난감 늑대인간 | 게임 캐릭터들과 가장 가깝게. **약 2~2.3등신**, 머리 크게(늑대 머리에 짧은 주둥이), 둥근 통 같은 상체와 넓은 어깨, 짧고 굵은 다리, 크고 동그란 앞발. 살짝 앞으로 숙였지만 거의 똑바로 선 자세. 보라 두건이 뒤로 젖혀져 목에 두건 망토처럼 걸려 있고, 갈색 벨트가 허리에 남아 있다(등불은 없음). 귀엽지만 덩치로 위압감을 주는 쪽. |
| `werewolf-3q-b-v01.png` | B · 사나운 늑대인간(살짝 변형) | 기존 비례에서 한 걸음 벗어난 버전. **약 2.5~3등신**, 상체가 크고 하체가 작은 역삼각형, **팔이 길어 손이 무릎 근처까지**, 등이 굽어 머리가 어깨 앞으로 나온 웅크린 자세(그래도 A자 팔·두 발 서기 유지). 주둥이 더 길고, 목·어깨에 크게 부풀어 오른 갈기 털 덩어리, 뒤꿈치가 든 짐승 다리(디지티그레이드)를 단순한 덩어리로. 찢긴 보라 망토 조각이 한쪽 어깨에만 걸리고, 짧은 크림 천 자락이 허리에 남는다. 같은 점토 화풍 안에서 더 사납고 야성적인 쪽. |
