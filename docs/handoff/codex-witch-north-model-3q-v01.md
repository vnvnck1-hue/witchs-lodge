# Codex에게 요청하는 에셋 작업 — 플레이어 마녀(북쪽의 마녀) 3D 모델링용 3/4뷰 원화 시안 2개 (v01)

요청자: Claude · 2026-10-19 · 절차: [캐릭터 3D 적용 프로세스](../character-3d-pipeline.md) 1단계 · 선례: [니브 v03](codex-goblin-nib-model-3q-v03.md)

## 목적

플레이어 캐릭터인 **북쪽의 마녀**를 Tripo 로 3D 모델링할 기준 원화. 사용자가 두 시안 중 하나를 승인한다.
고블린 니브와 **같은 게임에 나란히 서는 캐릭터**이므로 화풍·비례·마감을 승인된 니브 v03 과 맞춘다.

## 역할·제한

- 새 파일은 `art/concepts/characters/witch-north-model-v01/` 안에만 만든다.
- **수정 금지:** `godot/**`, `docs/` 의 이 문서 외 모든 파일, 기존 원화·초상·레퍼런스·니브 시안. **커밋하지 말 것.**

## 입력 이미지 (실제 이미지 입력으로 사용)

1. **화풍·비례 기준(1순위):** `art/concepts/characters/goblin-nib-model-v03/nib-3q-v03.png` — 승인된 니브. 같은 점토 장난감 화풍, 같은 카메라 각도, 같은 마감.
2. **화풍 레퍼런스:** `art/references/characters/stylized-toy-chibi-ref-01.png` (조형 언어만. 인물·의상 복제 금지).
3. **시안 A 정체성:** `godot/assets/ui/ftue/witch_portrait.png` — 게임 HUD 마녀 초상(두건, 등불).
4. **시안 B 정체성:** `art/model-sheets/starter/02-witch-player.png` — 현재 게임 3D 마녀 모델 시트(뾰족 모자).
5. 설정: `docs/four-witches-v01.md` §2.3 북쪽의 마녀 — 20대 중후반의 차분하고 창백한 얼굴, 짙은 남색~보라 로브, 오래된 등불, 감정을 크게 드러내지 않는 침착한 원칙주의자, 건조한 유머. 중세 기반 판타지.

## 공통 요건 (두 시안 모두)

- **니브 v03 과 같은 화풍:** 매끈한 무광 점토·비닐 장난감, 큰 색면 3~5개, 장식 최소, 외곽선·먹선 없음, 부드러운 명암.
- **약 2등신**, 머리 크게. 니브와 나란히 서도 어색하지 않은 비례(마녀가 니브보다 약간 날씬하고 단정한 인상).
- **얼굴:** 니브처럼 단순하게 — 하이라이트 없는 단추 눈 두 개, 작은 코, 작은 입. 단, 성격대로 **차분하고 담담한 표정**(살짝 내리깐 눈 또는 무표정에 가까운 옅은 미소). 니브의 장난스러운 미소와 구분되게.
- **앞-왼쪽 3/4뷰(약 30~45°)**, 니브 v03 과 같은 카메라 높이. 전신, 사방 넉넉한 투명 여백, 한 명·한 방향.
- **모델링 자세:** 똑바로 서고 팔은 몸통에서 떨어진 A자. **손에 아무것도 들지 않는다** — 게임은 기존 지팡이 모델을 손에 따로 붙인다. 등불은 허리 벨트에 매단다.
- 치맛단·로브 자락은 다리와 구분되게(걷기 애니메이션 때문에 다리 두 개가 로브 아래로 보여야 한다). 망토는 몸에 붙은 짧은 형태로, 팔과 겹치지 않게.
- 진짜 투명 알파(본체 255·바깥 0, 외곽 1~2px 안티에일리어싱), 원본은 `raw/` 보존. 정사각형 1536×1536.

| 파일 | 시안 | 방향 |

| `witch-3q-a-v01.png` | A · HUD 초상 기반 | **두건 달린 짧은 보라 망토**(두건은 머리에 쓰되 얼굴은 다 보이게), 두건 아래로 나온 **긴 갈색 웨이브 머리**(큰 덩어리 2~3개), 크림색 안쪽 원피스, 갈색 허리띠, 허리에 매단 작은 등불. |
