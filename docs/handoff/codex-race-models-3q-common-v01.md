# Codex에게 요청하는 에셋 작업 — 종족 대표 캐릭터 3D 모델링용 3/4뷰 원화 · 공통 요건 (v01)

요청자: Claude · 2026-10-20 · 절차: [캐릭터 3D 적용 프로세스](../character-3d-pipeline.md) 1단계 · 선례: [니브 v03](codex-goblin-nib-model-3q-v03.md), [마녀 v01](codex-witch-north-model-3q-v01.md)

고블린(니브·공용 고블린)과 플레이어 마녀는 끝났다. 나머지 다섯 종족(인간·드워프·요정·수인·오크)의 **대표 손님 1명씩**을 같은 방식으로 3D 모델링한다.
대표 손님의 전용 모델을 먼저 만들고, 뒤에 소품을 빼고 색을 바꿔 **그 종족 공용 손님 모델**로 재활용한다(니브 → 공용 고블린과 같음).
각 인물 요청서(`codex-<race>-<id>-model-3q-v01.md`)가 이 문서를 공통 요건으로 쓴다. **둘 다 읽고 작업한다.**

## 역할·제한

- 새 파일은 그 인물 요청서가 지정한 `art/concepts/characters/<race>-<id>-model-v01/` 안에만 만든다.
- **수정 금지:** `godot/**`, `docs/` 의 모든 파일(요청서 포함), 기존 원화·초상·레퍼런스·니브/마녀 시안. **커밋하지 말 것.**
- 다른 종족 폴더는 다른 작업이 동시에 쓰고 있을 수 있다. 건드리지 않는다.

## 공통 입력 이미지 (실제 이미지 입력으로 사용)

1. **화풍·비례 기준(1순위):** `art/concepts/characters/goblin-nib-model-v03/nib-3q-v03.png` — 승인된 니브. 같은 점토 장난감 화풍, 같은 카메라 각도·높이, 같은 마감.
2. **화풍 기준(2순위):** `art/concepts/characters/witch-north-model-v01/witch-3q-a-v01.png` — 승인된 마녀. 같은 게임에 나란히 선다.
3. **화풍 레퍼런스:** `art/references/characters/stylized-toy-chibi-ref-01.png` (조형 언어만. 인물·의상 복제 금지).
4. **정체성:** 인물 요청서가 지정한 게임 초상 `godot/assets/portraits/guest_<id>_cutout.png`(카드 화풍의 세밀한 일러스트). 얼굴 특징·색 배치·의상 구성만 따르고 세부 묘사는 버린다.
5. 세계 기준: 중세 기반, 일반적인 판타지 문법으로 각색한 세계. 현대 소재·현대 재봉·플라스틱 장신구 금지.

## 공통 요건 (모든 시안)

- **니브 v03·마녀 A 와 같은 화풍:** 매끈한 무광 점토·비닐 장난감, 큰 색면 3~5개, 장식 최소, 외곽선·먹선 없음, 부드러운 명암. 초상의 털 결·리벳·자수·흠집·사슬 고리 같은 세부는 **큰 덩어리 하나로 단순화**한다(사슬갑옷 → 회색 매끈한 천 덩어리, 모피 → 3~4개 둥근 뭉치).
- **약 2등신**, 머리 크게. 니브·마녀와 나란히 서도 어색하지 않은 비례. 종족 체격 차이는 덩어리로만(드워프 넓고 낮게, 오크 어깨 넓게, 요정 가늘고 작게).
- **얼굴:** 니브처럼 단순하게 — 하이라이트 없는 단추 눈 두 개, 작은 코, 작은 입. 표정은 인물 성격대로(인물 요청서 참고).
- **앞-왼쪽 3/4뷰(약 30~45°)**, 니브 v03 과 같은 카메라 높이. 전신, 사방 넉넉한 투명 여백, 한 명·한 방향.
- **모델링 자세:** 똑바로 서고 팔은 몸통에서 떨어진 A자. **두 손은 비운다.** 무기·도구는 등에 메거나 허리에 찬다(나중에 파츠로 떼어 낼 수 있게 몸에서 형태가 분명히 구분되게).
- **애니메이션용 분리:** 다리 두 개가 옷자락 아래로 분명히 보여야 한다(걷기). 팔은 몸통과 겹치지 않는다. 망토·모피 깃은 짧고 몸에 붙게, 팔을 덮지 않게.
- 진짜 투명 알파(본체 255·바깥 0, 외곽 1~2px 안티에일리어싱), 원본은 `raw/` 보존. 정사각형 1536×1536.

## 시안 A·B 의 공통 차이

| 시안 | 방향 |
| --- | --- |
| **A · 초상 충실** | 초상의 대표 소품·갑옷·무기를 단순화해서 모두 살린다(무기는 등/허리). 그 인물임을 바로 알아보게. |
| **B · 종족 공용 겸용** | 같은 얼굴·체형·종족 특징은 유지하되 **갑옷·무기를 덜어 낸 여행복 차림**. 나중에 같은 종족의 다른 손님(사냥꾼·나무꾼·채집가·여행자)에게 색만 바꿔 재활용할 수 있을 만큼 평범하게. 종족을 알리는 특징(귀·엄니·날개·수염·털 등)은 오히려 더 또렷하게. |

## 납품 (인물마다)

- 마지막 응답에 두 파일 경로와 차이 요약.
