# Codex에게 요청하는 에셋 작업 — 왼쪽 손님 말 걸기 알림 말풍선 2종 v01

요청자: Claude (게임 구현 담당) · 2026-10-22

## 배경

플레이 중 화면 왼쪽에서 손님이 마녀에게 말을 거는 알림(`GuestSpeechNotification`)을
사용자가 고른 시안 **`output/guest-speech-simplified-v02/03-speech-only.png`** 대로 다시 만든다.
구성은 **원형 초상 메달 + 밝은 종이 말풍선(왼쪽을 가리키는 꼬리) + 오른쪽 끝 진입 화살표**.
메달·화살표·글자는 게임 코드가 그린다. **Codex가 만들 것은 말풍선 그림 2장뿐**이다.

말풍선 글자는 게임이 BM 을지로체로 그리므로 **그림에는 글자를 절대 넣지 않는다.**

## 만들 것

| 파일 | 크기 | 내용 |
| --- | --- | --- |
| `godot/assets/ui/moon_runes/common/speech_plain.png` | 512×256 RGBA | 말풍선 **몸통만**(꼬리 없음). 9분할(StyleBoxTexture)로 가로·세로 늘려 쓴다 |
| `godot/assets/ui/moon_runes/common/speech_tail_left.png` | 96×96 RGBA | **왼쪽을 가리키는 꼬리** 한 조각. 몸통의 왼쪽 가장자리 위에 겹쳐 놓는다 |

### 몸통 `speech_plain.png`

- 시안의 말풍선과 같은 느낌: 밝은 크림 종이색 면, 그 둘레에 **짙은 자두/진보라 먹선 외곽(약 6~8px)**, 모서리는 둥글게(반지름 약 40px).
- 외곽선 바로 안쪽에 아주 옅은 어두운 가장자리(종이가 살짝 눌린 느낌)를 두어도 좋다. 시안을 그대로 참고한다.
- **9분할 조건이 핵심**: 네 모서리 장식은 각 변에서 **48px 안쪽**까지만. 그 안쪽 가운데 영역(가로 48~464, 세로 48~208)은 **늘려도 티가 나지 않게** 평평한 종이 면이어야 한다. 가운데에 큰 얼룩·무늬·그러데이션 금지. 아주 미세한 종이 결은 괜찮다.
- 꼬리 없음. 네 변 모두 같은 두께의 외곽선.
- 바깥은 **진짜 투명(alpha 0)**. 흰 배경·체크무늬·그림자 금지. 외곽선 가장자리 안티앨리어싱은 유지하되 색 번짐(halo) 없이.

### 꼬리 `speech_tail_left.png`

- 몸통과 **같은 크림색·같은 먹선 색·같은 선 두께**로 그린 작은 삼각 꼬리. 왼쪽으로 뾰족하게 뻗는다(시안에서 초상 메달을 가리키는 꼬리).
- 꼬리의 **오른쪽 변(x 60~96 구간)은 외곽선 없이 크림색 면만** 있어야 한다. 게임이 이 조각을 몸통 왼쪽 가장자리 위에 겹쳐 올려 몸통의 외곽선을 덮고 하나로 이어 붙이기 때문이다. 즉 오른쪽 끝은 크림 면이 그림 경계까지 꽉 차고, 위·아래·왼쪽 두 변에만 먹선이 있다.
- 세로 가운데(y 48)를 중심으로 위아래 대칭. 뾰족한 끝은 x 약 6.
- 바깥은 진짜 투명.

### 색 기준

시안 `03-speech-only.png`의 말풍선에서 직접 스포이트로 뽑아 맞춘다. 대략 크림 면 `#F6E8C6` 근처, 먹선 `#3A2240` 근처. 게임 공통 팔레트는 [아트 가이드](../art-direction.md) "색과 정서".

## 완료 기준

1. 두 PNG가 지정 크기·RGBA, 바깥은 alpha 0, 글자·그림자·배경 없음.
2. 몸통 가운데 영역을 가로 2배·세로 1.5배로 늘린 합성(시트)에서 늘어난 티가 나지 않는다.
3. 꼬리를 몸통 왼쪽 가장자리에 겹쳤을 때 먹선이 끊기거나 이중으로 보이지 않고 하나의 말풍선으로 읽힌다.
4. 시안 `03-speech-only.png`의 말풍선과 나란히 놓았을 때 같은 물건으로 보인다.
