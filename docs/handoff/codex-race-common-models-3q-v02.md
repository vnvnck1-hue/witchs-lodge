# Codex에게 요청하는 에셋 작업 — 종족 공용 손님 3D 모델링용 3/4뷰 원화 (v02)

요청자: Claude · 2026-10-20 · 절차: [캐릭터 3D 적용 프로세스](../character-3d-pipeline.md) 1단계 · 이전: [v01 공통 요건](codex-race-models-3q-common-v01.md)

## v01 반려 사유 (사용자 피드백 2026-10-20)

1. **특정 인물 전용 모델은 지금 필요 없다. 종족 공용 모델만 필요하다.** → 인물 이름·개인 특징(흉터·찢긴 귀·개인 장신구·무기)을 빼고, 그 종족 손님 누구에게나 쓸 수 있는 평범한 여행자로.
2. **니브와 등신 비율이 맞지 않는다.** v01 은 머리가 작고 몸·다리가 길어 니브보다 등신이 높았다. **니브와 같은 등신 비율로** 다시 그린다.

## 등신 비율 — 가장 중요한 조건

`art/concepts/characters/goblin-nib-model-v03/nib-3q-v03.png` 를 실제 이미지로 열어 비율을 재고 그대로 맞춘다.

- **머리(머리카락·귀 제외한 두상 + 머리카락) 높이가 전체 키의 약 45%.** 니브처럼 머리가 몸통+다리를 합친 것과 거의 같은 크기.
- 몸통은 짧고 둥글게, **다리는 아주 짧게**(니브처럼 장화가 몸통 바로 아래). 손은 뭉툭한 덩어리.
- 머리 너비는 어깨 너비와 같거나 더 넓게.
- 화면 속 크기도 니브와 같게: 1536 캔버스에서 캐릭터 전체 높이 약 1,100px, 머리 약 500px 내외.
- 종족 체격 차이는 **폭으로만** 준다(드워프·오크는 몸통을 넓게, 요정은 가늘게). 키를 늘려서 구분하지 않는다.
- 납품 전에 니브 v03 과 나란히 놓고 머리:몸 비율이 같은지 직접 비교하고 generation.md 에 측정값(전체 높이·머리 높이·비율)을 적는다.

## 공통 요건

- 화풍: 니브 v03 과 같은 매끈한 무광 점토·비닐 장난감, 큰 색면 3~5개, 장식 최소, 외곽선 없음. 얼굴은 니브처럼 하이라이트 없는 큰 단추 눈 두 개·작은 코·작은 입, 순하고 차분한 표정. v01 브람처럼 눈썹·주름을 자세히 그리지 않는다.
- 앞-왼쪽 3/4뷰(약 30~45°), 니브 v03 과 같은 카메라 높이. 전신, 한 명, 투명 배경.
- 똑바로 선 A자, **두 손은 비운다**, 무기·방패·등짐 없음. 팔은 몸통과 겹치지 않고, 다리 두 개가 분명히 분리. 망토·깃은 짧고 몸에 붙게.
- 중세 기반 판타지. 진짜 투명 알파, 원본 `raw/` 보존, 1536×1536.
- 입력 이미지(실제로 열어서 사용): ① 니브 v03(비율·화풍 1순위) ② `art/references/characters/stylized-toy-chibi-ref-01.png` ③ 아래 종족별 v01 B 시안(정체성·색만 참고, 비율은 따르지 말 것).

## 역할·제한

- 지정받은 종족의 출력 폴더 안에만 만든다(`<폴더>/<race>-common-3q-v02.png`, `raw/`, `generation.md`). 다른 폴더는 다른 작업이 동시에 쓰고 있으니 건드리지 않는다.
- **수정 금지:** `godot/**`, `docs/**`, 기존 원화·초상·v01 시안. **커밋하지 말 것.**
- `generation.md`: 입력 이미지·실제 프롬프트 전문·알파 검수·크기·SHA256·니브와의 비율 측정값·시각 검수와 한계. 마지막 응답에 파일 경로와 요약.
