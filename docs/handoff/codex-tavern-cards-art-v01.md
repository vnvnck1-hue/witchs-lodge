## 0. 수정 금지·주의

- `godot/scripts/`, `godot/assets/cards/catalog.json`, `godot/scenes/`, `godot/tools/`(검증 스크립트)는 **수정하지 않는다.** 카드 문구를 바꿔야 하면 사용자에게 먼저 묻는다.
- 커밋하지 않는다.
- 아래 §2의 경로와 파일명(카드 id)을 그대로 쓴다. 게임이 이 경로를 읽는다.

## 1. 사용자가 짚은 문제 — 이번 작업의 핵심

Claude가 GPT 이미지 API(`gpt-image-2`)로 만든 현재본은 사용자 검수에서 아래 이유로 반려됐다.

1. **카드 글씨체가 기존 카드와 다르다(최종 반려 사유).** 기존 카드의 한글은 이미지 생성으로 그린 **굵은 붓글씨풍 손글씨 고딕**이다. 현재 술 카드 4장은 Claude가 Noto Sans KR로 글자를 직접 써 넣어서 서체가 확연히 다르다. → **기존 카드(예: `godot/assets/cards/timber.png`, `wool.png`)와 같은 서체 느낌으로** 인쇄 문구를 다시 넣어야 한다.
2. **글자 크기가 기존 카드와 다르다.** 기존 기본 카드 실측(1024×1536 기준, `timber`·`wool`·`raw_meat`):
   | 항목 | 글자 높이 | 세로 중심 |
   | --- | --- | --- |
   | 제목 | 약 100px | y≈150 |
   | 분류 | 약 45px | y≈247 |
   | 설명 2줄 | 약 63px | y≈1272 · y≈1357 |
   종족 카드(예: `dark_ale.png`)는 제목 약 60px·설명 약 45px로 더 작다. 사용자는 **기본 카드(목재·양털) 크기를 기준**으로 본다. 술 카드 설명 문장이 목재보다 길어 한 줄 폭(안전 영역 x110..914)을 넘기 쉬우니 줄 배치를 신경 쓴다.
3. **술 4장 일러스트는 하스스톤 아이템 원화 느낌으로.** 사용자가 하스스톤 아이템 원화 3장(보라 잔, 금 성배, 빛 터지는 물약병)을 레퍼런스로 줬다. 요구: 술이 그림 창 **중앙에 크게**, **역동적 구도**(대각선 기울기·튀는 술·움직임), **표현은 큼직하고 단순하게**(자잘한 디테일·뜨개질 같은 질감 금지), 강한 림라이트·발광, 보라/청록 마법 연기 배경, 채도 높은 매끈한 페인팅. 처음 시도는 "정적이고 표현이 자잘하다"는 이유로 반려됐다.
   - 레퍼런스는 블리자드 저작물이라 이미지 그대로 베끼지 않는다(방향만 참고).
4. **에린 재설정(사용자 확정):** 누가 봐도 매력적인 **금발의 글래머러스한 미인**인데, 술을 너무 좋아해 **매일 취해 있는** 인물. 사용자 레퍼런스는 다른 작가의 금발 드레스 여성 그림(크림 오프숄더 블라우스·끈 코르셋·황갈색 겹치마). 이 요소를 반영하되 베끼지 않는다. 노출은 게임 카드에 맞게 과하지 않게.

GPT 이미지 생성은 한글 오탈자를 냈다("금빛"→"금맷", "독주"→"통주"). **납품 전에 모든 문구를 원본 해상도로 대조한다.**

### 원화 콘셉트 요약

- 불꽃 에일: 쇠테 두른 나무 맥주잔, 거품 위에서 불꽃이 타오르고 맥주가 크게 넘쳐 튐. 주황·빨강 발광.
- 금빛 꿀술: 둥근 유리병, 금 장식 목, 작은 금벌 장식, 코르크가 튀며 꿀술이 나선으로 솟음. 금색 발광.
- 도깨비불 독주: 가늘고 긴 남색 병, 마개가 튀며 눈 달린 청록 도깨비불들이 빠져나옴. 청록 발광.
- 망각의 이슬주: 크리스탈 디캔터, 마개가 열리며 은빛 안개가 흘러나오고 이슬방울이 흩어짐. 은청색 발광.
- 술 주정뱅이 에린: 술집 탁자에서 턱을 괴고 맥주잔을 든 금발 미인, 발그레한 볼·반쯤 감긴 눈. 배지는 종족 문장 대신 나무 맥주잔(주점 표식).
- 술주정: 탁자에 엎어져 횡설수설하는 에린, 손에서 카드가 흩날리고 빈 병이 굴러감. 코믹·따뜻한 난롯불.

## 3. 납품 경로·형식

| 파일 | 경로 | 형식 |
| --- | --- | --- |
| 카드 원본 | `art/cards/tavern-v01/<id>.png` | 1024×1536 RGBA |
| 카드 게임용 | `godot/assets/cards/<id>.png` | 1024×1536 RGBA, 둥근 모서리 바깥 투명(기존 카드와 같은 알파 — 예: `dark_ale.png`의 알파 채널) |

교체 전 파일은 `art/cards/tavern-v01/drafts/`에 이미 버전별로 보관돼 있다(덮어써도 됨). 새 시안도 같은 곳에 둔다.

## 4. 참고할 기존 산출물

- `art/cards/tavern-v01/drafts/art_<id>.png` — 하스스톤식 **일러스트만** 따로 생성한 1536×1024 원본(글자·프레임 없음). 사용자 반응이 괜찮았던 그림이니 재사용 가능.
- `art/cards/tavern-v01/drafts/icon_<id>.png` — 위 일러스트에 맞춘 작은 표식 아이콘(크림 배경).
- `art/cards/tavern-v01/drafts/base_blank.png` — 목재 카드에서 글자를 지우고 그림 창·표식만 초록(#00FF00)으로 비운 빈 틀.
- `art/cards/tavern-v01/prompts/` — Claude가 쓴 실제 프롬프트와 스크립트(`gen.sh`·`t2i.sh`·`build_card.py`·`composite.py`·`package.py`·`key_portrait.py`).
- 비교판: `art/cards/tavern-v01/compare-base-v05.png`(현재 술 4장 vs 목재·양털), `compare-event-person.png`(술주정·에린 vs 기존 사건·인물 카드).

## 5. 완료 조건

1. 6장 모두 같은 역할의 기존 카드와 나란히 놓았을 때 **서체·글자 크기·제목/분류/설명 위치·패널 모양이 같은 계열**로 보인다(§1 실측표).
2. 인쇄 문구가 §2 표와 한 글자도 다르지 않다.
3. 술 4장은 §1-3의 하스스톤식 중앙·역동 구도를 유지한다. 에린 2장과 초상은 같은 금발 에린이다.
4. 헤드리스 검증 통과(프로젝트 루트 기준):
   ```text
   .tools/Godot-4.7.2.exe --headless --path godot --import
   .tools/Godot-4.7.2.exe --headless --path godot --script res://tools/verify_tavern_cards.gd
   ```
   마지막 줄 `RESULT 49/49`(원화 6장이 1024·256 크기로 로드, 초상이 실루엣이 아님을 포함).
5. 게임 실행파일 갱신(게임이 켜져 있으면 실패하니 끄고):
   ```text
   .tools/Godot-4.7.2.exe --headless --path godot --export-release "Windows Desktop" ../WitchsLodge.exe
   ```
   **현재 상태:** 마지막 술 4장(Noto 글자판)은 게임 에셋에는 들어갔지만, 게임이 켜져 있어 실행파일 내보내기가 실패했다(13:43판이 남아 있음).
6. `docs/tavern-cards-v01.md` §4 납품 메모에 이번 판의 방식·수정 이력을 한 단락 덧붙인다.
