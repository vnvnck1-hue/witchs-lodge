# Codex에게 요청하는 에셋 작업 — 마법책 제작 화면 컨셉 시안 v01

요청자: Claude (게임 구현 담당) · 2026-10-19 · 기획: [마법책 제작 기획 v0.1](../spellbook-crafting-v01.md)

## 목적

손패 왼쪽에 놓인 **마법책 소품을 클릭하면 제작 창이 열리는** 새 콘텐츠를 만든다. 구현 전에 **어떤 비주얼로 만들지 가늠하기 위한 컨셉 시안(화면 목업 원화)**이 필요하다. 게임에 바로 들어가는 에셋이 아니라, 사용자가 방향을 고르는 판단 자료다.

규칙 요약(기획 §1·§4):
- 낮(준비 시간)에만 열리고, 열려 있는 동안 게임 시간이 멈춘다.
- 펼친 마법책: **왼쪽 페이지 = 제작법 목록**, **오른쪽 페이지 = 재료 슬롯 3칸 + 결과 미리보기 + [제작] 버튼**, 책 아래 = 손패의 재화 카드 줄(수량 배지).
- 목록은 분류 탭 **물약 · 장비 · 마법**. **모든 제작법이 처음부터 보이고, 모르는 것은 `???` + 빈 실루엣**으로 많이 보여야 한다(알아갈 게 많다는 느낌이 핵심). 탭마다 "2 / 5" 같은 진행 수.
- 재료를 넣어 직접 실험하다 맞히면 **"새로운 비법을 책에 적었다"** — `???` 칸에 잉크가 번지며 제작법이 적힌다.
- 모닥불 제작(음식)과는 다른, **마력으로 바꾸는** 느낌.

- **Claude 책임:** 게임 코드·검증·실행파일.

### 목록에 들어갈 예시 (모든 시안 공통)

- **물약 탭 (1 / 4):** 치유 물약(앎) · `???` · `???` · `???`
- **장비 탭 (1 / 5):** 누빈 솜옷(앎) · `???` ×4
- **마법 탭 (1 / 4):** 이끼 붕대(앎) · `???` ×3
- 02a·02b는 **물약 탭을 연 상태**에서 "치유 물약"을 선택: 슬롯 = 약초 ×2(1칸), 결과 = 치유 물약 카드. `???` 칸이 목록의 대부분을 차지해 "모르는 게 많다"가 한눈에 보여야 한다.
- 아래 재화 줄 예시: 약초 ×3, 정화된 정수 ×1, 양털 ×4, 목재 ×2, 쇠붙이 ×2, 토끼 가죽 ×1. 새 재료 그림 기준 — **약초:** 끈으로 묶은 초록 잎 다발(쑥·톱풀), **정화된 정수:** 작은 유리 방울 속 맑은 하늘빛·은빛으로 빛나는 물방울, **쇠붙이:** 녹슨 쇠 조각·경첩 한 줌.

**A/B 요약:** A는 손패 소품과 같은 보라 가죽·금속 모서리·라벤더 문양·보라 촛불을 이어 받아 책을 직접 읽고 실험하는 분위기가 강하다. 페이지 곡면·마법진·잉크를 나누어 구현할 레이어와 마스크가 필요하다. B는 크림 글자와 남색 바탕, 규칙적인 격자로 가독성과 배치·확장에 유리하며 책 자체를 다루는 분위기는 A보다 약하다. 두 안은 물약 1/4·장비 1/5·마법 1/4, 치유 물약, 약초 ×2가 든 슬롯 한 칸과 빈 두 칸, 아래 여섯 재료·수량이 동일하다.

**보정·후처리:** A·03·04의 정수 병을 하늘빛·은빛 물을 품은 유리 방울로 바꾸고 제작 버튼을 밀랍 도장으로 보정했다. 03은 ??? 잔상·잉크, 04는 말린 책장 모서리·흡수 광선을 강화했고 B 배경을 어둡게 했다. 선택 원본 1672×941을 자르지 않고 고품질 bicubic으로 1920×1080에 정규화했다. 원화 한글은 읽을 수 있는 상태로 유지했으며 비교 시트 주석은 Noto Sans KR 복사본으로 조판했다.

**남은 결정·문제:** A/B 방향 선택이 남아 있다. 확인된 납품 누락은 없다. 이번 결과는 레이어가 합쳐진 컨셉 목업이며 실제 게임용 자산 분리·반응형 배치·연출 타이밍 검증은 구현 단계에서 진행해야 한다. 03 아래 재화 수량은 제작 직전 예시이고 새 비법 발견으로 마법 탭은 2/4다. 카드 그림과 주변 HUD는 목업에 포함된 예시이며 기존 게임 자산 교체가 아니다.
