# Codex에게 요청하는 에셋 작업 — 회색 늑대인간: 몸통과 꼬리를 분리한 모델링 시트 (v03)

요청자: Claude · 2026-10-21 · 이전: [v02 회색 버전](codex-werewolf-witch-model-3q-v02.md)

## 배경

기준 원화 `art/concepts/characters/werewolf-witch-model-v02/werewolf-3q-b-v02.png`(회색 늑대인간)를 Tripo 로 3D 모델링한다.
사용자 지적: "이대로 쓰면 꼬리가 모델링에서 이상하게 나올 것 같다(다리 뒤로 낮게 뻗어 다리와 붙을 위험). **꼬리는 따로 빼서 옆에 잘 보이도록 따로 그려 줘. 한 장 그림에 몸통과 꼬리를 따로 잘 분리시켜서.**"

## 할 일 — 한 장에 ① 꼬리 없는 몸 ② 따로 놓인 꼬리

- **기준 이미지:** v02 를 실제 입력으로 열어 **몸의 형태·자세·비례·색·카메라·조명·화풍을 그대로** 유지한다(이미지 편집 우선).
- **① 몸(캔버스 왼쪽~가운데):** v02 와 같은 늑대인간에서 **꼬리만 지운다.** 꼬리가 가리던 왼쪽 다리·엉덩이 뒤를 자연스러운 털 덩어리로 채운다. 엉덩이 뒤에 꼬리가 붙을 자리(작고 둥근 꼬리뿌리 정도)는 있어도 되지만 꼬리 자체는 없다.
- **② 꼬리(캔버스 오른쪽, 몸과 확실히 떨어지게):** v02 의 꼬리와 같은 디자인 — 회색 털 덩어리에 크림색 끝, 같은 점토 무광 마감. **꼬리 전체가 한눈에 보이도록 옆에서 본 모양**으로, 뿌리(몸에 붙는 쪽)는 왼쪽·끝은 오른쪽 위로 살짝 휘게. 몸과 같은 배율(몸에 붙였을 때의 실제 크기 그대로).
  - 몸과 꼬리 사이에 투명 여백을 넉넉히(최소 80px) 둬서 서로 닿거나 겹치지 않게.
- 몸의 팔·다리도 서로 붙지 않게 v02 처럼 분리 유지.
- 진짜 투명 알파(본체 255·바깥 0, 외곽 1~2px 안티에일리어싱), 원본 `raw/` 보존. 캔버스는 몸과 꼬리가 다 들어가도록 **가로형 2048×1536**(몸 크기는 v02 와 같은 픽셀 크기 유지).
- 같은 꼬리를 몸 없이 단독으로 잘라 낸 파일도 따로 납품(Tripo 에서 몸과 꼬리를 따로 생성할 수 있도록). 몸만 있는 단독 파일도 1536×1536 으로 함께.
