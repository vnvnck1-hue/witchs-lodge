## 사용자 피드백

v01(`art/concepts/lobby/races-closeup-distant-v01/03-races-closeup-distant.png`)에 사용자가 빨간 선으로 고블린 얼굴~오른쪽 아래 원경 영역을 표시하고 이렇게 말했다.
표시한 이미지: [lobby-closeup-distant-v01-feedback.webp](refs/lobby-closeup-distant-v01-feedback.webp)

> 인물 쪽 부분과 원경이 자연스럽게 톤이 이어지도록 표현해 줘. 지금은 원경과 인물 쪽 그림이 끊겨 있어서 싫어.

## 무엇이 끊겨 보이나

- 인물 덩어리(특히 오른쪽 끝의 고블린 얼굴·붉은 스카프, 마녀 모자 챙, 오크 털 칼라)의 가장자리가 **크림색 평면 위에 오려 붙인 것처럼** 딱 잘려 있다.
- 원경은 오른쪽 아래 구석에만 따로 떠 있어서, 인물과 원경 사이에 아무 연결 없는 빈 크림 띠가 있다.
- 인물은 진하고 따뜻한 색인데 원경은 옅은 라벤더라서 **두 그림이 다른 그림처럼** 보인다.

## 이렇게 이어 달라

1. **원경을 인물 뒤까지 연장한다.** 숲·언덕·눈밭의 지평선이 오른쪽 아래에서 시작해 고블린 얼굴 뒤, 마녀 모자 아래, 오크 어깨 뒤로 이어져 들어가게 한다. 인물이 그 풍경 **앞에 서 있는** 것처럼.
2. **인물 가장자리를 공기 속에 녹인다.** 인물 실루엣 바깥쪽에 옅은 안개·눈발·차가운 반사광(라벤더/페리윙클 림라이트)을 둘러 크림 배경과 이어지게. 고블린 스카프·털 칼라·머리카락 끝이 안개 쪽으로 살짝 풀린다. 인물 오른쪽 가장자리에 크림이 아닌 원경의 색(옅은 보라·회청)이 비쳐 보이게.
3. **색의 다리를 놓는다.** 인물 쪽 어두운 자두·남색 그림자 → 중간 톤 숲 실루엣(인물 바로 뒤, 조금 진하게) → 멀리 갈수록 옅은 라벤더 안개 → 메뉴 뒤 크림. 거리에 따라 단계적으로 옅어지는 공기 원근.
4. **빛을 공유한다.** 원경 산장 창문의 앰버와 같은 따뜻한 빛이 인물 얼굴 오른쪽에 아주 약하게 닿고, 원경의 차가운 하늘빛이 인물 그림자 쪽에 섞이게 해서 같은 장소의 같은 시간처럼.
5. 원경 자체는 여전히 **어슴푸레하게**. 인물 바로 뒤만 약간 진하고, 오른쪽으로 갈수록 안개에 녹는다.

## 유지할 것

- 일곱 인물의 얼굴·표정·배치·크기·크롭. 가장자리 처리를 위해 실루엣 끝(머리카락·털·스카프 끝)이 조금 바뀌는 것은 괜찮지만 얼굴은 바뀌면 안 된다.
- 화풍(굵은 먹선·큰 색면·인쇄 질감).
- 타이틀 「마녀산장」·메뉴(이어하기·새로운 이야기·기록 보관소·설정)·나가기의 문구·위치·모양. **글자 바로 뒤는 밝고 깨끗하게** 유지해 가독성을 지킨다. 추가 문구 금지.

v01을 **편집 입력**으로 써서 사용자 표시 영역(고블린 얼굴~오른쪽 아래)과 인물 오른쪽 가장자리 전체를 다시 칠하는 것을 우선한다. 최종본에서 얼굴·UI가 흔들리면 v01 픽셀로 보존해 합성해도 된다. 단, 합성 경계가 다시 "오려 붙인" 느낌이 되지 않게.

## Claude 검수 후 추가 수정 요청 · 2026-10-21

v02는 인물–원경 연결이 크게 좋아졌다. 다만 확대해 보니 **타이틀·메뉴 뒤에 직사각형 크림 상자 경계가 그대로 보인다**(UI 보존 합성 영역의 가장자리). 예: x≈1260 세로선, y≈170 가로선 — [확대 이미지](refs/lobby-closeup-distant-v02-title-box-seam.png). 오크 털 칼라 오른쪽 끝에도 오려 낸 듯한 밝은 테두리가 조금 남았다.

- 크림 보존 영역을 **직사각형이 아니라 글자 주변의 부드럽고 불규칙한 안개 덩어리**로 바꾸고, 가장자리를 넓게(100px 이상) 페더링해 주변 라벤더 하늘·숲과 자연스럽게 섞는다. 직선 경계가 하나도 보이면 실패.
- 글자 획 자체는 원본 픽셀 보존, 획 주변 밝기만 가독성 유지 수준으로.
- 오크 털 칼라 오른쪽 끝의 밝은 테두리를 주변 하늘색에 녹인다.
- 결과는 같은 v02 폴더의 최종 PNG·sheet를 갱신하고(기존 최종본은 drafts/에 `-before-seamfix`로 보관), 이 절 아래에 `### Codex 추가 납품` 을 적는다.
