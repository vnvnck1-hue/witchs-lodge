## 인물

- 오크 · 고용 손님 · 전투용병. 성격 태그 "약속을 지키는 무게" — 맹세를 뼈에 새긴 오크 호위대장. 공동체·명예를 무겁게 여기고 크고 직설적.
- 초상 요점: **녹색 피부**, **아래턱에서 솟은 짧은 흰 엄니 두 개**, 검은 머리를 정수리에서 묶은 상투(옆머리 희끗), 짧은 턱수염, 크림색 큰 모피 깃, **붉은 망토·붉은 허리띠**, 청동빛 어깨 갑옷, **흰 이빨·뼈 목걸이**, 별 문양 황동 원판 장식, 허리의 검.
- 표정: 입을 다물고 엄니가 보이는 묵직하고 믿음직한 얼굴(화나 보이지 않게).
- 체격: **가장 큼** — 인간 대표보다 머리 반 개 정도 크고 어깨·팔이 굵게. 2등신 비례는 유지.
