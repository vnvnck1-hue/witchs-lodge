# Codex에게 요청하는 에셋 작업 — 로비 시안 2장, 게임 화풍으로 다시 그리기 v01

요청자: Claude (게임 구현 담당) · 2026-10-21 · 원본: [로비 시안 01·02](../../art/concepts/lobby/reference-composition-v01/prompts.md)

## 사용자 요청

> 가장 일찍 만들어진 두 개 이미지의 레이아웃을 활용해서, 우리 게임에 맞는 그림체로 변경해서 다시 그려줘. 두 개니까 두 개 그려줘.

대상은 `art/concepts/lobby/reference-composition-v01/`의 **01-story-edge.png**와 **02-winter-inn-window.png**다.
두 장 모두 **레이아웃(구도·인물 배치·UI 위치)은 그대로 두고 그림체만** 게임 화풍으로 바꾼다.

## 지금 무엇이 문제인가

두 시안은 매끈한 애니메이션·라이트노벨 일러스트 화풍(큰 눈, 고운 피부 셰이딩, 잔잔한 반짝이·꽃 장식이 화면 가득)이다.
게임에 들어가는 카드·포트레이트와 나란히 두면 다른 게임처럼 보인다.

## 맞춰야 할 게임 화풍 (승인 자료 기준)

- **굵게 시작해 가늘어지는 짙은 먹선** 외곽선. 인물·소품의 실루엣이 선으로 또렷하다.
- **큰 색면과 분명한 2~3단 명암**, 그 위에 **인쇄물 같은 페인터리 붓·안료 질감**(브람 v02, 마녀 포트레이트의 천 질감).
- 얼굴은 애니메이션식 큰 눈·작은 코가 아니라 **살짝 과장된 개성 있는 이목구비**(니브 카드처럼 코·귀·광대·눈썹이 형태로 드러남). 미형 일색 금지.
- 색은 보라·인디고·남색 그림자, 라벤더·크림 눈과 여백, 앰버 등불·창문 빛, 아주 적은 청록 하이라이트. 채도는 절제.
- 장식 밀도를 낮춘다. 작은 반짝이·별·꽃잎·잔무늬를 화면 전체에 뿌리지 않는다. 디테일은 얼굴·등불·핵심 소품에만.
- **중세 기반 판타지, 중세의 생활감과 분위기를 유지하면서 판타지적 각색 허용**(목재·석재, 직물·가죽·금속, 등불·양피지).
- 사진풍·3D 렌더·애니메이션풍 금지.

## 유지할 것

- **01**: 왼쪽 56%의 대각선 S자 몽타주 — 왼쪽 아래 전경의 은발·보라 큰 모자 마녀(목동 지팡이·등불, 발치에 잠든 양), 위쪽 나뭇가지 속 세 마녀(구리머리 불 마녀·청록 약초 마녀·책을 든 검은 계약 마녀), 경사 위 따뜻한 창의 목조 산장과 계단을 오르는 여행자들(드워프·인간·고블린), 왼쪽 위 숲 어둠 속 뿔 달린 나무 얼굴. 오른쪽 44%의 크림 여백과 타이틀 「마녀산장」(초승달 장식), 메뉴 이어하기(앰버 초승달 + 붓 밑줄)·새로운 이야기·기록 보관소·설정, 오른쪽 아래 나가기.
- **02**: 산장 안에서 큰 아치 창 너머 설경을 보는 구도. 오른쪽 전경 창가 의자의 은발·보라 모자 마녀(찻잔, 왼쪽을 바라봄)와 아래 잠든 양·책 더미, 아래쪽 나무 탁자의 등불·마법책·잔, 왼쪽 아래에서 이야기하는 고블린과 드워프, 오른쪽 중경에서 일하는 청록·구리머리 마녀, 위층 난간의 검은 머리 마녀. 왼쪽 위 크림 여백의 타이틀 「마녀산장」(가는 선 + 초승달), 메뉴 이어하기(앰버 마름모)·새로운 이야기·기록 보관소·설정, 왼쪽 아래 나가기.
- 두 장 모두 원본과 **같은 위치·크기 비율**로 인물·건물·UI가 놓여야 한다. 원본 위에 겹쳐 봤을 때 덩어리 배치가 맞으면 된다.

## 인물 정체성 맞추기

- 고블린은 [니브](../../art/concepts/cards/roles-individual-v02/01-character-nib.png): 올리브 초록 피부, 큰 뾰족 귀, 붉은 두건/스카프, 금 귀걸이.
- 드워프는 하랄드(`art/concepts/characters/dwarf-harald-model-v01/` 참고): 대머리·회색 옆머리, 두 갈래로 땋은 아주 두꺼운 수염, 가죽 작업복. 02의 붉은 수염 드워프도 하랄드로 통일한다.
- 01의 인간 여행자는 [브람 v02](../../art/concepts/portraits/card-style-v01/bram-card-style-v02.png) 인상을 따른다.
- 주인공 마녀는 은발·보라 큰 모자를 유지하되 게임 [마녀 포트레이트](../../art/portraits/card-style-v01/witch.png)의 보라 망토·천 질감을 따른다.

비교 시트를 직접 열어 01의 왼쪽 S자 인물·산장 몽타주와 오른쪽 UI, 02의 창가 마녀·큰 창틀·하단 탁자와 손님·왼쪽 UI를 원본과 대조했다. 고블린의 올리브 피부·붉은 두건과 스카프·금 귀걸이, 하랄드의 대머리·회색 옆머리·두 갈래 회색 수염·가죽 작업복을 확인했다. 01 인간 여행자에는 브람의 얼굴 인상과 복식을 반영했다. 두 장의 한글 여섯 문구와 선택 표시·나가기 위치를 확인했으며 추가 문구나 깨진 한글은 없다.

생성 원본은 각각 1672×941로 보존하고, 최종본은 고품질 bicubic으로 자르기 없이 1920×1080에 맞췄다. 개별 인물·UI 재배치와 폰트 재식자는 하지 않았다. 원본 비율과 16:9의 차이는 약 0.053%다. 현재 납품물은 사용자 최종 승인 전의 검토용 시안이다.

수정 범위는 `art/concepts/lobby/game-style-v01/`의 신규 산출물과 이 문서의 납품 절뿐이다. `godot/**`, 루트 `WitchsLodge.exe`, 다른 `docs/` 문서, `art/concepts/lobby/reference-composition-v01/`는 수정하지 않았다. Godot 실행·임포트·실행파일 내보내기와 커밋은 하지 않았고 기존의 다른 작업 트리 변경을 보존했다.
