# Codex에게 요청하는 에셋 작업 — 종족·언데드·화합 카드 43장 (v01)

요청자: Claude (게임 구현 담당) · 2026-10-19 · 기획: [덱 방향성 §3~§6](../deck-archetypes-v01.md) · 적용 기록: [종족·언데드·화합 카드 v1](../race-cards-v01.md) · 카드 기준: [카드 디자인 가이드](../card-design-guide.md) · 바로 앞의 같은 종류 요청: [고블린 카드 v01](codex-goblin-cards-v01.md)

## 배경

고블린에 이어 요정·드워프·오크·수인·인간 용병도 자기 종족 이벤트로 종족 카드를 준다(종족 = 덱 방향). 여기에 플레이 스타일 두 갈래(언데드 = 용병을 바치는 길, 화합 = 여러 종족을 섞는 길)와 공용 이벤트가 더해진다. 이 43장은 게임 코드·카탈로그에 이미 들어가 있거나 같은 날 들어가지만 **카드 그림 파일이 없어 지금은 카드 뒷면으로 보인다.** 이번 작업으로 정식 원화를 만들어 아래 경로에 **새로 저장**한다. 게임 코드는 경로만 맞으면 그림을 그대로 쓴다.

사건 카드 10장(`forest_promise` 등)은 게임에서 **용병 대화 이벤트**로 나오고 손패에는 들어오지 않는다. 원화는 도감·기록·이벤트 창 표시용이다. 그래도 다른 카드와 똑같은 규격·품질로 만든다.

## 역할 분담

- **Codex 책임:** 카드 43장(원본·게임용·손패용)의 생성·후처리·검증·문서화.
- **Claude 책임:** 게임 코드·카탈로그·검증 스크립트·실행파일 내보내기.
- **수정 금지:** `godot/scripts/**`, `godot/scenes/**`, `godot/shaders/**`, `godot/tools/**`, `godot/assets/cards/catalog.json`, `output/race-cards-v01/catalog_entries.json`, `godot/project.godot`, 이번 43장 외 기존 `godot/assets/cards/**/*.png`(종족 직업 카드 `godot/assets/cards/races/**` 포함), 기존 `art/cards/races-v01/**`(종족 직업 카드 원본), `docs/` 의 기획 문서(이 요청서 끝의 납품 결과 절만 추가), 루트 `WitchsLodge.exe`(Claude가 내보낸다). 다른 작업의 변경을 되돌리지 말 것. **커밋하지 말 것.** Claude와 다른 세션들이 같은 저장소에서 동시에 작업 중이다.

## 반드시 따를 기존 기준

먼저 읽기: [카드 디자인 가이드](../card-design-guide.md)(§2 역할별 포맷, §4 안전 영역, §6 절차, §7 검수), [고블린 카드 요청서](codex-goblin-cards-v01.md)(가장 최근의 같은 종류 작업과 **납품 결과의 동시 변경 기록**), [장비 카드 요청서](codex-equipment-cards-v01.md), 아트 가이드 `docs/art-direction.md`, 전역 지침 `CLAUDE.md`(중세 기반 판타지).

**실제 이미지 참고 입력(필수, 매 장):**

1. **해당 역할의 승인 PNG** — `art/concepts/cards/roles-individual-v02/` 의 아래 표 "포맷" 열 파일. 원화창 형태·프레임·패널·먹선·글자 배치를 그대로 따른다.
   - 인물(소환): `01-character-nib.png` · 스킬: `02-skill-warm-welcome.png` · 자원: `03-resource-timber.png` · 장비·유물(계약 변형 포함): `04-relic-moonlit-charm.png` · 시설: `05-facility-forest-altar.png` · **사건(침식 포함): `06-event-forbidden-harvest.png`**
2. **같은 역할의 현재 게임 카드** 1~2장(화풍·질감 일관성), 모두 `godot/assets/cards/`:
   - 스킬: `frost_rune.png`·`goblin_firecracker.png` · 자원: `timber.png`·`meat_stew.png` · 장비: `rusty_longsword.png`·`graz_whistle.png` · 유물: `moonlit_charm.png`·`hearth_ember.png` · 시설: `ward_lantern.png`·`junk_barricade.png` · 인물(소환): `goblin_gang.png`·`forest_monster.png` · 사건: `wolf_blood.png`·`guest_invitation.png` · 침식: `corrupt_prayer.png`·`cursed_whisper.png`
3. **종족 외형 기준**(종족 카드는 해당 종족 것을 매 장, 참고 입력 수 제한이 있으면 고블린 납품처럼 비율 유지 비교 시트 1장으로 묶어도 된다). 초상은 모두 `godot/assets/portraits/guest_<이름>_cutout.png`.
   - **요정** — 초상 `thistle`·`tilia`·`larch`·`fern`·`willow`·`pip`·`nivel`. 작은 몸, 잎·씨앗·엉겅퀴, 연초록 보조색, 씨앗 문장. (`art/concepts/cards/roles-races-v01/03-elf-elin-v01.png`는 이전 '엘프' 시안이므로 잎·청록 색감 참고로만 쓰고 외형 기준으로 쓰지 않는다.)
   - **드워프** — 초상 `harald`·`brynhild`·`thorgrim`·`durga`·`ormu`·`ketil`·`signy`. 돌·연장·조상 룬, 구리·주황 보조색, 망치 문장. 손으로 만든 단단한 물건.
   - **오크** — 초상 `garok`·`kranya`·`moga`·`shaga`·`ulma`·`bardu`·`eshka`. 공동체·음식·의식, 뼈·재·가죽, 적갈 보조색, 엄니 문장. 거칠지만 따뜻하게.
   - **수인** — 초상 `fargh`·`saya`·`urso`·`momi`·`luka`·`tass`·`selen` + `art/concepts/cards/roles-races-v01/04-beastfolk-luka-v01.png`. 털·발자국·후각·겨울잠, 호박색 보조색, 발자국 문장.
   - **인간** — 초상 `bram`·`mira`·`olaf`·`torbin`·`neri`·`oswin`·`sera`. 마을·길드·순례·교역, 크림·금빛 보조색, 등불 문장.
   - **언데드·화합·중립·브리지** — 종족 초상 없음. 언데드는 2번의 침식 카드와 시설 승인 PNG(`05-facility-forest-altar.png`)의 제단 분위기를 색감 참고로, 화합은 여러 종족 문장(씨앗·망치·엄니·발자국·등불·동전)을 함께, 브리지(`battle_ration`)는 드워프+오크 두 종족을, 중립은 인간 마을·산장 소품을 참고한다.

공통 요건:

- **RGBA 1024×1536(2:3), 네 모서리 라운드, 모서리 바깥 투명.** 손패용은 같은 그림을 **RGBA 256×384**로 균등 축소.
- 인쇄 문구(제목·분류 띠·설명 2줄)는 아래 표 **그대로**(철자·띄어쓰기·가운뎃점 ` · ` 포함). 제목 2줄·설명 4줄 안전 영역을 비워 둔다(`여러 문장이 박힌 깃발`처럼 긴 제목은 2줄로 나눠도 된다). 글칸 안 장식 금지. **원화에 수치·숫자 금지**(가격·체력·초·장 수·G 표기 없음).
- **"임시 카드" 같은 문구를 넣지 않는다.** 표에 없는 효과·조건을 그림 글자로 추가하지 않는다.
- 중세 기반 판타지. 겨울 숲·산장 지역(눈, 침엽수, 등불·모닥불의 따뜻한 빛).
- 종족 카드는 해당 종족 보조색과 문장 모티프를 **원화 안에 은근히** 넣는다. 프레임 자체는 승인 포맷 그대로이며, 인물 포맷이 아닌 카드에 종족 배지를 붙이지 않는다(가이드 §3: 스킬 자체에 종족 배지 금지).
- **언데드 10장은 민담풍 공포(folk-horror)이되 잔혹하지 않게:** 뼈·해골·촛불·까마귀·무덤 흙·묘비·이끼 낀 비석·창백한 푸른 빛. **피·상처·내장·살점·고어 표현 금지.** 시체 카드도 천에 덮인 형체·장례 수의로 표현하고 얼굴·상처를 보이지 않는다. `blood_oath`(오크)도 피를 흘리는 장면 대신 붉은 끈·붉은 물감 문양으로.
- 사건 포맷은 장면을 크게 보여주는 원화창과 하나의 넓은 설명 패널. 인쇄 문구에 선택지 두 개가 들어 있어도 **중앙 화살표·갈래 문양·두 칸 분할을 넣지 않는다**(가이드 §2).

### 원화 내용

**요정**

- **요정의 맞바꿈(스킬):** 작은 요정의 두 손이 서로 다른 두 물건(도토리와 녹슨 쇠단추 같은)을 공중에서 맞바꾸는 순간, 사이에 흩날리는 씨앗 빛과 한 가닥 검보라 연기(가끔 오는 침식). 마름모 중앙.
- **꿈 기록장(장비, 마녀용):** 잎사귀 표지에 씨앗 매듭 끈을 두른 작은 수첩, 펼친 장에서 희미한 별빛이 피어오른다. 방패형 창에 세로로.
- **엉겅퀴 맹세(장비):** 보라 엉겅퀴 꽃과 가시 줄기를 엮어 만든 팔찌·매듭 장신구, 가시 끝에 서리.
- **숲의 약속(사건):** 눈 덮인 숲 공터에서 요정이 도끼 박힌 그루터기 앞에 서서 손가락을 걸어 약속을 청하는 장면, 뒤편에 빛나는 고목. 넓은 장면창.

**드워프**

- **룬 새긴 망치(장비, 무기):** 짧고 굵은 대장장이 망치, 자루와 머리에 빛나는 구리색 룬. 방패형 창에 세로로.
- **흑맥주 통(자원):** 쇠테를 두른 작은 참나무 통과 거품 넘치는 나무 잔. 망치 문장 낙인.
- **돌 성벽 기초(시설):** 눈밭에 막 쌓아 올린 두꺼운 마름돌 벽의 밑단, 룬 새긴 머릿돌. 시설 포맷의 지붕 포인트·기둥 유지.
- **조상의 방패(장비, 방어구):** 둥근 철테 나무 방패, 가운데 조상의 얼굴 문양(돌 조각풍), 구리 리벳.
- **갱도 버팀목(시설):** 산장 벽 옆을 받친 굵은 갱목 기둥과 쐐기, 걸린 광부 등불. 돌 성벽과 달리 **나무 기둥** 실루엣.
- **돌 속의 노래(스킬):** 수염 난 드워프가 돌벽에 이마를 대고 노래하는 옆모습, 돌 표면에 구리빛 룬 물결이 퍼진다. 마름모 중앙.

**오크**

- **전쟁 북(스킬):** 가죽을 팽팽히 메운 큰 북과 뼈 북채가 내리치는 순간, 눈가루가 튀는 충격파. 마름모 중앙.
- **잔칫상(자원):** 긴 나무 탁자 위 김 오르는 큰 솥과 나무 그릇들. 고기 스튜 카드와 겹치지 않게 **솥+긴 상**의 넓은 구도.
- **피의 맹세(계약 변형):** 붉은 끈을 감고 붉은 물감 문양을 새긴 커다란 엄니(또는 뼈 패), 맹세의 손자국 하나. 피 흘림 없이. 방패형 창.
- **뼈 던지기(사건):** 모닥불 앞 오크 노파 주술사가 가죽 위에 작은 뼈들을 던지고 들여다보는 장면, 불티와 그림자.
- **승리의 함성(스킬):** 엄니 드러낸 오크가 고개를 젖혀 포효, 입김이 눈보라처럼 퍼진다. 전쟁 북과 구별되게 **얼굴·포효** 중심.
- **조상의 길(사건):** 눈 덮인 능선 위로 이어진 조상의 돌무더기 길을 따라 걸어가는 오크 순례자의 뒷모습, 먼 새벽빛.
- **재로 그린 문양(장비):** 회색 재로 엄니 문양을 그린 가죽 조각 부적, 끝에 작은 숯 조각. 피의 맹세와 구별되게 **회색·가죽 조각**.
- **통구이(자원):** 모닥불 위 꼬챙이에 꿰어 돌아가는 통짜 고기, 기름 불꽃. 잔칫상과 구별되게 **꼬챙이 하나** 세로 구도.

**수인**

- **무리의 냄새(장비):** 여러 빛깔의 털 뭉치를 엮은 목걸이, 발자국 모양 뼈 구슬.
- **짐꾼의 등짐(장비, 방어구):** 오소리 수인이 지는 커다란 가죽 등짐틀, 매달린 자루·덫·약초 다발.
- **겨울잠(사건):** 눈 덮인 굴 입구 안에서 담요를 덮고 몸을 말아 잠든 곰 수인, 따뜻한 등불 하나. 고요한 장면.

**인간 · 브리지**

- **소개장(사건):** 산장 문간에서 인간 전령이 밀랍 봉인 편지를 건네는 장면, 눈 내린 고개 길.
- **길드 증서(계약 변형):** 리본과 붉은 밀랍 인장이 달린 접힌 양피지 증서, 직업 도구(도끼·활·바구니)가 찍힌 도장. 방패형 창.
- **마을 민병(인물·소환):** 갑옷 대신 누빈 옷에 창·쇠스랑을 든 마을 사람 둘, 등불을 들고 눈길을 달려온다. 아치형 초상창.
- **오래된 기록(사건):** 무너진 석조 유적 안 낡은 책상, 펼친 두꺼운 고서와 촛불을 들여다보는 학자의 손.
- **순례자의 축복(스킬):** 순례자의 지팡이에 매단 작은 등불이 따뜻한 빛을 퍼뜨리고, 검은 연기 조각들이 흩어져 사라진다. 마름모 중앙.
- **상인 마차(사건):** 산장 앞에 선 덮개 마차, 옆판을 내리자 여러 종족 물건(구리 망치·씨앗 주머니·엄니 부적)이 진열된 모습.
- **전투 식량(자원, 브리지):** 드워프 흑맥주 작은 통과 오크식 말린 고기 묶음을 한 천에 싸 끈으로 묶은 꾸러미. 흑맥주 통과 구별되게 **천 꾸러미**가 주인공.

**언데드** (민담풍, 고어 금지)

- **제물의 단검(스킬):** 검은 손잡이에 뼈 장식이 달린 의식용 단검이 이끼 낀 제단석 위에 놓여 있고, 촛불과 까마귀 깃털. 피 없음. 마름모 중앙.
- **시체(자원):** 눈밭 위 수의(삼베 천)에 덮인 길쭉한 형체와 작은 이름표 끈(글자 없음), 곁의 꺼진 등불. 얼굴·상처 금지. **카드에 이름을 인쇄하지 않는다**(인물 이름은 게임이 따로 표시).
- **일어나라(스킬):** 무덤 흙을 뚫고 올라오는 해골 손과 창백한 푸른 불빛. 마름모 중앙.
- **뼈 방책(시설):** 큰 뼈와 나무 말뚝을 엮은 낮은 방책, 해골 장식과 촛불. 시설 포맷 유지. 고블린 고물 방책과 구별되게 **흰 뼈 색**.
- **영혼 병(자원):** 코르크와 밀랍으로 봉한 유리병 속에 갇힌 푸른 영혼 불빛, 병목에 묶인 뼈 구슬.
- **구울의 만찬(스킬):** 무덤가 돌판 위 촛불 만찬상에 몸을 굽힌 마른 그림자 하나(구울), 접시는 비어 있거나 뼈만. 고어 금지. 마름모 중앙.
- **죽음의 행진(스킬):** 안개 낀 묘지에서 줄지어 걸어 나오는 해골 병사들의 실루엣, 깃발 하나, 창백한 달. 일어나라와 구별되게 **여럿의 행렬**.
- **뼈 사냥개(인물·소환):** 뼈만 남은 날렵한 사냥개 두 마리가 푸른 눈빛으로 달려드는 모습. 아치형 초상창.
- **검은 소문(침식):** 산장 창문 밖에서 수군거리는 까마귀 떼와 검은 연기 같은 속삭임, 바닥에 떨어진 낡은 전단. 기존 침식 카드처럼 음울한 색조.
- **망자의 장부(장비, 마녀용):** 검은 가죽 표지에 쇠 걸쇠, 촛농이 흘러내린 두꺼운 장부와 깃펜. 통역사의 펜·꿈 기록장과 구별되게 **검은 가죽+쇠 걸쇠**.

**화합 · 중립**

- **여러 문장이 박힌 깃발(유물):** 산장 처마에 걸린 길쭉한 천 깃발에 씨앗·망치·엄니·발자국·등불·동전 문장을 조각보처럼 기운 모습. 방패형 창에 세로로.
- **통역사의 펜(장비, 마녀용):** 여러 색 깃털을 묶은 깃펜과 잉크병, 여러 문자가 섞여 적힌 쪽지(읽을 수 있는 글자는 넣지 않는다).
- **산장의 축제(사건):** 산장 앞마당 모닥불을 둘러싸고 여러 종족 용병이 함께 춤추고 건배하는 밤 장면, 깃발과 등불 줄.
- **낯선 손님의 선물(사건):** 두건 쓴 낯선 나그네가 산장 문 앞 눈 위에 천으로 싼 꾸러미를 두고 돌아서는 장면.
- **산장 대청소(사건):** 빗자루·먼지떨이를 든 용병들이 산장 안을 치우고, 낡은 카드 한 장이 바람에 날려 나가는 장면.
