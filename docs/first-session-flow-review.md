# 마녀산장 — 첫 실행 플로우(FTUE) 유저 시점 점검

작성일: 2026-10-17 · 대상: Godot 실행판(현재 `main` 작업 트리) · 상태: **조사 완료, 보강 방향은 함께 결정 예정(§7)**

처음 게임을 켠 유저가 **실행 → 시작 손패 → 1일차 낮 → 첫 밤 → (패배/재시작)** 을 거치며 어디서 어색함을 느끼는지 정리했다. 근거는 코드 추적과 헤드리스 실측(`godot/tools/verify_first_session.gd`)이다. 서사 기준은 [내러티브](narrative.md)·[세계관](world-races-card-formats-v01.md)·[코어 기획 §3.1](kingdom-integration-design.md#31-핵심-장기-플로우-네-마녀봉인석해금위험엔딩)·[지역·계절 기획](region-season-pocket-design.md)을 따른다.

## 2. 조사 방법

- **헤드리스 실측**: `godot/tools/verify_first_session.gd`가 실제 `main.tscn`을 띄우고, 실제 실행과 같은 순서로 시작 손패 화면을 연 뒤(검증 실행에서는 자동 지급이 꺼져 있어 직접 연다) **게임 시간 기준 실행~첫 밤 끝**의 토스트·효과음·목표 문구·손님 소개·고용 제안·일시정지 변화를 타임라인으로 남긴다. 4배속으로 돌린다.
- **비교 시나리오 4개**(첫 밤 결과를 가르는 행동 확인):

| 시나리오 | 플레이어 행동 | 첫 밤 결과 |
| --- | --- | --- |
| `idle`(기본) | 시작 손패만 확정하고 아무것도 안 함 | **패배** 41초 — 산장 0/300, 마녀 100 |
| `guard` | 밤이 되면 산장 문 앞으로 이동(H 키) | **패배** 41초 — 산장 0/300, 마녀 95 |
| `chase` | 카드·고용 없이 가장 가까운 괴물을 쫓아 기본 공격 | **패배** 13초 — 마녀 사망(쫓아가다 맹독 곤충 서식지에 들어간 직후), 산장 290 |
| `hire` | 고용 제안이 뜨면 즉시 고용, 계약 카드를 산장 앞에 사용 | **생존** 27~28초 — 산장 약 230/300, 마녀 100 |

- 결과 파일: `godot/art_sources/first-session-verify.json`(기본), `-guard`·`-chase`·`-hire.json`. 렌더 캡처는 하지 않았다(모든 항목이 상태·타이밍이라 헤드리스로 확인 가능).

1일차 낮 토스트 7개, 손님 소개 3회(약 30초), 고용 기회 2회(각 10초), 말 걸기 3회가 90초 안에 들어간다.

### 3.2. 첫 밤 (기본 시나리오)

- 거미 5마리(0초 3마리, 8초 2마리)가 산장을 친다. 마녀의 자동 공격은 사거리 4m(`BOLT_RANGE`)라 산장 반대편 괴물에 닿지 않는다. 마녀는 3발만 쏘고 1마리 처치.
- 101초부터 약 1초마다 산장 피격, **131.2초 산장 붕괴 → 패배**. 화면: "게임 오버 / 산장이 무너지고 봉인석을 빼앗겼습니다. (1일차 밤 / 12)".
- `hire` 시나리오(브람 전투용병 + 올라프 사냥꾼)는 27~28초 만에 정리, 2일차로 넘어간다. 첫 밤을 넘기는 열쇠는 **고용**인데, 이를 알 수 있는 단서는 목표 문구 "손님을 고용하세요"가 고용 창이 열린 10초 동안만 바뀌는 것뿐이다.

### 3.3. 2일차 아침 (비교)

- 새벽 전환(`dawn_elapsed=0.19`, 밤빛에서 낮빛으로 12초)과 새벽 효과음이 정상 동작한다.
- 새벽 토스트 3개: "양 3마리의 털이 자랐습니다" / "2일차 — 오늘 밤: 습격의 밤" / "아침 드로우 — 서리 룬". 아침 연출은 사실상 **빛 전환 + 토스트 묶음**이다.

## 4. 단계별 유저 시점 분석

### 4.1. 실행 · 로비

- **실행 즉시 게임 장면**: `project.godot`의 main_scene이 `main.tscn`이고 다른 장면이 없다. 첫 실행은 테두리 없는 전체 화면이라 유저가 마음의 준비를 할 틈 없이 숲 한가운데로 떨어진다.
- **진입점 부재**: 게임 끝내기는 Alt+F4뿐(일시정지 메뉴에 `계속하기·지도 보기·화면/디스플레이/소리 설정`만 있음). 이어하기·저장이 없어 12일 챕터를 한 번에 끝내야 한다.
- **기획과의 차이**: 기획상 시작 순서는 **마녀 선택 → 지역 선택 → 계절 선택 → 게임 시작·시작 손패**다([지역·계절 기획 §2](region-season-pocket-design.md)). 지금은 마지막 단계만 있다. 로비는 이 선택 화면들이 들어갈 자리이기도 하다.

### 4.2. 도입 · 세계관

- 도입 문구 초안([내러티브 §1](narrative.md#도입-문구-초안))과 세계 역사(마녀사냥 → 워록의 실종 → 네 마녀의 흩어짐)가 실행판에 하나도 없다.
- **봉인석**: 장기 플로우의 중심(네 마녀가 각자 봉인석을 지킴)인데, 플레이어는 패배 화면("봉인석을 빼앗겼습니다")이나 10일차 "봉인석 탈취의 밤"에서야 이 단어를 처음 본다. 무엇을 지키는지 모른 채 지키는 셈이다.
- 플레이어 캐릭터가 '마녀'라는 사실도 HUD 라벨과 토스트로만 드러난다. 이름·말투를 보여 주는 첫 대사가 없다([내러티브 §4](narrative.md#4-주인공-마녀): "일상적인 행동을 통해 먼저 어떤 사람인지 보여 준다").

### 4.3. 시작 손패(멀리건)

- 연출은 좋다(주머니에서 카드가 날아와 펼쳐짐, 게임 정지, 타이머 멈춤 — 실측 확인).
- 다만 **카드 게임이라는 사실을 처음 알려 주는 화면이 '교체할 카드를 고르라'는 결정 화면**이다. 처음 보는 6종(서리 룬·수호 등불·숙박 초대장·새끼양·잠자는 가시 씨앗·목장의 검은 양) 중 무엇이 좋은지 판단할 근거가 없다. 첫 판은 교체가 사실상 의미 없는 결정이다.
- 확정 후 토스트의 '주머니'·'아침마다 한 장'은 설명 없는 용어다. 카드를 **끌어서 쓴다**는 조작은 일시정지 메뉴의 `조작법`에만 있다.

### 4.4. 1일차 아침

- **원인(코드)**: `main.gd:167` `session.start()`가 첫 낮(PREP)을 알리는 시점에 아직 낮·밤 시계(`world.bind_day_and_sight()`, 168행)가 연결되지 않아 `day_cycle._on_state_changed`가 첫 신호를 못 받는다. 초깃값 `_dawn_elapsed := 12.0`(`day_cycle.gd:14`)이라 새벽 전환이 '이미 끝난' 상태로 시작한다. 새벽 효과음도 `game_session.gd:49-50`에서 `wave_index > 0`일 때만 울린다.
- **결과**: 첫날은 해가 높은 한낮에서 바로 시작하고, 둘째 날부터만 '밤 → 새벽 → 낮' 전환이 있다. 첫날의 시작을 알리는 장면(동틀녘 산장·굴뚝 연기·양 울음·마녀의 기지개 같은 일상)이 없다.
- 1일차 '오늘 밤' 예고 토스트는 멀리건에 가려 보이지 않는다(§3.1).

### 4.5. 1일차 낮(90초)

- **첫 5초는 할 일이 없다**: 목표는 "손님을 맞이하세요"인데 손님은 5초 뒤에 오고, 맞이하는 조작도 따로 없다(자동 입실).
- **정보 과부하와 겹침**: 손님 소개 패널은 게임을 멈추지 않는다(`guest_arrival` PAUSABLE). 소개 10초 × 3회 동안 타이머가 흐르고, 그 사이에 고용 창(10초)·말 걸기·숙박비가 끼어든다. 처음 하는 유저는 소개를 읽다가 고용 기회를 놓친다.
- **고용이 핵심인데 신호가 약하다**: 첫 밤 생존의 열쇠가 고용인데, 고용은 토스트 한 줄 + 손님 머리 위 클릭 + 10초 제한이다. 고용 뒤 받은 **계약 카드를 땅에 끌어 놓아야** 용병이 나온다는 두 번째 단계도 알려 주지 않는다.
- **돈의 의미**: 시작 40G, 첫 고용 30G. 숙박비가 들어오는 순간 고용 제안이 같이 뜨지만 "이 돈으로 지금 고용하라"는 연결이 없다.

### 4.6. 첫 밤 · 패배 · 재시작

- **밤 진입**: 해 지는 빛 변화는 90초 동안 서서히 진행되지만(낮 → 노을 → 황혼), 전환 순간의 '문을 걸어 잠그는' 연출이 없다. 같은 뜻의 토스트 두 줄 + 효과음뿐이다.
- **난이도**: 아무것도 몰라도 첫 밤은 버틸 수 있어야 '배우는 밤'이 된다. 지금은 기본 공격만으로는 버티지 못한다(§2 표). 첫 밤 패배는 이유를 모른 채 끝나는 경험이 된다.
- **패배 화면**: "산장이 무너지고 봉인석을 빼앗겼습니다" + 통계. 무엇을 했으면 좋았는지(고용·카드·용 공물) 힌트가 없다. `새 게임`은 장면 재로드라 다시 곧장 멀리건으로 들어간다.

### 4.7. 서사 리듬

- 도입 초안의 "해가 지면 당신의 문을 두드린다"와 달리 손님은 한낮에 오고 밤엔 괴물이 온다. 도입 문구를 쓸 때 실제 리듬(낮=손님, 밤=습격)에 맞춰 고치거나, 마지막 손님 묶음을 해 질 녘에 맞추는 조정이 필요하다.

## 5. 기획과 실행판 차이 정리

| 기획 | 실행판 |
| --- | --- |
| 마녀 선택 → 지역 → 계절 → 시작 손패 | 시작 손패만 |
| 네 마녀가 각자 봉인석을 지킴(장기 플로우의 중심) | 봉인석은 패배·승리 문구와 10일차 밤 이름에만 등장 |
| 도입 문구 초안·세계 역사 | 실행판에 없음 |
| "일상을 먼저 보여 준다"(내러티브 §10) | 첫 장면이 카드 결정 화면 |
| 초반: "필요한 잠자리 — 마녀의 생활과 말투를 먼저 익힌다"(내러티브 §9) | 마녀 대사 없음, 손님 소개가 일방향 |

## 6. 보강 제안 (우선순위안)

각 항목의 **인수 기준**은 `verify_first_session.gd`의 `[목표]` 판정이다. 지금은 15개 중 4개만 통과한다(통과 4개는 모두 '현재 동작' 확인 항목). 보강하면서 `[목표]` 항목을 하나씩 PASS로 바꾼다.

### P0 — 첫 판에서 이유 없이 지지 않게

1. **첫 밤 안전장치**: 다음 중 택1 또는 조합
   - (a) 1일차 낮에 브람(전투용병)을 **확정 고용 튜토리얼**로 연출: 첫 고용 창은 시간 제한 없음 + 게임 정지 + 손님 머리 위 화살표, 고용 후 "계약 카드를 산장 앞에 끌어 놓으세요" 안내까지.
   - (b) 1일차 밤 난이도 하향(거미 3마리, 산장 공격력 감소) — 아무것도 안 해도 산장 절반은 남게.
   - (c) 첫 밤 시작 시 손패의 서리 룬/수호 등불 사용을 유도하는 1회성 힌트.
2. **첫 패배 힌트**: 패배 화면에 원인별 다음 행동 한 줄(예: 산장 붕괴 → "손님을 고용해 용병을 산장 앞에 세우세요"). `다시 도전` / `타이틀로` 버튼 분리.

### P1 — 시작이 '시작'처럼 보이게

3. **타이틀 화면**(로비 최소형): 게임 제목·`새 이야기`·`설정`·`끝내기`. 배경은 실제 산장 장면을 밤 조명으로 천천히 도는 카메라(새 3D 리소스 불필요). 이후 마녀·지역·계절 선택 화면이 이 뒤에 들어갈 자리를 만든다.
4. **도입 프롤로그(15~30초, 건너뛰기 가능)**: 검은 화면 위 3~4줄 문구 → 동틀녘 산장으로 페이드. 내용은 도입 초안 + 세계 역사 + 봉인석 한 줄. 예시:
   > 마녀사냥이 끝난 뒤, 살아남은 마녀는 넷뿐이었다.  
   > 그중 하나인 당신은 깊은 숲에 산장을 열고, 그 아래 봉인석을 지킨다.  
   > 낮에는 당신을 꺼리는 여행자들이 잠자리를 찾아오고,  
   > 밤에는 숲의 괴물이 봉인석을 노린다.
5. **1일차 새벽 연출**: 첫 PREP도 새벽 전환을 타게 수정(시계를 `session.start()` 전에 연결하거나 첫 진입 때 `_dawn_elapsed=0`), 새벽 효과음 첫날 포함. 그 위에 **'1일차' 타이틀 카드**(가운데 큰 글씨 "첫째 날 · 습격의 밤 예고" 2초) + 마녀의 첫 혼잣말 한 줄.
6. **순서 재배치**: 프롤로그 → 새벽 연출 → 마녀 혼잣말 → **그다음 시작 손패**. 멀리건 앞에 뜨던 '오늘 밤' 토스트는 1일차 타이틀 카드로 옮긴다. 첫 판은 멀리건 교체를 생략하고 "주머니에서 3장"만 보여 주는 안도 검토.

### P2 — 첫 90초를 배우는 시간으로

7. **첫날 일정 재조정**: 1일차만 손님 묶음 2회(5초·40초), 손님 소개 중 타이머 정지 또는 1일차 낮 시간 연장(예: 120초), 첫날 말 걸기 1회로 제한.
8. **단계형 안내**: 목표 문구를 순서 있는 체크리스트로(손님 맞이 → 고용 → 계약 카드 배치 → 밤 대비). 각 단계 완료 시 다음 단계 강조.
9. **밤 진입 연출**: 토스트 2개를 하나의 가운데 배너("첫째 밤 — 습격의 밤 / 숲에서 괴물이 몰려옵니다")로 합치고, 밤 10초 전 경고를 소리 + 화면 가장자리 붉은 기운 + 배너로.
10. **서사 리듬 맞추기**: 도입 문구를 '낮 손님 · 밤 괴물'에 맞게 고치거나, 마지막 손님 묶음을 해 질 녘(70~80초)에 두어 "해가 지면 문을 두드린다"와 맞춘다.

## 7. 함께 정할 질문

1. **첫 밤 안전장치**: (a) 브람 확정 고용 튜토리얼 / (b) 1일차 난이도 하향 / (c) 둘 다 — 어느 쪽?
2. **로비 범위**: 지금은 타이틀(새 이야기·설정·끝내기)만 / 마녀 선택 화면 자리(잠긴 세 마녀 표시)까지 / 지역·계절 선택 껍데기까지?
3. **프롤로그 형식**: 글자만(검은 화면 + 문구) / 정지 일러스트 몇 장 / 실제 산장 장면 위 자막?
4. **주인공**: 이번 1일차 연출에 쓸 마녀는 네 마녀 중 누구(방위)로 가정할까? 이름은 아직 미정으로 두고 '마녀'로 부를까?
5. **멀리건**: 첫 판에도 교체를 허용할지, 첫 판만 생략할지?
6. **튜토리얼 강도**: 첫 판에 한해 게임을 멈추고 안내하는 강제형 / 멈추지 않는 힌트형?
7. **저장·이어하기**: 이번 보강 범위에 넣을지, 로비만 먼저 만들고 다음으로 미룰지?
