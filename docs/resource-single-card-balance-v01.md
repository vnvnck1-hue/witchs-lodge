# 재화 카드 1장 = 1개 전환 밸런스 기획 v0.1

작성 2026-10-18. 상태: **1장=1개는 같은 날 철회, 묶음으로 복원. 줄인 수치(§4)는 유지.** 검증: `tools/verify_resource_balance.gd` 36/36, `tools/verify_pocket.gd` 59/59.

> **후속 결정(사용자, 2026-10-18 저녁): 재화 카드는 다시 한 장에 수량으로 쌓는다(`stackable: true`).**
> - 수량 배지는 카드 **왼쪽 아래 모서리**로 옮겼다. 부채꼴 손패에서는 오른쪽 카드가 왼쪽 카드의 오른쪽을 덮으므로 오른쪽 아래 배지가 가려졌다. 실제 렌더 확인: `godot/screenshots/stack_badge/`(`tools/capture_stack_badge.gd`).
> - 산장 판매 시 **판매 수량을 고르는 창을 다시 띄운다**(한때 즉시 1장 판매로 바꿨던 것을 원래대로 복구). 묶음 합산·수량 조절 효과음(stack_gain·qty_tick)도 복구.
> - §4의 생산·소비 수치(벌목 15초, 나무꾼 보유 1, 건축 목재 최고 3, 수리 1개 +60, 판매가 6·8·10 등)와 재화 사용 시 소멸 규칙은 그대로 둔다.
> - 아래 본문은 1장=1개 전환 당시의 기획 기록이다.

## 1. 배경과 문제

지금 재화 카드(목재·양털·검은 털·생고기·토끼 가죽)는 `stackable: true`로, 손패 한 칸에 "목재 ×12"처럼 **수량 묶음**으로 들어 있다. 앞으로 넣을 기믹

> 손패 카드 3장을 무작위로 골라 주머니에 넣고, 그만큼 새로 뽑는다

같은 "손패를 흔드는" 효과는 묶음 구조와 충돌한다. 목재 ×12 한 장이 주머니로 가면 플레이어의 목재가 한순간에 0이 되고, 주머니 속 자원은 확정 규칙 9에 따라 쓸 수 없으니 복구도 아침 드로우 1장씩뿐이다.

**사용자 결정(2026-10-18): 재화 카드는 1장이 곧 재화 1개다.** 목재 카드 3장 = 목재 3개. 손패를 흔드는 효과는 재화를 "몇 장" 단위로만 건드리게 되어 손실이 유한해진다.

## 2. 전환이 깨뜨리는 것

손패 한도는 8장(확정 규칙 3)이다. 1장=1개가 되면 **재화가 손패 칸을 그대로 먹는다.** 지금 수치를 그대로 두면:

| 지금 수치 | 1장=1개일 때 벌어지는 일 |
| --- | --- |
| 객실 증축 목재 10, 목장·묘지 8~12, 제단 복구 10 | 손패 8장을 다 채워도 못 낸다. **구조적으로 불가능** |
| 나무꾼 벌목 4초/1개, 보유 10개까지 | 한 번 건네면 목재 10장. 손패가 터지고 나머지는 주머니로 묻힌다 |
| 나무 한 그루 목재 8~56개 | 하루에 수십 장이 흘러나온다 |
| 채집가 목재 2~4개 + 고기·가죽 | 한 번 다녀오면 재화만 4~6장 |
| 사슴 1마리 생고기 2개, 사냥감 최대 5마리 | 사냥꾼 하루 4~6장 |
| 손패 가득 차면 획득물은 주머니로 (확정 규칙 1) | 재화가 주머니에 묻히고 아침 드로우 1장으로만 돌아온다. 재화가 "쓸 수 없는 카드"가 된다 |

즉 **생산량과 소비 단가를 모두 1/4~1/10으로 줄이고**, 손패가 찬 상태에서 재화가 주머니로 새는 경로를 막아야 한다.

## 3. 설계 원칙

1. **하루 재화 유입은 전 종류 합쳐 4~6장 안팎.** 손패 8장 중 재화가 평소 3~4칸, 많아도 5칸을 넘지 않게 한다. 나머지는 주문·용병·설치물 몫이다.
2. **소비 단가는 1~3장.** 가장 비싼 건축도 3장이면 "하루 모아서 하나 짓는" 리듬이 된다. 수리는 항상 1장.
3. **카드 1장의 가치를 올린다.** 양이 줄었으니 목재 1장의 수리량, 재화 1장의 판매가를 올려 체감 가치를 유지한다.
4. ~~용병은 손패 빈칸만큼만 건넨다.~~ **사용자 결정(§9 답변 2): 전달 규칙은 현행 유지.** 용병은 들고 있는 것을 전부 넘기고, 손패가 가득 차면 넘친 재화는 주머니로 간다. 대신 **나무꾼 보유 상한을 1개**로 두어 플레이어가 나무꾼을 목재 창고로 쓰지 못하게 한다. 양털도 현행대로(가득 차면 주머니행).
5. **스택 코드 경로를 없앤다.** `stackable`을 모든 카드에서 false로 하고, 수량 `count`는 항상 1이 되게 한다. 종류별 수량 소비(`consume_id`)는 손패의 같은 id 카드를 N장 지우는 동작으로 그대로 성립한다.

## 4. 재화별 변경안

### 4.1 목재 (timber) — 가장 큰 변화

**생산**

| 항목 | 현재 | 제안 | 이유 |
| --- | --- | --- | --- |
| 벌목 1회 시간 `CHOP_TIME` | 4초 | **15초** | 하루(준비 90초) 최대 6회. 원래 값으로 되돌림 |
| 고목의 심장 벌목 시간 `RELIC_CHOP_TIME` | 2.7초 | **10초** | 유물 설명 "15→10초"와 다시 일치 |
| 벌목 1회 목재 `CHOP_YIELD` | 1 | 1 | 유지 |
| 나무꾼 보유 상한 `LUMBERJACK_CARRY` | 10 | **1** (사용자 결정) | 나무꾼을 목재 창고로 쓰는 것을 방지. 1개를 들면 마당에서 쉬며 마녀를 기다린다 |
| 나무 한 그루 목재 `TREE_YIELD_MIN/MAX`, `PER_M` | 8 / 56 / 6.67 | **2 / 6 / 1.0** | 한 그루가 하루 분량. 큰 나무는 이틀 |
| 채집가 줍기 표 목재 `GATHER_TABLE` | 2~4개 | **1개** | 3번 멈추니 최대 3장 |
| 하수인 시듦 `MINION_TIMBER` | 1 | 1 | 유지(드물고 주머니행 허용) |
| 상자 대체 목재 `CHEST_FALLBACK_TIMBER` | 10 | **2** | 유물 다 모은 뒤의 위로 보상 |

기대 유입: 나무꾼은 15초에 1장을 베어 들고 마당으로 와 기다리므로, 마녀가 부지런히 받아 가야 하루 3~4장이다. 채집가와 겹치면 5~6장이라 상한에 걸리지만, 둘 다 고용하는 날은 플레이어 선택이다.

**소비**

| 항목 | 현재 | 제안 | 이유 |
| --- | --- | --- | --- |

## 6. 손패 표시

같은 재화 카드가 3장이면 손패에 3칸을 차지한다. 이것이 의도한 압박이다. 다만 읽기 쉽게 **같은 id 카드는 손패에서 나란히 정렬**하고, 달 HUD의 목재·양털 수치는 `hand_count_of`가 장수를 세므로 그대로 맞는다.

손패 한도 8장은 확정 규칙이라 손대지 않는다. 플레이테스트에서 재화 압박이 과하면 한도 10장을 두 번째 조정안으로 둔다.

- `godot/scripts/game/card_inventory.gd`: `is_resource()` 추가. 재화는 사용 시 소멸(버림패 아님). `add`는 비스택 카드를 낱장으로 넣고, `consume_id`는 손패의 같은 id N장을 지운다(기존 코드 그대로 성립).
- `godot/scripts/game/lodge_economy.gd`: `sell_id(id, n)` 추가, `sell_resource(uid, n)`는 그 카드 종류를 손패에서 n장 판다.

- `godot/scripts/game/card_use_resolver.gd`: 목재 수리는 손패 장수로 판정, 끌어 놓은 카드 1장 + 필요 시 같은 목재를 더 소비. 판매 안내 "손패 N장 · 1장 XG".

- 검증: `godot/tools/verify_resource_single_card.gd`(43항목: 카탈로그·수치·낱장 획득·소멸·판매 N장·건축·수리·주머니행·나무꾼 1개), `tools/pocket_check.gd`의 묶음 전제 항목을 낱장 규칙으로 갱신, `tools/verify_roster_jobs.gd`의 나무꾼 기대값 갱신(이 스크립트는 변경 전부터 `contract_director.YARD` 참조 오류로 실패한다).

## 8. 플레이테스트 확인 항목

- 2일차에 객실 증축(목재 3)을 할 수 있는가. 나무꾼 1명이면 1일차 저녁에 3장이 모여야 한다.
- 손패 8장 중 재화가 5칸을 넘는 시간이 하루 중 얼마나 되는가.
- 손패를 3장 흔드는 기믹을 넣었을 때 재화 손실이 "아깝지만 복구 가능" 수준인가.

## 9. 사용자 확인 질문 (한 묶음)

1. **목재 단가 기준**: 건축 최고 3장·수리 1장(+60) 안으로 갈지, 더 빡빡하게 건축 2장·수리 1장(+40)으로 갈지.
2. **용병 전달**: 손패 빈칸만큼만 건네고 나머지는 계속 들고 있게 할지(제안), 아니면 지금처럼 전부 넘기고 넘친 재화는 주머니로 보낼지.
3. **판매 가격**: 양털 6·고기 8·가죽 10으로 올릴지, 지금 가격(4·5·7)을 유지할지.
4. **손패 한도**: 8장 유지(제안)인지, 재화 압박을 감안해 10장으로 올릴지.

**사용자 답변(2026-10-18):**

1. 건축 3장·수리 1장(+60) — 채택.
2. **전부 넘기고 넘친 재화는 주머니로(현행 규칙 유지).** 대신 나무꾼이 목재를 1개만 들 수 있게 바꿔, 플레이어가 나무꾼을 목재 인벤토리로 쓰는 것을 막는다.
3. 양털 6·고기 8·가죽 10 — 채택.
4. 손패 한도 8장 유지 — 채택.
