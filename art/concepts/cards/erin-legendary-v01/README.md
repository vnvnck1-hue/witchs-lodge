# 에린 전설카드 프레임 시안 3종

사용자 승인: **3번 보랏빛 마법 금박**. 하단 설명을 제거한 [최종 게임 에셋](../../../cards/tavern-v05/README.md)을 별도로 납품했다. 아래 세 시안은 비교 이력으로 보존한다.

2026-10-20 · 내장 `image_gen` 이미지 편집으로 제작한 비교용 원화 시안.

프로젝트에서 별도로 승인된 전설카드 프레임은 찾지 못해, 기존 인물 역할 포맷과 사용자 승인 에린 v04를 바탕으로 전설 등급의 세 가지 표현을 탐색했다. 에린의 얼굴·앉은 자세·치마까지 보이는 구도와 확정된 제목·분류·설명을 공통으로 유지했다.

| 시안 | 파일 | 방향 |
| --- | --- | --- |
| 1 · 황금 문장 | `01-gold-crest.png` | 두꺼운 금속 황금 테두리, 호박색 보석, 왕관·월계 장식의 술잔 문장 |
| 2 · 호박빛 스테인드글라스 | `02-amber-glass.png` | 청동 테두리와 넓은 호박색·보라색 유리 조각, 따뜻한 내부 발광 |

각 파일은 독립된 세로 2:3 카드다. [비교판](comparison.png), [실제 프롬프트](prompts.json), [생성 경로·메타데이터](manifest.json). 사용한 두 기준 이미지는 `references/`에 보존했다.

공통 인쇄 문구:

```text
술 주정뱅이 에린
인물 · 주점 손님
술병 네 가지 가운데
세 병을 아무렇게나 꺼냅니다.
[가끔 술주정을 부립니다]
```

시안 파일을 프로젝트에 보관했으며 게임 자산·카탈로그·기존 승인 포맷은 이번 작업에서 수정하지 않았다. 비교판은 개별 카드의 비율을 유지해 나란히 배치한 검수용 합본이다.
