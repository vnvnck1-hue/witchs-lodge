## 모델링 참고

- 보스의 둥근 반점 배·푸른 눈·얼음 송곳니·남보라 관절·흰 갈기·봉인실 매듭·등의 얼음 결정 왕관을 유지한다.
- 보스 구조 의도는 보행 다리 8개(좌우 각각 4개)와 별도 송곳니 2개. 다리 가림이 있어 3D 제작 시 부착 위치와 개수를 직접 확인한다.
- 정면/후면/측면 크기를 맞추도록 요청하고 니벨라 측면, 바닥 부품 수평 투영을 추가 보정했다.
- 생성형 모델링 참고 원화이며 수학적으로 정합성이 검증된 정투영 도면은 아니다. 일부 프랍의 상면 노출, 뷰 사이 반점·파손·수정 위치, 측면 폭과 반복 무늬에 차이가 남는다. 3D 블록아웃에서 형태·스케일을 확정한다.
- 절벽·기둥·아치·석재는 각각 하나의 조립체를 회전한 의도이며, 각 뷰를 서로 다른 변형 프랍으로 해석하지 않는다.
- 바닥판은 평탄한 바닥을 구성하는 참고 모듈이며 원화 그대로 높은 단차를 연속 배치하라는 뜻은 아니다. 실제 두께와 연결부는 지형 구성에 맞춘다.
- 눈·서리·실은 재질과 별도 메시를 분리해 제작할 수 있다. 서리실은 얇은 면/띠 구조로 해석하며 회색 배경은 자산에 포함하지 않는다.
- 수치 치수와 최종 폴리곤 예산은 이번 요청 범위에서 확정하지 않았다.
