## 원본 대비 바뀐 화풍

- 브람 v02·니브 카드의 굵고 가늘어지는 짙은 먹선으로 얼굴·모자·양·목재의 실루엣과 겹침을 강화했다.
- 부드러운 피부 셰이딩을 분명한 2~3단 명암과 큰 색면으로 바꾸고, 보라 의상·가죽·목재에 안료와 인쇄물 같은 붓 질감을 더했다.
- 코·광대·눈썹을 형태로 드러내고 인물마다 표정을 달리했다. 은발과 큰 보라 모자, 보라 망토의 천 질감을 유지했다.
- 꽃·장신구·작은 반짝이를 줄였다. 얼굴·등불·찻잔·마법책처럼 장면을 설명하는 핵심 요소에 디테일을 모았다.
- 보라·인디고 그림자, 라벤더 설경, 크림 여백, 앰버 등불·창문, 제한된 청록을 유지했다. 목재·석재·직물·가죽·금속 중심의 중세 기반 판타지 생활감을 따랐다.
- 고블린은 올리브 피부·큰 뾰족 귀·붉은 두건과 스카프·금 귀걸이를 가진 니브로, 드워프는 대머리·회색 옆머리·두 갈래 두꺼운 회색 수염·가죽 작업복의 하랄드로 맞췄다. 01 인간 여행자는 브람의 얼굴 인상과 녹색 망토를 반영했다.

## 검수와 후처리

비교 시트를 직접 열어 원본과 대조했다. 01의 전경 마녀와 양, 상단 세 마녀와 숲 얼굴, 산장·계단·여행자 덩어리, 오른쪽 제목·메뉴·나가기의 배치를 확인했다. 02의 창틀, 창가 마녀와 양·책, 하단 손님과 탁자, 중경 두 마녀와 위층 마녀, 왼쪽 제목·메뉴·나가기의 배치를 확인했다. 얼굴과 복식의 정체성을 수정한 범위에서 세부 윤곽은 다시 그렸으며 주요 덩어리의 위치·크기 비율을 유지했다.

두 장 모두 `마녀산장`, `이어하기`, `새로운 이야기`, `기록 보관소`, `설정`, `나가기`의 한글 표기가 정상이며 추가 UI 문구가 없다. 01의 초승달·붓 밑줄, 02의 마름모 선택 표시·제목 아래 가는 선과 초승달을 유지했다. 한글을 별도 글꼴로 다시 얹지 않았다.

생성 원본은 각각 1672×941이며 `drafts/`에 그대로 보존했다. 최종본은 고품질 bicubic으로 전체 화면을 1920×1080에 맞췄다. 자르기나 개별 요소 재배치는 없고, 원본 비율과 16:9의 차이는 약 0.053%다. 비교 시트의 원본도 같은 1920×1080 영역에 맞췄다.

이번 변경은 이 폴더와 지정 요청 문서 끝의 납품 절에 한정했다. `godot/**`, 루트 실행파일, 다른 `docs/` 문서, `reference-composition-v01/` 원본은 수정하지 않았으며 Godot 임포트·내보내기와 커밋을 하지 않았다. 기존 작업 트리의 다른 변경은 그대로 두었다.
