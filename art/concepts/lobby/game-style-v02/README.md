## v01 대비 바꾼 색

- 불 마녀의 강한 주황 불꽃 → 부드러운 앰버와 크림빛 중심. 불의 실루엣과 따뜻한 발광은 유지했다.
- 선명한 구리색 머리·노란 의상 → 차분한 오번/구리·오커. 얼굴의 온기는 별도로 보호했다.
- 강한 노랑 창문·등불·벽/목재의 주황 반사광 → 밝은 꿀빛 앰버와 브론즈. 01의 왼쪽 등불/산장 입구, 02의 탁자 등불/솥 불꽃이 따뜻한 주요 초점으로 남는다.
- 원색 보라 모자·망토 → 자두와 잉크 바이올렛. 검은 선과 보라색 정체성을 유지했다.
- 선명한 청록과 그림자의 초록·붉은 잡색 → 블루 틸·인디고/자두 그림자 쪽으로 묶었다.
- 고블린의 빨강 → 버건디 방향으로 정리하고 올리브 피부는 약하게만 조정했다.
- 강한 보라 구름 얼룩 → 잉크 바이올렛 계열로 완화했다. 설경의 밝은 라벤더/페리윙클, 따뜻한 크림 여백은 깨끗하게 남겼다.

중세 기반 판타지의 생활감, 목재·직물·가죽·금속·등불의 소재와 모든 기존 소품을 유지했다.

## 그림과 UI 보존 검수

최종 두 장과 비교 시트를 직접 열어, 불꽃·창문·보라 의상이 진정되면서 색과 명암이 남는지 대조했다. 원본 해상도에서 픽셀별 색만 바꿨으므로 인물·건물·소품의 재배치, 얼굴 재생성, 자르기와 리샘플링이 없다.

원본의 HSL 밝기 L을 보존했으며 8비트 반올림 최대 차이는 1/510이다. 가장 짙은 먹선과 밝은 크림 보호 픽셀은 RGB까지 원본과 같다. 제목·메뉴·나가기와 주변 선택 장식도 원본을 그대로 유지해 보호 영역 RGB 불일치가 두 장 모두 0이다. `마녀산장 / 이어하기 / 새로운 이야기 / 기록 보관소 / 설정 / 나가기`를 재식자하지 않았고 추가 문구가 없다.

생성 결과는 배색 검토 자료이며 최종 PNG와 구분해 drafts에 보존했다. [픽셀 검수](drafts/pixel-qa.json)와 [재현 스크립트](drafts/prepare-assets.ps1)를 함께 제공한다.

이번 납품은 시안 제작 범위다. `godot/**`, 루트 실행파일, 다른 docs 문서, reference-composition-v01 및 game-style-v01은 수정하지 않았다. Godot 실행·임포트·내보내기와 커밋을 하지 않았으며 기존 작업 트리 변경도 보존했다.

작업 전후 8,378개 보호 파일의 경로·크기·수정 시각을 비교했다. 작업 중 다른 작업에서 `catalog.json`, `catalog_en.json`, `en.json`, `tavern_cards.gd`, `tavern_check.gd`, `docs/tavern-cards-v01.md`가 변경된 것을 감지했으며 그대로 보존했다. 이 작업은 해당 파일에 쓰지 않았다. v01 PNG의 작업 전후 SHA-256 불일치는 0이다. 상세 경로는 manifest에 구분해 기록했다.
