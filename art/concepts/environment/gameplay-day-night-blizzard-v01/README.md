# 실제 게임 캡처 기반 낮·밤 콘셉트 원화

제작일: 2026-10-17. 사용자 요청에 따라 현재 Godot 소스의 실제 낮·밤 렌더를 캡처하고, 내장 `image_gen`의 실제 이미지 참고 입력으로 사용했다. 블리자드·워크래프트·하스스톤풍의 큼직한 실루엣과 페인터리 표현을 탐색한 환경 시안이다. 중세 기반 판타지이며 중세의 생활감과 분위기를 유지하면서 판타지적 각색을 허용한다.

## 제작·검수

- 프로젝트에 포함된 Godot 4.7.2, Vulkan Forward+ 및 실제 GPU 렌더를 사용했다. 기본 `toon_midnight` 화면 스타일, `lens_wide` 카메라와 실제 현재 소스 자산을 사용했다. 낮·밤 원본은 같은 카메라와 정지한 배우 상태에서 시간대 조명만 바꿨다. 원화 입력에서는 CanvasLayer를 숨겼다.
- 낮은 `DayCycle`의 `day`, 밤은 실제 밤 웨이브 시작과 `night` 조명을 사용했다. 최종 원화는 UI 없는 환경 콘셉트이며 손패/카드 포맷 신규 제작이 아니다.
- 낮 캡처를 실제 참고 입력으로 첫 원화를 생성하고, 밤 캡처와 완성한 낮 원화를 함께 실제 참고 입력으로 넣어 밤을 제작했다. 낮은 밝은 설경과 금빛 목재, 밤은 청보라 달빛과 앰버 산장 조명을 강조했다.
- 두 원화에서 높은 게임 시점, 작은 박공지붕 산장과 굴뚝, 오른쪽 목장·양 세 마리·통·열린 문, 보라색 SD 마녀와 징검돌, 두 갈래 접근로를 시각 검수했다. 생성형 페인트오버이므로 주변 수목·눈·돌의 세부 형태와 상대 위치에는 해석 차이가 있다.
- 생성 원본을 리사이즈하지 않고 그대로 복사했다. 원본·프로젝트 복사본 SHA-256 일치와 PNG 치수를 확인했다.
- HUD 포함 캡처도 별도 기록했다. 시작 카드 이동 연출과 숨김 레이어가 방해하지 않게 정리한 추가 실행의 HUD 기록이며 원화 생성 입력에는 사용하지 않았다.
- 기존 게임 코드·런타임 자산·승인 아트 기준은 교체하지 않았다. 이번 결과의 사용자 승인과 게임 적용은 별도다.

캡처 실행 로그에는 제한된 환경의 사용자 로그 경로·인증서 저장소 경고와 종료 시 객체 누수 경고가 남았다. 4개 렌더 저장 완료 및 파서·셰이더 오류 없음은 확인했다. 게임 기능 전체에 대한 테스트를 의미하지 않는다.
