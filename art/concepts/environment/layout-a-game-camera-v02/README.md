## 실제 참고한 카메라

현재 프로젝트의 `camera_style.gd`, `player_camera.gd`, `project.godot`를 읽고, 현재 소스를 Godot 4.7.2 Forward+ 실제 렌더러로 실행하여 새로 캡처했다. 기본 플레이어 추적 상태이며 카메라 줌·포즈·프리셋은 덮어쓰지 않았다. 비교를 위해 낮 조명과 UI 숨김만 지정했다.

- 투영: 원근, 기본 프리셋 `lens_wide`
- FOV: 34°
- 하향각: 약 50°, 회전 Y: 약 35°
- 추적 화면 높이: 18
- 실제 캡처 화면: 1600×800, 게임 기본 창과 같은 2:1
- 카메라 위치: 약 (15.1209, 22.5506, 20.2257)

캡처 도구는 [capture_camera.gd](../../../../output/layout-a-camera-v02/capture_camera.gd)에 보존했다. 숨긴 캡처 창의 프레임 진행 대기 문제가 있어 최종 도구는 초기화 후 명시적인 실제 렌더 호출로 이미지를 저장했다. 사용자 로그 경로·인증서 저장소 경고는 해당 실행 로그에 남는다. 새 캡처 PNG와 닫힌 JSON 메타데이터 파일을 직접 읽어 결과를 확인했다.

## 보정 내용과 확인 범위

- 기존 A의 대칭에 가까운 중앙 쉼터 구조는 유지했다. 산장 왼쪽 증축 여유, 오른쪽 양 목장, 중앙 모닥불과 일꾼 2명, 감시탑 사각 공터 2곳, 왼쪽 아래 원형 제단 공터 1곳, 좌우 웨이브 진입로와 후면 바위·식생 띠를 최종 PNG에서 시각 확인했다.
- 원화용으로 크게 배치된 산장·인물의 화면 크기를 줄이고, 지붕과 공터 윗면이 더 보이도록 보정했다. 넓은 2:1 화면과 실제 캡처의 원근감을 제작 기준으로 사용했다.
- 사용자가 좋다고 한 부드러운 색과 옛날 워크래프트·LoL풍 형태를 유지했다. 중세 기반 판타지의 생활 재료와 분위기를 유지하며 판타지적 과장을 허용했다.
- 첫 보정과 카메라 연구 시안은 `drafts/`에 보존했다. 카메라 연구 시안은 세부 재질·산장 형태가 달라지고 마녀가 누락되어 최종으로 택하지 않았다. 최종은 첫 보정의 화풍과 시설 구성을 유지하면서 실제 캡처를 다시 참고한 추가 보정이다.
- 최종 생성 원본과 프로젝트 복사본의 SHA-256 일치, PNG 치수를 확인했다.

**정확도 구분:** 이 PNG는 실제 캡처를 이미지 입력으로 사용한 생성형 원화다. 렌즈 수치로 재투영한 A 배치의 실제 3D 렌더나 픽셀 정합 결과는 아니며, 카메라·물체 형태에 해석 차이가 남을 수 있다. 게임 소스·런타임 카메라·배치·충돌·내비메시는 변경하지 않았다. A안의 실제 게임 배치 구현과 경로 검증은 별도 작업이다.
