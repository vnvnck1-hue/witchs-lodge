2026-10-17. 사용자가 좋다고 평가한 [v03의 부드러운 톤](../gameplay-warcraft-lol-v03-soft/01-day-concept.png)을 실제 이미지 참고 입력으로 사용했다. 내장 `image_gen`으로 배치를 새로 설계한 환경 콘셉트 원화 두 장을 제작했다. 중세 기반 판타지의 생활감과 재료를 유지하면서 옛날 워크래프트·LoL풍의 과장된 형태를 이어간다.

두 안의 차이가 배치에서 읽히도록 같은 부드러운 겨울 낮 조명을 사용했다. 모닥불은 밤에 나무꾼·채집가가 모여 쉬는 시설의 위치를 나타내며, 두 인물·통나무 의자·도끼·바구니로 용도를 표현했다. 이번 산출물은 비교 원화이며 게임 소스·지형·충돌·내비메시는 수정하지 않았다.

## 그림을 읽는 기준

네 모서리에 작은 돌을 둔 **사각 흙 공터 두 곳**이 감시탑 건설 자리다. 낮은 돌을 두른 **원형 공터 한 곳**은 제단 자리다. 건물 벽에 직접 붙은 **아무 시설도 없는 넓은 눈밭**은 산장 증축용이다. 해당 공터에 감시탑·제단·증축 건물을 미리 세우지 않았다.

A는 중앙 모닥불과 좌우 길·감시탑을 한 화면에서 파악하기 쉬운 배치다. B는 생활 쉼터를 웨이브 주동선의 안쪽으로 넣고 현관과 짧게 연결한 비대칭 배치다. 두 안 모두 증축 공터와 문 앞 이동 공간을 분리하고, 모닥불·의자·공터 한가운데로 웨이브 길을 통과시키지 않았다.

## 요구사항별 시각 검수

최종 PNG 두 장을 직접 열어 아래 항목을 각각 확인했다. 이는 원화의 공간 표현 검수이며 런타임 경로·충돌 검증을 뜻하지 않는다.

- 사용자 지정의 부드러운 톤과 중세 판타지 재료, 높은 게임 시점: 두 장에서 확인.
- 산장 뒤쪽 이동을 막는 자연스러운 바위·식생 둘레: A의 후면 바위·수목 띠, B의 후면~증축 공터 뒷경계 연결 띠에서 확인. B 초안의 우회 가능해 보이는 틈은 추가 편집으로 보강.
- 나무꾼·채집가가 쉬는 모닥불 1곳: 각 그림에 불 1개, 쉬는 인물 2명과 의자·도끼·바구니가 보임.
- 모닥불 주변 감시탑 건설 공터 정확히 2곳: 두 장 모두 사각 흙 공터 2개와 낮은 모서리 돌로 확인.
- 산장 기준 좌·우로 뻗는 몬스터 진입로: 두 장 모두 양쪽 화면 경계에서 전면으로 들어오는 흙·눈 길이 이어짐.
- 제단 건설 공터 정확히 1곳: A 왼쪽 아래, B 오른쪽 아래 원형 빈 공터에서 확인.
- 산장 주변 증축 여유: A 왼편, B 오른편에 건물 벽과 이어진 넓고 평평한 빈 공간을 확인.
- 전반적 지형·이동 공간 재정비와 2개 대안: 기존 시안의 중앙 관목 띠를 걷어내고 현관~시설 사이를 넓게 연결했으며, 두 안의 산장·쉼터·목장·증축·제단 위치가 다름.
- PNG 복사본: 치수, 파일 크기, 원본과 SHA-256 일치를 확인. 정확한 크기는 [manifest.json](manifest.json)에 기록.

[실제 생성·수정 프롬프트](prompts.md). B 초안은 [drafts/02-side-camp-initial.png](drafts/02-side-camp-initial.png)에 이력으로 보존했다. 최종 B는 후면 경계를 보강한 파일이다.
