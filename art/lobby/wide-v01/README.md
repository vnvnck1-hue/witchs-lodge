# 로비 레이어 왼쪽 확장 v01

2026-10-24. [작업 요청](../../../docs/handoff/codex-lobby-wide-v01.md)에 따른 넓은 화면용 에셋 납품이다.

## 최종 파일

| 파일 | 규격 | 내용 |
| --- | --- | --- |
| [lobby_bg_wide.png](../../../godot/assets/ui/lobby/lobby_bg_wide.png) | 2640×1080 RGB | 인물 없는 겨울 숲·안개를 왼쪽으로 확장한 배경판 |
| [lobby_characters_wide.png](../../../godot/assets/ui/lobby/lobby_characters_wide.png) | 2640×1080 RGBA | 인간 털 망토·초록 천·가죽끈, 드워프 어깨 갑옷·털과 요정 날개 끝의 연장 |
| [lobby_character_ids_wide.png](../../../godot/assets/ui/lobby/lobby_character_ids_wide.png) | 2640×1080 RGB | 원본 구역 지도를 보존하고 확장부를 같은 정수값으로 연결 |

세 파일 모두 현재 원본 1920×1080을 **(720,0)에 픽셀 그대로** 붙였다. 원본 영역의 크기·색·알파·숨은 RGB를 바꾸지 않는다. 확장부만 새로 제작했으며 새 얼굴·인물·현대 소품을 추가하지 않았다. 중세 기반 판타지, 원화의 굵은 먹선·큰 색면·인쇄 질감과 라벤더·인디고 계열을 따른다. 맨 왼쪽은 자두·남색 그림자로 살짝 낮췄다.

인물은 생성된 투명 실루엣을 유지한다. 불투명 의복 내부에 생성 도구가 남긴 alpha 250~253은 255로 복원하고 경계의 부분 알파와 바깥 alpha 0을 유지했다. 새 영역에서 alpha 0의 RGB도 0이다. 배경판은 인물 뒤를 모두 채워 작은 이동으로 빈 구멍이 드러나지 않는다.

확장부 구역 값은 **20(인간 망토 및 가장 가까운 얼굴 없는 털·천), 160(드워프), 220(요정 날개 끝)**이다. R=G=B, 경계에 보간값은 없다. 인물 alpha 0과 ID 0이 정확히 대응한다. 구역 지도는 게임 담당자가 최근접 샘플링으로 사용한다.

## 좌표와 화면 비율

합성 순서는 배경 → 인물 → 기존 타이틀·메뉴다. 기존 1920×1080 타이틀·메뉴 레이어만 x+720으로 옮겨 얹으며, 새 글자를 생성하거나 기존 글자를 고치지 않는다. 게임 코드 적용은 이번 납품에 포함되지 않는다.

높이를 1080으로 유지하고 오른쪽 기준으로 자를 때:

| 화면 | 넓은 원화에서 보이는 영역 |
| --- | --- |
| 16:9 | x=720~2639, 1920×1080 |
| 통상 21:9인 2560×1080 | x=80~2639, 2560×1080 |
| 3440×1440 | x=60~2639, 2580×1080을 균등 확대 |

어느 경우에도 위아래를 자르지 않는다.

## 검수와 재현

- [sheet.png](sheet.png): 5280×2248. 전체 재합성, x=600~840 이음매 2배(상·하를 나란히 분할), 오른쪽 기준 21:9 화면, ID 50% 겹침의 네 칸. 전체·21:9·지도는 원본 해상도다.
- [verification.json](verification.json): 저장된 PNG를 다시 읽은 독립 검사 **34/34 통과**. 세 파일 각각 기존 영역 **2,073,600픽셀**, **차이 0픽셀**, **최대 채널 차이 0**. 크기·모드·원본 파일 해시·ID 값·알파 대응·화면 비율도 확인한다.
- [prompts.md](prompts.md): 내장 image_gen 편집 **3회**의 실제 입력 프롬프트와 파일, 결정적 후처리 설명. CLI/API 대체 생성은 사용하지 않았다.
- [drafts/build_wide.py](drafts/build_wide.py), [drafts/verify_wide.py](drafts/verify_wide.py): 재현과 독립 검증. Python 3, Pillow, NumPy가 필요하며 Godot를 시작하지 않는다. 명령은 prompts.md에 있다.
- [drafts/](drafts/): 생성 원본, 편집 입력, 원본 레이어 픽셀 스냅샷, 경계 등록 값, ID 윤곽, 체크무늬 위 인물, 두 화면 비율의 원본 크기 합성, 이음매 2배, 인물 (-6,-4) 이동 그림을 보관한다. 초안의 큰 추가 날개는 검수 중 발견해 제거했고 최종본은 원래 날개의 작은 끝만 잇는다.

최종 합성·이음매·21:9·3440:1440 상당 크롭·구역 겹침·투명 경계·배경 단독·이동 결과를 열어 검수했다. 새 얼굴과 식별 가능한 새 인물이 없는지, 천·털·갑옷이 원래 인물에 이어지는지 확인했다.

## 쓰기 범위와 병행 변경 관측

직접 쓰기는 지정 세 `_wide.png`, 본 폴더와 요청 문서 끝의 납품 절에 한정한다. 기존 로비 PNG, 게임 코드·씬·셰이더·도구·다른 자산·다른 문서·실행파일에는 쓰지 않았다. 커밋·Godot 실행·임포트 명령·내보내기도 수행하지 않았다.

[drafts/protected-before.json](drafts/protected-before.json)과 [drafts/protected-verification.json](drafts/protected-verification.json)은 보호 파일 8,788개의 크기·수정 시각과 로비 원본·문서·실행파일의 해시를 대조한 기록이다. **작업 공간 전체가 변하지 않았다는 의미는 아니다.** 첫 대조에서 별도 코드·도구·문서·실행파일 변경과 새 파일이 관측됐다. 기존 로비 PNG의 내용 해시는 그대로다. 새 `_wide.png.import` 및 Godot 임포트 캐시도 관측했으나 이 작업은 생성 명령을 실행하거나 이를 편집·삭제하지 않았다. 자동 감시 프로세스가 만들었을 가능성이 있으며 정확한 외부 실행 주체는 확인하지 않았다. 경로별 관측값을 그대로 남겼다.

요청 문서의 작업 전 바이트는 `drafts/handoff-original.bin`으로 보관하며 납품 후에도 그대로 접두부로 남는지 검사한다. 게임 적용·임포트·루트 실행파일 갱신은 요청서의 역할 분담에 따라 구현 담당자의 작업이다.
