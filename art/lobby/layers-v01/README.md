# 로비 레이어 v01 · 납품

2026-10-24. [작업 요청](../../../docs/handoff/codex-lobby-layers-v01.md)에 따른 승인 원화의 게임용 레이어 분리다. 최종 파일은 [godot/assets/ui/lobby/](../../../godot/assets/ui/lobby/)에 있다.

## 파일과 좌표

게임용 PNG 11개는 모두 **1920×1080, 원화와 같은 좌표**다. 배경판과 구역 지도는 RGB, 인물·타이틀·메뉴 9개는 RGBA straight alpha다. 투명 바깥의 알파와 RGB는 0이며, 조각을 bbox로 잘라 저장하지 않았다.

| 파일 | 내용 |
| --- | --- |
| `lobby_bg.png` | 인물·글자·장식을 제거하고 가려졌던 숲을 복원한 배경판 |
| `lobby_characters.png` | 원화에서 추출한 일곱 인물 덩어리 |
| `lobby_character_ids.png` | 셰이더용 평면 회색 구역 지도 |
| `lobby_title.png` | 「마녀산장」·상단 달·지붕·덩굴 장식 |
| `lobby_menu_continue.png` | 「이어하기」 |
| `lobby_menu_new.png` | 「새로운 이야기」 |
| `lobby_menu_archive.png` | 「기록 보관소」 |
| `lobby_menu_settings.png` | 「설정」 |
| `lobby_menu_exit.png` | 「나가기」 |
| `lobby_menu_moon.png` | 이어하기 왼쪽 금색 달 |
| `lobby_menu_underline.png` | 이어하기 아래 붓 밑줄 |
| `lobby_layout.json` | `layers[파일명]`의 실제 알파 영역 bbox `{x,y,w,h}` |

합성은 배경 → 인물 → 타이틀 → 이어하기 → 새로운 이야기 → 기록 보관소 → 설정 → 나가기 → 메뉴 달 → 밑줄 순서다. 원본 크기에서 좌상단을 모두 `(0,0)`에 맞춰 일반 알파 합성한다. bbox는 클릭 영역·앵커를 계산하기 위한 값이며, 이미지의 표시 위치를 bbox로 옮기는 값이 아니다.

## 구역 지도

R=G=B이며 중간 보간값을 넣지 않았다. 값 0은 인물 알파 0과 정확히 대응한다. 지도는 게임 적용 시 최근접 샘플링으로 읽고 R값을 0–255 정수 기준으로 해석해야 한다.

| 값 | 인물·부위 |
| --- | --- |
| 20 | 인간 남자 |
| 40 | 늑대 수인 |
| 60 | 오크 |
| 80 | 요정 몸·얼굴·머리·망토 |
| 100 | 마녀 몸·얼굴·머리·귀걸이 |
| 120 | 마녀 모자·잎 장식 |
| 160 | 드워프 |
| 180 | 고블린 몸·머리·목도리·가방 |
| 200 | 고블린 큰 귀·귀걸이 |
| 220 | 요정 날개 |
| 240 | 요정 더듬이 |

늑대 귀는 화면 위로 잘려 있으므로 선택 값 140을 사용하지 않았다. 겹친 곳은 보이는 앞쪽 인물·부위를 따른다. [50% 구역 겹침 그림](ids-overlay.png)으로 배치를 확인할 수 있다.

## 원화 보존과 배경 복원

인물과 글자는 새로 그리지 않고 승인 원화에서 추출했다. 불투명 픽셀의 RGB는 원본 그대로이며, 반투명 가장자리는 크림·라벤더 배경을 빼서 색을 복원했다. 복원 숲은 내장 image_gen 편집 결과를 사용하고, 원경의 중세 목조 산장·설경·하늘은 허락된 수정 영역 밖에서 원본 픽셀을 유지한다. 크림 상자의 경계는 불규칙하고 넓게 풀어 주변 대기에 연결한다.

## 검수와 재현

- [여섯 칸 검수 시트](sheet.png): 원화, 재합성, 배경판, 체크무늬 위 인물, 체크무늬 위 UI, 인물 `(-6,-4)` 이동 결과. 5760×2256이며 각 그림은 원본 해상도다.
- [verification.json](verification.json): 원본 해시, 모든 파일의 크기·모드·해시, 재합성 수치, 제외 영역, 저장 파일 독립 검증과 보호 경로 관측 결과.
- [prompts.md](prompts.md): 실제 내장 image_gen 프롬프트, 입력·출력, 처리 방식과 재현 명령.
- [drafts/build_layers.py](drafts/build_layers.py), [drafts/verify_delivery.py](drafts/verify_delivery.py): 생성본에서 최종 레이어 재현 및 별도 검증. Godot 실행이 필요 없다.

재합성 비교에서 제외하는 곳은 요청서의 크림 상자 경계 ±120px 띠뿐이다. 정확한 합집합은 `(1140,50,241,800)`과 `(1140,50,780,241)`이며 `x,y,w,h` 형식이다. [실제 제외 마스크](drafts/verification-exclusion-mask.png)를 제공한다. 그 밖의 영역에 요청서의 ‘대부분 채널 차이 2 이하, 최대 채널 차이 8 초과 픽셀 0.5% 미만’ 기준을 적용한다. 완전한 0 오차라고 표현하지 않고 측정값을 기록한다.

`drafts/`에는 생성 원본, 실루엣·종이 경계 마스크, 좌표 앵커, 최신 재합성·이동 그림, 초기 확대 검수 이력도 남겼다. 최종 판단은 루트의 `sheet.png`, `ids-overlay.png`, `verification.json`과 게임용 파일을 기준으로 한다.

## 작업 범위

새 파일은 `godot/assets/ui/lobby/`와 `art/lobby/layers-v01/`에만 만들고 요청 문서 끝에 납품 절만 추가했다. 기존 원화, 게임 코드·씬·셰이더·도구·다른 자산·실행파일·다른 문서에 쓰지 않는다. 기존 변경사항을 되돌리거나 커밋하지 않는다. 이번 요청서의 역할 분담에 따라 `.import` 생성과 실행파일 내보내기는 Claude에게 남긴다.


## 납품 검증 수치 · 2026-10-24

독립 검사 42/42 통과. 허용 경계 띠 밖에서 채널 차이 2 이하 97.767435%, 8 초과 0.428694%로 기준을 통과했다. 배경 생성은 내장 image_gen 편집 1회이며 실제 프롬프트는 `prompts.md`에 있다.
