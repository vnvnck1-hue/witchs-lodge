# 그라즈 메달 전용 컷아웃 v01

2026-10-23 · [작업 요청](../../../docs/handoff/codex-speech-medal-portrait-graz-v01.md)

시안에 보이는 그라즈의 실제 픽셀을 보존하고, 원형 틀에 가려진 팔·어깨·상반신을 내장 image_gen 생성 결과로 보완했다. 기존 초상의 비율을 바꾸어 대체하지 않았다. 중세 기반 판타지의 냄비 투구·단검·가죽/직물 의복과 검은 먹선·큰 명암 색면을 유지한다.

## 채택 과정과 검수

1. 첫 생성은 기존 초상의 긴 칼·얼굴 비율을 따라가서 버렸다.
2. 시안만 입력한 두 번째 생성은 더 가까워졌지만 얼굴·귀 길이가 달라졌다. 생성본 전체를 최종으로 쓰지 않고 가려졌던 몸통 보완에 사용했다.
3. 시안의 얼굴·투구·칼·귀·표정·목도리를 윤곽 마스크로 분리해 실제 픽셀을 유지했다. 원형 틀·말풍선·숲 배경을 제외했고, 손잡이와 귀걸이의 내부도 투명하게 정리했다. 생성 몸통은 원형 틀 안쪽에 가려질 경계에서 연결했다.
4. 투구 외곽의 알파 절단을 복원하고 목 옆 배경 잔여를 제거했다. 밝은/어두운 배경에서 가장자리와 내부 구멍을 확인했다.

최종 알파 영역의 경계는 **x [115, 1007), y [112, 1245)**다. 상단 여백 **112px = 7.99%**, 가로 중심 **561px**로 캔버스 중심과 일치한다. 캔버스 사방 끝의 알파 최댓값은 **0**이다. 최종본에는 틀·글자·배경·드롭섀도가 없다. 체크무늬는 검수 시트에만 그렸다.

시안의 칼끝과 투구 손잡이 꼭대기가 거의 같은 높이에 놓이는 관계, 큰 투구, 귀 길이와 목도리 구도를 유지했다. 얼굴 영역(시안 x 338~426, y 158~264)의 합성 대조 평균 RGB 절대 오차는 **1.79/255**다. 이는 보존 픽셀을 두 번 리사이즈하면서 생긴 오차이며, 생성 유사도 점수나 전체 이미지의 동일성 주장이 아니다. 지정 프레임은 원래 시안 프레임과 별도 에셋이므로 그 차이는 시트에 그대로 드러난다.

**용도상의 한계:** 시안 원본은 작은 UI 그림이다. 보이는 부분의 정확한 비율·표정을 우선하여 원본 디테일을 보존했으므로 전체를 확대하면 상단이 새로 보완한 하단보다 부드럽게 보인다. 메달 전용 에셋이며, 기존 도착 소개·관리창용 고해상도 초상은 그대로 사용한다.

## 합성 배치 정보

시안 3배 발췌 좌표 `(u, v)`에서 최종 컷아웃 좌표 `(x, y)`로의 변환:

```text
x = 2.25 × u - 178.375
y = 2.25 × v + 47.75
```

검수 시트 합성은 이 변환을 되돌려 시안과 같은 좌표에 놓는다:

```text
u = x / 2.25 + 79.2777777778
v = y / 2.25 - 21.2222222222
```

원 중심 `(342, 223)`, 지정 `medal_frame.png`의 바깥 지름 450px, 안쪽 마스크 반지름 185px. 인물 하단은 원 안쪽에, 상단은 틀 위에 그린다. **검수용 합성이며 현재 게임 스크립트의 자동 배치 결과를 캡처한 것은 아니다.** 실제 연결·임포트·배치는 구현 담당이 한다.

프로젝트 루트에서 Windows PowerShell로 아래 명령을 실행하면 보관된 원본으로 시트와 최종 PNG를 재구성한다. 실행 정책은 이 프로세스에만 적용된다.

```powershell
& 'C:/Windows/System32/WindowsPowerShell/v1.0/powershell.exe' -NoProfile -ExecutionPolicy Bypass -File 'art/portraits/graz-medal-v01/build-sheet.ps1' -Install
```
