# 사용자 제작 산장 적용

2026-10-15. 사용자 제공 `medieval+cottage+3d+model.glb`를 기존 게임 산장에 적용했다.

원본은 노드 하나·메시 하나에 서로 떨어진 집 세 개가 들어 있었다. X 좌표의 빈 공간(-0.17 / 0.16)을 기준으로 삼각형을 세 그룹으로 분리했다. 경계를 가로지르는 삼각형이 없음을 확인했으며, 정점·법선·UV와 내장 JPEG 텍스처를 그대로 보존했다. 모델을 새로 생성하거나 리토폴로지하지 않았다.

- `original-three-cottages.glb`: 원본의 보존 사본. 다운로드 폴더의 원본도 그대로 유지한다.
- `candidate-left.glb`: 현관·계단·벽등이 있는 왼쪽 집. **이 모델을 선택했다.** 3,157 삼각형.
- `candidate-middle.glb`, `candidate-right.glb`: 분리 보관한 나머지 두 집. 게임에는 표시하지 않는다.
- 실제 게임 리소스: `../../../godot/assets/cottage/user_cottage.glb`.

선택 모델의 바닥 중앙을 원점으로 옮기고 17배 등방 스케일과 Z +0.35m 오프셋을 적용했다. 전체 크기는 약 5.22 × 5.26 × 5.01m. 현관은 기존 +Z 방향이다. 기존 산장의 클릭·충돌·체력·수리·증축·방문객 경로 래퍼를 사용한다.

`godot/scripts/visual/user_cottage.gd`에서 배치와 창문·벽등의 따뜻한 조명을 연결한다. 원래 텍스처를 그대로 샘플링하는 전용 셰이더로 기존 안개와 피격 점멸에 대응한다. 굴뚝 연기·불씨는 새 굴뚝 입구 좌표 (1.20, 5.23, 1.28)m로 옮겼다. 이전 산장 에셋과 구현도 보존되어 있다.

검수 이미지와 실행 결과는 `../../../output/user-cottage/`에 저장한다. `godot/tools/verify_user_cottage.gd`가 선택한 한 모델만 표시되는지, 텍스처·연기 위치·클릭 대상·피격·수리·입구까지 실제 이동·증축을 검사하고 낮/밤 화면을 캡처한다.
