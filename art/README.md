# 전체 이미지 갤러리

19장의 PNG를 원본 해상도로 보존했다. 각 이미지 제목을 누르면 원본을 열 수 있다. 최신 게임 방향은 **로우폴리 환경 + 2~3등신 SD 캐릭터**다.

## 최신 게임 컨셉 · 4장

### 01. 여행자의 방문

![여행자의 방문](concepts/gameplay/01-travelers-arrival.png)

마녀가 배낭과 짐을 가진 여행자들을 맞이한다.

### 02. 산장 증축

![산장 증축](concepts/gameplay/02-lodge-expansion.png)

작은 본채에 객실이 붙고 다른 공간은 공사 중이다.

### 03. 숲의 괴물

![숲의 괴물](concepts/gameplay/03-forest-encounter.png)

숲에서 괴물이 나타나 마녀와 여행자가 대응한다.

### 04. 골드 공물과 지붕 위 용

![용의 방어](concepts/gameplay/04-dragon-gold-defense.png)

모아둔 골드를 바친 마녀가 거대한 용을 소환한다. 용은 지붕 위에서 독립된 불덩이를 한 발씩 쏘아 몰려온 괴물을 휩쓴다.
