# 손패 소품 위계·배치 비교 시안 v02

2026-10-18 · 사용자 수정 요청에 따라 내장 image_gen으로 제작한 두 가지 배치 시안. 실제 게임 소스·배포 실행파일은 이번 비교 제작에서 변경하지 않았다.

공통: 카드 아래 청록·보라 장식 받침 전체 제거. 카드의 따뜻하고 밝은 크림 패널·선명한 원화를 시각적 중심으로 삼고, 소품은 저채도 회청·회보라, 낮은 밝기와 대비, 억제한 금속 반사로 눌렀다. 중세 판타지 생활 소품과 기존 먹선 화풍을 유지한다.

- [A · 낮은 좌우 배치](01-low-flanking.png): 소품을 카드 높이의 절반 정도로 축소하고 양옆 아래에 배치. 카드와 간격을 둔 여유 있는 구성. 실제 프롬프트: [prompt-a.md](prompt-a.md).
- [B · 카드 뒤로 모은 배치](02-tucked-behind.png): 카드 부채꼴을 중심으로 소품을 가장자리 뒤에 일부 숨긴 조밀한 구성. 실제 프롬프트: [prompt-b.md](prompt-b.md).

참고 입력: 기존 실제 게임 캡처 `output/hand-workbench-v01/01-hand-three.png`, 사용자가 받침 삭제 위치를 표시한 첨부 이미지. 빨간 표시는 삭제 대상 위치 참고로만 사용했다.

이미지 생성 과정에서 카드 안의 문구·세부 원화가 재해석된 부분이 있다. 이 이미지는 소품의 시각적 위계와 카드 주변 레이아웃을 검토하는 비교 시안이며, 새로운 카드·게임 규칙·정식 카드 원화를 승인하거나 교체하는 자료가 아니다. 실제 적용 시 기존 카드 원본과 확정 문구를 그대로 사용한다.
