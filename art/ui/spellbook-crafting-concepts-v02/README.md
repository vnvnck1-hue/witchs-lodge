## v01에서 뺀 것과 단순화한 것

- 책 가죽의 촘촘한 결·주름·스티치, 금속 리벳·음각을 없앴다. 큰 보라 면과 넓은 금속 모서리, 적은 명암 면으로 형태를 읽게 했다.
- 양피지의 미세 얼룩·찢김·반점과 페이지 전역의 꽃·넝쿨 테두리를 없앴다. 책 안의 넓은 크림색 여백을 비웠다. 04의 전달 책장만 장면상 필요한 찢어진 외곽을 남겼다.
- 작은 별·점 흩뿌리기와 복잡한 룬·달 문양 마법진을 없앴다. 슬롯은 굵은 원 하나와 중앙의 작은 표식, 결과는 단순한 원 두 겹과 약한 보라 빛으로 정리했다.
- 책상 소품은 **왼쪽 촛불 하나 + 오른쪽 재료 주머니 하나**다. 깃펜·잉크병·꽃·주변 잎 덤불·책 더미를 없앴다. 책에 붙은 보라 리본 책갈피는 유지했다.
- 촛대·주머니는 넓은 면으로 정리하고, 책상 나뭇결을 큰 갈색 덩어리로 줄였다. 소품을 추가해 빈 곳을 메우지 않았다.
- 재화 카드 안의 배경·잔무늬·여러 작은 물체를 줄이고 잎 덩어리·물방울·양털 덩어리·통나무·쇠 덩어리·가죽 실루엣을 크게 두었다.
- 발견 효과는 잉크 번짐 한 덩어리, 보라 빛 조금으로 줄였다. 책장 획득도 한 장과 곡선 방향선 하나로 표현했다.

책자 정체성인 보라 가죽·단순한 금속 모서리·크림 양피지·보라 리본·보라 촛불과, 왼쪽 목록 / 오른쪽 3슬롯·결과·제작 도장 / 하단 6재화의 정보 위계는 유지했다. 중세의 생활감에 맞춘 판타지 소재를 사용했다.

비교 시트를 직접 열어 보았을 때 장식·미세 묘사는 v01 대비 절반 이하를 목표로 충분히 줄어든다. 이는 그림의 시각적 밀도에 대한 정성 검수이며, 선 개수나 픽셀 점유율을 기계적으로 계측한 수치는 아니다.

## 후처리

- 생성 원본 1672×941을 비율 유지 확대하고, 수직 합계 약 0.57px만 중앙 크롭해 정확한 1920×1080으로 저장했다.
- `godot/assets/fonts/NotoSansKR-wght.ttf`를 읽기 전용으로 로드했다. 생성기가 월드 HUD에 넣었던 책 제목을 `1일차 · 낮`으로 정정하고, `마법책 / 낮 · 시간 멈춤`을 책등 위의 작은 무장식 표찰로 옮겼다.
- 03 발견 칸에 이전 상태 `??? →`를 보충했다. 다른 생성 한글은 직접 확인 후 유지했다. 비교 시트의 한글도 같은 게임 글꼴이다.
- 03 책 제목은 발견 배너와 탭 사이에 맞도록 높이를 줄였다. 3장의 탭·미지 칸·재료 슬롯·수량 배지·제작 도장과 04의 기존/신규 제작법 구분을 직접 확인했다.
- [finish-and-sheet.ps1](drafts/finish-and-sheet.ps1)에 크기 정리·타이포 조판·시트 조립 절차를 남겼다. System.Drawing을 사용하며 이미지 API를 추가 호출하지 않는다.

## 남은 한계와 적용 범위

- 러프한 화풍·정보 위계 비교용 정적 이미지다. v01 픽셀 좌표와 완전히 등록된 런타임 UI, 개별 임포트용 파츠 또는 동작하는 애니메이션은 아니다.
- 03·04의 `???`와 새 이름은 변화 직전·직후를 한 프레임에 함께 표시한다. 04 손끝은 책장을 건네는 순간으로 남아 있으며, 곡선 방향선과 책 안의 장화 항목으로 흡수 상황을 표현한다.
- 큰 색면을 우선했지만 물약 반사광·촛농·부츠 등에는 형태를 읽기 위한 소수의 내부선이 남아 있다.
- Godot 임포트·실행·코드 수정·내보내기 및 커밋은 하지 않았다. `godot/**`, `WitchsLodge.exe`, v01 폴더는 쓰기 대상으로 사용하지 않았다. 문서는 이 요청서 납품 절과 요청된 신규 프롬프트 기록만 작성했다.
