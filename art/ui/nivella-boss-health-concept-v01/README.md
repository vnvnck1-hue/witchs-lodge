## 디자인

- 현재 보스바는 `boss_health_bar.gd::_rect`에서 높이를 화면 높이의 0.019(12~20px)로 정한다. 900px 높이 기준 논리 높이는 약 17px이다.
- 콘셉트 요청 목표: 체력 **채움 영역 자체** 높이 약 40px, 기존 대비 2배 이상. 생성 이미지의 실제 픽셀 높이는 출력 크기에 따라 다르다. 프레임만 두껍게 만드는 방식은 피했다.
- 기존 HUD와 통일된 짙은 보라 바탕·먹선·아이보리 금속 프레임에 서리실, 작은 얼음 조각과 네 눈 거미 문장을 추가했다.
- 이름 `니벨라`, 부제 `서리 둥지의 여왕`은 현재 런타임 표기를 유지했다.
- 체력 단은 기존처럼 보라 → 주황 → 빨강. 소비된 단계석을 빈 금 간 소켓으로 남겨 색 이외의 형태로도 구분한다.
- 실드는 체력을 덮지 않게 독립된 은청색 보조 게이지로 제안했다.
- 체력바가 보스의 얼굴을 가리지 않고 상단 시계·플레이어 HUD와 간격을 확보하는 배치다.

## 실제 캡처

현재 프로젝트의 기존 `godot/tools/capture_nivella_combat.gd`를 실행했다.

```text
.tools/Godot-4.7.2.exe --path godot --resolution 1600x900 --script res://tools/capture_nivella_combat.gd
```

- Vulkan Forward+ / NVIDIA GeForce RTX 3070 실제 렌더.
- 정상 종료 코드 0, `SHOT 01-intro-appear`부터 `SHOT 19-defeat`까지 저장 확인.
- 합성 입력: 이번 실행의 `04-hit-ghost.png`, `08-shield.png`를 위 폴더에 복사해 보존했다.
- 캡처 도구가 플레이어 생존을 위해 5000 HP를 사용하므로 원본 상단 플레이어 HP 수치는 일반 플레이 수치와 다르다.

## 검수와 적용 참고

- 기본 합성에서 체력 채움 영역이 기존보다 확연히 두꺼워졌고 보스 이름·3단계석·잔상·대미지 표기가 식별된다.
- 실드 합성과 상태 시트에서 붉은 체력과 은청색 실드를 동시에 볼 수 있다.
- 상태 시트의 실드 게이지 채움 폭을 추가 보정했다. 숫자는 총 체력/900, 메인 게이지는 현재 단/300으로 표현하는 제안이다.
- 생성형 원화이므로 게이지의 픽셀 비율·일부 한국어 획·프레임 형상·배경 픽셀은 엄밀히 고정된 구현 자산이 아니다. 일부 채움 길이와 단계별 수치의 비율은 근사치다. 실제 구현은 현재 단 체력 비율을 코드로 계산하고 텍스트를 별도 렌더해야 한다.
- 이번 결과는 합성 원화이며 런타임 적용이나 개별 투명 PNG 분리를 완료한 자료가 아니다.
- 실제 프롬프트는 [prompts.md](prompts.md)에 기록했다.
