# 손패 후면 고정 소품 · 실제 게임 적용

**후속 수정:** 사용자가 승인 원화와의 불일치를 지적하여 이 새 소품 시트·개별 배치·색보정 방식은 폐기했다. 현재 구현과 검수는 [runtime-v03](../hand-workbench-runtime-v03/README.md)을 따른다.

2026-10-18 · 승인한 v04 배치를 실제 게임에 적용.

- 최대 8장 손패를 기준으로 7개 장식의 위치·크기를 고정했다. 카드 수·확대·드래그에 따라 소품이 움직이지 않는다.
- 기존 카드 크기·바닥선(디자인 y=772)·부채꼴·원본 원화·확정 문구를 유지한다. 아래 청록·보라 받침은 제거했다.
- 양 끝에는 마법서·촛불과 약병·수정·약초를, 가운데에는 낮고 성긴 잉크병·깃펜·약초·두루마리·주머니·부적을 배치했다. 가운데 소품은 카드 바닥선보다 위에 있어 8장에서는 자연스럽게 가려진다.
- 소품은 입력을 받지 않고 CardHand보다 먼저 그리는 MoonHud에만 존재한다. 카드 확대·설명·드래그도 소품보다 앞에 표시한다.
- 소품 전용 셰이더로 채도·밝기를 낮추고 회청·회보라의 차가운 톤을 입혔다. 알파를 보존하며 카드 색에는 적용하지 않는다.

내장 image_gen으로 승인 v03·v04 원화를 참조해 [투명 스프라이트 시트](witch-props-sheet.png)를 제작했다. 실제 프롬프트는 [prompt.md](prompt.md). 중세 기반 판타지의 생활감과 분위기를 적용했다. 원본은 1774×887 RGBA이며, 게임 복사본은 `godot/assets/ui/hand_workbench/witch-props-v02.png`다. AtlasTexture 영역으로 각 소품을 표시한다.

실제 렌더링 검토는 `output/hand-workbench-runtime-v02/`의 3장·8장·확대·드래그·1280×720·3440×1440 캡처와 `layout-snapshots.json`에 기록한다. 3장과 8장에서 7개 장식의 화면 좌표·크기가 모두 같고 카드가 장식보다 나중에 그려지는 것을 확인했다.

작업 중 D드라이브 공간이 부족해 재생성 가능한 스크린샷 가져오기 캐시 약 505MB를 정리했다. 원본 캡처는 보존하고 `godot/screenshots/.gdignore`로 검토 이미지를 게임 리소스 자동 스캔에서 제외한다. 기존 내보내기 설정도 screenshots를 제외한다.

배포 대상은 프로젝트 루트 `WitchsLodge.exe` 한 개다. Windows Desktop 단일 파일로 다시 내보냈고, 해당 exe의 내장 게임 데이터를 `--main-pack`으로 실행해 같은 캡처 절차를 완료했다. `output/hand-workbench-runtime-v02/packaged/`에 배포 데이터의 3장·8장·확대·드래그·일반·울트라와이드 화면과 좌표 기록을 보존했다. 내보내기 종료 코드 0, 배포판에서도 3장·8장의 소품 위치 동일 및 카드 후순위 그리기를 확인했다.
