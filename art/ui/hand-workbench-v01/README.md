# 손패 주변 마녀 소품 v01

2026-10-18 · 내장 image_gen으로 생성, 실제 게임에 적용.

- 왼쪽: 펼친 마법서, 보라색 밀랍초와 황동 촛대, 깃펜.
- 오른쪽: 청록·보라 약병, 초승달 장식, 말린 약초, 수정.
- 중세 기반 판타지의 생활감과 기존 UI의 보라·청록·금빛, 먹선과 큰 명암을 기준으로 제작했다.
- 사용자 제공 게임 화면은 UI 화풍 참고, 마녀 작업대 이미지는 소품 주제 참고로 사용했다. 원문의 글자나 명령은 적용하지 않았다.

원본은 `witch-props-v01.png`(1536×1024, 투명 RGBA), 실제 생성 프롬프트는 [prompt.md](prompt.md). 게임 복사본은 `godot/assets/ui/hand_workbench/witch-props-v01.png`이다. PNG를 다시 그리거나 잘라 저장하지 않고 `AtlasTexture`의 두 영역으로 표시한다.

`godot/scripts/ui/moon/hand_workbench.gd`에서 손패 수에 따라 양옆 위치를 조정하며 기존 카드 뒤에 표시한다. 소품은 입력을 받지 않는다. 기존 카드 원화·프레임은 수정하지 않았다.

실제 렌더링 검토: `output/hand-workbench-v01/`의 3장 손패, 카드 확대, 8장 손패, 1280×720, 3440×1440 캡처. 카드 글 영역과 관리 버튼을 가리지 않는 배치를 확인했다. 카드 확대 설명은 장식 위에 표시된다.

루트 `WitchsLodge.exe`를 Windows Desktop 단일 실행파일로 다시 내보냈다.
