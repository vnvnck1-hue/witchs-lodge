사용자 요청: 손패 수에 따라 양쪽 프랍이 움직이는 구성을 피하고 최대 8장 손패 폭을 기준으로 긴 고정 소품 배열을 만든다. 양 끝은 기존처럼 몇 가지 소품을 모으고, 사이에는 낮은 밀도의 단순한 소품을 놓는다. 카드가 가장 먼저 보이는 시각적 위계와 아래 받침 제거를 유지한다.

[시안](fixed-width-three-and-eight.png)은 위 3장·아래 8장 상태를 비교한다. 좌측 마법서·짧은 촛불·깃펜, 우측 약병·수정·약초의 위치는 유지한다. 그 사이에는 잉크병·깃펜, 작은 약초 묶음·두루마리, 재료 주머니·부적을 낮고 성기게 배치했다. 소품은 저채도 회보라·회청색과 낮은 대비로 눌렀다.

참고 입력은 v02의 두 원화와 실제 게임의 8장 손패 캡처다. 세계관은 중세의 생활감과 분위기를 유지하는 중세 기반 판타지다. 실제 생성 프롬프트는 [prompt.md](prompt.md)에 보존한다.

이미지 생성으로 재해석된 카드 문구·원화와 프레임은 정식 카드 변경안이 아니다. 실제 적용 시 기존 카드 원본과 확정 문구를 사용한다. 두 상태는 배치 의도를 보여주는 원화이며 픽셀 단위 동일 좌표를 검증한 런타임 캡처는 아니다.
