## 장면별 의도

### 01 · 입구 3상태
[01-entry-book-states.png](01-entry-book-states.png)는 손패 왼쪽의 같은 책·촛불 소품을 평소, 제작 가능, 밤 비활성으로 비교한다. 제작 가능 상태는 촛불 밝기·보라 테두리 빛·작은 반짝임으로 알리고 커서가 이 책을 가리킨다. 밤에는 촛불이 꺼지고 달·자물쇠가 붙는다. 세 소품의 형태와 배치는 유지하며, 각 상태를 확대하는 비교용 판이므로 실제 게임 창의 구현을 뜻하지 않는다.

### 02a · 방향 A 실물 책
[02a-window-diorama.png](02a-window-diorama.png)는 책 자체가 제작 창이다. 보라 가죽·금속 모서리·라벤더 식물 문양·보라 촛불을 손패 소품에서 이어받고, 양피지의 왼쪽 제작법 목록과 오른쪽 세 룬 원을 나눴다. 물약 탭에서 치유 물약을 선택했으며 약초 ×2가 한 슬롯에 들어가고 두 슬롯은 비어 있다. 결과 카드 아래는 초승달이 찍힌 보라 밀랍 제작 도장이다.

### 02b · 방향 B 달 룬 UI
[02b-window-ui-frame.png](02b-window-ui-frame.png)는 승인 남색·금테·달 룬 프레임으로 같은 정보를 배열한다. 책은 창 왼쪽 위 장식 아이콘으로 축소하고 목록·슬롯·결과·버튼의 경계를 또렷하게 나눴다. 실제 낮 배경은 어두운 막 뒤로 두어 창을 먼저 읽게 했다. A와 동일하게 물약 1/4·장비 1/5·마법 1/4, 치유 물약, 약초 ×2와 빈 슬롯 두 칸, 아래 여섯 재료와 수량을 표시한다.

### 03 · 새 비법 발견
[03-discovery-moment.png](03-discovery-moment.png)는 A에서 약초 ×2와 정화된 정수 ×1을 넣어 덩굴 올가미를 발견하는 순간이다. 왼쪽 타일의 ??? 흔적 위로 잉크가 번지며 이름·그림이 드러나고, 오른쪽에서는 결과 카드가 마법진 위에 떠오른다. 배너는 “새로운 비법을 책에 적었다”, 마법 탭은 발견 후 2/4다. 아래 손패 수량은 연출 직전의 보유량을 유지한 비교용 값이며 재료 차감 시점의 구현 사양을 추가로 확정하지 않는다.

### 04 · 제작법 획득
[04-recipe-reward.png](04-recipe-reward.png)는 중세풍 손님의 장갑 낀 손에서 떨어진 찢어진 책장이 빛을 따라 책으로 들어오는 순간이다. 누빈 솜옷의 그림·이름이 있는 낡은 쪽지를 일반 결과 카드와 구별하고, 말린 모서리·광선·종잇조각으로 흡수 방향을 표현했다. 장비 목록은 아는 제작법 한 개와 ??? 네 칸을 보여 준다.

## 방향 A/B 비교

**A · 분위기 중심.** 손패 소품과 커다란 제작 창이 같은 책으로 연결되며, 양피지·리본·룬·밀랍 도장 덕분에 책에 비법을 쌓는 감각이 강하다. 잉크 발견과 책장 흡수 연출을 자연스럽게 이어갈 수 있다. 다만 종이 명암·문양·곡면 위의 글자와 선택 강조는 축소 화면에서 대비가 약해질 수 있다. 구현 시 페이지·글자·선택 영역·마법진·연출을 별도 레이어로 나누고 페이지 경계에 맞는 마스크가 필요해 B보다 손이 더 간다.

**B · 가독성 중심.** 남색 바탕의 크림 글자와 규칙적인 금테 격자로 제작법·빈 슬롯·결과가 빠르게 읽힌다. 패널·격자·슬롯을 중심으로 구성할 수 있어 배치와 확장, 다양한 화면 비율 대응이 A보다 수월하다. 기존 승인 HUD와도 잘 연결된다. 책을 직접 다룬다는 분위기는 A보다 약하므로 작은 책 아이콘과 발견 시의 잉크·종이 연출로 소품과의 연결을 보완할 수 있다. 이 비교는 작업량에 대한 시각 검토이며 실제 구현 시간 측정은 아니다.

- 발견 장면의 마법 탭 2/4: 이끼 붕대, 새 덩굴 올가미, ??? 두 칸. 보상 장면의 장비 탭 1/5: 누빈 솜옷 + ??? 네 칸.
- 재화 줄: 약초 ×3 / 정화된 정수 ×1 / 양털 ×4 / 목재 ×2 / 쇠붙이 ×2 / 토끼 가죽 ×1.
- 약초는 묶은 초록 잎 다발, 정수는 맑은 하늘빛·은빛 물을 품은 유리 방울, 쇠붙이는 녹슨 경첩·쇠 조각이다.
- 중세 기반 판타지의 생활감, 두꺼운 실루엣·큰 색면·따뜻한 손그림, 보라·남색·금테를 유지했다.

## 생성·후처리·검수

내장 image_gen을 **초안 5회 + 부분 보정 4회** 호출했다. 참고 입력은 실제 낮 게임 화면, SpellbookAndCandle 소품, 승인 moon-runes mockup/hand이며, 03·04는 A 초안을 추가 참고했다. 모든 호출은 참고 이미지 5장 이하를 사용했다. 생성 원본과 수정본 9장은 [drafts/](drafts/)에 보관했다.

A·03·04의 정수 병을 유리 방울로 바꾸고 제작 버튼을 밀랍 도장으로 보정했다. 03의 ??? 잔상과 잉크, 04의 말린 책장 모서리·흡수 광선을 강화하고 B의 배경을 어둡게 했다. 최종 선택 원본은 모두 1672×941이었으며, 자르지 않고 고품질 bicubic으로 1920×1080에 정규화했다. 원화의 한글은 최종본에서 읽을 수 있어 생성된 글자를 유지했다. 비교 시트의 제목·주석은 게임 폰트 Noto Sans KR의 **drafts 내 복사본**으로 정확하게 조판했다. 게임 폰트 원본은 읽기만 했다.

최종 5장과 sheet.png를 직접 열어 한글, ???, A/B 정보 일치, 세 재료 슬롯, 여섯 보유 재료·수량, 책 정체성, 밤의 소등을 확인했다. [최종 파일 명세](drafts/final-manifest.json)에 크기·바이트·SHA-256을 남겼다. [후처리 스크립트](drafts/finish-delivery.ps1)는 치수 정규화·비교 시트·명세만 재생성한다. 저장소 루트에서 UTF-8로 읽어 실행한다.

## 남은 결정과 범위

사용자의 A/B 방향 선택이 남아 있다. 이번 결과는 레이어가 합쳐진 컨셉 PNG이므로 실제 게임용 배경·패널·슬롯·버튼·글자·이펙트 분리와 반응형 배치, 연출 타이밍 검증은 구현 단계의 일이다. 카드 그림·손님 손·주변 HUD도 화면 목업의 일부이며 기존 게임 카드나 초상을 교체한 것이 아니다. 보상 쪽지의 누빈 솜옷은 예시 연출이며 새 제작 규칙을 확정하지 않는다.

godot/ 전체, WitchsLodge.exe, 다른 기존 docs 문서, scrap·junk_sack 원화는 수정하지 않았다. 게임 임포트·실행·내보내기와 커밋도 하지 않았다. 문서 변경은 새 프롬프트 기록과 요청서 끝의 납품 결과 절로 한정했다.
