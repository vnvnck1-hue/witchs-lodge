# 사냥목표 동물 모델링 원화 v01

2026-10-18 (Asia/Seoul). 내장 image_gen으로 생성한 모델링 참고 시안이며 사용자 승인 전이다.

## 대상과 산출물

현재 게임의 `godot/scripts/game/wildlife_director.gd`와 `godot/scripts/actors/wild_animal.gd`에 등장하는 사냥목표 토끼·사슴 2종을 대상으로 했다.

- [토끼 원화](01-rabbit-model-sheet.png): 회갈색 몸, 크림색 배·발끝, 긴 귀, 둥근 밝은 꼬리.
- [사슴 원화](02-deer-model-sheet.png): 적갈색 몸, 짙은 목·가슴, 밝은 배와 꼬리 안쪽, 상아색 뿔과 짙은 갈라진 발굽.

각 PNG는 4시점(정면·측면·후면·사선)과 기본색 견본을 포함한다. 실제 사용한 전체 프롬프트는 [prompts.md](prompts.md)에 보존했다. 생성 원본 해상도를 그대로 보존했으며 후처리하지 않았다.

## 모델링 인계

[아트 가이드](../../../docs/art-direction.md)의 중세 기반 판타지, 간결한 실루엣과 큰 색면, 툰 명암을 기준으로 했다. 동물에 장비·장식·마법 설정은 추가하지 않았다. 기존 [야생 동물 에셋](../../../docs/wildlife-assets-v01.md)의 종별 색과 특징을 출발점으로 삼았다.

기존 게임 크기 참고: 토끼 길이 0.45m·귀 포함 높이 0.35m, 사슴 길이 1.50m·어깨 약 1.10m·뿔 포함 높이 1.60m. 두 시트는 각각 화면에 맞춰 배치되어 서로 같은 축척이 아니다. 3D 제작 시 치수는 기존 에셋 문서를 사용한다.

생성 원화이므로 시점 간 미세한 형태·뿔 각도 차이는 블록아웃 단계에서 통일한다. 털의 작은 붓질은 메시 세부나 촘촘한 텍스처로 모두 옮기지 않고 큰 형태와 색 경계 위주로 단순화한다. 기존 엔진 축(+Y 위·+Z 정면), 지면 원점 및 Body/Head 규약은 기존 에셋 문서를 따른다.

이번 작업은 원화 제작이며 게임 모델·소스·실행파일 교체는 하지 않았다.
