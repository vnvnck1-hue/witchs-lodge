# 양 모델링 원화 v01

2026-10-18 (Asia/Seoul). 내장 image_gen으로 제작한 모델링 참고 시안. 사용자 승인 전이며 기존 게임 모델은 교체하지 않았다.

## 산출물

- [일반 양](01-sheep-model-sheet.png): 크림색 털, 짙은 얼굴·귀·다리, 뿔과 장식 없는 기본형.
- [새끼양](02-lamb-model-sheet.png): 밝은 얼굴과 털, 분홍 코·귀 안쪽, 어린 비례, 가죽 목줄과 작은 황동 방울.
- [검은 양](03-black-sheep-model-sheet.png): 자주빛을 띤 검은 털, 금빛 눈, 작은 굽은 뿔, 자주색 목줄과 황동 방울.

각 PNG는 정면·측면·후면·사선의 4시점 및 기본색 견본을 포함한다. 앞서 만든 [토끼·사슴 시트](../wildlife-v01/README.md)와 같은 제작용 형식이다. 생성 원본 해상도 그대로 저장했으며 후처리하지 않았다. 전체 실제 프롬프트는 [prompts.md](prompts.md)에 보존했다.

## 제작 근거와 모델링 인계

[아트 가이드](../../../docs/art-direction.md)의 중세 기반 판타지, 큰 색면·간결한 형태·툰 명암을 적용했다. [기존 양 시트](../starter/05-sheep.png), 실제 새끼양·검은 양 카드, `godot/scripts/actors/sheep.gd`와 현재 모델 제작 소스를 확인했다.

일반 양은 기존 모델과 시트의 어두운 얼굴·크림색 털·뿔 없는 실루엣을 유지했다. 새끼양과 검은 양은 카드에서 보이는 특징을 모델링 원화로 반영했다. 현재 런타임에서는 새끼양이 일반 양 모델의 0.6배 축소형이고, 검은 양도 같은 모델의 개별 재질과 금빛 눈을 사용한다. 따라서 이번 새끼양의 밝은 얼굴·목방울 및 검은 양의 뿔·목방울은 카드와 형태를 맞추기 위한 모델링 시안이며 아직 런타임에 구현된 형태는 아니다.

시트끼리는 같은 절대 축척이 아니다. 새끼양의 게임 적용 기준 배율은 `Cfg.LAMB_SCALE = 0.6`이다. 새 모델 제작 시 기존 발 접점·Body/Head 피벗 규약을 확인한다. 털은 큰 덩어리 중심으로 모델링하며 작은 붓질을 모두 형상화하지 않는다. 생성 시점 간 세부 차이는 블록아웃 단계에서 통일한다.
