**마녀의 주머니**는 창고를 대신하는 마녀산장의 덱이다(2026-10-16). 시작 카드 {{cfg|STARTER_CARDS.length}}장은 모두 주머니에 들어가 {{cfg|STARTER_DRAW}}장을 펼쳐 {{cfg|MULLIGAN_SWAPS}}장을 바꿀 수 있고(하스스톤식 시작 손패), 아침마다 {{cfg|MORNING_DRAW}}장이 가운데에 공개된 뒤 손패 오른쪽에 쌓인다. 자원은 손패에 뽑힌 것만 쓴다.

## 확정 규칙

| 항목 | 규칙 |
| --- | --- |
| 신규 획득 | 자리가 있으면 손패로 즉시 획득. 가득 차서 넣지 못한 카드·자원은 주머니로 보내며 잃지 않음 |
| 시작 | 시작 카드를 주머니에 넣고 {{cfg|STARTER_DRAW}}장을 공개, {{cfg|MULLIGAN_SWAPS}}장 교체 가능 |
| 손패 | {{cfg|HAND_VISIBLE}}장 한도. 가득 차면 드로우를 건너뛰고 주머니에 보존 |
| 주머니 | 덱 역할. 목록은 볼 수 있지만 자유 입출고는 불가 |
| 아침 | 주머니에 카드가 있으면 무작위 {{cfg|MORNING_DRAW}}장 드로우 |
| 드로우 카드 | {{card|gatherer}}: 사용 시 1장 / {{card|poison_mushroom}}: 체력 {{cfg|MUSHROOM_HP_COST}} 대가로 1장 / {{card|old_spellbook}}: 최대 {{cfg|SPELLBOOK_CHOICES}}장 중 1장 선택 |
| 사용 후 | 자원 외 카드는 버림패, 활동 카드는 활동 종료 후 버림패. 자원은 수량 차감 |
| 재순환 | 버림패의 자동 재순환 없음 |
| 빈 주머니 | 드로우 전용 카드는 사용 불가·비용 없음 |
| 자원 드로우 | 주머니에서 자원 1개씩 가져옴 |
| 자원 사용 | 건축·수리·판매·봉헌 모두 손패의 자원만 사용 |
| 직접 들어오는 카드 | {{card|wolf_blood}}를 쓰면 달 카드 세 장이 손패를 거치지 않고 주머니로 날아 들어온다([[늑대의 피]]) |

## 시작 손패

시작 카드는 {{table|starter_cards}}이다. 확정 뒤 "시작 손패 3장 — 주머니에 3장이 남아 아침마다 한 장씩 옵니다"라는 토스트가 뜬다.

## 주머니 창

주머니 창은 카드를 넓게 펼친 갤러리다. 마우스를 올린 카드가 떠오르며 커지고 나머지는 어두워지며 옆에 툴팁이 붙는다. 주머니 창을 여는 동안 시간은 멈춘다.
