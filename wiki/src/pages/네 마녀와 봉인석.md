**네 마녀와 봉인석**은 마녀산장의 핵심 장기 플로우다(사용자 확정, 2026-10-17). 플레이어는 동쪽·서쪽·남쪽·북쪽 마녀의 이야기를 플레이하고, 각 마녀는 자신이 맡은 **봉인석**을 지켜야 한다. 한 마녀의 이야기가 끝나도 그 결과는 다음 마녀의 이야기에 영향을 남기며, 네 이야기의 결과가 최종 엔딩으로 모인다. 로그라이크 덱빌딩의 다회차 동기를 만드는 구조이며 아직 게임에 구현되지 않았다.

## 흐름

**마녀 선택 → 해당 이야기 플레이 → 봉인석 수호/파괴 결과 기록 → 결과별 고가치 카드 해금 및 파괴에 따른 위험 반영 → 다음 마녀 이야기 시작 → 네 마녀의 결과를 종합한 최종 엔딩**

| 축 | 확정한 방향 |
| --- | --- |
| 개별 목표 | 네 마녀는 각각 자신의 봉인석을 지킨다 |
| 결과별 카드 | 같은 마녀라도 수호 결말과 파괴 결말에서 서로 다른 고가치 카드가 해금된다 |
| 다음 이야기와 연결 | 해금한 카드는 다음 마녀의 이야기를 시작할 때 선택하거나 사용할 수 있다. 지급 방식은 미정 |
| 파괴의 위험 | 봉인석을 지키지 못하면 이후 이야기들의 적이 더 강해진다 |
| 방향별 위험 분기 | 동·서·남·북 중 어느 봉인석을 잃었는지에 따라 적 강화의 갈래가 달라진다 |
| 누적 위험 | 봉인석을 지키지 못할수록 이후 이야기의 위험이 커진다 |
| 순서의 의미 | 누구를 먼저 플레이하고 어떤 결과를 남겼는지에 따라 후속 이야기의 카드 선택지와 위협이 달라진다 |

## 엔딩

| 최종 엔딩 | 네 마녀의 봉인석 결과 |
| --- | --- |
| 전체 수호 엔딩 | 네 봉인석을 모두 지킴 |
| 전체 파괴 엔딩 | 네 봉인석을 모두 지키지 못함 |
| 일부 수호 엔딩 | 1~3개의 봉인석을 지킴 |

예시 여정: **동쪽 파괴 → 남쪽 수호 → 서쪽 수호 → 북쪽 파괴**. 남쪽은 동쪽의 파괴 결말 카드를 활용할 기회와 동쪽 파괴에 따른 적 강화 위험을 함께 안고 시작한다. 최종적으로 두 봉인석을 지킨 이 여정은 일부 수호 엔딩이다. 이 순서는 설명용이며 고정 진행 순서가 아니다.

## 게임 속 봉인석

현재 실행판에서 봉인석은 산장 아래에 있다고 설정되며, 프롤로그 3장과 '첫째 날' 타이틀 카드("산장 아래 봉인석을 지키세요")에서 처음 소개된다. <span class="night-tag">봉인석 탈취의 밤</span>에는 모든 괴물이 봉인석만 노리고, 패배 화면 문구는 "산장이 무너지고 봉인석을 빼앗겼습니다"다. 마녀 선택 화면에서는 '마녀' 한 칸만 열려 있고, 주인공이 네 방위 중 누구인지는 미정이다.

## 미정 사항

- 마녀별 수호/파괴 해금 카드 목록·효과·가치
- 시작 덱 편입, 시작 시 선택 지급 등 실제 카드 제공 방식
- 방향별 적 강화의 종류·수치와 여러 파괴 위험의 조합 방식
- 일반 전투 패배·재도전과 봉인석 파괴 결말의 관계
- 세 엔딩 범주의 구체적 내용
