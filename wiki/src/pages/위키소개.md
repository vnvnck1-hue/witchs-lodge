**마녀산장 위키**는 개발 중인 게임 [[마녀산장]](Witch's Lodge)의 설정·시스템·카드·인물을 정리한 백과사전이다. 미디어위키의 문서 레이아웃을 따르되, 저장소에서 자동으로 생성되는 정적 사이트다.

## 어떻게 만들어지나

| 부분 | 원본 | 반영 방식 |
| --- | --- | --- |
| 수치·표·목록 | `godot/scripts/config.gd`, `chapter_data.gd`, `guest_profiles.gd`, `assets/cards/catalog.json`, `godot/README.md` 조작표 | 생성 스크립트가 직접 읽는다. 게임 데이터를 고치면 다음 배포에 그대로 반영 |
| 카드·손님 개별 문서 | 카드 카탈로그, 손님 정의 | 자동 생성. `wiki/src/pages/cards/<id>.md`, `guests/<id>.md`가 있으면 비고·인물 절로 덧붙임 |
| 서술 문서 | `wiki/src/pages/*.md` | 위키용 마크다운. 본문 안에서 `{{cfg|상수}}`로 게임 수치를 끌어 쓴다 |
| 문서 역사·최근 바뀜 | 저장소 커밋 이력 | 원본 파일의 git log |

main 브랜치에 푸시하면 GitHub Actions가 `wiki/dist`를 만들어 GitHub Pages에 올린다. 각 문서의 '편집' 탭에서 원본 마크다운과 GitHub 편집 링크를 볼 수 있다.

## 마크다운 문법

- 링크: `[[문서]]`, `[[문서|표시]]`, 카드: `{{card|frost_rune}}`
- 게임 수치: `{{cfg|COST_DRAGON}}`, `{{cfg|ENEMY_KINDS.boss.hp}}`, `{{ch|PURIFY_PRICE}}`, 월드 설정 `{{wsc|MAJOR_WEIGHT}}`
- 표: `{{table|enemies}}` 등 (enemies · nights · days · market · relics · rituals · build_costs · controls · guests · races · race_cards · jobs · towers · gather_table · animals · cards_by_kind · gallery · reward_pool · starter_cards)
- 그림: `{{thumb|파일|설명|tright|320}}`, 안내 상자: `{{note|dev}}` / `{{note|plan}}`
- 정보상자: `{{infobox` 로 시작해 `caption:`, `image: 파일|설명`, `항목: 값` 줄을 적고 `}}`로 닫는다.

## 면책

이 위키의 수치는 모두 프로토타입 시험값이며 플레이테스트로 바뀔 수 있다. '미정'으로 표시한 항목은 아직 결정되지 않은 설정이다. 토론·계정 기능은 흉내만 낸 것으로 실제로 동작하지 않는다.
