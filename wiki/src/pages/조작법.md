마녀산장은 마우스와 키보드로 조작한다. 창 크기 1600×800, 기준 뷰포트 1774×887. 일시 정지 메뉴(Esc)의 '조작법'에서도 볼 수 있다. 아래 표는 Godot 프로젝트 README의 조작표에서 자동으로 가져온다.

## 입력

{{table|controls}}

## 카드와 손님

| 입력 | 동작 |
| --- | --- |
| 손패 카드 드래그 | 유효한 대상(나무·지면·적·산장·목장·마녀)에 놓아 사용 |
| 손님 머리 위 클릭 | 고용 제안 수락({{cfg|CONTRACT_COST}}G) |
| 털 난 양 클릭 | 목장에 들어가 {{cfg|HARVEST_TIME}}초 동안 털 깎기 |
| 좌상단 말풍선 클릭 | 손님과 선택형 대화 |

새 실행의 기본 조합은 **강렬한 툰 · 심야 + 넓은 원근 34° + 극적인 공기**다.

## 프롤로그·튜토리얼

프롤로그는 클릭·Space로 다음 장, Esc로 건너뛴다. 타이틀 설정의 '튜토리얼 다시 보기'로 첫 고용 안내를 다시 켤 수 있다.
