# Witch's Lodge · 마녀산장

깊은 설산 숲의 작은 산장을 운영하는 마녀의 이야기. 이따금 찾아오는 여행자를 맞이하고 산장을 조금씩 증축하며 숲에서 나오는 괴물에 대응한다. 감당하기 어려운 몬스터 무리가 몰려오면 모아둔 골드를 용에게 바쳐, 산장 지붕 위에 거대한 용을 소환한다.

> 따뜻한 작은 거처를 키워가는 일상과, 그 거처를 지키기 위해 저축을 내놓아야 하는 위기.

이 리포지토리는 현재 **게임 설정과 컨셉 원화 자료집**이다. 플레이 가능한 게임 코드나 확정된 수치 설계는 포함하지 않는다.

## 시각적 기준

알비온 온라인을 참고한 높은 고정 쿼터뷰, 각진 로우폴리 환경, 2~3등신 SD 캐릭터를 사용한다. 보랏빛 눈과 인디고 그림자를 주조색으로 두고, 짙은 초록 숲과 산장의 따뜻한 창문 빛을 더한다. 지형은 거의 평지이며 산장 주변에 둥글게 관리된 공터와 아주 작은 양 목장이 있다.

이미지는 방향을 검토하기 위한 컨셉 자료다. 이전 탐색 시안, 구조 참고 시트, 사용자 제공 참고 이미지도 보존하며 각각의 용도를 갤러리에 표시했다.
