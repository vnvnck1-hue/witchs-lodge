배경·메인 HUD·손패는 실제 캡처 그대로 유지했습니다. 중앙 관리창과 예시 가격만 검토용으로 올렸습니다. 가격은 예시이며 현재 게임 데이터 바인딩이 아닙니다.

현재 판단: 같은 게임의 UI로 잘 이어집니다

카드의 불규칙한 먹선과 종이색, 상태판의 인디고·청록 경계를 공유합니다. 새 시설 아이콘도 기존 산장·양털·목재 그림과 같은 굵기와 채색으로 맞췄습니다. 밝은 크림은 제목·선택 탭·강조 버튼에 집중했습니다.

크기에 따라 장식량을 나눴습니다

큰 창에는 달과 설목을 허용하고, 작은 월드 체력 바·이름표에는 초상과 큰 장식을 제거했습니다. 작은 표시가 기존 HUD나 카드보다 먼저 눈에 들어오지 않도록 구분한 방향입니다.

01 · 산장 시설 / 손님 / 대화 기록

원본 PNG

기본 탭을 종이 탭으로, 시설 행을 작은 그림 아이콘과 단정한 버튼으로 확장했습니다. 손님 목록과 기록도 같은 창의 형제로 구성했습니다.

사용자 확정에 따라 이 시안부터 브람·미라·토르빈의 기존 PNG를 직접 사용합니다. 얼굴·의상·채색·화풍을 다시 그리지 않고 크기와 표시 영역만 조절했습니다. 글자·수치·설명은 원화에 고정하지 않고 별도 UI로 배치할 예정입니다.

02 · 일시정지 / 설정 / 주머니 / 교역 / 고용

원본 PNG

닫힌 선택 박스와 달 모양 토글, 키캡, 스크롤, 수량 선택과 판매/취소 버튼까지 같은 표면으로 묶었습니다. 설정 항목과 주머니의 네 구역은 현재 게임 명칭에 맞췄습니다.

03 · 툴팁 / 알림 / 말풍선 / 월드 표시

원본 PNG

양피지 툴팁, 성공/실패 안내, 자원 말풍선, 성장 안내, 도착 띠, 다섯 종류 체력 바, 털 깎기 게이지, 행동/계약 이름표, 유물 슬롯과 작은 배지를 담았습니다.

첫 초안에서 체력 바에 붙었던 큰 초상·장식은 제거했습니다. 적용 때 월드 바는 기존 44~120px 범위에서 선 두께와 대비를 검토하고, 읽히지 않는 미세 장식은 추가하지 않는 방향입니다.

04 · 지도 / 대화 선택 / 승리·패배

원본 PNG

승패는 프레임의 계보를 유지하면서 따뜻한 산장과 꺼진 등불로 정서를 달리했습니다. 대화 선택 버튼은 같은 얇은 크림 선과 청록 선택 강조를 사용합니다.

지도 내부는 재질·표식의 원화 예시이며 실제 길/탐색 데이터는 그대로 사용합니다. 대화창에는 기존 브람 PNG를 직접 배치했습니다. 종이 면은 구성 참고이며, 이미 적용된 기존 초상·잉크 패널 연출은 유지하고 선택/진행/닫기 버튼만 확장하는 계획입니다.

기존 기준 원화와 대조
