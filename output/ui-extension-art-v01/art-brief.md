# UI 원화 방향 · 달빛 UI 확장 v01

## 사용자의 결정 전 단계

미적용 UI 전체를 기존 그래픽 스타일로 교체하는 요청의 첫 단계인 원화입니다. 실제 게임 연결은 원화를 확인한 사용자의 디자인 결정 이후에 진행합니다. 생성 이미지는 최종 분리 에셋이나 런타임 기능 완성본이 아닙니다.

## 반드시 이어갈 결

- 기존 승인 아틀라스가 시각 기준. 큰 색면과 두께가 변하는 짙은 먹선, 살짝 비대칭인 손그림 외곽.
- 인디고 판, 크림 경계와 종이, 작은 청록 곡선. 앰버는 동전·산장 불빛의 초점.
- 카드의 손그림 아이콘과 같은 셀 명암/종이 질감. 반짝이는 금속 테두리나 매끈한 벡터 UI로 바꾸지 않기.
- 제목·선택 탭은 종이 면. 동적 문장은 잔무늬 없는 넓은 면에 별도 텍스트로 표시.
- 큰 창의 달·설목과 작은 월드 정보의 장식량을 분리. 월드 체력 바와 계약 이름표는 초상 없는 얇은 형태.

## 원화 세트

1. `01-lodge-management-existing-portraits.png`: 시설/손님/기록과 공통 창, 탭, 행, 버튼.
2. `02-menus-pocket-trade.png`: 일시정지/현재 설정/조작법/주머니 네 구역/판매/고용.
3. `03-feedback-world-ui.png`: 툴팁, 사용 안내, 토스트, 성장/자원/손님 말풍선, 도착, 체력/작업, 이름표, 유물/배지.
4. `04-map-dialogue-results-existing-portraits.png`: 지도 재질·표식, 대화 선택/진행/닫기, 승패 결과.
5. `05-management-frame-transparent.png`: 화면 배치 검토용으로 분리한 투명 관리창. 예시 가격은 HTML 별도 레이어.

## 검토 중 바로잡은 부분

- 메뉴 첫 생성본이 음악/언어 설정과 다른 주머니 분류를 제안해, 현재 게임의 셰이딩·카메라·공기 원근·시간대·안개와 주머니/손패/활동 중/버림패로 수정했다.
- 보조 UI 첫 생성본의 월드 체력 바는 초상·장식이 과했다. 초상을 제거하고 얇은 먹선/크림 경계만 남겼다.
- 사용자 확정: **인물 포트레이트는 기존 게임 에셋만 사용한다. 원화 검토 단계부터 예외 없이 적용한다.** 새 인물 생성, 얼굴/의상 재해석, 재채색, 화풍 변환을 하지 않는다. 기존 PNG를 별도 레이어로 직접 배치하며 크기와 표시 영역만 조절한다.
- 관리창 시안의 새로 그려진 인물 3명은 제거하고 기존 브람·미라·토르빈 PNG로 교체했다. 대화 시안의 임시 실루엣도 기존 브람 PNG로 교체했다. 기존 포트레이트 7종의 파일 해시를 검증 기록에 남긴다.
- 이미 적용된 대화 잉크 패널 연출을 원화의 종이 패널로 교체하자는 제안이 아니다. 이번 대상은 선택/다음/닫기 버튼이다.
- 지도는 원화 재질 검토용 예시. 실제 탐색 지형/경로/미탐색 판정은 기존 데이터를 사용한다.

## 후속 제작 시 필요한 작업

방향이 정해지면 실제 부품의 투명 분리·9-slice 안전 영역·본문/수치 영역·hover/pressed/disabled/focus 상태를 확정하고, 기존 게임 함수와 데이터에 연결한다. 현재 그림에 빈 영역이 있다는 것은 이 단계가 데이터 UI 완성본이 아니라 원화라는 의미다.

## 생성 기록

내장 image_gen을 사용했다. CLI/API 대체 경로를 사용하지 않았다. 최종/초안 프롬프트는 `source/*-prompt.txt`, 채택 전 초안은 `source/`에 보존한다. 기존 게임 파일이나 PCK를 수정하지 않았다.
