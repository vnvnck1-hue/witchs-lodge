# 달빛 UI 확장 원화 v01 · 사용자 채택 완료

현재 게임의 미적용 UI를 기존 승인 달빛 UI의 먹선·인디고·크림·청록 장식으로 확장하는 검토용 원화입니다.

- 기준: `art/ui/moon-runes-v01/approved/atlas.png`, 기존 공통 부품, 실제 배포판 화면.
- 제작: 내장 image_gen. 원본 생성물은 수정하지 않고 보존합니다.
- 사용자 결정: 현재 원화 채택 후 게임에 적용. 구현·배포판·캡처·검증은 `../ui-extension-implementation/report.html` 참조.
- 인물 포트레이트는 사용자 결정에 따라 **원화 시안부터 기존 게임 PNG만 직접 사용**합니다. 새 인물 생성·재해석·재채색·화풍 변환 없이 크기/표시 영역만 조절합니다. 기존 7종의 원본 일치 해시를 검증합니다.
- 시안의 예시 문구/배치는 기능 구현이나 최종 데이터 계약이 아닙니다. 기존 카드·HUD는 유지합니다.

검토 기준: 외곽 먹선 굵기, 크림 경계의 밝기, 청록 장식의 양, 설경 위 대비, 카드 원화와의 밀도 차이, 작은 월드 표시의 가독성.
