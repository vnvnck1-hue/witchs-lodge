# 마녀산장 · 사운드 검토

**v02:** 필드 BGM·저녁 BGM 각 2개와 낮·저녁 자연 환경음 각 4개를 추가했다. BGM과 환경음은 종류당 한 개씩 고르며 시간대에 맞춰 부드럽게 전환된다. 이전 짧은 효과음은 여러 개를 고르면 순환 재생한다. [새 후보와 제작 기록](../audio-field-v01/README.md).

현재 검토 화면: http://127.0.0.1:8614/

1. 각 후보의 재생 버튼으로 듣는다.
2. 사용할 후보를 체크하고, 필요하면 메모와 종류별 음량을 조절한다.
3. **선택한 사운드 적용**을 누른다.
4. **게임 실행**을 눌러 실제 동작에서 확인한다. 이 버튼도 현재 체크 결과를 적용한 뒤 실행한다.

같은 종류에 여러 후보를 선택하면 순서대로 번갈아 재생한다. 종류에서 아무것도 선택하지 않으면 해당 동작은 무음이다. 체크와 메모는 자동 저장되며 실제 게임 설정은 적용 또는 게임 실행 버튼을 눌렀을 때 바뀐다. 화면의 청취 음량과 게임 음량은 같은 dB 설정이다.

검토 화면은 이 PC의 로컬 서버에서 실행된다. 닫힌 뒤 다시 열 때는 `start-review.ps1`을 PowerShell에서 실행한다. `dist/index.html`을 직접 열면 청취·체크·메모와 선택 결과 다운로드가 가능한 오프라인 검토 모드이고, 게임에 직접 적용하려면 위 로컬 주소를 사용한다. 공개 사이트에 업로드하지 않았다.

## 게임 연결

- 마녀 마법탄 발사 → `magic_bolt`
- 용병·하수인 배치, 목재 수리, 양털 판매 확정 → `card_play`
- 숙박비와 양털 판매 수입 → `gold_reward`
- 용 소환 성공 → `dragon_arrival`

승인 후 원본 MP3와 `selected.json`이 `godot/assets/audio/`, `build/audio/`, `build/audio-review/audio/`에 저장된다. 설정 변경은 게임에서 1초마다 읽는다. 원본 후보는 보존한다. 취소한 후보는 재생 대상에서 제외하고 재생 중인 소리도 멈춘다.

게임 실행 버튼은 `build/audio-review/WitchsLodge.exe`를 실행한다. 현재 기본 `build/WitchsLodge.pck`에도 사운드 연결을 반영했다. 이전 실행판은 `build/WitchsLodge-before-audio-review.pck`로 보존했다. 이 변경 이전부터 실행 중이던 게임은 한 번 다시 실행해야 한다.

## 검증

- 브라우저: 16개 음원 모두 로딩, 사용 체크·해제와 선택 개수 갱신, 좁은 화면에서 가로 넘침 없음.
- `game-verification.json`: 13개 통과. 미승인 무음, MP3 로딩, 후보 순환, 중복 억제, 실제 공격·수입·카드·용 동작, 일시 정지, 잘못된 설정 보존, 승인 해제 반영.
- `server-verification.json`: 10개 통과. 승인 파일만 복사, 여러 후보·음량 보존, 소스와 두 실행판 반영, 승인 해제, 잘못된 파일명·음량 거부. 실제 사용자의 선택을 바꾸지 않고 별도 시험 폴더에서 검증했다.
- 새 실행 데이터의 헤드리스 시작 확인.

선택 결과는 `selection.json`, 마지막 게임 적용 결과는 `applied.json`이다. 사용자가 결정하기 전 후보를 임의로 승인하지 않았다. 무료 플랜 생성 음원은 후보 검토와 비상업 사용 범위로 보관하며 출시 전 사용 권리를 확인한다.
