# 마녀산장 — 카드 효과음 후보 v01

작성일: 2026-10-15. 코드 합성(외부 음원·생성 서비스 없음), 44.1kHz · 16bit · 모노 WAV 48개.

카드 경험의 11가지 상황에 후보 4개씩, 그리고 카드 종류별 획득 강조음 4종(도끼 용병·양털·목재·숲의 괴물)을 만들었다. 게임 코드는 아직 변경하지 않았다.

| 상황 | 언제 | 파일 |
| --- | --- | --- |
| 카드 들어옴 | 획득한 카드가 손패에 자리 잡을 때 | `card-draw-01~04.wav` |
| 마우스 오버 | 손패 카드에 커서가 올라갈 때 | `card-hover-01~04.wav` |
| 카드 집어 들기 | 드래그 시작 | `card-pickup-01~04.wav` |
| 대상 위에 올림 | 끄는 중 사용 가능한 대상에 들어섬 | `card-target-01~04.wav` |
| 카드 사용 확정 | 유효 대상에 놓음 | `card-play-01~04.wav` |
| 취소 · 손패로 복귀 | 빈 곳에 놓기 · 우클릭 · Esc | `card-cancel-01~04.wav` |
| 사용 불가 | 무효 대상 · 조건 부족 | `card-deny-01~04.wav` |
| 카드 소멸 | 계약 종료 · 카드 소비 | `card-consume-01~04.wav` |
| 창고 보관 | 손패 넘침 · 창고 교환 | `card-stash-01~04.wav` |
| 손패 정렬 | 손패 재배치 | `card-shuffle-01~04.wav` |
| 카드 뒤집기 · 확대 | 상세 보기 | `card-inspect-01~04.wav` |
| 종류별 획득 강조 (세트) | 들어옴 소리에 겹치는 종류별 시그니처 | `card-acquire-01~04.wav` |

- 후보 이름과 설명은 [manifest.json](manifest.json)에 있다.
- 시청 페이지 [card-sfx-audition.html](card-sfx-audition.html)은 모든 WAV와 손패 카드 이미지를 내장한다. 손패 시험대에서 카드를 끌어 쓰면 고른 소리로 전체 흐름을 들을 수 있다.
- 다시 만들기: `node create_card_sfx.mjs` (시드 고정이라 같은 결과) → `node build_page.mjs`.
- 음량은 상황별로 다르게 정규화했다(오버 -10~-15dBFS, 대상 -9~-11, 나머지 -3~-8). 게임 안 최종 음량은 연결할 때 `selected.json`의 `volume_db`로 맞춘다.
- 기존 ElevenLabs `card-play-0x.mp3`(카드 사용)과는 별개 후보다. 선택 뒤 둘 중 어느 쪽을 쓸지 정한다.
