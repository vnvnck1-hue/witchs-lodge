# 마녀산장 카드 디자인 작업 기록

작성: 2026-10-13

**확정: 마지막 라운드 2번, 비대칭 S자 곡선 포맷.**

![확정 기본 카드](curve-original-02-flowing-sides-v01.png)

## 디자인 결정

- 얼굴과 상체를 크게 보여주는 캐릭터 원화.
- 보라색 바탕, 굵은 검은 먹선, 따뜻한 크림색 이름·설명란.
- 굵게 휘고 가늘게 빠지는 곡선의 뉘앙스 유지.
- 좌상단에서 내려오는 곡선과 우하단에서 올라오는 곡선을 비대칭으로 배치.
- 최초 레퍼런스의 뿔·리본 문양을 그대로 복제하지 않고 새로운 곡선 흐름으로 변형.
- 용병·자원·몬스터에 반복해서 적용하는 기본 포맷. 캐릭터·배경·이름·분류·효과 문구를 교체해 사용.
