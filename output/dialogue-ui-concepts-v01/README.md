# 플레이 중 왼쪽 인물 말 걸기 UI — 콘셉트 3종

대상은 대화창을 열기 전의 `GuestSpeechNotification`이다. 중앙 선택형 대화창이 아니다.

2026-10-21 현재 작업 소스의 `main.tscn`을 Godot 4.7.2 Forward+ / Vulkan / RTX 3070으로 실제 실행해 1774×887 PNG를 새로 캡처했다. 재현 스크립트 `capture_notification.gd`는 손님 입실·이야기 준비 상태를 설정하고 기존 UI를 그대로 렌더링한다. 게임 구현·배포 exe는 변경하지 않았다.

- 원본: `captures/5-notification-current.png`
- 같은 실행에서 말 걸기 알림만 숨긴 실제 배경: `captures/6-notification-cleanplate.png`
- 촬영 로그: `notification-capture.log`
- 생성 도구: built-in `image_gen`
- 최종 생성 프롬프트: `notification-prompts.json`
- 인물 참고 입력: `godot/assets/portraits/guest_graz_cutout.png`

## 현재 화면의 문제

초상, 밝은 말풍선, 배경 위에 떠 있는 이름/대화 건수, 기다림 막대가 서로 다른 기준선에 놓여 있다. 이름은 눈밭에서 대비가 낮고, 기다림 막대가 인물과 어떤 관계인지 즉시 읽기 어렵다. 클릭할 수 있는 범위도 시각적으로 뚜렷하지 않다.

## 세 방향

| 안 | 구성 | 장점 | 조정할 점 |
| --- | --- | --- | --- |
| A · 가로 알림 카드 | 초상·이름·한마디·행동·시간을 하나의 어두운 프레임에 통합 | 읽는 순서와 클릭 범위가 분명하며 밝은 눈밭에서도 글이 잘 읽힘. 우선 추천 | 게임 적용 시 청록 행동 글자와 금 장식의 강도를 한 단계 낮추면 차분해짐 |
| B · 초상 메달 + 말풍선 | 원형 초상과 밝은 말풍선을 연결하고 하단에 행동/시간을 통합 | 인물이 말을 거는 느낌을 잘 살리고 기존 할 일 양피지와 어울림 | 가로 폭이 가장 넓음. 실제 적용 시 문구 길이에 상한을 두고 2줄까지 허용 |
| C · 세로 손님 패널 | 좁은 세로 프레임에 인물·이야기·행동을 쌓음 | 좌측의 알림 영역을 일정한 폭으로 관리하기 좋음 | 세로 공간을 더 차지함. 다른 알림이 쌓이는 상황을 함께 확인할 필요 |

`2`는 대기 중인 대화 건수이며 수락 횟수가 아니다. 시간 막대는 이 손님이 떠날 때까지 남은 시간을 뜻한다. 시안의 문구와 강조는 검토용이며 실제 상호작용은 구현하지 않았다.

시안은 실제 캡처를 입력으로 만든 생성 이미지다. 배경·기존 HUD에 작은 재생성 차이가 있을 수 있어 구현 검증용 스크린샷과 구분한다. 초기 중앙 대화창 캡처 1~4와 `prompts.json`은 대상 정정 이전의 참고 이력이며 최종 시안이 아니다.
