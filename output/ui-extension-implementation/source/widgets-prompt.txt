Production UI sprite atlas for the approved Witch's Lodge UI expansion. Reference images are binding: same uneven thick dark-plum ink contour, matte midnight-indigo, warm cream inner keyline/parchment, restrained turquoise curlicues, chunky hand-painted cel shading, faint dry gouache texture. Do not switch to shiny gold metal, thin vector icons, generic app gradients or a new fantasy style. TRUE TRANSPARENT ALPHA outside each isolated sprite. No solid background, no checkerboard painted into pixels, no text, no numerals, no characters or portrait illustrations. Perfect evenly spaced grid; nothing crosses cell boundaries. Each sprite centered inside its cell with at least 12% transparent gutter on all sides; each cell contains exactly ONE isolated component. Keep the entire atlas front-on 2D, no perspective. The parts will be sliced by grid into AtlasTexture resources, so grid alignment is crucial. A SQUARE 4x4 GRID on a 2048x2048 canvas, exactly sixteen isolated reusable UI surfaces in row-major order. All text areas blank. Row 4: (13) small horizontal ON TOGGLE track with turquoise fill and tiny ivory crescent thumb at right; (14) SAME OFF TOGGLE with muted indigo track and ivory crescent thumb at left; (15) small round CLOSE BUTTON with cream X, dark ink edge and indigo interior; (16) small ivory-plus utility icon with dark-plum ink edge.
